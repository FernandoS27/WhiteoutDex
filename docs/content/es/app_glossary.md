# Glosario

Palabras que encuentras en WhiteoutDex y en este manual.

| Palabra | Significado |
|---|---|
| **MDX / MDL** | Los archivos de modelo de Warcraft III. `.mdx` es binario y pequeño. `.mdl` es texto que puedes leer y editar. Los dos contienen los mismos datos. |
| **Clásico** | Warcraft III versión 1.x y los gráficos clásicos. Los modelos usan la versión 800 de MDX. |
| **Reforged** | Warcraft III: Reforged con gráficos HD. Los modelos usan las versiones 900 a 1800 de MDX. WhiteoutDex exporta la versión 1800. |
| **MPQ** | Los archivos comprimidos del juego clásico (por ejemplo `War3.mpq`). |
| **CASC** | El almacenamiento de Warcraft III: Reforged. |
| **BLP** | El formato de textura del juego clásico. |
| **DDS** | El formato de textura de Reforged. |
| **Geoset** | Una malla de un modelo. Un modelo puede tener muchos geosets. |
| **Hueso** | Un nodo que mueve vértices de una malla con skin. |
| **Ayudante** | Un nodo que mueve otros nodos, pero no lo ves en el juego. |
| **Skin** | Indica qué hueso mueve cada vértice y con qué fuerza (peso). |
| **Secuencia** | Una animación del modelo, por ejemplo *Walk*. Tiene un nombre, un fotograma inicial y un fotograma final. |
| **Secuencia global** | Una animación que se repite siempre, sin depender de la secuencia actual. Sirve para cosas que siempre se mueven, como un cristal que gira. |
| **Clave / fotograma clave** | Un valor en un momento dado. El juego pasa de una clave a otra. |
| **Controlador** | Cómo pasa el juego de una clave a otra: *None* (salto), *Linear*, *Bezier* o *Hermite* (suave). |
| **Punto de anclaje** | Un lugar del modelo donde el juego coloca cosas: armas, efectos de hechizos, el círculo de selección. |
| **Objeto de evento** | Inicia algo en un momento de una animación: un sonido, una huella, sangre, un modelo que aparece. |
| **Emisor de partículas 1** | Emite modelos pequeños. |
| **Emisor de partículas 2** | Emite partículas con textura: fuego, humo, chispas. |
| **Emisor de estelas** | Dibuja una estela detrás de un punto que se mueve. |
| **Popcorn FX** | El sistema de partículas de Reforged (archivos `.pkfx`). |
| **Forma de colisión** | Una caja o una esfera. El juego la usa para saber dónde puedes hacer clic en el modelo. |
| **Extensiones** | El tamaño del modelo en una secuencia. El juego las usa para saber cuándo el modelo está en la pantalla. |
| **Textura reemplazable** | Una textura que pone el juego, por ejemplo el color de equipo. |
| **Color de equipo / brillo de equipo** | El color del jugador en una unidad. |
| **Modo de filtro** | Cómo se dibuja un material: sólido, transparente, aditivo (brilla) y más. |
| **Billboard** | Un nodo que siempre gira hacia la cámara. |
| **Nivel de arte** | Qué gráficos muestra el previsualizador: Classic, Reforged (HD) o Definitive. |
| **WhiteoutFlakes** | El previsualizador que muestra tu modelo como el juego. |
