# Anim.: herramientas generales

Pequeñas ayudas que te ahorran tiempo cuando animas o terminas un modelo.

Ábrelas con **WhiteoutDex > [[t:menu_anim_general]]**.

[[shot:anim_general|Las herramientas generales.]]

| N.º | Qué hace |
|---|---|
| [[ctl:4]] | Añade claves en el fotograma 0 y al inicio y al final de cada secuencia, para los objetos seleccionados. Así una animación no cambia la siguiente. |
| [[ctl:6]] | Usa la herramienta TCB en las claves de posición. |
| [[ctl:7]] | … en las claves de rotación. |
| [[ctl:8]] | … en las claves de escala. |
| [[ctl:9]] | Pone *Continuity* a 0 en las claves actuales de los objetos seleccionados. Esto quita el exceso de recorrido de las claves TCB. |
| [[ctl:11]] | Las claves de rotación que giran más de 90° entre dos claves pueden verse mal en el juego. Esta herramienta añade una clave en el medio. Úsala otra vez para giros muy grandes (más de 180°). |
| [[ctl:13]] | Crea puntos de anclaje para huesos con nombres conocidos (por ejemplo *Head*, *Chest*, *Hand*). |
| [[ctl:14]] | Crea una cámara de retrato que mira al objeto seleccionado. Sin selección, mira a la parte superior del modelo. |
| [[ctl:15]] | Crea dos esferas de colisión que se ajustan al modelo, como hace Blizzard con las unidades. |
| [[ctl:16]] | Crea una caja de colisión que se ajusta al modelo, como hace Blizzard con los edificios. |

!!! tip
    Usa las **herramientas de un clic** en un modelo terminado. Miden el modelo, así que funcionan mejor cuando tiene su tamaño final.
