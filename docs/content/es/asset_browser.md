# Explorador del juego

El explorador del juego muestra los archivos de tu juego Warcraft III: modelos, texturas y efectos de partículas. Ves una imagen pequeña de cada archivo, así encuentras rápido lo que necesitas.

Se abre desde muchos lugares:

| Dónde | Botón | Eliges |
|---|---|---|
| Menú WhiteoutDex | [[t:menu_import_casc]] | un modelo para importar |
| Punto de anclaje | *Explorar los archivos del juego* | un modelo para el anclaje |
| Emisor de partículas 1 | *Explorar los archivos del juego* | un modelo para las partículas |
| Emisor de partículas 2 | *Explorar MPQ / CASC* | una textura para las partículas |
| Popcorn FX | *Explorar los archivos del juego* | un efecto `.pkb` o `.pkfx` |
| Wc3Bitmap | *Abrir el Explorador de texturas* | una textura |
| Wc3Material | el botón ⚙ junto a un mapa | una textura para esta ranura |

## Cómo usarlo

1. Escribe una parte del nombre en el campo de búsqueda, por ejemplo `footman`.
2. Cambia entre la **cuadrícula** (imágenes) y el **árbol** (carpetas).
3. Haz las imágenes más grandes o más pequeñas con el zoom.
4. Haz clic en un archivo. La línea de abajo muestra el archivo seleccionado.
5. Haz clic en **Seleccionar**.

!!! note
    El explorador necesita las carpetas de tu juego. Defínelas en [[t:menu_settings]]. Los modelos clásicos vienen de los archivos MPQ, los archivos de Reforged de CASC.
