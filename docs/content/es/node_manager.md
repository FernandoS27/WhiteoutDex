# Gestor de nodos

Un modelo tiene muchos tipos de objetos: mallas, huesos, ayudantes, emisores y más. El Gestor de nodos muestra, oculta o congela a la vez todos los objetos de un tipo.

Ábrelo con **WhiteoutDex > [[t:menu_node_manager]]**.

[[shot:node_manager|El Gestor de nodos.]]

## 2. Haz algo con ellos

| N.º | Qué hace |
|---|---|
| [[ctl:20]] | Muestra los objetos. |
| [[ctl:21]] | Oculta los objetos. |
| [[ctl:22]] | Congela los objetos, así no los seleccionas por error. |
| [[ctl:23]] | Descongela los objetos. |
| [[ctl:24]] | Muestra los objetos transparentes. |
| [[ctl:25]] | Muestra los objetos sólidos otra vez. |

!!! tip
    Oculta todos los ayudantes, huesos y emisores mientras trabajas en la malla. Congela los huesos mientras pintas los pesos de skin.
