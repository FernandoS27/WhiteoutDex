# Cambiador de skin

Prepara el skin de tus mallas para Warcraft III.

Ábrelo con **WhiteoutDex > [[t:menu_skin_changer]]**. Antes, selecciona las mallas con skin.

[[shot:skin_changer|El Cambiador de skin.]]

| N.º | Qué hace |
|---|---|
| [[ctl:3]] | Cambia el skin para que cada vértice tenga como máximo 5 huesos con pesos limpios. Puedes deshacerlo. |
| [[ctl:7]] | Se quitan los pesos iguales o menores que este valor. 0.0 quita solo los pesos que son exactamente cero. |
| [[ctl:8]] | Quita los pesos pequeños y reparte su parte entre los otros huesos del vértice. |
| [[ctl:11]] | Une las mallas con skin seleccionadas que usan el mismo material en una malla con un solo Skin. Los huesos, los pesos y la pose no cambian, así la malla se mueve exactamente como antes. Puedes deshacerlo. |

!!! tip
    Menos mallas hacen un modelo más rápido. Usa *Combinar malla + Skin* cuando un modelo tiene muchas partes pequeñas con la misma textura.
