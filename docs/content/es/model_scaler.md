# Anim.: escalador de modelos

Escala todo el modelo, con sus huesos, sus animaciones y sus objetos especiales. Úsalo cuando un modelo es demasiado grande o demasiado pequeño para el juego.

Ábrelo con **WhiteoutDex > [[t:menu_anim_scaler]]**.

[[shot:model_scaler|El Escalador de modelos.]]

| N.º | Qué hace |
|---|---|
| [[ctl:4]] | Una altura objetivo del juego, por ejemplo *Footman* o *Townhall* (clásico o Reforged). |
| [[ctl:6]] | Escala el modelo a la altura elegida. |
| [[ctl:10]] | Tu propio factor. 2 hace el modelo el doble de grande, 0.5 la mitad. |
| [[ctl:11]] | Escala el modelo con tu factor. |

!!! warning
    Los modelos con un rig **Biped** o **CAT** y un modificador Skin no se escalan bien de esta forma. WhiteoutDex te avisa. Escala el rig con sus propias herramientas.

!!! tip
    Guarda tu escena antes de escalar. Así puedes volver atrás si el resultado no es correcto.
