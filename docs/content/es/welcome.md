# Bienvenido a WhiteoutDex

WhiteoutDex es un conjunto de herramientas para **3ds Max**. Con él puedes crear, cambiar y probar modelos para **Warcraft III**. Funciona con el juego clásico (Warcraft III, versión 1.x) y con **Warcraft III: Reforged**.

![WhiteoutDex en 3ds Max 2027. A la izquierda, el previsualizador WhiteoutFlakes. A la derecha, el Gestor de nodos y el modelo en el visor.](media_1.png)

## Qué puedes hacer

- **Importar** un modelo de Warcraft III (`.mdx` o `.mdl`) en 3ds Max. WhiteoutDex también carga las texturas desde tu juego.
- **Editar** el modelo como cualquier otro objeto de 3ds Max: cambia la malla, los huesos, las animaciones y los materiales.
- **Previsualizar** el modelo en **WhiteoutFlakes**. Esta ventana muestra el modelo igual que lo muestra el juego.
- **Exportar** el modelo de nuevo a `.mdx` o `.mdl`, para el juego clásico o para Reforged. WhiteoutDex convierte las texturas por ti.
- Usar **objetos especiales** que solo tiene Warcraft III: emisores de partículas, estelas, puntos de anclaje, objetos de evento, formas de colisión y más.

## Qué necesitas

| | |
|---|---|
| Windows | Windows 10 o posterior |
| 3ds Max | Cualquier versión de 2016 a 2027 |
| Warcraft III | Opcional, pero recomendado: WhiteoutDex toma texturas y modelos de la carpeta de tu juego. |

## Cómo leer este manual

El manual tiene cuatro tipos de páginas:

- **Para empezar** te ayuda a instalar y configurar WhiteoutDex.
- **Tutoriales** son lecciones cortas. Hazlas en orden si eres nuevo.
- **Páginas de herramientas y objetos** explican una ventana o un objeto. Cada imagen tiene números. La tabla bajo la imagen te dice qué hace cada número.
- **Apéndice** son listas para consultar.

Las palabras en un **cuadro azul**, como [[t:menu_importer]], son las palabras que ves en 3ds Max. Las teclas se ven así: [[key:Ctrl+Z]].

!!! tip
    El manual está en el mismo idioma que WhiteoutDex. Puedes cambiar el idioma de WhiteoutDex en [[t:menu_settings]]. Consulta *Ajustes*.
