# Anim.: controladores

Warcraft III conoce cuatro formas de pasar de una clave a otra: *None* (salto), *Linear*, *Bezier* y *Hermite* (TCB). Esta herramienta da a los objetos seleccionados los controladores que eliges. Lo hace para posición, rotación y escala a la vez.

Ábrela con **WhiteoutDex > [[t:menu_anim_controllers]]**.

[[shot:anim_controllers|La herramienta Controladores.]]

| N.º | Qué hace |
|---|---|
| [[ctl:4]] | La posición se mueve en línea recta entre las claves. |
| [[ctl:5]] | La posición se mueve en curvas suaves. |
| [[ctl:6]] | La posición usa claves TCB (suaves, con tensión, continuidad y sesgo). |
| [[ctl:7]] | Deja el controlador de posición como está. |
| [[ctl:10]] | La rotación gira de forma uniforme entre las claves. |
| [[ctl:11]] | La rotación gira de forma suave. |
| [[ctl:12]] | La rotación usa claves TCB. |
| [[ctl:13]] | Deja el controlador de rotación como está. |
| [[ctl:16]] | La escala cambia de forma uniforme. |
| [[ctl:17]] | La escala cambia en curvas suaves. |
| [[ctl:18]] | La escala usa claves TCB. |
| [[ctl:19]] | Deja el controlador de escala como está. |
| [[ctl:22]] | Da estos controladores a los objetos seleccionados. |

!!! note
    El exportador también reemplaza los controladores que el juego no puede leer (consulta *Problemas de la escena y Corregir todo*). Con esta herramienta eliges tú el tipo.
