# 라이트

Warcraft III 라이트는 모델과 그 주변의 바닥을 비춥니다. 예: 횃불이나 마법 수정의 빛.

**Create > Helpers > Warcraft III Plugins > Wc3 Light**로 만듭니다.

## 일반 기능

[[shot:obj_light_r1|일반 기능.]]

| 번호 | 기능 |
|---|---|
| [[ctl:3]] | 이것을 클릭한 뒤 오브젝트를 클릭합니다. 라이트가 그 오브젝트로 이동하고 링크됩니다. |

## 기본 파라미터

[[shot:obj_light_r3|기본 파라미터.]]

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | *전방향*은 한 점에서 모든 방향으로 비춥니다. *지향성*은 태양처럼 한 방향으로 비춥니다. *앰비언트*는 모든 것을 고르게 밝힙니다. |
| [[ctl:9]] | 빛이 약해지기 시작하는 거리입니다. |
| [[ctl:16]] | 빛이 끝나는 거리입니다. |
| [[ctl:21]] | 빛의 색상입니다. |
| [[ctl:29]] | 빛의 강도입니다. |
| [[ctl:35]] | 앰비언트 부분의 색상입니다. |
| [[ctl:43]] | 앰비언트 부분의 강도입니다. |
| [[ctl:11]] | **컨트롤:** 애니메이션된 값이 키 사이에서 바뀌는 방식입니다. 값마다 자기 컨트롤이 있습니다. |

## Reforged 매개변수

[[shot:obj_light_r2|Reforged 매개변수.]]

이 값은 Reforged 모델에서만 사용됩니다.

| 번호 | 기능 |
|---|---|
| [[ctl:6]] | 그림자 강도입니다. 씬의 주 라이트에서는 이미지 기반 조명의 크기도 조절합니다. |
| [[ctl:8]] | 라이트가 그림자를 드리웁니다. |
| [[ctl:12]] | 그림자가 시작되는 거리입니다. |
| [[ctl:16]] | 그림자가 끝나는 거리입니다. |
| [[ctl:21]] | 빛이 약해지는 빠르기입니다. 2차 부분 … |
| [[ctl:25]] | … 1차 부분 … |
| [[ctl:29]] | … 그리고 댐핑. |
