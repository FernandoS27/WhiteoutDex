# 파티클 이미터 2

파티클 이미터 2는 Warcraft III 이펙트의 대부분을 만듭니다. 불, 연기, 불꽃, 먼지, 마법 등입니다. 작고 평평한 그림(파티클)을 많이 내보냅니다. 각 파티클은 짧은 시간 동안 살면서 색상, 크기, 투명도가 바뀝니다.

**Create > Geometry > Particle Systems > Wc3Particles2**로 만듭니다. WhiteoutDex는 뷰포트에서 파티클을 바로 보여 줍니다.

아래 그림은 예제 모델 *HeroPaladin*의 이미터입니다.

!!! tip
    불과 마법에는 *Additive*, 작은 원뿔 각도, 짧은 수명을 사용하세요. 알파를 0에서 255로, 다시 0으로 바꾸세요. 그러면 파티클이 부드럽게 나타났다가 사라집니다.
