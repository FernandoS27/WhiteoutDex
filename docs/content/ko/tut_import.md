# 튜토리얼: 모델 가져오기

이 강좌에서는 Warcraft III 모델을 3ds Max로 불러옵니다. 그리고 WhiteoutDex가 모델을 어떻게 만드는지 살펴봅니다.

**필요한 것:** 모델 파일. WhiteoutDex 소스 코드의 `samples` 폴더에 예제가 있습니다. 예: `HeroPaladin.mdx`. 인터넷이나 직접 만든 맵의 `.mdx` 또는 `.mdl`도 사용할 수 있습니다.

## 1단계: 가져오기 시작

1. **WhiteoutDex > [[t:menu_importer]]** 메뉴를 선택합니다.
2. `HeroPaladin.mdx` 파일을 고르고 **Open**을 클릭합니다.

가져오기 창이 열립니다.

![가져오기 창. 모델에 무엇이 들어 있는지 보여 줍니다.](importer.png)

## 2단계: 옵션 선택

1. *빠른 설정*에서 **전체**를 고릅니다.
2. *모드*에서 **새 씬**을 고릅니다.
3. **가져오기**를 클릭합니다.

몇 초 뒤에 모델이 씬에 들어옵니다.

![가져온 팔라딘. 부착점(노란색)과 이벤트 오브젝트(초록색)가 보입니다.](tut_model_helpers.png)

## 3단계: 둘러보기

이제 씬에는 다음이 있습니다.

- 모델의 **메시**. *Wc3Material*과 텍스처가 적용되어 있습니다.
- 메시를 움직이는 **본**.
- 이름이 노란색인 **부착점**. 예: *Hand Right Ref*.
- 이름이 초록색인 **이벤트 오브젝트**. 예: 발자국 *FPT…*, 소리 *SND…*.
- 모델에 있다면 **충돌 형태**, **파티클 이미터**, **리본**.

## 4단계: 애니메이션 재생

1. **WhiteoutDex > [[t:menu_sequence_manager]]** 메뉴를 엽니다.
2. 시퀀스를 더블클릭합니다. 예: *Walk*.

3ds Max가 걷기 애니메이션을 재생합니다.

!!! tip
    화면에 헬퍼가 너무 많나요? [[t:menu_node_manager]]를 열고 *헬퍼 / 더미*, *부착점*, *이벤트 오브젝트*를 체크한 뒤 **숨기기**를 클릭하세요.
