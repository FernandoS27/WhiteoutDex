# 표시 키어

Warcraft III에서는 **표시 키**로 모델의 일부를 보이거나 숨깁니다. 예: 공격 애니메이션에서만 나타나는 무기, 유닛이 주문을 거는 동안만 나타나는 빛. 표시 키어가 이 키를 대신 설정합니다.

**WhiteoutDex > [[t:menu_visibility_keyer]]** 메뉴로 엽니다. 먼저 오브젝트를 선택하세요.

[[shot:visibility_keyer|표시 키어.]]

| 번호 | 기능 |
|---|---|
| [[ctl:3]] | 현재 프레임에서 선택한 오브젝트를 보이거나 숨깁니다. |
| [[ctl:5]] | 선택한 모든 오브젝트에 비저빌리티 컨트롤러를 추가합니다. |
| [[ctl:6]] | 선택한 오브젝트에서 비저빌리티 컨트롤러를 제거합니다. |
| [[ctl:7]] | 선택한 오브젝트의 표시 키를 복사합니다. |
| [[ctl:8]] | 선택한 오브젝트에 붙여 넣습니다. |
| [[ctl:9]] | 키 사이에서 게임이 바꾸는 방식입니다. *None*은 바로 바뀌고, 다른 유형은 서서히 바뀝니다. |
| [[ctl:11]] | 기존 컨트롤러에 고른 유형을 적용합니다. |
| [[ctl:13]] | 현재 프레임에 *표시* 키를 설정합니다. |
| [[ctl:14]] | 현재 프레임에 *숨김* 키를 설정합니다. |
| [[ctl:16]] | 전체 애니메이션 범위에서 오브젝트를 보이게 합니다. |
| [[ctl:17]] | 전체 애니메이션 범위에서 오브젝트를 숨깁니다. |
| [[ctl:19]] | *시퀀스 관리자*에서 선택한 시퀀스에서 오브젝트를 보이게 합니다. |
| [[ctl:20]] | 선택한 시퀀스에서 오브젝트를 숨깁니다. |

## 예: 공격할 때만 보이는 무기

1. 무기를 선택합니다.
2. [[ctl:17]] 버튼을 클릭해 모든 곳에서 숨깁니다.
3. *시퀀스 관리자*에서 *Attack* 시퀀스를 선택합니다.
4. [[ctl:19]] 버튼을 클릭합니다.

!!! tip
    대부분의 표시 키에는 보간 유형 *None*을 사용하세요. 다른 유형을 쓰면 게임이 오브젝트를 서서히 나타내거나 사라지게 합니다. 대부분의 부분에서는 이것이 이상해 보입니다.
