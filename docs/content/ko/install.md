# 설치

설치 프로그램 하나로 컴퓨터의 모든 3ds Max 버전(2016~2027)에 WhiteoutDex를 설치합니다.

## 설치하기

1. 3ds Max를 닫습니다.
2. 최신 `WhiteoutDex_Setup_v<version>.exe`를 다운로드합니다. GitHub의 **Releases** 페이지와 Hive Workshop에 있습니다.
3. 설치 프로그램을 실행합니다. Windows가 관리자 권한을 요청합니다. **예**를 클릭하세요.
4. 언어를 고르고 단계를 따라 진행합니다. 설치 프로그램이 모든 3ds Max 버전을 스스로 찾습니다.
5. 3ds Max를 시작합니다. 이제 **WhiteoutDex** 메뉴와 WhiteoutDex 사이드바가 보입니다.

!!! note
    3ds Max 2026 이상은 **.NET 8**이 필요합니다. 없으면 설치 프로그램이 알려 줍니다.

## 파일이 설치되는 위치

WhiteoutDex는 폴더 하나에 설치됩니다.

`C:\ProgramData\Autodesk\ApplicationPlugins\WhiteoutDex`

3ds Max는 이 폴더에서 모든 것을 불러옵니다. 파일을 직접 복사할 필요가 없습니다.

개인 설정(언어, 게임 폴더, 마지막 내보내기 옵션)은 3ds Max 설정 폴더 `plugcfg`에 있습니다. WhiteoutDex를 업데이트해도 그대로 남습니다.

## 업데이트

WhiteoutDex는 3ds Max가 시작될 때 새 버전을 확인할 수 있습니다(3ds Max 2018 이상). 새 버전이 나오면 다음과 같이 묻습니다.

- **예**를 클릭하면 다운로드하고 설치합니다. 업데이트를 위해 3ds Max가 닫힙니다.
- **아니요**를 클릭하면 작업을 계속합니다. 다음 날 다시 묻습니다.

이 기능은 [[t:menu_settings]]에서 끄거나, 바로 확인할 수 있습니다.

## 제거

**Windows 설정 > 앱**을 열고 **WhiteoutDex**를 찾아 **제거**를 클릭합니다.
