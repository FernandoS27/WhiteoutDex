# 애니메이션: 일반 도구

모델을 애니메이션하거나 마무리할 때 시간을 줄여 주는 작은 도구입니다.

**WhiteoutDex > [[t:menu_anim_general]]** 메뉴로 엽니다.

[[shot:anim_general|일반 도구.]]

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 선택한 오브젝트에 키를 추가합니다. 프레임 0과 모든 시퀀스의 시작과 끝에 추가합니다. 그러면 한 애니메이션이 다음 애니메이션을 바꾸지 않습니다. |
| [[ctl:6]] | 위치 키에 TCB 도구를 사용합니다. |
| [[ctl:7]] | … 회전 키에 사용합니다. |
| [[ctl:8]] | … 스케일 키에 사용합니다. |
| [[ctl:9]] | 선택한 오브젝트의 현재 키에서 *Continuity*를 0으로 설정합니다. TCB 키의 오버슈트가 없어집니다. |
| [[ctl:11]] | 두 키 사이에서 90°보다 많이 도는 회전 키는 게임에서 잘못 보일 수 있습니다. 이 도구는 가운데에 키를 추가합니다. 아주 크게 도는 경우(180° 이상)에는 다시 실행하세요. |
| [[ctl:13]] | 알려진 이름(예: *Head*, *Chest*, *Hand*)의 본에 부착점을 만듭니다. |
| [[ctl:14]] | 선택한 오브젝트를 바라보는 초상화 카메라를 만듭니다. 아무것도 선택하지 않으면 모델의 위쪽을 바라봅니다. |
| [[ctl:15]] | 모델에 맞는 충돌 구체 두 개를 만듭니다. Blizzard가 유닛에 하는 방식입니다. |
| [[ctl:16]] | 모델에 맞는 충돌 박스 하나를 만듭니다. Blizzard가 건물에 하는 방식입니다. |

!!! tip
    **원클릭** 도구는 완성된 모델에 사용하세요. 이 도구는 모델을 측정합니다. 그래서 모델이 최종 크기일 때 가장 잘 작동합니다.
