# 스킨 체인저

메시의 스킨을 Warcraft III에 맞게 준비합니다.

**WhiteoutDex > [[t:menu_skin_changer]]** 메뉴로 엽니다. 먼저 스킨이 적용된 메시를 선택하세요.

[[shot:skin_changer|스킨 체인저.]]

| 번호 | 기능 |
|---|---|
| [[ctl:3]] | 모든 정점이 최대 5개의 본과 깔끔한 웨이트를 갖도록 스킨을 바꿉니다. 실행 취소할 수 있습니다. |
| [[ctl:7]] | 이 값 이하의 웨이트를 제거합니다. 0.0은 정확히 0인 웨이트만 제거합니다. |
| [[ctl:8]] | 작은 웨이트를 제거하고, 그 몫을 정점의 다른 본에 나눠 줍니다. |
| [[ctl:11]] | 선택한 스킨 메시 중 같은 머티리얼을 쓰는 것을 메시 하나로 합칩니다. 합친 메시에는 Skin이 하나 있습니다. 본, 웨이트, 포즈는 그대로입니다. 그래서 메시가 전과 똑같이 움직입니다. 실행 취소할 수 있습니다. |

!!! tip
    메시가 적을수록 모델이 빨라집니다. 같은 텍스처를 쓰는 작은 부분이 많은 모델에는 *메시 + 스킨 결합*을 사용하세요.
