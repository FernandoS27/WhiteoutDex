# 셀 셰이드 생성기

메시에 만화 같은 외곽선을 줍니다. 이 도구는 메시를 둘러싸는 약간 더 큰 복사본을 만들고, 면을 뒤집습니다. 그러면 게임에서 모델 둘레에 어두운 선이 보입니다.

**WhiteoutDex > [[t:menu_cell_shade]]** 메뉴로 엽니다. 먼저 메시를 선택하세요.

[[shot:cell_shade|셀 셰이드 생성기.]]

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 외곽선의 색상입니다. 클릭하면 다른 색을 고를 수 있습니다. |
| [[ctl:6]] | 빠른 색상입니다. 하나를 클릭하면 그 색을 사용합니다. |
| [[ctl:19]] | 외곽선의 두께입니다. |
| [[ctl:21]] | 복사본의 면을 뒤집습니다. 이렇게 해야 외곽선이 생깁니다(일반적인 선택). |
| [[ctl:22]] | 면을 그대로 둡니다. |
| [[ctl:25]] | 외곽선이 불투명합니다. |
| [[ctl:26]] | 외곽선이 텍스처의 투명도를 사용합니다. |
| [[ctl:27]] | 외곽선이 빛납니다(빛을 더함). |
| [[ctl:28]] | 외곽선이 빛나고 텍스처의 투명도를 사용합니다. |
| [[ctl:30]] | 선택한 메시에 외곽선을 만듭니다. |

!!! tip
    외곽선은 *Wc3Material*을 가진 일반 메시입니다. 나중에 다른 메시처럼 색상이나 두께를 바꿀 수 있습니다.
