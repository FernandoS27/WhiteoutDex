# 부착점

부착점은 모델의 한 위치를 표시합니다. 게임은 그곳에 무언가를 붙입니다. 예: 영웅의 무기, 손에 거는 주문 이펙트, 가슴에 맞는 화살, 머리 위의 체력 막대.

**Create > Helpers > Warcraft III Plugins > Wc3 AttachPoint**로 만듭니다. 따라가야 할 본에 링크하세요.

뷰포트에서 각 부착점은 이름을 노란색으로 표시합니다.

## 일반 기능

[[shot:obj_attachpoint_r1|일반 기능.]]

| 번호 | 기능 |
|---|---|
| [[ctl:3]] | 이것을 클릭한 뒤 뷰포트에서 오브젝트를 클릭합니다. 부착점이 그 오브젝트로 이동하고 링크됩니다. |

## 모델 맵 매개변수

[[shot:obj_attachpoint_r2|모델 맵 매개변수.]]

부착점은 자기 모델을 가질 수 있습니다. 예: 유닛이 항상 들고 있는 칼.

| 번호 | 기능 |
|---|---|
| [[ctl:9]] | 디스크에서 모델 파일을 고릅니다. |
| [[ctl:10]] | 게임 아카이브에서 모델을 고릅니다. |

버튼 위의 두 필드에는 폴더와 파일 이름이 들어 있습니다. 경로는 Warcraft III 폴더를 기준으로 한 상대 경로입니다. 예: `Textures\Model.mdx`.

## 어태치먼트 파라미터

[[shot:obj_attachpoint_r3|어태치먼트 파라미터.]]

게임은 부착점을 **이름**으로 찾습니다. 이름은 네 부분으로 만듭니다.

| 번호 | 기능 |
|---|---|
| [[ctl:5]] | **유형:** 주요 위치입니다. *Head*, *Overhead*, *Origin*, *Foot*, *Chest*, *Hand*, *Weapon* 또는 *Sprite*. |
| [[ctl:8]] | **탈것:** 탈것에 탄 기수용입니다. |
| [[ctl:11]] | **좌우:** *Left* 또는 *Right*. 손과 발에 씁니다. |
| [[ctl:14]] | **추가:** 추가 단어입니다. 예: *Rear*, *Alternate*, *RallyPoint*, *Gold*, 건물에는 *First* … *Sixth*. |
| [[ctl:22]] | *모델 맵 매개변수*의 모델을 사용합니다. |
| [[ctl:26]] | 표시 여부(0~1)입니다. 애니메이션하면 부착된 모델을 보이거나 숨깁니다. |
| [[ctl:27]] | 모델 경로가 무엇을 기준으로 하는지 보여 줍니다. |
| [[ctl:34]] | 부착점의 번호입니다. |
| [[ctl:36]] | 이 번호를 모델에 씁니다. |

예: 유형 *Hand*, 좌우 *Right*를 고르면 이름은 `Hand Right Ref`가 됩니다. 게임은 오른손용 주문 이펙트를 그곳에 놓습니다.

!!! tip
    *애니메이션: 일반 도구*의 *원클릭 부착 지점* 도구는 본 이름이 알려진 이름이면 일반적인 부착점을 대신 만들어 줍니다.
