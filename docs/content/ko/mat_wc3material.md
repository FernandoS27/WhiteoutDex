# Wc3Material

내보내는 모든 메시에는 **Wc3Material**이 필요합니다. Wc3Material은 텍스처를 담고, 게임에 텍스처를 그리는 방식을 알려 줍니다. 임포터는 Wc3Material을 대신 만듭니다. 직접 만든 메시라면 Material Editor에서 만들거나, *머티리얼 수정*으로 머티리얼을 변환하세요.

그림은 Compact Material Editor에 열린 예제 모델의 머티리얼입니다.

## 머티리얼 기본 매개변수

[[shot:mat_wc3material_r1|머티리얼 기본 매개변수.]]

| 번호 | 기능 |
|---|---|
| [[ctl:3]] | **셰이더.** 클래식 모델은 *SD*, Reforged는 *HD*, Reforged 모델 속 클래식 텍스처는 *SD on HD*, Reforged의 수정 셰이더는 *Crystal*입니다. |
| [[ctl:5]] | **필터 모드** – 머티리얼을 그리는 방식입니다(아래 표 참고). |
| [[ctl:8]] | 면의 양쪽을 모두 그립니다. |
| [[ctl:9]] | 조명을 무시합니다. 빛나는 부분에 좋습니다. |
| [[ctl:10]] | 안개를 무시합니다. |
| [[ctl:11]] | 메시 전체에 한 가지 색을 씁니다. |
| [[ctl:12]] | 머티리얼의 *Full Resolution* 플래그를 설정합니다. |
| [[ctl:13]] | 다른 것 위에 그립니다. |
| [[ctl:14]] | 뒤에 있는 것을 가리지 않습니다. |
| [[ctl:15]] | 플레이어가 이 부분을 클릭할 수 없습니다. |
| [[ctl:16]] | 앰비언트 오클루전을 사용합니다(Reforged). |
| [[ctl:17]] | 뒷면이 그림자를 드리웁니다(Reforged). |
| [[ctl:18]] | 조명을 전혀 받지 않습니다(Reforged). |
| [[ctl:20]] | 투명 레이어를 그리는 순서입니다. 가까운 것부터 먼 것, 또는 먼 것부터 가까운 것. |
| [[ctl:24]] | 머티리얼 사이에서 그리는 순서입니다(−20~20). 높을수록 나중에 그립니다. |
| [[ctl:26]] | 게임이 채워 넣는 텍스처를 사용합니다. 팀 색상, 팀 글로우, 절벽, 또는 나무 텍스처 중 하나입니다. |

| 필터 모드 | 보이는 모습 | 용도 |
|---|---|---|
| 없음 | 불투명. | 일반 부분. |
| 투명 | 알파가 낮은 곳에 구멍, 딱딱한 가장자리. | 나뭇잎, 머리카락, 울타리. |
| 블렌드 | 부드러운 투명. | 유리, 부드러운 가장자리, 그림자. |
| 가산 | 빛을 더해 빛납니다. 검은색은 보이지 않습니다. | 불, 마법, 광선. |
| 가산 알파 | 빛을 더하고 알파를 사용합니다. | 모양이 있는 빛. |
| 변조 | 뒤에 있는 것을 어둡게 합니다. | 어두운 자국, 그림자. |
| 변조 2x | 어둡게 하거나 밝게 합니다. | 특수 효과. |

## 레이어 애니메이션

[[shot:mat_wc3material_r2|레이어 애니메이션.]]

| 번호 | 기능 |
|---|---|
| [[ctl:6]] | 레이어의 불투명도(0~1)입니다. 애니메이션하면 머티리얼이 서서히 나타나고 사라집니다. |
| [[ctl:7]] | 키 사이에서 불투명도가 바뀌는 방식입니다. |
| [[ctl:9]] | 불투명도 애니메이션을 모델에 씁니다. |
| [[ctl:11]] | 플립북처럼 시간에 따라 텍스처가 단계별로 바뀝니다. |
| [[ctl:14]] | 텍스처가 사용하는 UV 채널입니다. |
| [[ctl:15]] | 텍스처 변경 애니메이션을 모델에 씁니다. |

움직이는 텍스처(UV 애니메이션)는 여기가 아니라 *Wc3Bitmap*에서 설정합니다.

## 머티리얼 텍스처 맵

[[shot:mat_wc3material_r3|머티리얼 텍스처 맵.]]

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | **디퓨즈:** 색상 텍스처입니다. 클래식 모델은 이것만 사용합니다. |
| [[ctl:5]] | 이 슬롯의 텍스처 브라우저(게임의 텍스처)를 엽니다. |
| [[ctl:10]] | **노멀:** 표면의 세부 모양입니다(Reforged). |
| [[ctl:16]] | **ORM:** 오클루전, 러프니스, 메탈릭을 한 텍스처에 담습니다(Reforged). |
| [[ctl:22]] | **이미시브:** 스스로 빛나는 부분입니다(Reforged). |
| [[ctl:28]] | **팀 색상:** 팀 색상용 마스크입니다(Reforged, 선택 사항). |
| [[ctl:34]] | **환경:** 반사 텍스처입니다(Reforged). |

각 슬롯에는 **경로 접두사**가 있습니다. 익스포터가 파일 이름 앞에 쓰는 폴더입니다. 예: `Textures\`.
