# 게임에서 가져오기

디스크에 파일이 없어도 Warcraft III 게임에서 모델을 바로 가져올 수 있습니다.

1. **WhiteoutDex > [[t:menu_import_casc]]** 메뉴를 선택합니다.
2. 게임 브라우저가 열립니다. 모델을 찾습니다. 예: `footman`으로 검색.
3. 모델을 클릭한 뒤 **선택**을 클릭합니다.
4. 일반 가져오기 창이 열립니다(*임포터* 참고). 옵션을 고르고 **가져오기**를 클릭합니다.

WhiteoutDex는 모델과 텍스처를 임시 폴더에 복사하고 그곳에서 가져옵니다. 게임 파일은 바뀌지 않습니다.

!!! tip
    게임의 모델을 바꾸려면 이 방법으로 가져와서 수정하세요. 그런 다음 새 이름으로 맵 폴더나 모드 폴더에 내보내세요.

!!! note
    게임의 모델은 Blizzard Entertainment의 소유입니다. Blizzard가 허용하는 범위에서만 사용하세요. 예: Warcraft III용 맵과 모드.
