# 문제와 해결

## WhiteoutDex 메뉴가 없습니다

- 3ds Max 버전이 2016과 2027 사이인지 확인하세요.
- 3ds Max를 닫은 상태에서 WhiteoutDex를 다시 설치하세요.
- 3ds Max 2026 이상은 **.NET 8**이 필요합니다. Microsoft에서 설치하고 3ds Max를 다시 시작하세요.

## 모델에 텍스처가 없습니다(흰색 또는 분홍색)

- [[t:menu_settings]]을 열고 게임 폴더를 확인하세요. 상태 줄에 아카이브를 찾았다고 표시되어야 합니다.
- 클래식 모델은 MPQ 아카이브에서, Reforged 모델은 CASC에서 찾습니다. 모델이 나온 게임의 폴더를 지정하세요.
- 커스텀 모델의 텍스처는 모델 파일 옆에 있거나, 모델이 사용하는 경로의 하위 폴더에 있어야 합니다(예: `Textures\`).

## 게임에서 모델이 뒤집혀 보입니다

삼각형이 잘못된 방향을 향하고 있습니다. 익스포터는 자기 노멀과 반대 방향을 향하는 메시를 뒤집습니다. 그래도 어떤 부분이 이상해 보이면 그 부분을 선택하고, 3ds Max에서 노멀에 **Flip**을 사용하세요.

## 모델이 보이지 않거나 화면 가장자리에서 깜박입니다

**익스텐트**(각 애니메이션의 크기)가 너무 작습니다. 익스포터는 모든 프레임에서 익스텐트를 측정합니다. 가져온 뒤에 모델을 옮겼다면 다시 내보내세요. 익스포터는 모델을 담지 못하는 익스텐트를 바꿉니다.

## 모델의 일부가 본을 따라 움직이지 않습니다

- 메시에 본이 들어 있는 **Skin** 모디파이어가 필요합니다.
- 가져오기 창에서 *스킨 적용* 옵션이 켜져 있어야 합니다.
- 클래식 모델은 내보내기 창에서 *스킨 웨이트 양자화*를 켜세요.

## 내보내기에서 경고가 표시됩니다

내보내기 보고서는 확인이 필요한 것을 보여 줍니다. 줄마다 오브젝트 이름이 있습니다. 전체 목록은 `mdlx_export_debug.log`에 있습니다(*파일과 설정* 참고).

## 3ds Max에 "Startup Failure Detection"이 표시됩니다

지난번에 3ds Max가 제대로 닫히지 않았습니다. **Continue Without Restore**를 클릭하세요. 3ds Max 전체를 초기화하려는 경우가 아니면 *Restore Factory Settings*를 고르지 마세요.
