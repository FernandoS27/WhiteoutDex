# 시퀀스 관리자

Warcraft III 모델은 모든 애니메이션을 타임라인 하나에 둡니다. 애니메이션 하나하나가 **시퀀스**입니다. 시퀀스는 이름, 시작 프레임, 끝 프레임으로 이루어집니다. 시퀀스 관리자는 이 시퀀스를 만들고 바꿉니다.

**WhiteoutDex > [[t:menu_sequence_manager]]** 메뉴 또는 사이드바의 **Sequence** 버튼으로 엽니다.

[[shot:sequence_manager_selected|시퀀스 "Stand - 1"이 선택된 시퀀스 관리자.]]

## 목록

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 단어를 입력하면 이름에 그 단어가 있는 시퀀스만 보입니다. |
| [[ctl:6]] | 검색 필드를 비우고 모든 시퀀스를 다시 보여 줍니다. |
| [[ctl:7]] | 모델의 모든 시퀀스입니다. 클릭하면 하나를 선택합니다. [[key:Ctrl]]을 누른 채 클릭하면 여러 개를 선택합니다. 시퀀스를 **더블클릭**하면 뷰포트에서 재생합니다. `[GLOBAL 1]` 같은 줄은 글로벌 시퀀스입니다. |
| [[ctl:10]] | 모든 시퀀스를 선택합니다. |
| [[ctl:11]] | 선택을 모두 해제합니다. |
| [[ctl:12]] | 선택되지 않은 것을 선택하고, 선택된 것은 해제합니다. |

## 만들기와 삭제

| 번호 | 기능 |
|---|---|

| [[ctl:15]] | 선택한 시퀀스를 삭제합니다. 애니메이션 키는 타임라인에 남습니다. |
| [[ctl:16]] | 선택한 시퀀스를 복사합니다. |

## 선택한 시퀀스 바꾸기

| 번호 | 기능 |
|---|---|
| [[ctl:20]] | 이름입니다. 이름은 게임에 언제 애니메이션을 재생할지 알려 줍니다. *애니메이션 이름*을 참고하세요. |
| [[ctl:23]] | 타임 슬라이더의 현재 프레임을 시작 프레임으로 사용합니다. |
| [[ctl:26]] | 시퀀스의 첫 프레임입니다. |
| [[ctl:28]] | 현재 프레임을 끝 프레임으로 사용합니다. |
| [[ctl:31]] | 시퀀스의 마지막 프레임입니다. |
| [[ctl:32]] | **희귀도**(0–40). 이름이 같은 애니메이션 중에서 값이 높을수록 게임이 이 애니메이션을 덜 자주 재생합니다. |
| [[ctl:36]] | **이동 속도**(0–700). 이 걷기 애니메이션을 재생할 때 유닛이 움직이는 빠르기입니다. 대부분의 유닛은 250~400입니다. |
| [[ctl:40]] | 애니메이션을 한 번만 재생하고 반복하지 않습니다. *Death*, *Attack*, *Spell*에 사용하세요. |
| [[ctl:41]] | 익스포터가 이 시퀀스를 빼놓습니다. |
| [[ctl:44]] | 시작 프레임을 한 프레임 앞으로 옮깁니다. [[ctl:45]] 버튼은 한 프레임 뒤로 옮깁니다. |
| [[ctl:47]] | 끝 프레임을 한 프레임 앞으로 옮깁니다. [[ctl:48]] 버튼은 한 프레임 뒤로 옮깁니다. |

| 번호 | 기능 |
|---|---|
| [[ctl:50]] | 텍스트 파일에서 시퀀스를 불러옵니다. |
| [[ctl:51]] | 시퀀스를 텍스트 파일에 저장합니다. 다른 씬으로 복사할 때 사용합니다. |

## 시퀀스 만들기

[[shot:sequence_new|새 시퀀스 창.]]

1. [[t:seq_new_btn]]를 클릭합니다.
2. 프리셋을 고릅니다. 예: *Walk*. 프리셋이 알맞은 이름과 길이를 설정합니다.
3. 이름과 프레임을 확인합니다. 새 시퀀스는 마지막 시퀀스 뒤에서 시작합니다.
4. **확인**을 클릭합니다.

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 자주 쓰는 애니메이션의 프리셋 또는 *Custom*입니다. |
| [[ctl:7]] | 새 시퀀스의 이름입니다. |
| [[ctl:12]] | 첫 프레임입니다. |
| [[ctl:16]] | 마지막 프레임입니다. |
| [[ctl:17]] | 희귀도 값을 켭니다. |
| [[ctl:21]] | 이동 속도를 켭니다. |
| [[ctl:25]] | 애니메이션을 한 번만 재생합니다. |

!!! tip
    두 시퀀스 사이에 빈 프레임을 몇 개 두세요. 그러면 한 애니메이션의 키가 다음 애니메이션을 바꾸지 않습니다.

!!! note
    WhiteoutDex는 시퀀스를 `.max` 파일에 저장합니다. *note track*에 시퀀스가 있는 오래된 씬도 작동합니다. WhiteoutDex가 그것도 읽습니다.
