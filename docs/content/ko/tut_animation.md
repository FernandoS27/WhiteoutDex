# 튜토리얼: 애니메이션

이 강좌에서는 지난 강좌의 상자에 애니메이션 두 개를 줍니다. *Stand*(아무것도 하지 않음)와 *Death*(부서짐)입니다.

## 1단계: 타임라인 계획

모델의 모든 애니메이션은 타임라인 하나를 함께 씁니다. 애니메이션마다 자기 구간이 있습니다.

| 시퀀스 | 프레임 |
|---|---|
| Stand | 0 – 80 |
| Death | 100 – 164 |

구간 사이에 몇 프레임을 비워 두세요.

## 2단계: 시퀀스 만들기

1. **WhiteoutDex > [[t:menu_sequence_manager]]** 메뉴를 엽니다.
2. **새로 만들기...**를 클릭하고 *Stand*를 고릅니다. 시작 0, 끝 80으로 설정하고 **확인**을 클릭합니다.
3. **새로 만들기...**를 클릭하고 *Death*를 고릅니다. 시작 100, 끝 164로 설정합니다. **반복 안 함**을 켜고 **확인**을 클릭합니다.

![시퀀스가 선택된 시퀀스 관리자.](sequence_manager_selected.png)

## 3단계: 키 설정

1. 3ds Max에서 **Auto Key**를 켭니다.
2. 각 시퀀스의 시작과 끝에 키를 설정합니다. **WhiteoutDex > [[t:menu_anim_general]]** 메뉴를 열고 상자를 선택한 뒤 **시작/끝 키 추가**를 클릭합니다.
3. 프레임 130으로 갑니다. 상자가 넘어지듯이 회전시키고 아래로 이동합니다.
4. 프레임 164로 가서 상자를 바닥 아래로 이동합니다.
5. **Auto Key**를 끕니다.

## 4단계: 테스트

1. 시퀀스 관리자에서 *Death*를 더블클릭합니다. 3ds Max가 재생합니다.
2. 미리보기 창(**WhiteoutDex > [[t:menu_renderer]]**)을 열고 **애니메이션** 목록에서 *Death*를 고릅니다.

!!! tip
    메시보다 본을 애니메이션하는 것이 좋습니다. 모델의 각 부분을 본에 링크하고 본을 애니메이션하세요. 그런 다음 메시에 **Skin** 모디파이어를 사용하세요.

!!! note
    게임은 *Stand*를 계속 반복해서 재생합니다. *Death*는 한 번만 재생됩니다. 그 뒤 시체는 *Decay* 애니메이션까지 남아 있습니다(모델에 있는 경우).
