# Wc3 Vertex Color

**Wc3 Vertex Color** 모디파이어는 메시 전체에 색을 입힙니다. 색상을 애니메이션할 수 있습니다. 예: 수정이 맥박처럼 빛나게 하거나, 유닛이 맞을 때 한 부분을 빨갛게 빛나게 합니다. 익스포터는 이것을 메시의 *지오셋 애니메이션* 색상으로 씁니다.

Modifier List에서 추가합니다. 메시를 선택하고 **Wc3 Vertex Color**를 고르세요.

[[shot:obj_vertexcolor_r1|모디파이어의 기본 파라미터.]]

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 메시에 입힐 색입니다. 흰색이면 텍스처가 그대로입니다. **Auto Key**로 애니메이션하세요. |
| [[ctl:7]] | 메시의 *Drop Shadow* 플래그를 설정합니다. |
| [[ctl:9]] | 색상을 사용합니다. 끄면 플래그만 씁니다. |

!!! tip
    한 부분을 서서히 나타나고 사라지게 하려면 표시 키(*표시 키어*) 또는 Wc3Material의 *불투명도*를 대신 사용하세요.
