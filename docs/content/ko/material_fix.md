# 머티리얼 수정

익스포터는 **Wc3Material**만 읽을 수 있습니다. 머티리얼 수정은 다른 머티리얼(Standard, Physical, PBR)을 Wc3Material로 변환합니다. 텍스처는 유지하고, 여기에서 고른 Warcraft III 옵션을 설정합니다.

내보내기 창의 [[t:exp_fix_all_btn]]도 같은 설정을 사용합니다.

**WhiteoutDex > [[t:menu_material_fix]]** 메뉴로 엽니다.

[[shot:material_fix|클래식 모델(SD) 설정이 보이는 머티리얼 수정.]]

설정은 두 벌입니다. 하나는 클래식 모델용(**SD**), 하나는 Reforged용(**HD**)입니다.

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 클래식 모델용 설정입니다. |
| [[ctl:5]] | Reforged 모델용 설정입니다. |

## 렌더링

| 번호 | 기능 |
|---|---|
| [[ctl:8]] | 머티리얼을 그리는 방식입니다. *Automatic*은 알파 채널이 있는 머티리얼을 투명하게 만듭니다. 모든 모드는 *Wc3Material*을 참고하세요. |
| [[ctl:10]] | 면의 양쪽을 모두 그립니다. |
| [[ctl:11]] | 머티리얼이 조명을 무시합니다. |
| [[ctl:12]] | 머티리얼이 안개를 무시합니다. |
| [[ctl:13]] | 메시 전체에 한 가지 색을 사용합니다. |
| [[ctl:14]] | 모든 것 위에 그립니다(깊이 테스트 없음). |
| [[ctl:15]] | 뒤에 있는 것을 가리지 않습니다. |
| [[ctl:16]] | 앰비언트 오클루전을 사용합니다(Reforged 전용). |
| [[ctl:17]] | 뒷면이 그림자를 드리웁니다(Reforged 전용). |
| [[ctl:18]] | *양면*, *셰이딩 없음*, *투명도*를 위의 체크 상자 대신 원래 머티리얼에서 가져옵니다. |

## 텍스처

| 번호 | 기능 |
|---|---|
| [[ctl:23]] | 모델 안에서 텍스처 이름 앞에 붙는 폴더입니다. 예: `Textures\`. |
| [[ctl:26]] | 텍스처가 반복되는 방식입니다. 원래 머티리얼과 같게, 양방향, U만, V만, 또는 반복 안 함. |
| [[ctl:28]] | 노멀 맵 또는 범프 맵이 *노멀* 맵이 됩니다(Reforged). |
| [[ctl:29]] | 방출 맵이 *이미시브* 맵이 됩니다(Reforged). |
