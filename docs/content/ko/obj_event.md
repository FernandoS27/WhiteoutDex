# 이벤트 오브젝트

이벤트 오브젝트는 애니메이션의 정확한 순간에 무언가를 시작합니다. 예: 칼이 맞을 때의 소리, 발이 땅에 닿을 때의 발자국, 유닛이 죽을 때의 피, 나타나는 모델.

**Create > Helpers > Warcraft III Plugins > Wc3 Event Object**로 만듭니다. 이벤트가 일어날 위치에 놓습니다. 움직여야 하면 본에 링크합니다.

뷰포트에서 각 이벤트 오브젝트는 이름을 초록색으로 표시합니다.

[[shot:obj_event_r2|예제 모델의 사망 소리를 담은 이벤트 오브젝트 롤아웃.]]

## 이벤트 선택

| 번호 | 기능 |
|---|---|
| [[ctl:5]] | 이벤트의 종류입니다(아래 표 참고). |
| [[ctl:8]] | 게임 목록에서 고르는 정확한 이벤트입니다. 예: 소리 또는 피의 색. |
| [[ctl:13]] | 선택한 것을 적용하고 오브젝트의 이름을 정합니다. 버튼 아래 줄에 이벤트 코드가 표시됩니다. |

*사용자 데이터*에 이벤트 코드를 직접 입력할 수도 있습니다.

| 유형 | 코드 시작 | 일어나는 일 |
|---|---|---|
| FootPrint | `FPT` | 땅에 발자국이 남습니다. |
| BloodSplat | `SPL` | 땅에 튀긴 자국이 남습니다. 예: 피. |
| UberSplat | `UBR` | 땅에 큰 자국이 남습니다. 예: 구덩이, 건물 바닥. |
| Sound | `SND` | 소리가 납니다. |
| SpawnObject | `SPN` | 모델이 나타납니다. 예: 떨어지는 몸의 일부. |

## 일어나는 시점

| 번호 | 기능 |
|---|---|
| [[ctl:19]] | 이벤트가 일어나는 시간 목록입니다. |
| [[ctl:20]] | 타임 슬라이더를 알맞은 프레임으로 옮긴 뒤 이것을 클릭해 시간을 추가합니다. |
| [[ctl:21]] | 선택한 시간을 제거합니다. |
| [[ctl:22]] | 모든 시간을 제거합니다. |

!!! tip
    *시퀀스 관리자*로 애니메이션으로 이동하세요. 그런 다음 슬라이더를 한 프레임씩 옮겨 정확한 순간을 찾으세요. 예: 발이 땅에 닿는 순간.
