# Wc3Bitmap

**Wc3Bitmap**은 WhiteoutDex의 텍스처 맵입니다. *Wc3Material*의 슬롯에 넣으세요. `.blp`, `.dds`, `.tga`, `.png` 및 3ds Max의 다른 이미지 형식을 읽습니다. 텍스처 애니메이션(UV 애니메이션)과 게임 속 텍스처 경로도 담습니다.

## WC3 텍스처 매개변수

[[shot:mat_wc3bitmap_r1|WC3 텍스처 매개변수.]]

| 번호 | 기능 |
|---|---|
| [[ctl:6]] | 디스크에서 이미지 파일을 고릅니다. |
| [[ctl:7]] | 게임 아카이브에서 텍스처를 고릅니다. |
| [[ctl:9]] | 게임이 채워 넣는 텍스처를 사용합니다(팀 색상, 팀 글로우, 절벽, 나무). |
| [[ctl:12]] | 텍스처가 가로로 반복됩니다. |
| [[ctl:13]] | 텍스처가 세로로 반복됩니다. |
| [[ctl:14]] | 텍스처를 반사로 사용합니다(구체 환경 맵). |

## UV 애니메이션 (TXAN)

[[shot:mat_wc3bitmap_r2|UV 애니메이션.]]

이 값을 애니메이션하면 텍스처가 움직입니다. *텍스처 애니메이션 생성기*가 대신 설정할 수 있습니다.

| 번호 | 기능 |
|---|---|
| [[ctl:3]] | 키 사이에서 값이 바뀌는 방식입니다. |
| [[ctl:8]] | 텍스처를 옆으로 이동합니다(U). |
| [[ctl:11]] | 텍스처를 위아래로 이동합니다(V). |
| [[ctl:14]] | W 오프셋입니다. |
| [[ctl:17]] | 텍스처를 회전합니다. |
| [[ctl:20]] | 텍스처가 가로로 반복되는 횟수를 늘리거나 줄입니다. |
| [[ctl:23]] | 텍스처가 세로로 반복되는 횟수를 늘리거나 줄입니다. |

## 경로 접두사

[[shot:mat_wc3bitmap_r3|경로 접두사.]]

접두사는 익스포터가 텍스처 이름 앞에 쓰는 폴더입니다. 예: `Textures\` 또는 `war3mapImported\`.

| 번호 | 기능 |
|---|---|
| [[ctl:5]] | 저장된 접두사를 고릅니다. |
| [[ctl:6]] | 저장된 접두사 목록을 편집합니다. |

!!! tip
    맵의 텍스처는 그 맵이 사용하는 접두사를 써야 합니다. 맵의 커스텀 모델에서는 보통 `war3mapImported\`입니다.
