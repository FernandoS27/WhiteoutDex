# 익스포터

익스포터는 씬을 Warcraft III 모델(`.mdx` 또는 `.mdl`)로 저장합니다. 텍스처를 게임 형식으로 변환할 수도 있습니다.

## 익스포터 열기

- 메뉴 **WhiteoutDex > [[t:menu_exporter]]**
- WhiteoutDex 사이드바의 **Export** 버튼
- **File > Export**를 선택하고 *Warcraft III MDX/MDL Model*을 고릅니다

파일 이름을 정합니다. 그러면 내보내기 창이 열립니다.

## 내보내기 창

[[shot:exporter|지오메트리 탭이 열린 내보내기 창.]]

창 위쪽에 파일 이름이 표시됩니다. 그 아래에서 새 파일인지, 같은 이름의 파일이 이미 있는지 알 수 있습니다.

| 번호 | 기능 |
|---|---|
| [[ctl:1001]] | **모델 이름.** 파일 안에 저장되는 이름입니다. 게임은 보여 주지 않지만 다른 도구는 보여 줍니다. |
| [[ctl:1011]] | 클래식 게임용으로 내보냅니다(MDX 버전 800). 텍스처는 `.blp` 파일이 됩니다. |
| [[ctl:1012]] | Reforged용으로 내보냅니다(MDX 버전 1800). 텍스처는 `.dds` 파일이 됩니다. |
| [[ctl:1015]] | 메시 옵션을 보여 줍니다(이 그림). |
| [[ctl:1016]] | 텍스처 옵션을 보여 줍니다. |
| [[ctl:1021]] | 같은 머티리얼을 쓰는 메시를 하나로 합칩니다. 모델이 작아지고 빨라집니다. |
| [[ctl:1027]] | 두 메시가 만나는 곳의 노멀을 같게 만듭니다. 이음매가 감춰집니다. 스무딩 그룹으로 날카로운 모서리를 만들었다면 사용하지 마세요. |
| [[ctl:1028]] | 아무것도 사용하지 않는 본과 헬퍼도 내보냅니다. 보통 익스포터는 이것을 빼놓습니다. |
| [[ctl:1032]] | 스킨 웨이트를 클래식 게임에서 작동하도록 바꿉니다. 클래식 게임은 단순한 웨이트만 사용할 수 있습니다. [[t:exp_format_classic_title]] 전용입니다. |
| [[ctl:1030]] | 파일이 이미 있으면 익스포터가 이름에 `_1`, `_2` 등을 붙입니다. 기존 파일은 그대로 남습니다. |
| [[ctl:1031]] | 내보낸 뒤 파일이 있는 폴더를 엽니다. |
| [[ctl:1]] | 내보내기를 시작합니다. |
| [[ctl:2]] | 내보내지 않고 창을 닫습니다. |

옵션 아래의 초록색 상자는 WhiteoutDex가 씬에서 문제를 찾지 못했다는 뜻입니다. 문제를 찾으면 상자가 노란색이 됩니다. *씬 문제와 모두 수정*을 참고하세요.

### 텍스처 탭

[[shot:exporter_textures|텍스처 탭. 여기서는 클래식 내보내기입니다.]]

| 번호 | 기능 |
|---|---|
| [[ctl:1060]] | 머티리얼의 텍스처를 `.blp`(클래식) 또는 `.dds`(Reforged)로 변환하고 모델 옆에 저장합니다. |
| [[ctl:1071]] | **클래식 전용.** [[t:exp_blp_paletted_item]] 또는 *JPEG*입니다. JPEG는 색이 더 많습니다. 팔레트 파일은 더 작습니다. JPEG를 고르면 품질(1–100)도 설정합니다. |
| [[ctl:1075]] | 색을 조금 섞습니다. 팔레트 텍스처에서 색 사이의 딱딱한 경계를 감춥니다. |
| [[ctl:1061]] | 게임이 멀리 있는 모델에 사용하는 작은 버전의 텍스처를 만듭니다. 켜 두세요. |
| [[ctl:1062]] | 이미 있는 텍스처 파일을 덮어씁니다. 끄면 익스포터가 기존 파일을 유지합니다. |

**Reforged**에서는 대신 DDS 형식을 고릅니다. *BC3 (DXT5)* 또는 *BC7*입니다. BC7이 더 보기 좋습니다. BC3는 오래된 그래픽 카드에서도 작동합니다.

## 클래식인가요, Reforged인가요?

| | 클래식 | Reforged |
|---|---|---|
| 게임 | Warcraft III 1.x와 Reforged의 클래식 그래픽 | Reforged 그래픽(HD) |
| MDX 버전 | 800 | 1800 |
| 텍스처 | `.blp` | `.dds` |
| 스킨 | 단순한 웨이트([[t:exp_quantize_skin_weights_chk]] 사용) | 전체 웨이트 |

!!! tip
    익스포터는 다음 내보내기를 위해 모든 옵션을 기억합니다.
