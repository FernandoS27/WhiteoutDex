# 씬 문제와 모두 수정

내보내기 전에 WhiteoutDex가 씬을 검사합니다. 게임에서 모델을 망가뜨리거나 내보내기를 실패하게 만드는 것을 찾습니다. 결과는 내보내기 창에 표시됩니다.

[[shot:exporter_problems|내보내기 창이 문제 세 개를 찾았습니다.]]

| 번호 | 기능 |
|---|---|
| [[ctl:1092]] | 모든 문제를 한 번에 고칩니다. 씬이 바뀝니다. 수정 종류마다 실행 취소 단계가 하나씩 있습니다. 그래서 [[key:Ctrl+Z]]로 되돌릴 수 있습니다. |
| [[ctl:1093]] | 모든 문제의 목록을 엽니다. |

## 문제 목록

[[shot:scene_problems|각 행이 문제 하나입니다.]]

| 번호 | 기능 |
|---|---|
| [[ctl:2000]] | 문제 목록입니다. 행을 더블클릭하면 씬에서 그 오브젝트가 선택됩니다. |

## WhiteoutDex가 고치는 것

| 문제 | [[t:exp_fix_all_btn]]이 하는 일 |
|---|---|
| 두 오브젝트의 이름이 같음 | 이름을 바꿉니다: `_2`, `_3` 등. 게임은 고유한 이름이 필요합니다. |
| 빈 메시 | 삭제합니다. |
| Editable Poly | *Edit Mesh* 모디파이어를 추가합니다. 그러면 익스포터가 삼각형을 받습니다. |
| *Skin* 위의 *Edit Mesh* | 축소(collapse)합니다. 그러면 스킨이 올바르게 유지됩니다. |
| 게임이 읽을 수 없는 컨트롤러 | 리니어 컨트롤러로 바꿉니다. |
| Multi/Sub-Object 머티리얼을 쓰는 메시 | 메시를 나눕니다. 그러면 각 부분이 머티리얼 하나를 가집니다. |
| 머티리얼이 Wc3Material이 아님 | 변환합니다. 설정은 *머티리얼 수정*에서 가져옵니다(해당 페이지 참고). |
| 두 머티리얼이 같음 | 하나로 합칩니다. |

!!! tip
    문제를 꼭 고칠 필요는 없습니다. 고치지 않아도 익스포터는 작동합니다. 하지만 게임에서 모델이 잘못 보일 수 있습니다.
