# WhiteoutFlakes 미리보기 창

**WhiteoutFlakes**는 Warcraft III가 보여 주는 방식 그대로 모델을 보여 줍니다. 게임의 셰이더, 팀 색상, 조명, 파티클, 리본을 사용합니다. 3ds Max를 실시간으로 따라갑니다. 타임 슬라이더를 움직이거나 무언가를 바꾸면 미리보기 창이 갱신됩니다.

**WhiteoutDex > [[t:menu_renderer]]** 메뉴 또는 사이드바의 **Renderer** 버튼으로 엽니다.

![3ds Max 2027 옆의 WhiteoutFlakes. 팀 색상이 적용된 Reforged 모델.](media_1.png)

## 도구 모음

| 요소 | 기능 |
|---|---|
| **애니메이션** | 모델의 시퀀스를 재생합니다. *Free Range*를 고르면 Max의 타임 슬라이더를 따라갑니다. |
| **카메라** | *자유 카메라* 또는 씬의 카메라 중 하나입니다. 예: 초상화 카메라. |
| **팀** | 모델의 플레이어 색상입니다. |
| **조명** | *인게임*(게임과 같음), *글루*(메뉴와 같음) 또는 *동적*. |
| **Sync Camera** | 미리보기 창이 3ds Max의 활성 뷰포트를 따라갑니다. |
| **Resync** | 씬 전체를 다시 읽습니다. 예: 오브젝트를 추가한 뒤. |

## 메뉴

| 메뉴 | 내용 |
|---|---|
| **보기** | 그리드, 파티클, 리본, 이벤트 오브젝트를 보이거나 숨깁니다. *Warcraft III 아트*: 사용할 텍스처(*렌더 모드 따르기*, *Classic*, *Reforged (HD)*, *Definitive*). *타일셋*: 바닥. |
| **디버그** | 충돌 형태와 라이트의 표시, 특수 보기(알베도, 노멀, LOD, 라이트 개수 …), LOD 선택. |
| **설정** | 배경, 밝기, 소리 크기, 시간대, 이미지 기반 조명, 그림자, 안개, 그래픽 백엔드(Direct3D 11, Direct3D 12, Vulkan), 게임 폴더. |

## 알아 두기

- 파티클과 리본은 게임과 같이 시뮬레이션됩니다. 타임 슬라이더에서 다른 위치로 건너뛰면 미리보기 창이 새 프레임까지 이펙트를 계산합니다. 그래서 애니메이션이 그 위치까지 재생된 것처럼 보입니다.
- 미리보기 창은 설정을 `3dsmax.exe` 옆의 `WhiteoutFlakes.ini`에 저장합니다.
- 미리보기 창에 아무것도 보이지 않거나 멈추면 `WhiteoutDex_render.log`를 확인하세요(*파일과 설정* 참고).

!!! tip
    **보기 > Warcraft III 아트**에서 *Classic* 또는 *Reforged (HD)*를 고르세요. 게임의 각 버전에서 모델이 어떻게 보이는지 확인할 수 있습니다.
