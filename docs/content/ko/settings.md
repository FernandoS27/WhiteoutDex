# 설정

설정에서는 WhiteoutDex의 언어를 고르고, 게임이 있는 위치를 알려 줍니다.

**WhiteoutDex > [[t:menu_settings]]** 메뉴를 선택하거나, 사이드바 아래쪽의 톱니바퀴 버튼을 클릭해 엽니다.

[[shot:settings|WhiteoutDex 설정.]]

## 언어

| 번호 | 기능 |
|---|---|
| [[ctl:5]] | 모든 WhiteoutDex 창의 언어입니다. 열려 있는 창은 다시 열면 바뀝니다. WhiteoutDex 메뉴는 3ds Max를 다시 시작한 뒤에 바뀝니다. |

## 클래식 게임(MPQ)

클래식 Warcraft III(버전 1.x)는 파일을 **MPQ** 아카이브에 보관합니다. WhiteoutDex는 여기에서 텍스처와 모델을 읽습니다.

| 번호 | 기능 |
|---|---|
| [[ctl:10]] | 클래식 Warcraft III 폴더입니다. |
| [[ctl:12]] | 폴더를 직접 고릅니다. |
| [[ctl:14]] | 폴더를 자동으로 찾습니다. |
| [[ctl:15]] | 폴더를 지웁니다. |
| [[ctl:16]] | MPQ 아카이브의 순서를 정합니다. 파일을 가진 첫 번째 아카이브가 우선합니다. 보통은 필요 없습니다. |

## Reforged(CASC)

Warcraft III: Reforged는 파일을 **CASC** 저장소에 보관합니다.

| 번호 | 기능 |
|---|---|
| [[ctl:20]] | Warcraft III: Reforged 폴더입니다. 보통 `C:\Program Files (x86)\Warcraft III`입니다. |
| [[ctl:24]] | 폴더를 자동으로 찾습니다. |
| [[ctl:25]] | 폴더를 지웁니다. |
| [[ctl:27]] | **장면 아트.** 미리보기 창이 사용할 텍스처입니다. [[t:set_art_tier_items#2]], [[t:set_art_tier_items#3]], [[t:set_art_tier_items#4]] 중에서 고릅니다. [[t:set_art_tier_items#1]]는 자동으로 고릅니다. 이 값은 씬과 함께 저장됩니다. |

!!! note
    작업하는 게임만 설정하면 됩니다. 클래식 모델에는 MPQ 폴더를 지정하세요. Reforged 모델에는 CASC 폴더를 지정하세요. 둘 다 지정하면 WhiteoutDex가 가장 많은 파일을 찾습니다.
