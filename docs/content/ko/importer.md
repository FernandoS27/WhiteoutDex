# 임포터

임포터는 Warcraft III 모델(`.mdx` 또는 `.mdl`)을 3ds Max로 불러옵니다. 모델의 텍스처도 게임에서 불러옵니다.

## 임포터 열기

다음 중 한 가지 방법을 사용합니다.

- 메뉴 **WhiteoutDex > [[t:menu_importer]]**
- WhiteoutDex 사이드바의 **Import** 버튼
- **File > Import**를 선택하고 파일 형식 *Warcraft III MDX/MDL Model*을 고릅니다

파일을 고릅니다. 그러면 가져오기 창이 열립니다.

## 가져오기 창

창 위쪽에는 파일 이름, 모델의 게임 버전(*클래식* 또는 *Reforged*), 그리고 본, 메시(지오셋), 애니메이션의 개수가 표시됩니다.

| [[ctl:1059]] | 지금 열린 씬을 지우고 빈 씬으로 모델을 가져옵니다. |
| [[ctl:1060]] | 지금 열린 씬에 모델을 추가합니다. 모델을 합칠 때 사용합니다. |
| [[ctl:1061]] | 모델의 오브젝트를 보여 줍니다(이 그림). |
| [[ctl:1062]] | 애니메이션 옵션을 보여 줍니다. |
| [[ctl:1063]] | 메시, 머티리얼, 텍스처 옵션을 보여 줍니다. |
| [[ctl:1021]] | 모든 오브젝트의 스위치입니다. 끄면 오브젝트를 가져오지 않습니다. |
| [[ctl:1022]] | 스켈레톤입니다. 애니메이션과 스킨 메시에 필요합니다. |
| [[ctl:1023]] | 헬퍼 오브젝트입니다. 다른 오브젝트를 움직이지만 게임에서는 보이지 않습니다. |
| [[ctl:1024]] | 라이트입니다. |
| [[ctl:1025]] | 부착점입니다. 예를 들어 무기와 주문 이펙트에 씁니다. |
| [[ctl:1028]] | 이벤트 오브젝트입니다. 예: 소리, 발자국, 피. |

| [[ctl:1027]] | 파티클 이미터 2: 불, 연기, 불꽃 같은 이펙트용 이미터입니다. |

각 오브젝트 유형 옆의 숫자는 모델에 있는 개수입니다. 모델에 없는 유형은 회색입니다.

!!! note
    Reforged 모델에는 오브젝트 유형이 두 개 더 있을 수 있습니다. *Popcorn FX* 이미터와 *FaceFX*입니다. 모델에 있을 때만 보입니다.

## 텍스처를 찾는 위치

WhiteoutDex는 각 텍스처를 다음 순서로 찾습니다.

1. 모델 폴더와 그 하위 폴더.
2. 게임 아카이브. 클래식 모델(버전 800)은 먼저 **MPQ** 아카이브에서 찾고, 그다음 **CASC**에서 찾습니다. Reforged 모델은 반대 순서입니다.

창의 맨 아래 줄에 사용하는 아카이브가 표시됩니다. 게임 폴더는 [[t:menu_settings]]에서 지정합니다.

!!! tip
    임포터는 게임 아카이브에서 가져온 텍스처를 모델 파일 옆에 저장합니다. 그래서 다음에는 바로 찾습니다.

## 알아 두기

- 임포터는 선택한 옵션을 다음 번을 위해 기억합니다.
- 디스크에 파일이 없어도 게임에서 모델을 가져올 수 있습니다. *게임에서 가져오기*를 참고하세요.
