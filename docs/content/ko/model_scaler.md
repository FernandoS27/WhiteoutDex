# 애니메이션: 모델 스케일러

모델 전체를 본, 애니메이션, 특수 오브젝트와 함께 스케일합니다. 모델이 게임에 비해 너무 크거나 작을 때 사용하세요.

**WhiteoutDex > [[t:menu_anim_scaler]]** 메뉴로 엽니다.

[[shot:model_scaler|모델 스케일러.]]

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 게임 기준의 목표 높이입니다. 예: *Footman* 또는 *Townhall*(클래식 또는 Reforged). |
| [[ctl:6]] | 모델을 고른 높이로 스케일합니다. |
| [[ctl:10]] | 직접 정하는 배율입니다. 2는 모델을 두 배로, 0.5는 절반으로 만듭니다. |
| [[ctl:11]] | 모델을 지정한 배율로 스케일합니다. |

!!! warning
    **Biped** 또는 **CAT** 리그와 Skin 모디파이어가 있는 모델은 이 방법으로 잘 스케일되지 않습니다. WhiteoutDex가 경고합니다. 이 경우에는 리그 자체의 도구로 스케일하세요.

!!! tip
    스케일하기 전에 씬을 저장하세요. 결과가 맞지 않으면 되돌아갈 수 있습니다.
