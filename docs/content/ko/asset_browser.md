# 게임 브라우저

게임 브라우저는 Warcraft III 게임 안의 파일을 보여 줍니다. 모델, 텍스처, 파티클 이펙트가 있습니다. 파일마다 작은 그림이 보이므로 필요한 것을 빨리 찾을 수 있습니다.

여러 곳에서 열 수 있습니다.

| 위치 | 버튼 | 고르는 것 |
|---|---|---|
| WhiteoutDex 메뉴 | [[t:menu_import_casc]] | 가져올 모델 |
| 부착점 | *게임 아카이브 찾아보기* | 부착할 모델 |
| 파티클 이미터 1 | *Browse Game Archives* | 파티클용 모델 |
| 파티클 이미터 2 | *MPQ / CASC 찾아보기* | 파티클용 텍스처 |
| Popcorn FX | *게임 아카이브 찾아보기* | `.pkb` 또는 `.pkfx` 이펙트 |
| Wc3Bitmap | *텍스처 브라우저 열기* | 텍스처 |
| Wc3Material | 맵 옆의 ⚙ 버튼 | 이 슬롯의 텍스처 |

## 사용 방법

1. 검색 필드에 이름의 일부를 입력합니다. 예: `footman`.
2. **그리드**(그림)와 **트리**(폴더) 사이를 전환합니다.
3. 그림을 확대하거나 축소합니다.
4. 파일을 클릭합니다. 아래쪽 줄에 선택한 파일이 표시됩니다.
5. **선택**을 클릭합니다.

!!! note
    브라우저에는 게임 폴더가 필요합니다. [[t:menu_settings]]에서 지정하세요. 클래식 모델은 MPQ 아카이브에서, Reforged 파일은 CASC에서 가져옵니다.
