# 애니메이션: 컨트롤러

Warcraft III는 키 사이를 움직이는 방법을 네 가지 압니다. *None*(점프), *Linear*, *Bezier*, *Hermite*(TCB)입니다. 이 도구는 선택한 오브젝트에 고른 컨트롤러를 지정합니다. 위치, 회전, 스케일에 한 번에 지정합니다.

**WhiteoutDex > [[t:menu_anim_controllers]]** 메뉴로 엽니다.

[[shot:anim_controllers|컨트롤러 도구.]]

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 위치가 키 사이에서 직선으로 움직입니다. |
| [[ctl:5]] | 위치가 부드러운 곡선으로 움직입니다. |
| [[ctl:6]] | 위치에 TCB 키를 사용합니다(장력, 연속성, 바이어스가 있는 부드러운 움직임). |
| [[ctl:7]] | 위치 컨트롤러를 그대로 둡니다. |
| [[ctl:10]] | 회전이 키 사이에서 고르게 돕니다. |
| [[ctl:11]] | 회전이 부드럽게 돕니다. |
| [[ctl:12]] | 회전에 TCB 키를 사용합니다. |
| [[ctl:13]] | 회전 컨트롤러를 그대로 둡니다. |
| [[ctl:16]] | 스케일이 고르게 바뀝니다. |
| [[ctl:17]] | 스케일이 부드러운 곡선으로 바뀝니다. |
| [[ctl:18]] | 스케일에 TCB 키를 사용합니다. |
| [[ctl:19]] | 스케일 컨트롤러를 그대로 둡니다. |
| [[ctl:22]] | 선택한 오브젝트에 이 컨트롤러를 지정합니다. |

!!! note
    익스포터도 게임이 읽을 수 없는 컨트롤러를 바꿉니다(*씬 문제와 모두 수정* 참고). 이 도구를 쓰면 유형을 직접 고를 수 있습니다.
