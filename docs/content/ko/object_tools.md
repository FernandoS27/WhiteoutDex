# 오브젝트 조작 도구

오브젝트 사이에서 위치, 링크, 정점 위치를 복사하고 붙여 넣습니다. 대칭 모델에 좋습니다. 왼쪽을 만든 뒤 오른쪽으로 복사하세요.

**WhiteoutDex > [[t:menu_object_tools]]** 메뉴로 엽니다.

[[shot:object_tools|메시가 선택된 오브젝트 조작 도구.]]

## 오브젝트

| 번호 | 기능 |
|---|---|
| [[ctl:5]] | **계층 구조:** 선택한 오브젝트의 부모 링크를 저장하고 링크를 끊습니다. |
| [[ctl:6]] | 오브젝트를 저장된 부모에 다시 링크합니다. |
| [[ctl:8]] | **위치:** 처음 선택한 오브젝트의 위치를 복사합니다. |
| [[ctl:9]] | 선택한 오브젝트를 복사한 위치로 옮깁니다. |
| [[ctl:11]] | **구조 (L↔R):** 선택한 모든 오브젝트의 위치를 이름과 함께 복사합니다. |
| [[ctl:12]] | 이름이 대칭인 오브젝트에 붙여 넣습니다. `Arm_L`에서 복사한 위치는 `Arm_R`로 갑니다. |
| [[ctl:14]] | 붙여 넣는 동안 오브젝트의 링크를 잠시 끊습니다. 그러면 자식이 함께 움직이지 않습니다. |
| [[ctl:15]] | 붙여 넣을 때 체크한 축을 따라 위치를 대칭시킵니다: [[ctl:16]], [[ctl:17]], [[ctl:18]]. |

## 정점(폴리 도구)

먼저 Editable Poly 또는 Editable Mesh의 정점을 선택하세요. 버튼 위의 줄에 오브젝트와 선택한 정점 수가 표시됩니다.

| 번호 | 기능 |
|---|---|
| [[ctl:22]] | 선택한 정점의 위치를 복사합니다. |
| [[ctl:23]] | 정점에 위치를 붙여 넣습니다. |
| [[ctl:26]] | 붙여 넣을 때 X 값을 대칭시킵니다. [[ctl:27]] 버튼과 [[ctl:28]] 버튼은 Y와 Z에 같은 일을 합니다. |
| [[ctl:29]] | 월드 중심을 기준으로 대칭시킵니다. |
| [[ctl:30]] | 오브젝트의 피벗을 기준으로 대칭시킵니다. |
| [[ctl:31]] | 선택 영역의 중심을 기준으로 대칭시킵니다. |
| [[ctl:35]] | 같은 정점 번호에 붙여 넣습니다. 같은 메시나 그 복사본에 사용하세요. |
| [[ctl:36]] | 선택한 정점에 붙여 넣습니다. 다른 메시에도 됩니다. |

!!! tip
    오브젝트 이름에 `_L`과 `_R`(또는 `Left`와 `Right`)을 붙이세요. 그러면 *구조 (L↔R)* 기능이 각 오브젝트의 짝을 자동으로 찾습니다.
