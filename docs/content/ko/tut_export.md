# 튜토리얼: 모델 내보내기

이제 모델을 다시 Warcraft III 파일로 저장합니다.

**필요한 것:** 강좌 *모델 가져오기*의 씬.

## 1단계: 내보내기 시작

1. **WhiteoutDex > [[t:menu_exporter]]** 메뉴를 선택합니다.
2. 폴더와 파일 이름을 고릅니다. 예: `MyPaladin.mdx`. **Save**를 클릭합니다.

내보내기 창이 열립니다.

![내보내기 창. 클래식이 선택되어 있습니다.](exporter.png)

## 2단계: 게임 선택

- 클래식 게임용이면 **클래식**을 고릅니다. 텍스처는 `.blp`가 됩니다.
- Reforged용이면 **Reforged**를 고릅니다. 텍스처는 `.dds`가 됩니다.

팔라딘은 클래식 모델입니다. **클래식**을 고르세요.

## 3단계: 씬 검사

버튼 위의 상자를 봅니다.

- **초록색 – 문제 없음:** 계속 진행합니다.
- **노란색 – 문제:** [[t:exp_fix_all_btn]]을 클릭합니다. WhiteoutDex가 씬을 고칩니다. *씬 문제와 모두 수정*을 참고하세요.

## 4단계: 내보내기

1. *텍스처* 탭에서 *내보낼 때 텍스처 변환*이 켜져 있는지 확인합니다.
2. **내보내기**를 클릭합니다.

이제 폴더에 `MyPaladin.mdx` 파일과 텍스처가 있습니다. 확인이 필요한 것이 있으면 내보내기 보고서가 열립니다(*내보내기 보고서* 참고).

## 5단계: 게임에서 테스트

1. 모델과 텍스처를 맵 폴더에 복사합니다. 또는 World Editor의 **Import Manager**로 가져옵니다.
2. World Editor의 *Object Editor*에서 유닛에 모델을 지정합니다(필드 *Art – Model File*).
3. 맵을 테스트합니다.

!!! tip
    익스포터는 모든 옵션을 기억합니다. 같은 모델을 다음에 내보낼 때는 클릭 한 번이면 됩니다.
