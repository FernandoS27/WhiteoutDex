# WhiteoutDex에 오신 것을 환영합니다

WhiteoutDex는 **3ds Max**용 도구 모음입니다. 이 도구로 **Warcraft III** 모델을 만들고, 고치고, 테스트할 수 있습니다. 클래식 게임(Warcraft III 버전 1.x)과 **Warcraft III: Reforged** 모두에서 작동합니다.

![3ds Max 2027의 WhiteoutDex. 왼쪽: WhiteoutFlakes 미리보기 창. 오른쪽: 노드 관리자와 뷰포트의 모델.](media_1.png)

## 할 수 있는 일

- Warcraft III 모델(`.mdx` 또는 `.mdl`)을 3ds Max로 **가져오기**합니다. WhiteoutDex는 게임에서 텍스처도 불러옵니다.
- 모델을 다른 3ds Max 오브젝트처럼 **편집**합니다. 메시, 본, 애니메이션, 머티리얼을 바꿀 수 있습니다.
- **WhiteoutFlakes**에서 모델을 **미리 봅니다**. 이 창은 게임과 같은 방식으로 모델을 보여 줍니다.
- 모델을 다시 `.mdx` 또는 `.mdl`로 **내보내기**합니다. 클래식 게임용과 Reforged용 모두 가능합니다. 텍스처는 WhiteoutDex가 변환합니다.
- Warcraft III에만 있는 **특수 오브젝트**를 사용합니다. 파티클 이미터, 리본, 부착점, 이벤트 오브젝트, 충돌 형태 등이 있습니다.

## 필요한 것

| | |
|---|---|
| Windows | Windows 10 이상 |
| 3ds Max | 2016부터 2027까지 모든 버전 |
| Warcraft III | 선택 사항이지만 권장합니다. WhiteoutDex는 게임 폴더에서 텍스처와 모델을 가져옵니다. |

## 이 매뉴얼을 읽는 방법

매뉴얼에는 네 종류의 페이지가 있습니다.

- **시작하기**는 WhiteoutDex의 설치와 설정을 돕습니다.
- **튜토리얼**은 짧은 강좌입니다. 처음이라면 순서대로 따라 하세요.
- **도구와 오브젝트 페이지**는 창 하나 또는 오브젝트 하나를 설명합니다. 각 그림에는 번호가 있습니다. 그림 아래의 표에서 각 번호의 기능을 확인하세요.
- **부록** 페이지는 찾아보기용 목록입니다.

[[t:menu_importer]]처럼 **파란 상자** 안의 말은 3ds Max 화면에 표시되는 말입니다. 키는 [[key:Ctrl+Z]]처럼 표시됩니다.

!!! tip
    매뉴얼은 WhiteoutDex와 같은 언어로 표시됩니다. WhiteoutDex의 언어는 [[t:menu_settings]]에서 바꿀 수 있습니다. *설정*을 참고하세요.
