# 오브젝트 설정

Warcraft III 오브젝트에는 3ds Max에 없는 추가 설정이 있습니다. 예: *빌보드*. 오브젝트 설정은 선택한 오브젝트에 이 설정을 지정합니다. WhiteoutDex는 설정을 오브젝트 안(User Properties)에 저장합니다. 익스포터는 이 설정을 모델에 씁니다.

**WhiteoutDex > [[t:menu_object_settings]]** 메뉴로 엽니다. 먼저 오브젝트를 하나 이상 선택하세요.

[[shot:object_settings|본이 선택된 오브젝트 설정.]]

## 플래그

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 오브젝트가 부모와 함께 이동하지 않습니다. |
| [[ctl:5]] | 오브젝트가 부모와 함께 회전하지 않습니다. |
| [[ctl:6]] | 오브젝트가 부모와 함께 스케일되지 않습니다. |
| [[ctl:7]] | 오브젝트가 항상 카메라를 향합니다. 빛과 평면 이펙트에 좋습니다. |
| [[ctl:8]] | 카메라를 향하지만 X축으로만 돕니다. |
| [[ctl:9]] | … Y축으로만 돕니다. |
| [[ctl:10]] | … Z축으로만 돕니다. |
| [[ctl:11]] | 오브젝트가 카메라 화면에서 제자리에 머뭅니다. |

## 메시

| 번호 | 기능 |
|---|---|
| [[ctl:13]] | **일반 스키닝:** Skin 모디파이어 또는 링크된 본을 사용합니다. |
| [[ctl:14]] | **ArtTools 스키닝:** 내보낼 때 서로 다른 메시의 정점을 연결합니다. 서로 섞이게 하고 싶은 메시에만 사용하세요. |
| [[ctl:17]] | 플레이어가 게임에서 이 메시를 클릭할 수 없습니다. |
