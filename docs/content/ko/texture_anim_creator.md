# 텍스처 애니메이션 생성기

텍스처를 움직이게 합니다. 예: 흐르는 물, 스프라이트 시트로 만든 타오르는 불, 여러 이미지로 만든 플립북. 키는 도구가 대신 씁니다.

**WhiteoutDex > [[t:menu_texture_anim_creator]]** 메뉴로 엽니다.

애니메이션에는 세 종류가 있습니다.

| 종류 | 용도 |
|---|---|
| **흐름 애니** | 텍스처가 미끄러지거나, 돌거나, 커집니다. 물, 용암, 에너지에 씁니다. |
| **시퀀스 (단일)** | 이미지 하나에 작은 그림이 격자로 많이 있습니다(*스프라이트 시트*). 도구가 그림을 차례로 보여 줍니다. |
| **시퀀스 (여러 장)** | 이미지가 많이 든 폴더입니다. 도구가 이미지를 차례로 보여 줍니다(*플립북*). |

[[shot:texture_anim_creator|시퀀스 (단일)이 선택된 텍스처 애니메이션 생성기.]]

## 흐름 애니

[[shot:texture_anim_flow|흐름 애니.]]

1. 시작 시간과 종료 시간을 설정합니다.
2. 텍스처가 움직일 방향의 화살표를 클릭합니다. 회전(왼쪽, 오른쪽)과 확대·축소(+, −)도 할 수 있습니다.
3. 항상 움직이는 텍스처라면 *전역 애니메이션*을 켭니다.
4. **애니메이션 생성**을 클릭합니다.

## 시퀀스 (여러 장)

[[shot:texture_anim_many|시퀀스 (여러 장).]]

1. 이미지가 있는 폴더를 고릅니다(버튼 **...**). 이미지는 이름 순서대로 사용됩니다.
2. 재생 순서, 속도, 시작 프레임을 설정합니다.
3. 경로 접두사를 설정합니다. 예: `Textures\`. 모델은 각 이미지에 이 경로를 사용합니다.
4. **애니메이션 생성**을 클릭합니다.

!!! tip
    텍스처 키는 *Wc3Bitmap*(UV 애니메이션) 또는 *Wc3Material*(플립북)에 있습니다. 나중에 바꾸려면 그곳을 보세요.
