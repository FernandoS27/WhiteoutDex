# 리본 이미터

리본 이미터는 움직이는 점 뒤로 **궤적**을 그립니다. 예: 칼을 휘두를 때의 빛 궤적, 혜성의 꼬리, 로켓의 연기. 움직이는 본에 링크하세요. 예: 무기.

**Create > Geometry > Particle Systems > Wc3Ribbon**으로 만듭니다.

## 리본 머티리얼 파라미터

[[shot:obj_ribbon_r1|리본 머티리얼 파라미터.]]

| 번호 | 기능 |
|---|---|
| [[ctl:1079]] | 궤적의 머티리얼(*Wc3Material*)입니다. 클릭하면 Material Editor에 넣습니다. |
| [[ctl:1073]] | 텍스처가 그림의 격자입니다. 행의 개수(1, 2, 4, 8 …) … |
| [[ctl:1075]] | … 와 열의 개수(1, 2, 4, 8 …)입니다. |
| [[ctl:1077]] | 궤적이 보여 줄 격자의 그림입니다. 애니메이션하면 궤적이 깜박입니다. |

## 리본 속성

[[shot:obj_ribbon_r2|리본 속성.]]

| 번호 | 기능 |
|---|---|
| [[ctl:1066]] | 궤적의 색상입니다. |
| [[ctl:1059]] | 궤적이 이미터 위로 뻗는 거리입니다. |
| [[ctl:1067]] | 궤적이 이미터 아래로 뻗는 거리입니다. 위 + 아래 = 궤적의 너비. |
| [[ctl:1080]] | 투명도입니다. 0 = 보이지 않음, 1 = 불투명. 0으로 애니메이션하면 궤적이 숨겨집니다. |
| [[ctl:1069]] | 초당 시작하는 궤적 조각의 개수입니다. 조각이 많을수록 궤적이 부드럽습니다. |
| [[ctl:1071]] | 조각 하나가 남아 있는 시간(초)입니다. 수명이 길수록 궤적이 길어집니다. |
| [[ctl:1082]] | 궤적을 아래로 끌어당깁니다. |
| [[ctl:1090]] | **컨트롤러:** 애니메이션된 값이 키 사이에서 바뀌는 방식입니다. 값마다 자기 컨트롤러가 있습니다. |

!!! tip
    칼 궤적에는: 이미터는 칼날에 두고, *Additive* 머티리얼을 쓰고, 휘두를 때 외에는 알파를 0으로, 수명은 약 0.2초로 하세요.
