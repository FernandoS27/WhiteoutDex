# 노드 관리자

모델에는 여러 종류의 오브젝트가 있습니다. 메시, 본, 헬퍼, 이미터 등입니다. 노드 관리자는 한 종류의 모든 오브젝트를 한 번에 보이거나, 숨기거나, 고정합니다.

**WhiteoutDex > [[t:menu_node_manager]]** 메뉴로 엽니다.

[[shot:node_manager|노드 관리자.]]

## 2. 작업하기

| 번호 | 기능 |
|---|---|
| [[ctl:20]] | 오브젝트를 보이게 합니다. |
| [[ctl:21]] | 오브젝트를 숨깁니다. |
| [[ctl:22]] | 오브젝트를 고정합니다. 실수로 선택할 수 없습니다. |
| [[ctl:23]] | 오브젝트의 고정을 해제합니다. |
| [[ctl:24]] | 오브젝트를 반투명하게 보여 줍니다. |
| [[ctl:25]] | 오브젝트를 다시 불투명하게 보여 줍니다. |

!!! tip
    메시를 작업하는 동안에는 모든 헬퍼, 본, 이미터를 숨기세요. 스킨 웨이트를 칠하는 동안에는 본을 고정하세요.
