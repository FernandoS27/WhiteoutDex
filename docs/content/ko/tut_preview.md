# 튜토리얼: 모델 미리 보기

3ds Max는 모델을 게임과 똑같이 보여 줄 수 없습니다. 게임에는 고유한 조명, 셰이더, 팀 색상, 이펙트가 있기 때문입니다. **WhiteoutFlakes** 미리보기 창은 이것을 보여 줄 수 있습니다.

**필요한 것:** 강좌 *모델 가져오기*의 씬.

## 1단계: 미리보기 창 열기

**WhiteoutDex > [[t:menu_renderer]]** 메뉴를 선택합니다. 새 창이 열리고 모델이 보입니다.

![3ds Max 2016 옆의 WhiteoutFlakes 미리보기 창.](media_2.png)

## 2단계: 애니메이션 선택

1. 미리보기 창의 도구 모음에서 **애니메이션** 목록을 엽니다.
2. *Walk*를 고릅니다. 팔라딘이 걷습니다.
3. *Free Range*를 고릅니다. 이제 미리보기 창이 3ds Max의 타임 슬라이더를 따라갑니다. 슬라이더를 움직이며 확인하세요.

## 3단계: 모습 바꾸기

1. **팀** 색상 상자를 클릭하고 다른 색을 고릅니다. 망토의 색이 바뀝니다.
2. **조명**에서 *글루*를 고릅니다. 게임 메뉴의 조명입니다.
3. **보기 > Warcraft III 아트**에서 *Classic* 또는 *Reforged (HD)*를 골라 두 모습을 비교합니다.

## 4단계: 모델을 바꾸고 바로 확인

1. 3ds Max에서 메시를 선택하고 조금 움직입니다.
2. 미리보기 창을 봅니다. 변경 내용이 바로 보입니다.
3. [[key:Ctrl+Z]]로 변경을 실행 취소합니다.

!!! tip
    오브젝트를 추가하거나 삭제한 뒤에는 미리보기 창에서 **Resync**를 클릭하세요. 씬 전체를 다시 읽습니다.

**다음 강좌:** 모델을 내보냅니다.
