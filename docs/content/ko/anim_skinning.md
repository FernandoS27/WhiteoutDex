# 애니메이션: 스키닝

메시가 본에 링크되어 있는데 본을 바꾸고 싶을 때가 있습니다. 본을 움직이면 링크된 메시도 움직입니다. 이 도구는 메시의 링크를 잠시 끊고, 나중에 다시 링크합니다.

**WhiteoutDex > [[t:menu_anim_skin]]** 메뉴로 엽니다.

[[shot:anim_skinning|스키닝 도구.]]

| 번호 | 기능 |
|---|---|
| [[ctl:4]] | 선택한 각 오브젝트의 부모를 저장하고 링크를 끊습니다. |
| [[ctl:5]] | 선택한 오브젝트를 저장된 부모에 다시 링크합니다. |

## 사용 방법

1. 본에 링크된 메시를 선택합니다.
2. [[ctl:4]] 버튼을 클릭합니다.
3. 본을 바꿉니다. 예: IK에서 FK로 변환합니다.
4. 메시를 다시 선택하고 [[ctl:5]] 버튼을 클릭합니다.
