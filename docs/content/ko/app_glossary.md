# 용어집

WhiteoutDex와 이 매뉴얼에 나오는 용어입니다.

| 용어 | 의미 |
|---|---|
| **MDX / MDL** | Warcraft III의 모델 파일입니다. `.mdx`는 바이너리이고 작습니다. `.mdl`은 읽고 편집할 수 있는 텍스트입니다. 둘 다 같은 데이터를 담습니다. |
| **클래식** | Warcraft III 버전 1.x와 클래식 그래픽입니다. 모델은 MDX 버전 800을 사용합니다. |
| **Reforged** | HD 그래픽의 Warcraft III: Reforged입니다. 모델은 MDX 버전 900~1800을 사용합니다. WhiteoutDex는 버전 1800으로 내보냅니다. |
| **MPQ** | 클래식 게임의 아카이브 파일입니다(예: `War3.mpq`). |
| **CASC** | Warcraft III: Reforged의 저장소입니다. |
| **BLP** | 클래식 게임의 텍스처 형식입니다. |
| **DDS** | Reforged의 텍스처 형식입니다. |
| **지오셋** | 모델의 메시 하나입니다. 모델에는 지오셋이 여러 개 있을 수 있습니다. |
| **본** | 스킨 메시의 정점을 움직이는 노드입니다. |
| **헬퍼** | 다른 노드를 움직이지만 게임에서는 보이지 않는 노드입니다. |
| **스킨** | 어떤 본이 어떤 정점을 얼마나 강하게(웨이트) 움직이는지 정합니다. |
| **시퀀스** | 모델의 애니메이션 하나입니다. 예: *Walk*. 이름, 시작 프레임, 끝 프레임이 있습니다. |
| **글로벌 시퀀스** | 현재 시퀀스와 상관없이 항상 반복되는 애니메이션입니다. 회전하는 수정처럼 항상 움직이는 것에 좋습니다. |
| **키 / 키프레임** | 한 시점의 값입니다. 게임은 키 사이를 이어서 움직입니다. |
| **컨트롤러** | 게임이 키 사이를 움직이는 방식입니다. *None*(점프), *Linear*, *Bezier* 또는 *Hermite*(부드러움). |
| **부착점** | 게임이 무언가를 붙이는 모델의 위치입니다. 무기, 주문 이펙트, 선택 원 등. |
| **이벤트 오브젝트** | 애니메이션의 한 순간에 무언가를 시작합니다. 소리, 발자국, 피, 생성되는 모델 등. |
| **파티클 이미터 1** | 작은 모델을 내보냅니다. |
| **파티클 이미터 2** | 텍스처가 있는 파티클을 내보냅니다. 불, 연기, 불꽃 등. |
| **리본 이미터** | 움직이는 점 뒤로 궤적을 그립니다. |
| **Popcorn FX** | Reforged의 파티클 시스템입니다(`.pkfx` 파일). |
| **충돌 형태** | 박스 또는 구체입니다. 게임은 이것으로 모델을 클릭할 수 있는 위치를 압니다. |
| **익스텐트** | 한 시퀀스에서 모델의 크기입니다. 게임은 이것으로 모델이 화면에 있는지 판단합니다. |
| **교체 가능 텍스처** | 게임이 채워 넣는 텍스처입니다. 예: 팀 색상. |
| **팀 색상 / 팀 글로우** | 유닛에 표시되는 플레이어 색상입니다. |
| **필터 모드** | 머티리얼을 그리는 방식입니다. 불투명, 투명, 가산(빛남) 등. |
| **빌보드** | 항상 카메라 쪽으로 도는 노드입니다. |
| **아트 등급** | 미리보기 창이 보여 주는 그래픽입니다. Classic, Reforged (HD) 또는 Definitive. |
| **WhiteoutFlakes** | 모델을 게임처럼 보여 주는 미리보기 창입니다. |
