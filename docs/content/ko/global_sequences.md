# 글로벌 시퀀스

**글로벌 시퀀스**는 항상 반복되는 애니메이션입니다. 유닛이 어떤 애니메이션을 재생하든 상관없습니다. 멈추지 않는 것에 사용하세요. 예: 회전하는 수정, 타오르는 횃불, 바람에 날리는 깃발.

각 글로벌 시퀀스에는 프레임 단위의 길이가 있습니다. 오브젝트의 키는 일반 타임라인 대신 글로벌 시퀀스에 속할 수 있습니다.

*시퀀스 관리자*의 [[t:seq_globals_btn]] 버튼으로 글로벌 시퀀스 매니저를 엽니다.

[[shot:global_sequences|예제 모델의 글로벌 시퀀스 두 개가 보이는 글로벌 시퀀스 매니저.]]

## 오브젝트를 계속 회전시키기

1. 오브젝트를 선택합니다.
2. **지속 시간**을 설정합니다. 예: 60프레임.
3. **새로 만들기**를 클릭합니다. 타임 슬라이더가 프레임 0으로 가고, 컨트롤러, 채널, 회전 옵션이 나타납니다.
4. **컨트롤러**를 고릅니다. 예: *Linear*. 축도 고릅니다.
5. 타임 슬라이더를 한 바퀴의 마지막 프레임으로 옮깁니다. 예: 60.
6. **> CW**(시계 방향) 또는 **CCW <**(시계 반대 방향)를 클릭합니다.
7. **완료**를 클릭합니다.

이제 오브젝트는 모든 애니메이션에서 60프레임에 한 바퀴씩 돕니다.

직접 애니메이션할 수도 있습니다. **새로 만들기** 뒤에 지속 시간 안에서 평소처럼 오브젝트에 키를 설정하세요. 그런 다음 **완료**를 클릭합니다. WhiteoutDex가 이 키를 새 글로벌 시퀀스로 옮깁니다.

!!! note
    게임은 글로벌 시퀀스를 밀리초 단위로 셉니다. WhiteoutDex가 프레임을 변환해 줍니다.
