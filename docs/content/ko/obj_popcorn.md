# Popcorn FX

**Popcorn FX**는 Warcraft III: Reforged의 파티클 시스템입니다. 이펙트 자체는 PopcornFX 편집기로 만든 `.pkfx`(또는 `.pkb`) 파일입니다. 3ds Max의 Popcorn 오브젝트는 이 이펙트를 모델에 배치하고, 언제 재생할지 제어합니다.

**Create > Helpers > Warcraft III Plugins > Wc3 Popcorn**으로 만듭니다. Popcorn은 **Reforged** 모델에서만 작동합니다.

## Popcorn FX 파일

[[shot:obj_popcorn_r2|Popcorn FX 파일.]]

| 번호 | 기능 |
|---|---|
| [[ctl:9]] | 게임 아카이브에서 `.pkb` 또는 `.pkfx` 이펙트를 고릅니다. |
| [[ctl:10]] | 디스크에서 이펙트 파일을 고릅니다. |
| [[ctl:11]] | 짧은 설명을 보여 줍니다. |

버튼 위의 두 필드에는 이펙트의 경로와 그 앞에 붙는 폴더가 들어 있습니다.

[[shot:obj_popcorn_r3|애니메이션 표시 가이드.]]

| 번호 | 기능 |
|---|---|

| [[ctl:10]] | 씬의 애니메이션을 고릅니다 … |
| [[ctl:12]] | … 그리고 예외로 추가합니다. |
