# 키프레임 최적화

다른 프로그램이나 모션 캡처에서 온 애니메이션은 프레임마다 키가 있는 경우가 많습니다. 그러면 모델이 커집니다. 키프레임 최적화는 필요 없는 키를 제거합니다. 움직임은 거의 그대로 유지됩니다.

**WhiteoutDex > [[t:menu_keyframe_optimizer]]** 메뉴로 엽니다. 먼저 애니메이션된 오브젝트를 선택하세요.

[[shot:keyframe_optimizer|키프레임 최적화.]]

## 설정

| 번호 | 기능 |
|---|---|
| [[ctl:7#2]] | **임계값:** 곡선이 바뀌어도 되는 정도입니다. 값이 높을수록 키를 더 많이 제거합니다. 0.5로 시작하세요. |
| [[ctl:11#2]] | **스텝:** 도구가 측정하는 정밀도(프레임 단위)입니다. 0.49보다 작게 유지하세요. |
| [[ctl:13#2]] | MAXScript Listener에 자세한 내용을 씁니다. 꺼 두세요. 켜면 느려집니다. |

## 최적화

| 번호 | 기능 |
|---|---|
| [[ctl:3]] | 목록을 시간순 또는 이름순으로 정렬합니다. |
| [[ctl:5]] | 모델의 시퀀스입니다. 최적화할 시퀀스를 선택하세요. |
| [[ctl:7]] | 위치 키를 최적화합니다. |
| [[ctl:8]] | 회전 키를 최적화합니다. |
| [[ctl:9]] | 스케일 키를 최적화합니다. |
| [[ctl:14]] | 선택한 시퀀스를 최적화합니다. |
| [[ctl:15]] | 모든 시퀀스를 최적화합니다. |
| [[ctl:16]] | 어떤 시퀀스에도 속하지 않는 키를 삭제합니다. 이 키는 게임에서 아무 일도 하지 않습니다. |

!!! tip
    최적화하기 전에 씬을 저장하세요. 최적화한 뒤에는 애니메이션을 확인하세요. 이상해 보이면 실행 취소하고 더 작은 임계값으로 다시 시도하세요.
