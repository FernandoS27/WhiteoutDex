# 튜토리얼: 나만의 첫 모델

이 강좌에서는 간단한 오브젝트를 처음부터 만듭니다. 맵에 놓을 장식물 같은 나무 상자입니다.

## 1단계: 상자 모델링

1. **Box**를 만듭니다: *Create > Geometry > Box*. 크기는 약 60 × 60 × 60 단위로 합니다. 3ds Max의 1단위는 게임의 1단위입니다.
2. 바닥에 서도록 놓습니다(아래쪽 높이 0). 중심은 0, 0에 둡니다.

## 2단계: 머티리얼 지정

1. Material Editor를 엽니다([[key:M]]).
2. 빈 슬롯을 고르고 머티리얼 유형 버튼을 클릭한 뒤 **Wc3Material**을 고릅니다.
3. *머티리얼 텍스처 맵*에서 **디퓨즈** 버튼을 클릭하고 **Wc3Bitmap**을 고릅니다.
4. **비트맵 선택...**을 클릭해 텍스처를 고릅니다. 또는 **텍스처 브라우저 열기**를 클릭해 게임에서 텍스처를 가져옵니다(`crate` 또는 `wood`로 검색).
5. 머티리얼을 상자 위로 끌어다 놓습니다.

![텍스처 슬롯이 있는 Wc3Material.](mat_wc3material_r3.png)

!!! tip
    이미 Standard 또는 Physical 머티리얼이 있나요? *머티리얼 수정*이 Wc3Material로 변환해 줍니다.

## 3단계: 충돌

플레이어가 상자를 클릭할 수 있어야 합니다.

1. 상자를 선택합니다.
2. **WhiteoutDex > [[t:menu_anim_general]]** 메뉴를 열고 **원클릭 충돌 박스**를 클릭합니다.

## 4단계: Stand 애니메이션

움직임이 없어도 모든 모델에는 시퀀스가 하나 이상 필요합니다.

1. **WhiteoutDex > [[t:menu_sequence_manager]]** 메뉴를 엽니다.
2. **새로 만들기...**를 클릭하고 프리셋 *Stand*를 고른 뒤 **확인**을 클릭합니다.

## 5단계: 내보내기와 테스트

1. 상자를 `Crate.mdx`로 내보냅니다(강좌 *모델 내보내기* 참고).
2. 내보내기 창의 상자를 확인합니다. 노란색이면 [[t:exp_fix_all_btn]]을 클릭합니다.
3. 미리보기 창에서 결과를 봅니다: **WhiteoutDex > [[t:menu_renderer]]**.

첫 Warcraft III 모델을 만들었습니다.
