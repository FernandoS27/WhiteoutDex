# Инструменты объектов

Копируйте и вставляйте позиции, привязки и позиции вершин между объектами. Удобно для симметричных моделей: постройте левую сторону, затем скопируйте её на правую.

Откройте инструменты через **WhiteoutDex > [[t:menu_object_tools]]**.

[[shot:object_tools|Инструменты объектов, выделен меш.]]

## Объекты

| № | Что делает |
|---|---|
| [[ctl:5]] | **Иерархия:** запоминает привязки к родителям у выделенных объектов и отвязывает их. |
| [[ctl:6]] | Привязывает объекты обратно к запомненным родителям. |
| [[ctl:8]] | **Позиция:** копирует позицию первого выделенного объекта. |
| [[ctl:9]] | Перемещает выделенные объекты в скопированную позицию. |
| [[ctl:11]] | **Структура (L↔R):** копирует позиции всех выделенных объектов вместе с их именами. |
| [[ctl:12]] | Вставляет их на объекты с зеркальным именем: позиция, скопированная с `Arm_L`, переходит на `Arm_R`. |
| [[ctl:14]] | Временно отвязывает объекты при вставке, чтобы их дочерние объекты не двигались вместе с ними. |
| [[ctl:15]] | Отражает позицию при вставке по отмеченным осям: [[ctl:16]], [[ctl:17]], [[ctl:18]]. |

## Вершины (Инструменты полигонов)

Сначала выделите вершины в Editable Poly или Editable Mesh. Строка над кнопками показывает объект и число выделенных вершин.

| № | Что делает |
|---|---|
| [[ctl:22]] | Копирует позиции выделенных вершин. |
| [[ctl:23]] | Вставляет позиции на вершины. |
| [[ctl:26]] | Отражает значения X при вставке. [[ctl:27]] и [[ctl:28]] делают то же для Y и Z. |
| [[ctl:29]] | Отражает относительно центра мира. |
| [[ctl:30]] | Отражает относительно опорной точки объекта. |
| [[ctl:31]] | Отражает относительно центра выделения. |
| [[ctl:35]] | Вставляет на вершины с теми же номерами. Используйте это на том же меше или на его копии. |
| [[ctl:36]] | Вставляет на выделенные вершины, даже на другом меше. |

!!! tip
    Называйте объекты с `_L` и `_R` (или `Left` и `Right`). Тогда *Структура (L↔R)* сама находит пару для каждого объекта.
