# Имена анимаций

Warcraft III находит анимацию по её **имени**. Юнит, который атакует, проигрывает анимацию, имя которой начинается с *Attack*. Поэтому имена ваших последовательностей важны.

Имя состоит из **главного слова** и может иметь **дополнительные слова**. Примеры: `Stand`, `Stand Ready`, `Attack Slam`, `Walk Fast`, `Stand - 2`.

## Главные слова

| Имя | Когда игра его проигрывает |
|---|---|
| Stand | Юнит ничего не делает. |
| Walk | Юнит движется. |
| Attack | Юнит атакует. |
| Spell | Юнит произносит заклинание. |
| Death | Юнит умирает. |
| Decay | Мёртвое тело разлагается (*Decay Flesh*, затем *Decay Bone*). |
| Birth | Здание строится или юнит появляется. |
| Dissipate | Призванный юнит или дух исчезает, когда умирает. |
| Portrait | Лицо в окне портрета. *Portrait Talk* проигрывается, пока юнит говорит. |
| Morph | Юнит меняет форму. |
| Sleep | Юнит спит. |
| Cinematic | Используется только в роликах и картах. |

## Дополнительные слова

| Слово | Значение |
|---|---|
| Ready | Готов к бою, например *Stand Ready*. |
| Slam | Сильный удар, например *Attack Slam* или *Spell Slam*. |
| Victory | После выигранного боя. |
| Hit | По юниту попали. |
| Channel | Заклинание, которое длится некоторое время. |
| Throw | Бросает что-то. |
| Fast | Быстрый вариант, например *Walk Fast*. |
| Alternate | Вторая форма юнита, например после *Metamorphosis*. |
| Upgrade First … Fifth | Здание после 1-го – 5-го улучшения. |
| Work, Gold, Lumber | Анимации рабочих. |
| Swim | Движется в воде. |
| Defend | Со включённой способностью *Defend*. |
| Talk | Говорит (вместе с *Portrait*). |

## Много анимаций с одним именем

Может быть несколько анимаций с одним главным словом, например `Stand - 1`, `Stand - 2` и `Stand - 3`. Игра выбирает одну случайно. Значение **редкости** в [[t:menu_sequence_manager]] говорит игре, как часто выбирать анимацию: чем выше значение, тем реже.

## Подходящая длина

В [[t:menu_sequence_manager]] есть шаблоны с такой длиной (при 30 кадрах в секунду):

| Шаблон | Кадры |
|---|---|
| Stand | 80 |
| Walk | 28 |
| Stand Ready | 20 |
| Attack | 24 |
| Attack Slam | 30 |
| Spell | 28 |
| Spell Slam | 24 |
| Death | 64 |
| Portrait Talk | 70 |

!!! note
    *Death*, *Decay*, *Birth* и *Dissipate* проигрываются только один раз. Включите для них **Не зацикливать** в Менеджере секвенций.
