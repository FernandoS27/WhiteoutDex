# Создание анимации текстур

Заставляет текстуры двигаться: текущая вода, горящий огонь из спрайт-листа или перелистывание из многих изображений. Инструмент сам пишет ключи.

Откройте его через **WhiteoutDex > [[t:menu_texture_anim_creator]]**.

Есть три вида анимации:

| Вид | Для чего |
|---|---|
| **Поток** | Текстура скользит, вращается или растёт: вода, лава, энергия. |
| **Спрайт-лист** | Одно изображение со многими маленькими картинками в сетке (*спрайт-лист*). Инструмент показывает их одну за другой. |
| **Кадры (много)** | Папка со многими изображениями. Инструмент показывает их одно за другим (*перелистывание*). |

[[shot:texture_anim_creator|Создание анимации текстур, вкладка «Спрайт-лист».]]

| № | Что делает |

| [[ctl:46]] | Кадр, на котором начинается анимация. |
| [[ctl:50]] | Сколько раз повторяется анимация. |
| [[ctl:54]] | Сколько картинок в одной строке листа. |
| [[ctl:58]] | Сколько строк в листе. |

## Поток

[[shot:texture_anim_flow|Поток.]]

1. Задайте время начала и конца.
2. Нажмите стрелки направления, в котором движется текстура. Текстуру также можно вращать (влево, вправо) и увеличивать или уменьшать (+, −).
3. Для текстуры, которая движется всегда, включите *Глобальная анимация* (ВКЛ).
4. Нажмите **Создать анимацию**.

## Кадры (много)

[[shot:texture_anim_many|Кадры (много).]]

1. Выберите папку с изображениями (кнопка **...**). Изображения используются в порядке их имён.
2. Задайте порядок воспроизведения, скорость и начальный кадр.
3. Задайте префикс пути, например `Textures\`. Модель использует этот путь для каждого изображения.
4. Нажмите **Создать анимацию**.

!!! tip
    Ключи текстуры находятся на *Wc3Bitmap* (UV-анимация) или на *Wc3Material* (перелистывание). Чтобы изменить их позже, ищите там.
