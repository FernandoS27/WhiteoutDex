# Смена скинов

Подготавливает скин ваших мешей для Warcraft III.

Откройте его через **WhiteoutDex > [[t:menu_skin_changer]]**. Сначала выделите меши со скином.

[[shot:skin_changer|Смена скинов.]]

| № | Что делает |
|---|---|
| [[ctl:3]] | Меняет скин так, чтобы у каждой вершины было не больше 5 костей с чистыми весами. Это можно отменить. |
| [[ctl:7]] | Веса, равные этому значению или меньше, удаляются. 0.0 удаляет только веса, которые точно равны нулю. |
| [[ctl:8]] | Удаляет маленькие веса и распределяет их долю на другие кости вершины. |
| [[ctl:11]] | Объединяет выделенные меши со скином и одинаковым материалом в один меш с одним Skin. Кости, веса и поза остаются прежними, поэтому меш двигается точно как раньше. Это можно отменить. |

!!! tip
    Меньше мешей – быстрее модель. Используйте *Объединить меш + Skin*, когда в модели много маленьких частей с одной текстурой.
