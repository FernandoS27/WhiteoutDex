# Глобальные последовательности

**Глобальная последовательность** – это анимация, которая повторяется всё время, какую бы анимацию ни проигрывал юнит. Используйте её для того, что никогда не останавливается: вращающийся кристалл, горящий факел, флаг на ветру.

У каждой глобальной последовательности есть длина в кадрах. Ключи объекта могут принадлежать глобальной последовательности, а не обычной шкале времени.

Откройте Менеджер глобальных последовательностей кнопкой [[t:seq_globals_btn]] в *Менеджере секвенций*.

[[shot:global_sequences|Менеджер глобальных последовательностей с двумя глобальными последовательностями модели-примера.]]

## Как заставить объект вращаться всё время

1. Выделите объект.
2. Задайте **Длительность**, например 60 кадров.
3. Нажмите **Новый**. Ползунок времени переходит на кадр 0, и появляются параметры контроллера, каналов и вращения.
4. Выберите **Контроллер**, например *Linear*, и ось.
5. Переместите ползунок времени на последний кадр одного оборота, например 60.
6. Нажмите **> ЧС** (по часовой стрелке) или **ПЧС <** (против часовой стрелки).
7. Нажмите **Готово**.

Теперь объект делает один оборот за 60 кадров, в каждой анимации.

Можно анимировать и вручную: после **Новый** поставьте ключи на объекте как обычно в пределах длительности, затем нажмите **Готово**. WhiteoutDex переносит эти ключи в новую глобальную последовательность.

!!! note
    Игра считает глобальные последовательности в миллисекундах. WhiteoutDex сам пересчитывает кадры.
