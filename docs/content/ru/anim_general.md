# Анимация: общие инструменты

Небольшие помощники, которые экономят время, когда вы анимируете или заканчиваете модель.

Откройте их через **WhiteoutDex > [[t:menu_anim_general]]**.

[[shot:anim_general|Общие инструменты.]]

| № | Что делает |
|---|---|
| [[ctl:4]] | Добавляет выделенным объектам ключи на кадре 0, а также в начале и в конце каждой последовательности. Тогда одна анимация не меняет следующую. |
| [[ctl:6]] | Применяет инструмент TCB к ключам позиции. |
| [[ctl:7]] | … к ключам вращения. |
| [[ctl:8]] | … к ключам масштаба. |
| [[ctl:9]] | Устанавливает *Continuity* в 0 на текущих ключах выделенных объектов. Это убирает выброс ключей TCB. |
| [[ctl:11]] | Ключи вращения с поворотом больше 90° между двумя ключами могут выглядеть в игре неправильно. Этот инструмент добавляет ключ посередине. Для очень больших поворотов (больше 180°) запустите его ещё раз. |
| [[ctl:13]] | Создаёт точки крепления для костей с известными именами (например *Head*, *Chest*, *Hand*). |
| [[ctl:14]] | Создаёт камеру портрета, которая смотрит на выделенный объект. Если ничего не выделено, она смотрит на верх модели. |
| [[ctl:15]] | Создаёт две сферы столкновений по размеру модели, как Blizzard делает для юнитов. |
| [[ctl:16]] | Создаёт один блок столкновений по размеру модели, как Blizzard делает для зданий. |

!!! tip
    Используйте инструменты **в один клик** на готовой модели. Они измеряют модель, поэтому лучше всего работают, когда у неё окончательный размер.
