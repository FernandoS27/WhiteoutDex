# Импорт из игры

Вы можете импортировать модель прямо из вашей игры Warcraft III, без файла на диске.

1. Выберите **WhiteoutDex > [[t:menu_import_casc]]**.
2. Откроется браузер игры. Найдите модель, например введите в поиск `footman`.
3. Щёлкните по модели, затем нажмите **Select**.
4. Откроется обычное окно импорта (см. *Импортёр*). Выберите параметры и нажмите **Импортировать**.

WhiteoutDex копирует модель и её текстуры во временную папку и импортирует её оттуда. Файлы вашей игры не меняются.

!!! tip
    Чтобы изменить модель из игры, импортируйте её этим способом, измените и экспортируйте под новым именем в папку вашей карты или мода.

!!! note
    Модели из игры принадлежат Blizzard Entertainment. Используйте их только так, как разрешает Blizzard, например в картах и модах для Warcraft III.
