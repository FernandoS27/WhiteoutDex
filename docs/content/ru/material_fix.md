# Исправление материалов

Экспортёр понимает только **Wc3Material**. «Исправление материалов» преобразует другие материалы (Standard, Physical, PBR) в Wc3Material. Он сохраняет текстуры и устанавливает параметры Warcraft III, которые вы выбираете здесь.

Те же настройки использует кнопка [[t:exp_fix_all_btn]] в окне экспорта.

Откройте его через **WhiteoutDex > [[t:menu_material_fix]]**.

[[shot:material_fix|Исправление материалов с настройками для классических моделей (SD).]]

Есть два набора настроек: один для классических моделей (**SD**) и один для Reforged (**HD**).

| № | Что делает |
|---|---|
| [[ctl:4]] | Настройки для классических моделей. |
| [[ctl:5]] | Настройки для моделей Reforged. |

## Отображение

| № | Что делает |
|---|---|
| [[ctl:8]] | Как рисуется материал. *Авто* делает материалы с альфа-каналом прозрачными. Все режимы описаны на странице *Wc3Material*. |
| [[ctl:10]] | Рисуются обе стороны граней. |
| [[ctl:11]] | Материал не реагирует на свет. |
| [[ctl:12]] | Материал не реагирует на туман. |
| [[ctl:13]] | Один цвет для всего меша. |
| [[ctl:14]] | Рисуется поверх всего (без теста глубины). |
| [[ctl:15]] | Не скрывает то, что находится за ним. |
| [[ctl:16]] | Использует фоновое затенение (только Reforged). |
| [[ctl:17]] | Задние грани отбрасывают тени (только Reforged). |
| [[ctl:18]] | Берёт двусторонность, отсутствие затенения и прозрачность из старого материала, а не из флажков выше. |

## Текстуры

| № | Что делает |
|---|---|
| [[ctl:23]] | Папка, которая ставится перед именами текстур в модели, например `Textures\`. |
| [[ctl:26]] | Как повторяются текстуры: как в старом материале, в обе стороны, только U, только V или совсем не повторяются. |
| [[ctl:28]] | Карта нормалей или рельефа становится картой *Normal* (Reforged). |
| [[ctl:29]] | Карта свечения становится картой *Emissive* (Reforged). |
