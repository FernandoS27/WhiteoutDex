# Установка

Один установщик добавляет WhiteoutDex во все версии 3ds Max на вашем компьютере (от 2016 до 2027).

## Установить

1. Закройте 3ds Max.
2. Скачайте новейший `WhiteoutDex_Setup_v<version>.exe`. Он есть на странице **Releases** на GitHub и на Hive Workshop.
3. Запустите установщик. Windows запросит права администратора. Нажмите **Да**.
4. Выберите язык и выполните шаги. Установщик сам находит все ваши версии 3ds Max.
5. Запустите 3ds Max. Теперь вы видите меню **WhiteoutDex** и боковую панель WhiteoutDex.

!!! note
    Для 3ds Max 2026 и новее нужен **.NET 8**. Если его нет, установщик сообщит об этом.

## Куда попадают файлы

WhiteoutDex устанавливается в одну папку:

`C:\ProgramData\Autodesk\ApplicationPlugins\WhiteoutDex`

3ds Max загружает всё оттуда. Вам не нужно копировать файлы вручную.

Ваши личные настройки (язык, папки игры, последние параметры экспорта) хранятся в папке настроек 3ds Max `plugcfg`. При обновлении WhiteoutDex они сохраняются.

## Обновление

WhiteoutDex может проверять новые версии при запуске 3ds Max (3ds Max 2018 и новее). Когда выходит новая версия, он спрашивает вас:

- Нажмите **Да**, чтобы скачать и установить её. 3ds Max закроется для обновления.
- Нажмите **Нет**, чтобы продолжить работу. Вопрос повторится на следующий день.

Эту проверку можно выключить или запустить сразу в [[t:menu_settings]].

## Удаление

Откройте **Параметры Windows > Приложения**, найдите **WhiteoutDex** и нажмите **Удалить**.
