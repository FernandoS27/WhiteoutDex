# Браузер игры

Браузер игры показывает файлы внутри вашей игры Warcraft III: модели, текстуры и эффекты частиц. Вы видите маленькую картинку каждого файла, поэтому быстро находите нужное.

Он открывается из многих мест:

| Где | Кнопка | Что вы выбираете |
|---|---|---|
| Меню WhiteoutDex | [[t:menu_import_casc]] | модель для импорта |
| Точка крепления | *Обзор архивов игры* | модель для точки крепления |
| Particle Emitter 1 | *Browse Game Archives* | модель для частиц |
| Particle Emitter 2 | *Обзор MPQ / CASC* | текстуру для частиц |
| Popcorn FX | *Обзор игровых архивов* | эффект `.pkb` или `.pkfx` |
| Wc3Bitmap | *Открыть браузер текстур* | текстуру |
| Wc3Material | кнопка ⚙ рядом с картой | текстуру для этого слота |

## Как пользоваться

1. Введите часть имени в поле поиска, например `footman`.
2. Переключайтесь между **сеткой** (картинки) и **деревом** (папки).
3. Увеличивайте или уменьшайте картинки.
4. Щёлкните по файлу. Строка внизу показывает выбранный файл.
5. Нажмите **Select**.

!!! note
    Браузеру нужны папки вашей игры. Укажите их в [[t:menu_settings]]. Классические модели берутся из архивов MPQ, файлы Reforged – из CASC.
