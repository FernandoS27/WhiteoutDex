# Создание сел-шейдинга

Даёт мешу мультяшный контур. Инструмент создаёт вокруг меша немного увеличенную копию, у которой грани вывернуты наизнанку. В игре вы видите тёмную линию вокруг модели.

Откройте его через **WhiteoutDex > [[t:menu_cell_shade]]**. Сначала выделите меши.

[[shot:cell_shade|Создание сел-шейдинга.]]

| № | Что делает |
|---|---|
| [[ctl:4]] | Цвет контура. Щёлкните, чтобы выбрать другой цвет. |
| [[ctl:6]] | Быстрые цвета. Щёлкните по цвету, чтобы использовать его. |
| [[ctl:19]] | Толщина контура. |
| [[ctl:21]] | Выворачивает грани копии наизнанку. Так получается контур (обычный выбор). |
| [[ctl:22]] | Оставляет грани как есть. |
| [[ctl:25]] | Контур сплошной. |
| [[ctl:26]] | Контур использует прозрачность текстуры. |
| [[ctl:27]] | Контур светится (добавляет свет). |
| [[ctl:28]] | Контур светится и использует прозрачность текстуры. |
| [[ctl:30]] | Создаёт контур для выделенных мешей. |

!!! tip
    Контур – это обычный меш с материалом *Wc3Material*. Позже вы можете изменить его цвет или толщину, как у любого другого меша.
