# Эмиттер лент

Эмиттер лент рисует **след** за движущейся точкой: световой след взмаха меча, хвост кометы, дым ракеты. Привяжите его к движущейся кости, например к оружию.

Создайте его через **Create > Geometry > Particle Systems > Wc3Ribbon**.

## Параметры материала ленты

[[shot:obj_ribbon_r1|Параметры материала ленты.]]

| № | Что делает |
|---|---|
| [[ctl:1079]] | Материал следа (*Wc3Material*). Щёлкните, чтобы поместить его в Material Editor. |
| [[ctl:1073]] | Текстура – это сетка картинок: число строк (1, 2, 4, 8 …) … |
| [[ctl:1075]] | … и столбцов (1, 2, 4, 8 …). |
| [[ctl:1077]] | Какую картинку из сетки показывает след. Анимируйте это значение, чтобы след мерцал. |

## Свойства ленты

[[shot:obj_ribbon_r2|Свойства ленты.]]

| № | Что делает |
|---|---|
| [[ctl:1066]] | Цвет следа. |
| [[ctl:1059]] | Насколько след выходит над эмиттером. |
| [[ctl:1067]] | Насколько он выходит под эмиттером. Сверху + снизу = ширина следа. |
| [[ctl:1080]] | Прозрачность: 0 = невидимый, 1 = сплошной. Анимируйте до 0, чтобы скрыть след. |
| [[ctl:1069]] | Сколько частей следа появляется в секунду. Чем больше частей, тем плавнее след. |
| [[ctl:1071]] | Сколько секунд остаётся одна часть. Чем дольше жизнь, тем длиннее след. |
| [[ctl:1082]] | Тянет след вниз. |
| [[ctl:1090]] | **Контроллер:** как анимированное значение меняется между ключами. У каждого значения свой контроллер. |

!!! tip
    Для следа меча: эмиттер на клинке, материал *Аддитивный*, альфа 0 везде, кроме взмаха, время жизни около 0.2 секунды.
