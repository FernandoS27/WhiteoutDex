# Wc3Bitmap

**Wc3Bitmap** – это текстурная карта WhiteoutDex. Помещайте её в слоты материала *Wc3Material*. Она читает `.blp`, `.dds`, `.tga`, `.png` и другие форматы изображений 3ds Max. В ней хранятся анимация текстуры (UV-анимация) и путь текстуры в игре.

## Параметры текстуры WC3

[[shot:mat_wc3bitmap_r1|Параметры текстуры WC3.]]

| № | Что делает |
|---|---|
| [[ctl:6]] | Выбрать файл изображения на диске. |
| [[ctl:7]] | Выбрать текстуру из архивов игры. |
| [[ctl:9]] | Использует текстуру, которую подставляет игра (цвет команды, свечение команды, утёс, деревья). |
| [[ctl:12]] | Текстура повторяется по ширине. |
| [[ctl:13]] | Текстура повторяется по высоте. |
| [[ctl:14]] | Использует текстуру как отражение (сферическая карта окружения). |

## UV-анимация (TXAN)

[[shot:mat_wc3bitmap_r2|UV-анимация.]]

Анимируйте эти значения, чтобы текстура двигалась. *Создание анимации текстур* может задать их за вас.

| № | Что делает |
|---|---|
| [[ctl:3]] | Как значения меняются между ключами. |
| [[ctl:8]] | Сдвигает текстуру в сторону (U). |
| [[ctl:11]] | Сдвигает текстуру вверх и вниз (V). |
| [[ctl:14]] | Смещение W. |
| [[ctl:17]] | Поворачивает текстуру. |
| [[ctl:20]] | Повторяет текстуру чаще или реже по горизонтали. |
| [[ctl:23]] | Повторяет текстуру чаще или реже по вертикали. |

## Префикс пути

[[shot:mat_wc3bitmap_r3|Префикс пути.]]

Префикс – это папка, которую экспортёр пишет перед именем текстуры, например `Textures\` или `war3mapImported\`.

| № | Что делает |
|---|---|
| [[ctl:5]] | Выбрать сохранённый префикс. |
| [[ctl:6]] | Изменить список сохранённых префиксов. |

!!! tip
    Текстуры в карте должны использовать префикс, который использует карта. Для своих моделей в картах это обычно `war3mapImported\`.
