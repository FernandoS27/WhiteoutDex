# Настройки объекта

У объектов Warcraft III есть дополнительные настройки, которых нет в 3ds Max, например *биллборд*. Инструмент «Настройки объекта» устанавливает их на выделенных объектах. WhiteoutDex сохраняет их в объекте (как пользовательские свойства), а экспортёр записывает их в модель.

Откройте его через **WhiteoutDex > [[t:menu_object_settings]]**. Сначала выделите один или несколько объектов.

[[shot:object_settings|Настройки объекта, выделена кость.]]

## Флаги

| № | Что делает |
|---|---|
| [[ctl:4]] | Объект не перемещается вместе с родителем. |
| [[ctl:5]] | Объект не вращается вместе с родителем. |
| [[ctl:6]] | Объект не масштабируется вместе с родителем. |
| [[ctl:7]] | Объект всегда повёрнут к камере. Подходит для свечений и плоских эффектов. |
| [[ctl:8]] | Повёрнут к камере, но вращается только вокруг оси X. |
| [[ctl:9]] | … только вокруг оси Y. |
| [[ctl:10]] | … только вокруг оси Z. |
| [[ctl:11]] | Объект остаётся на месте в поле зрения камеры. |

## Меш

| № | Что делает |
|---|---|
| [[ctl:13]] | **Обычный скиннинг:** использует модификатор Skin или привязанные кости. |
| [[ctl:14]] | **Скиннинг ArtTools:** соединяет вершины отдельных мешей при экспорте. Используйте его только на мешах, которые должны плавно переходить друг в друга. |
| [[ctl:17]] | Игрок не может щёлкнуть по этому мешу в игре. |
