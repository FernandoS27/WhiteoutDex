# Эмиттер частиц 1

Particle Emitter 1 выпускает не картинки, а **маленькие модели**. Используйте его для падающих листьев, камней или стрел, которые сами являются моделями.

Создайте его через **Create > Geometry > Particle Systems > Wc3Particles1**.

## Particle Configuration

[[shot:obj_particles1_r1|Свиток Particle Configuration.]]

| № | Что делает |
|---|---|
| [[ctl:2020]] | Загружает все настройки из файла `.ini`. |
| [[ctl:2021]] | Сохраняет все настройки в файл `.ini`. |
| [[ctl:2022]] | Если включено, *Import* загружает также анимированные ключи значений. |

## Emitter Options

[[shot:obj_particles1_r2|Свиток Emitter Options.]]

| № | Что делает |
|---|---|
| [[ctl:5002]] | Как быстро разлетаются модели. |
| [[ctl:5004]] | Угол направления вверх и вниз. |
| [[ctl:5006]] | Угол направления в сторону. |
| [[ctl:5008]] | Тянет модели вниз. |
| [[ctl:2030]] | **Control:** как анимированное значение меняется между ключами. У каждого значения свой элемент Control. |

## Timing Options

[[shot:obj_particles1_r3|Свиток Timing Options.]]

| № | Что делает |
|---|---|
| [[ctl:5010]] | Сколько секунд живёт одна модель. |
| [[ctl:5012]] | Сколько моделей появляется в секунду. |

## Model Options

[[shot:obj_particles1_r4|Свиток Model Options.]]

| № | Что делает |
|---|---|
| [[ctl:5017]] | Папка модели внутри игры. |
| [[ctl:5016]] | Имя файла модели, например `Abilities\Weapons\Arrow\ArrowMissile.mdl`. |
| [[ctl:2024]] | Выбрать модель из архивов игры. |
| [[ctl:2023]] | Выбрать файл модели на диске. |
| [[ctl:5014]] | Размер моделей в предпросмотре во вьюпорте. |

!!! note
    Классические модели часто пишут в этом пути расширение `.mdl`, даже если в игре файл `.mdx`. Игра находит оба.
