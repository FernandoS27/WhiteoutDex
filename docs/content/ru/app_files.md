# Файлы и настройки

На этой странице перечислено, где WhiteoutDex хранит свои файлы. Обычно открывать их не нужно. Они помогают, когда что-то идёт не так или когда вы переходите на новый компьютер.

## Папка установки

`C:\ProgramData\Autodesk\ApplicationPlugins\WhiteoutDex`

| Папка или файл | Что в ней |
|---|---|
| `native plugins\Max<year>\` | Плагины для каждой версии 3ds Max (импортёр, экспортёр, частицы, ленты, окно предпросмотра, чтение BLP). |
| `scripts\` | Инструменты WhiteoutDex (MAXScript). |
| `lang\` | Переводы окна предпросмотра. |
| `whiteoutdex_icons\` | Значки боковой панели и инструментов. |
| `maps\WhiteoutDex\TeamGlow\` | Текстуры свечения команды. |
| `version.txt` | Установленная версия. |

Не меняйте файлы здесь. Обновление заменяет их.

## Ваши настройки

Ваши настройки находятся в папке настроек 3ds Max **plugcfg**. Чтобы найти её, откройте MAXScript Listener ([[key:F11]]) и введите `getDir #plugcfg`.

| Файл | Что хранит |
|---|---|
| `WhiteoutDex_Settings.ini` | Язык, папку Reforged, порядок MPQ, боковую панель, проверку обновлений. |
| `WhiteoutDexMPQ.ini` | Папку классической игры. |
| `WhiteoutDexImporter.ini` | Ваши последние параметры импорта. |
| `MDLXExporter.ini` | Ваши последние параметры экспорта. |
| `WhiteoutDex_MaterialFix.ini` | Настройки *Исправление материалов* для SD и HD. |

!!! tip
    Чтобы вернуть WhiteoutDex в состояние первого запуска, закройте 3ds Max и удалите эти файлы. WhiteoutDex создаст новые со значениями по умолчанию.

## Окно предпросмотра

| Файл | Что хранит |
|---|---|
| `WhiteoutFlakes.ini` (рядом с `3dsmax.exe`) | Настройки окна предпросмотра WhiteoutFlakes. |

## Файлы журнала

Когда что-то идёт не так, эти файлы показывают, что произошло. Они находятся в вашей временной папке. Чтобы открыть её, нажмите [[key:Win+R]], введите `%TEMP%` и нажмите [[key:Enter]].

| Файл | Кто его пишет |
|---|---|
| `mdlx_import_debug.log` | Импортёр |
| `mdlx_export_debug.log` | Экспортёр, с полным списком предупреждений |
| `WhiteoutDex_render.log` | Окно предпросмотра WhiteoutFlakes |

Прикладывайте эти файлы, когда сообщаете о проблеме.
