# Точка крепления

Точка крепления отмечает место на модели. Игра прикрепляет туда разные вещи: оружие героя, эффект заклинания на руке, стрелу, которая попадает в грудь, полосу здоровья над головой.

Создайте её через **Create > Helpers > Warcraft III Plugins > Wc3 AttachPoint**. Привяжите её к кости, за которой она должна следовать.

Во вьюпорте каждая точка крепления показывает своё имя жёлтым цветом.

## Общие функции

[[shot:obj_attachpoint_r1|Общие функции.]]

| № | Что делает |
|---|---|
| [[ctl:3]] | Нажмите эту кнопку, затем щёлкните по объекту во вьюпорте. Точка крепления переходит к этому объекту и привязывается к нему. |

## Параметры карты модели

[[shot:obj_attachpoint_r2|Параметры карты модели.]]

Точка крепления может нести свою модель, например меч, который юнит держит всегда.

| № | Что делает |
|---|---|
| [[ctl:9]] | Выбрать файл модели на диске. |
| [[ctl:10]] | Выбрать модель из архивов игры. |

Два поля над кнопками содержат папку и имя файла. Путь указывается относительно папки Warcraft III, например `Textures\Model.mdx`.

## Параметры точки крепления

[[shot:obj_attachpoint_r3|Параметры точки крепления.]]

Игра находит точку крепления по её **имени**. Имя складывается из четырёх частей:

| № | Что делает |
|---|---|
| [[ctl:5]] | **Тип:** основное место: *Head*, *Overhead*, *Origin*, *Foot*, *Chest*, *Hand*, *Weapon* или *Sprite*. |
| [[ctl:8]] | **Верхом:** для всадников на ездовом животном. |
| [[ctl:11]] | **Сторона:** *Left* или *Right*, для рук и ног. |
| [[ctl:14]] | **Дополнительно:** другие слова, например *Rear*, *Alternate*, *RallyPoint*, *Gold* или *First* … *Sixth* для зданий. |
| [[ctl:22]] | Использует модель из свитка *Параметры карты модели*. |
| [[ctl:26]] | Видимость (от 0 до 1). Анимируйте её, чтобы показать или скрыть прикреплённую модель. |
| [[ctl:27]] | Показывает, относительно чего указан путь модели. |
| [[ctl:34]] | Номер точки крепления. |
| [[ctl:36]] | Записывает этот номер в модель. |

Пример: тип *Hand* и сторона *Right* дают имя `Hand Right Ref`. Туда игра ставит эффект заклинания для правой руки.

!!! tip
    Инструмент *Точки крепления в один клик* в *Анимация: общие инструменты* сам создаёт обычные точки крепления, если у ваших костей известные имена.
