# Менеджер секвенций

Модель Warcraft III хранит все свои анимации на одной шкале времени. Каждая анимация – это **последовательность**: имя, начальный кадр и конечный кадр. Менеджер секвенций создаёт и изменяет эти последовательности.

Откройте его через **WhiteoutDex > [[t:menu_sequence_manager]]** или кнопкой **Sequence** на боковой панели.

[[shot:sequence_manager_selected|Менеджер секвенций с выбранной последовательностью «Stand - 1».]]

## Список

| № | Что делает |
|---|---|
| [[ctl:4]] | Введите слово, чтобы показать только последовательности с этим словом в имени. |
| [[ctl:6]] | Очищает поле поиска и снова показывает все последовательности. |
| [[ctl:7]] | Все последовательности модели. Щёлкните, чтобы выбрать одну. Удерживайте [[key:Ctrl]], чтобы выбрать несколько. **Дважды щёлкните** последовательность, чтобы проиграть её во вьюпорте. Строки вида `[GLOBAL 1]` – это глобальные последовательности. |
| [[ctl:10]] | Выбирает все последовательности. |
| [[ctl:11]] | Снимает выбор со всех. |
| [[ctl:12]] | Выбирает невыбранные и снимает выбор с выбранных. |

## Создание и удаление

| № | Что делает |
|---|---|
| [[ctl:14]] | Создаёт новую последовательность (см. ниже). |
| [[ctl:15]] | Удаляет выбранные последовательности. Ключи анимации остаются на шкале времени. |
| [[ctl:16]] | Копирует выбранные последовательности. |
| [[ctl:17]] | Открывает *Менеджер глобальных последовательностей*. |

## Изменение выбранной последовательности

| № | Что делает |
|---|---|
| [[ctl:20]] | Имя. По имени игра знает, когда проигрывать анимацию. См. *Имена анимаций*. |
| [[ctl:23]] | Берёт текущий кадр ползунка времени как начальный кадр. |
| [[ctl:26]] | Первый кадр последовательности. |
| [[ctl:28]] | Берёт текущий кадр как конечный кадр. |
| [[ctl:31]] | Последний кадр последовательности. |
| [[ctl:32]] | **Редкость** (0–40). Для анимаций с одинаковым именем: чем выше значение, тем реже игра проигрывает эту анимацию. |
| [[ctl:36]] | **Скорость движения** (0–700). Как быстро движется юнит, когда проигрывает эту анимацию ходьбы. У большинства юнитов от 250 до 400. |
| [[ctl:40]] | Анимация проигрывается один раз и не повторяется. Используйте это для *Death*, *Attack* и *Spell*. |
| [[ctl:41]] | Экспортёр пропускает эту последовательность. |
| [[ctl:44]] | Сдвигает начальный кадр на один кадр раньше. Кнопка [[ctl:45]] сдвигает его на один кадр позже. |
| [[ctl:47]] | Сдвигает конечный кадр на один кадр раньше. Кнопка [[ctl:48]] сдвигает его на один кадр позже. |

## Сохранение и загрузка

| № | Что делает |
|---|---|
| [[ctl:50]] | Загружает последовательности из текстового файла. |
| [[ctl:51]] | Сохраняет последовательности в текстовый файл. Так их можно перенести в другую сцену. |

## Создание последовательности

[[shot:sequence_new|Окно новой последовательности.]]

1. Нажмите [[t:seq_new_btn]].
2. Выберите шаблон, например *Walk*. Шаблон задаёт подходящее имя и длину.
3. Проверьте имя и кадры. Новая последовательность начинается после последней.
4. Нажмите **OK**.

| № | Что делает |
|---|---|
| [[ctl:4]] | Шаблоны для обычных анимаций или *Custom*. |
| [[ctl:7]] | Имя новой последовательности. |
| [[ctl:12]] | Первый кадр. |
| [[ctl:16]] | Последний кадр. |
| [[ctl:17]] | Включает значение редкости. |
| [[ctl:21]] | Включает скорость движения. |
| [[ctl:25]] | Анимация проигрывается только один раз. |

!!! tip
    Оставляйте несколько пустых кадров между двумя последовательностями. Тогда ключи одной анимации не меняют следующую.

!!! note
    WhiteoutDex сохраняет последовательности в вашем файле `.max`. Старые сцены с последовательностями в *note tracks* тоже работают: WhiteoutDex читает и их.
