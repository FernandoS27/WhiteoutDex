# Создание сетки и пустышек

Создаёт сетку для оценки размера и точечные хелперы.

Откройте его через **WhiteoutDex > [[t:menu_grid_dummy]]**.

[[shot:grid_dummy|Создание сетки и пустышек.]]

| № | Что делает |
|---|---|
| [[ctl:4]] | Цвет сетки. |
| [[ctl:8]] | Размер сетки в единицах мира. |
| [[ctl:9]] | Создаёт сетку в центре сцены (0, 0, 0). |
| [[ctl:11]] | Цвет точек. |
| [[ctl:15]] | Размер точек. |
| [[ctl:16]] | Создаёт точку у каждого выделенного объекта. Если ничего не выделено, создаёт одну точку в центре. |
