# Менеджер узлов

В модели много видов объектов: меши, кости, хелперы, эмиттеры и другие. Менеджер узлов показывает, скрывает или замораживает сразу все объекты одного вида.

Откройте его через **WhiteoutDex > [[t:menu_node_manager]]**.

[[shot:node_manager|Менеджер узлов.]]

## 1. Выберите виды

| № | Вид |
|---|---|
| [[ctl:4]] | Меши. |
| [[ctl:5]] | Кости 3ds Max. |
| [[ctl:6]] | Кости рига Biped. |
| [[ctl:7]] | Кости рига CAT. |
| [[ctl:8]] | Хелперы и пустышки. |
| [[ctl:9]] | Точки крепления. |
| [[ctl:10]] | Объекты событий. |
| [[ctl:11]] | Источники света. |
| [[ctl:12]] | Камеры. |
| [[ctl:13]] | Эмиттеры частиц 1. |
| [[ctl:14]] | Эмиттеры частиц 2. |
| [[ctl:15]] | Эмиттеры лент. |
| [[ctl:16]] | Эмиттеры Popcorn FX. |
| [[ctl:17]] | Объекты FaceFX. |
| [[ctl:18]] | Формы столкновений. |
| [[ctl:27]] | Отмечает все виды. [[ctl:28]] снимает все отметки, [[ctl:29]] меняет каждую отметку на противоположную. |

## 2. Сделайте с ними что-нибудь

| № | Что делает |
|---|---|
| [[ctl:20]] | Показывает объекты. |
| [[ctl:21]] | Скрывает объекты. |
| [[ctl:22]] | Замораживает объекты, чтобы их нельзя было случайно выделить. |
| [[ctl:23]] | Размораживает объекты. |
| [[ctl:24]] | Показывает объекты прозрачными. |
| [[ctl:25]] | Снова показывает объекты сплошными. |

!!! tip
    Скрывайте все хелперы, кости и эмиттеры, пока работаете с мешем. Замораживайте кости, пока рисуете веса скина.
