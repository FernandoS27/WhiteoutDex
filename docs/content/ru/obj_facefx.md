# FaceFX

**FaceFX** двигает лицо героев Reforged, когда они говорят: рот, глаза и брови следуют за голосом. Данные хранятся в файле `.facefx_ingame`. Объект FaceFX связывает этот файл с моделью.

Создайте его через **Create > Helpers > Warcraft III Plugins > Wc3 FaceFX**. FaceFX работает только в моделях **Reforged**.

[[shot:obj_facefx_r2|Настройки FaceFX.]]

| № | Что делает |
|---|---|
| [[ctl:9]] | Выбрать файл `.facefx_ingame`. |
| [[ctl:10]] | Показывает короткое описание. |

Два поля содержат **имя цели** (имя, которое игра использует для этого лица) и **путь файла**.

!!! note
    Импортёр переносит объекты FaceFX из моделей Reforged в сцену. Экспортёр записывает их обратно без изменений.
