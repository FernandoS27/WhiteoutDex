# Экспортёр

Экспортёр сохраняет вашу сцену как модель Warcraft III (`.mdx` или `.mdl`). Он также может конвертировать ваши текстуры в форматы игры.

## Открыть экспортёр

- Меню **WhiteoutDex > [[t:menu_exporter]]**
- Кнопка **Export** на боковой панели WhiteoutDex
- **File > Export**, затем выберите *Warcraft III MDX/MDL Model*

Выберите имя файла. Затем откроется окно экспорта.

## Окно экспорта

[[shot:exporter|Окно экспорта с вкладкой «Геометрия».]]

Вверху окна видно имя файла. Под ним видно, новый ли это файл или файл с таким именем уже есть.

| № | Что делает |
|---|---|
| [[ctl:1001]] | **Имя модели.** Имя внутри файла. Игра его не показывает, но другие программы показывают. |
| [[ctl:1011]] | Экспорт для классической игры (MDX версии 800). Текстуры становятся файлами `.blp`. |
| [[ctl:1012]] | Экспорт для Reforged (MDX версии 1800). Текстуры становятся файлами `.dds`. |
| [[ctl:1015]] | Показывает параметры меша (этот рисунок). |
| [[ctl:1016]] | Показывает параметры текстур. |
| [[ctl:1021]] | Объединяет меши с одинаковым материалом в один. Модель становится меньше и быстрее. |
| [[ctl:1027]] | Выравнивает нормали там, где касаются два меша. Это скрывает швы. Не используйте это, если вы делаете жёсткие рёбра группами сглаживания. |
| [[ctl:1028]] | Экспортирует также кости и хелперы, которые ничем не используются. Обычно экспортёр их пропускает. |
| [[ctl:1032]] | Меняет веса скина так, чтобы они работали в классической игре. Классическая игра понимает только простые веса. Только для [[t:exp_format_classic_title]]. |
| [[ctl:1030]] | Если файл уже есть, экспортёр добавляет к имени `_1`, `_2` и так далее. Ваш старый файл остаётся. |
| [[ctl:1031]] | Открывает папку файла после экспорта. |
| [[ctl:1]] | Запускает экспорт. |
| [[ctl:2]] | Закрывает окно без экспорта. |

Зелёное поле под параметрами говорит, что WhiteoutDex не нашёл проблем в вашей сцене. Если он находит проблемы, поле жёлтое. См. *Проблемы сцены и «Исправить все»*.

### Вкладка «Текстуры»

[[shot:exporter_textures|Вкладка «Текстуры», здесь для классического экспорта.]]

| № | Что делает |
|---|---|
| [[ctl:1060]] | Конвертирует текстуры ваших материалов в `.blp` (Классика) или `.dds` (Reforged) и сохраняет их рядом с моделью. |
| [[ctl:1071]] | **Только Классика.** [[t:exp_blp_paletted_item]] или *JPEG*. В JPEG больше цветов. Файлы с палитрой меньше. Для JPEG вы также задаёте качество (1–100). |
| [[ctl:1075]] | Немного смешивает цвета. Это скрывает резкие переходы между цветами в текстурах с палитрой. |
| [[ctl:1061]] | Создаёт уменьшенные версии текстуры, которые игра использует для далёких моделей. Оставьте включённым. |
| [[ctl:1062]] | Заменяет уже существующие файлы текстур. Если выключено, экспортёр оставляет существующие файлы. |

Для **Reforged** вместо этого вы выбираете формат DDS: *BC3 (DXT5)* или *BC7*. BC7 выглядит лучше. BC3 работает на старых видеокартах.

## Классика или Reforged?

| | Классика | Reforged |
|---|---|---|
| Игра | Warcraft III 1.x и классическая графика Reforged | Графика Reforged (HD) |
| Версия MDX | 800 | 1800 |
| Текстуры | `.blp` | `.dds` |
| Скин | Простые веса (используйте [[t:exp_quantize_skin_weights_chk]]) | Полные веса |

!!! tip
    Экспортёр запоминает все параметры до следующего экспорта.
