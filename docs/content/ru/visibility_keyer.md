# Ключи видимости

В Warcraft III части модели показываются и скрываются **ключами видимости**. Например, оружие появляется только в анимации атаки, а свечение – только пока юнит произносит заклинание. Инструмент «Ключи видимости» ставит эти ключи за вас.

Откройте его через **WhiteoutDex > [[t:menu_visibility_keyer]]**. Сначала выделите объекты.

[[shot:visibility_keyer|Ключи видимости.]]

| № | Что делает |
|---|---|
| [[ctl:3]] | Показывает или скрывает выделенные объекты на текущем кадре. |
| [[ctl:5]] | Добавляет контроллер видимости на все выделенные объекты. |
| [[ctl:6]] | Удаляет контроллеры видимости с выделенных объектов. |
| [[ctl:7]] | Копирует ключи видимости выделенного объекта. |
| [[ctl:8]] | Вставляет их на выделенные объекты. |
| [[ctl:9]] | Как игра переходит между ключами: *None* переключает сразу, остальные плавно меняют прозрачность. |
| [[ctl:11]] | Назначает существующим контроллерам выбранный тип. |
| [[ctl:13]] | Ставит ключ «видим» на текущем кадре. |
| [[ctl:14]] | Ставит ключ «скрыт» на текущем кадре. |
| [[ctl:16]] | Делает объект видимым во всём диапазоне анимации. |
| [[ctl:17]] | Скрывает объект во всём диапазоне анимации. |
| [[ctl:19]] | Показывает объект в последовательностях, выбранных в *Менеджере секвенций*. |
| [[ctl:20]] | Скрывает объект в выбранных последовательностях. |

## Пример: оружие только для атаки

1. Выделите оружие.
2. Нажмите [[ctl:17]], чтобы скрыть его везде.
3. В *Менеджере секвенций* выберите последовательности *Attack*.
4. Нажмите [[ctl:19]].

!!! tip
    Для большинства ключей видимости используйте интерполяцию *None*. С другими типами игра плавно меняет прозрачность объекта, а для большинства частей это выглядит неправильно.
