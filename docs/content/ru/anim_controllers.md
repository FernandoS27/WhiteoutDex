# Анимация: контроллеры

Warcraft III знает четыре способа перехода между ключами: *Нет* (скачок), *Линейный*, *Безье* и *Эрмит* (TCB). Этот инструмент назначает выделенным объектам выбранные контроллеры сразу для позиции, вращения и масштаба.

Откройте его через **WhiteoutDex > [[t:menu_anim_controllers]]**.

[[shot:anim_controllers|Инструмент «Контроллеры».]]

| № | Что делает |
|---|---|
| [[ctl:4]] | Позиция движется по прямым линиям между ключами. |
| [[ctl:5]] | Позиция движется по плавным кривым. |
| [[ctl:6]] | Позиция использует ключи TCB (плавно, с натяжением, непрерывностью и смещением). |
| [[ctl:7]] | Оставляет контроллер позиции без изменений. |
| [[ctl:10]] | Вращение равномерное между ключами. |
| [[ctl:11]] | Вращение плавное. |
| [[ctl:12]] | Вращение использует ключи TCB. |
| [[ctl:13]] | Оставляет контроллер вращения без изменений. |
| [[ctl:16]] | Масштаб меняется равномерно. |
| [[ctl:17]] | Масштаб меняется по плавным кривым. |
| [[ctl:18]] | Масштаб использует ключи TCB. |
| [[ctl:19]] | Оставляет контроллер масштаба без изменений. |
| [[ctl:22]] | Назначает эти контроллеры выделенным объектам. |

!!! note
    Экспортёр тоже заменяет контроллеры, которые игра не понимает (см. *Проблемы сцены и «Исправить все»*). С этим инструментом вы выбираете тип сами.
