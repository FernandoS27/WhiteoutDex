# Оптимизатор ключей

В анимациях из других программ или из захвата движения часто есть ключ на каждом кадре. Из-за этого модель становится большой. Оптимизатор ключей удаляет ненужные ключи, а движение остаётся почти таким же.

Откройте его через **WhiteoutDex > [[t:menu_keyframe_optimizer]]**. Сначала выделите анимированные объекты.

[[shot:keyframe_optimizer|Оптимизатор ключей.]]

## Настройки

| № | Что делает |
|---|---|
| [[ctl:7#2]] | **Порог:** насколько может измениться кривая. Чем выше значение, тем больше ключей удаляется. Начните с 0.5. |
| [[ctl:11#2]] | **Шаг:** насколько точно инструмент измеряет, в кадрах. Держите значение ниже 0.49. |
| [[ctl:13#2]] | Пишет подробности в MAXScript Listener. Оставьте выключенным: так работает медленнее. |

## Оптимизация

| № | Что делает |
|---|---|
| [[ctl:3]] | Сортирует список по времени или по имени. |
| [[ctl:5]] | Последовательности модели. Выберите те, которые хотите оптимизировать. |
| [[ctl:7]] | Оптимизировать ключи позиции. |
| [[ctl:8]] | Оптимизировать ключи вращения. |
| [[ctl:9]] | Оптимизировать ключи масштаба. |
| [[ctl:14]] | Оптимизирует выбранные последовательности. |
| [[ctl:15]] | Оптимизирует все последовательности. |
| [[ctl:16]] | Удаляет ключи, которые не входят ни в одну последовательность. В игре они ничего не делают. |

!!! tip
    Сохраните сцену перед оптимизацией. Потом проверьте анимацию. Если что-то выглядит неправильно, отмените и попробуйте меньший порог.
