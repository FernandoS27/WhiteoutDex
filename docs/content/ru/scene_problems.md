# Проблемы сцены и «Исправить все»

Перед экспортом WhiteoutDex проверяет вашу сцену. Он ищет то, что сломает модель в игре или помешает экспорту. Результат вы видите в окне экспорта.

[[shot:exporter_problems|Окно экспорта нашло три проблемы.]]

| № | Что делает |
|---|---|
| [[ctl:1092]] | Исправляет все проблемы сразу. Это меняет вашу сцену. Каждый вид исправления – один шаг отмены, поэтому его можно отменить клавишами [[key:Ctrl+Z]]. |
| [[ctl:1093]] | Открывает список всех проблем. |

## Список проблем

[[shot:scene_problems|Каждая строка – одна проблема.]]

| № | Что делает |
|---|---|
| [[ctl:2000]] | Проблемы. Дважды щёлкните по строке, чтобы выделить объект в сцене. |
| [[ctl:2004]] | Снова проверяет сцену, например после того, как вы что-то исправили вручную. |
| [[ctl:2002]] | Исправляет только проблемы, выбранные в списке. |
| [[ctl:2003]] | Исправляет все проблемы в списке. |
| [[ctl:1]] | Закрывает список. |

## Что исправляет WhiteoutDex

| Проблема | Что делает [[t:exp_fix_all_btn]] |
|---|---|
| У двух объектов одинаковое имя | Переименовывает их: `_2`, `_3` и так далее. Игре нужны уникальные имена. |
| Пустой меш | Удаляет его. |
| Editable Poly | Добавляет модификатор *Edit Mesh*, чтобы экспортёр получил треугольники. |
| *Edit Mesh* над *Skin* | Сворачивает его, чтобы скин остался правильным. |
| Контроллер, который игра не понимает | Заменяет его линейным контроллером. |
| Меш с материалом Multi/Sub-Object | Разделяет меш, чтобы у каждой части был один материал. |
| Материал не Wc3Material | Преобразует его. Настройки берутся из *Исправление материалов* (см. эту страницу). |
| Два материала одинаковые | Объединяет их в один. |

!!! tip
    Исправлять проблемы не обязательно. Экспортёр работает и без этого. Но в игре модель может выглядеть неправильно.
