# Глоссарий

Слова, которые встречаются в WhiteoutDex и в этом руководстве.

| Слово | Значение |
|---|---|
| **MDX / MDL** | Файлы моделей Warcraft III. `.mdx` – двоичный и маленький. `.mdl` – текст, который можно читать и править. Оба содержат одни и те же данные. |
| **Классика** | Warcraft III версии 1.x и классическая графика. Модели используют MDX версии 800. |
| **Reforged** | Warcraft III: Reforged с графикой HD. Модели используют MDX версий от 900 до 1800. WhiteoutDex экспортирует версию 1800. |
| **MPQ** | Файлы архивов классической игры (например `War3.mpq`). |
| **CASC** | Хранилище Warcraft III: Reforged. |
| **BLP** | Формат текстур классической игры. |
| **DDS** | Формат текстур Reforged. |
| **Геосет** | Один меш модели. В модели может быть много геосетов. |
| **Кость** | Узел, который двигает вершины меша со скином. |
| **Хелпер** | Узел, который двигает другие узлы, но в игре его не видно. |
| **Скин** | Говорит, какая кость двигает какую вершину и насколько сильно (вес). |
| **Последовательность** | Одна анимация модели, например *Walk*. У неё есть имя, начальный кадр и конечный кадр. |
| **Глобальная последовательность** | Анимация, которая повторяется всё время, независимо от текущей последовательности. Подходит для того, что движется всегда, например для вращающегося кристалла. |
| **Ключ** | Значение в одной точке времени. Игра переходит от ключа к ключу. |
| **Контроллер** | Как игра переходит между ключами: *Нет* (скачок), *Линейный*, *Безье* или *Эрмит* (плавно). |
| **Точка крепления** | Место на модели, куда игра прикрепляет вещи: оружие, эффекты заклинаний, круг выделения. |
| **Объект события** | Запускает что-то в один момент анимации: звук, след, кровь, появление модели. |
| **Эмиттер частиц 1** | Выпускает маленькие модели. |
| **Эмиттер частиц 2** | Выпускает частицы с текстурой: огонь, дым, искры. |
| **Эмиттер лент** | Рисует след за движущейся точкой. |
| **Popcorn FX** | Система частиц Reforged (файлы `.pkfx`). |
| **Форма столкновения** | Куб или сфера. По ней игра знает, где можно щёлкнуть по модели. |
| **Границы (extents)** | Размер модели в одной последовательности. По ним игра знает, когда модель находится на экране. |
| **Заменяемая текстура** | Текстура, которую подставляет игра, например цвет команды. |
| **Цвет команды / свечение команды** | Цвет игрока на юните. |
| **Режим фильтра** | Как рисуется материал: сплошной, прозрачный, аддитивный (светится) и другие. |
| **Биллборд** | Узел, который всегда повёрнут к камере. |
| **Графика сцены** | Какую графику показывает окно предпросмотра: Classic, Reforged (HD) или Definitive. |
| **WhiteoutFlakes** | Окно предпросмотра, которое показывает вашу модель как в игре. |
