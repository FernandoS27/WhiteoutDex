# Источник света

Источник света Warcraft III освещает модель и землю вокруг неё, например свечение факела или магического кристалла.

Создайте его через **Create > Helpers > Warcraft III Plugins > Wc3 Light**.

## Общие функции

[[shot:obj_light_r1|Общие функции.]]

| № | Что делает |
|---|---|
| [[ctl:3]] | Нажмите эту кнопку, затем щёлкните по объекту. Источник света переходит к этому объекту и привязывается к нему. |

## Основные параметры

[[shot:obj_light_r3|Основные параметры.]]

| № | Что делает |
|---|---|
| [[ctl:4]] | *Всенаправленный* светит из точки во все стороны. *Направленный* светит в одну сторону, как солнце. *Окружающий* освещает всё равномерно. |
| [[ctl:9]] | Расстояние, на котором свет начинает ослабевать. |
| [[ctl:16]] | Расстояние, на котором свет заканчивается. |
| [[ctl:21]] | Цвет света. |
| [[ctl:29]] | Сила света. |
| [[ctl:35]] | Цвет рассеянной части. |
| [[ctl:43]] | Сила рассеянной части. |
| [[ctl:11]] | **Управление:** как анимированное значение меняется между ключами. У каждого значения свой элемент управления. |

## Параметры Reforged

[[shot:obj_light_r2|Параметры Reforged.]]

Эти значения используют только модели Reforged.

| № | Что делает |
|---|---|
| [[ctl:6]] | Сила тени. У главного источника света сцены она также масштабирует освещение на основе изображения. |
| [[ctl:8]] | Источник света отбрасывает тени. |
| [[ctl:12]] | Расстояние, на котором начинается тень. |
| [[ctl:16]] | Расстояние, на котором тень заканчивается. |
| [[ctl:21]] | Как быстро свет ослабевает: квадратичная часть … |
| [[ctl:25]] | … линейная часть … |
| [[ctl:29]] | … и затухание. |
