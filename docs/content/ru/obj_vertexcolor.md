# Wc3 Vertex Color

Модификатор **Wc3 Vertex Color** окрашивает весь меш. Цвет можно анимировать, например чтобы кристалл пульсировал или чтобы часть светилась красным, когда по юниту попадают. Экспортёр записывает его как цвет *анимации геосета* меша.

Добавьте его из списка модификаторов: выделите меш и выберите **Wc3 Vertex Color**.

[[shot:obj_vertexcolor_r1|Основные параметры модификатора.]]

| № | Что делает |
|---|---|
| [[ctl:4]] | Цвет, которым окрашивается меш. Белый оставляет текстуру без изменений. Анимируйте его с **Auto Key**. |
| [[ctl:7]] | Устанавливает для меша флаг *Тень* (Drop Shadow). |
| [[ctl:9]] | Использует цвет. Если выключено, записывается только флаг. |

!!! tip
    Чтобы часть плавно появлялась и исчезала, используйте ключи видимости (*Ключи видимости*) или *Непрозрачность* материала Wc3Material.
