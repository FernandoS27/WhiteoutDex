# Импортёр

Импортёр загружает модель Warcraft III (`.mdx` или `.mdl`) в 3ds Max. Он также загружает текстуры модели из вашей игры.

## Открыть импортёр

Выберите один из способов:

- Меню **WhiteoutDex > [[t:menu_importer]]**
- Кнопка **Import** на боковой панели WhiteoutDex
- **File > Import**, затем выберите тип файла *Warcraft III MDX/MDL Model*

Выберите файл. Затем откроется окно импорта.

## Окно импорта

[[shot:importer|Окно импорта с вкладкой «Объекты».]]

Вверху окна видны имя файла, версия игры для модели (*Классика* или *Reforged*) и число костей, мешей (геосетов) и анимаций.

| № | Что делает |
|---|---|
| [[ctl:1052]] | **Быстрые настройки.** Выберите шаблон. Он сам устанавливает все переключатели ниже. Выберите *Всё*, чтобы импортировать всё. Другие шаблоны импортируют меньше, например только меш без материалов. |
| [[ctl:1059]] | Удаляет открытую сцену и импортирует модель в пустую сцену. |
| [[ctl:1060]] | Добавляет модель в открытую сцену. Так можно объединять модели. |
| [[ctl:1061]] | Показывает объекты модели (этот рисунок). |
| [[ctl:1062]] | Показывает параметры анимации. |
| [[ctl:1063]] | Показывает параметры меша, материалов и текстур. |
| [[ctl:1021]] | Переключатель для всех объектов. Если он выключен, объекты не импортируются. |
| [[ctl:1022]] | Скелет. Он нужен для анимаций и для мешей со скином. |
| [[ctl:1023]] | Хелперы. Они двигают другие объекты, но в игре их не видно. |
| [[ctl:1024]] | Источники света. |
| [[ctl:1025]] | Точки крепления, например для оружия и эффектов заклинаний. |
| [[ctl:1028]] | Объекты событий, например звуки, следы и кровь. |
| [[ctl:1026]] | Эмиттеры частиц 1: эмиттеры, которые создают маленькие модели. |
| [[ctl:1027]] | Эмиттеры частиц 2: эмиттеры для огня, дыма, искр и похожих эффектов. |
| [[ctl:1029]] | Эмиттеры лент: следы, например за мечом. |
| [[ctl:1030]] | Формы столкновений (кубы и сферы). По ним игра знает, где можно щёлкнуть по модели. |
| [[ctl:1031]] | Камеры, например камера портрета. |
| [[ctl:1]] | Запускает импорт. |
| [[ctl:2]] | Закрывает окно без импорта. |

Число рядом с каждым типом объекта показывает, сколько их в модели. Типы, которых в модели нет, серые.

!!! note
    У моделей Reforged могут быть ещё два типа объектов: эмиттеры *Popcorn FX* и *FaceFX*. Вы видите их, только если они есть в модели.

### Вкладка «Модель»

[[shot:importer_model|Вкладка «Модель».]]

| № | Что делает |
|---|---|
| [[ctl:1001]] | Импортирует скин: какая кость двигает какую вершину. Без него меш не следует за костями. |
| [[ctl:1011]] | Создаёт для модели материалы WhiteoutDex. |
| [[ctl:1012]] | Загружает текстуры. WhiteoutDex ищет их в папках вашей игры (см. *Настройки*). |
| [[ctl:1071]] | Импортирует хелперы как объекты *Point*. Если выключено, хелперы импортируются как кости. |
| [[ctl:1081]] | Сваривает вершины, которые находятся в одном месте, и упрощает меш. |
| [[ctl:1082]] | Удаляет кости и хелперы, у которых нет анимации и которые не нужны. |

## Откуда берутся текстуры

WhiteoutDex ищет каждую текстуру в таком порядке:

1. В папке модели и её подпапках.
2. В архивах игры. Для классических моделей (версия 800) он сначала ищет в архивах **MPQ**, затем в **CASC**. Для моделей Reforged – наоборот.

Нижняя строка окна показывает, какие архивы он использует. Папки игры задаются в [[t:menu_settings]].

!!! tip
    Импортёр сохраняет текстуры, которые он берёт из архивов игры, рядом с файлом модели. В следующий раз он сразу находит их.

## Полезно знать

- Импортёр запоминает ваш выбор до следующего раза.
- Чтобы импортировать модель из игры без файла на диске, см. *Импорт из игры*.
