# Объект события

Объект события запускает что-то в точный момент анимации: звук, когда меч попадает в цель, след, когда нога касается земли, кровь, когда юнит умирает, или появление модели.

Создайте его через **Create > Helpers > Warcraft III Plugins > Wc3 Event Object**. Поставьте его туда, где должно произойти событие. Если он должен двигаться, привяжите его к кости.

Во вьюпорте каждый объект события показывает своё имя зелёным цветом.

[[shot:obj_event_r2|Свиток «Объект событий» со звуком смерти из модели-примера.]]

## Выбор события

| № | Что делает |
|---|---|
| [[ctl:5]] | Вид события (см. таблицу ниже). |
| [[ctl:8]] | Точное событие из списка игры, например звук или цвет крови. |
| [[ctl:13]] | Применяет ваш выбор и даёт объекту имя. Строка под кнопкой показывает код события. |

Код события можно также ввести вручную в поле *Свои данные*.

| Тип | Код начинается с | Что происходит |
|---|---|---|
| След | `FPT` | След на земле. |
| Кровь | `SPL` | Брызги на земле, например кровь. |
| Пятно на земле | `UBR` | Большая отметка на земле, например воронка или основание здания. |
| Звук | `SND` | Звук. |
| Порождение | `SPN` | Появляется модель, например падающая часть тела. |

## Когда это происходит

| № | Что делает |
|---|---|
| [[ctl:19]] | Моменты времени, когда происходит событие. |
| [[ctl:20]] | Переместите ползунок времени на нужный кадр, затем нажмите эту кнопку, чтобы добавить момент. |
| [[ctl:21]] | Удаляет выбранный момент. |
| [[ctl:22]] | Удаляет все моменты. |

!!! tip
    С помощью *Менеджера секвенций* перейдите к анимации. Затем двигайте ползунок по одному кадру, чтобы найти точный момент, например когда нога касается земли.
