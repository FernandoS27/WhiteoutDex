# Настройки

В настройках вы выбираете язык WhiteoutDex и указываете, где находится ваша игра.

Откройте их через **WhiteoutDex > [[t:menu_settings]]** или кнопкой с шестерёнкой внизу боковой панели.

[[shot:settings|Настройки WhiteoutDex.]]

## Язык

| № | Что делает |
|---|---|
| [[ctl:5]] | Язык всех окон WhiteoutDex. Открытые окна меняют язык, когда вы открываете их снова. Меню WhiteoutDex меняется после перезапуска 3ds Max. |

## Классическая игра (MPQ)

Классический Warcraft III (версия 1.x) хранит свои файлы в архивах **MPQ**. WhiteoutDex читает оттуда текстуры и модели.

| № | Что делает |
|---|---|
| [[ctl:10]] | Папка вашего классического Warcraft III. |
| [[ctl:12]] | Выбрать папку вручную. |
| [[ctl:14]] | Находит папку сам. |
| [[ctl:15]] | Удаляет папку. |
| [[ctl:16]] | Задаёт порядок архивов MPQ. Побеждает первый архив, в котором есть файл. Обычно это не нужно. |

## Reforged (CASC)

Warcraft III: Reforged хранит свои файлы в хранилище **CASC**.

| № | Что делает |
|---|---|
| [[ctl:20]] | Папка Warcraft III: Reforged, обычно `C:\Program Files (x86)\Warcraft III`. |
| [[ctl:24]] | Находит папку сам. |
| [[ctl:25]] | Удаляет папку. |
| [[ctl:27]] | **Графика сцены.** Какие текстуры использует окно предпросмотра: [[t:set_art_tier_items#2]], [[t:set_art_tier_items#3]] или [[t:set_art_tier_items#4]]. [[t:set_art_tier_items#1]] выбирает сам. Это значение сохраняется вместе со сценой. |

!!! note
    Вам нужна только та игра, для которой вы работаете. Для классических моделей укажите папку MPQ. Для моделей Reforged укажите папку CASC. С обеими папками WhiteoutDex находит больше всего.
