# Wc3Material

Каждому мешу, который вы экспортируете, нужен **Wc3Material**. Он содержит текстуры и говорит игре, как их рисовать. Импортёр сам создаёт материалы Wc3Material. Для своих мешей создайте материал в Material Editor или преобразуйте ваши материалы с помощью *Исправление материалов*.

Рисунки показывают материал модели-примера в Compact Material Editor.

## Основные параметры материала

[[shot:mat_wc3material_r1|Основные параметры материала.]]

| № | Что делает |
|---|---|
| [[ctl:3]] | **Шейдер.** *SD* для классических моделей, *HD* для Reforged, *SD on HD* для классических текстур в модели Reforged, *Crystal* для кристального шейдера Reforged. |
| [[ctl:5]] | **Режим фильтра** – как рисуется материал (см. таблицу ниже). |
| [[ctl:8]] | Рисуются обе стороны граней. |
| [[ctl:9]] | Не реагирует на свет. Подходит для светящихся частей. |
| [[ctl:10]] | Не реагирует на туман. |
| [[ctl:11]] | Один цвет для всего меша. |
| [[ctl:12]] | Устанавливает для материала флаг *Полное разрешение*. |
| [[ctl:13]] | Рисуется поверх других объектов. |
| [[ctl:14]] | Не скрывает то, что находится за ним. |
| [[ctl:15]] | Игрок не может щёлкнуть по этой части. |
| [[ctl:16]] | Использует фоновое затенение (Reforged). |
| [[ctl:17]] | Задние грани отбрасывают тени (Reforged). |
| [[ctl:18]] | Совсем не освещается (Reforged). |
| [[ctl:20]] | Порядок отрисовки прозрачных слоёв: от ближних к дальним или от дальних к ближним. |
| [[ctl:24]] | Порядок отрисовки между материалами (от −20 до 20). Большие значения рисуются позже. |
| [[ctl:26]] | Использует текстуру, которую подставляет игра: цвет команды, свечение команды, утёс или одну из текстур деревьев. |

| Режим фильтра | Как выглядит | Для чего |
|---|---|---|
| Нет | Сплошной. | Обычные части. |
| Прозрачный | Дыры там, где альфа низкая, резкие края. | Листья, волосы, заборы. |
| Смешивание | Плавная прозрачность. | Стекло, мягкие края, тени. |
| Аддитивный | Добавляет свет, светится. Чёрный цвет невидим. | Огонь, магия, лучи света. |
| AddAlpha | Добавляет свет, использует альфу. | Свечения определённой формы. |
| Умножение | Затемняет то, что позади. | Тёмные отметки, тени. |
| Умножение 2x | Затемняет или осветляет. | Особые эффекты. |

## Анимация слоя

[[shot:mat_wc3material_r2|Анимация слоя.]]

| № | Что делает |
|---|---|
| [[ctl:6]] | Непрозрачность слоя (от 0 до 1). Анимируйте её, чтобы материал плавно появлялся и исчезал. |
| [[ctl:7]] | Как непрозрачность меняется между ключами. |
| [[ctl:9]] | Записывает анимацию непрозрачности в модель. |
| [[ctl:11]] | Текстура меняется во времени шагами, как при перелистывании. |
| [[ctl:14]] | Какой UV-канал использует текстура. |
| [[ctl:15]] | Записывает анимацию смены текстуры в модель. |

Движущиеся текстуры (UV-анимация) задаются на *Wc3Bitmap*, а не здесь.

## Текстурные карты материала

[[shot:mat_wc3material_r3|Текстурные карты материала.]]

| № | Что делает |
|---|---|
| [[ctl:4]] | **Диффузная:** цветная текстура. Классические модели используют только её. |
| [[ctl:5]] | Открывает браузер текстур для этого слота (текстуры из игры). |
| [[ctl:10]] | **Карта нормалей:** детали поверхности (Reforged). |
| [[ctl:16]] | **ORM-карта:** затенение, шероховатость и металл в одной текстуре (Reforged). |
| [[ctl:22]] | **Карта свечения:** части, которые светятся сами (Reforged). |
| [[ctl:28]] | **Цвет команды:** маска для цвета команды (Reforged, не обязательно). |
| [[ctl:34]] | **Карта окружения:** текстура отражения (Reforged). |

У каждого слота есть **Префикс пути**: папка, которую экспортёр пишет перед именем файла, например `Textures\`.

## Настройки Reforged

[[shot:mat_wc3material_r4|Настройки Reforged.]]

| № | Что делает |
|---|---|
| [[ctl:5]] | Насколько сильно светится текстура свечения. |
| [[ctl:9]] | Цвет Френеля (свет по краям): красный … |
| [[ctl:12]] | … зелёный … |
| [[ctl:15]] | … и синий. |
| [[ctl:18]] | Сила света по краям. |
| [[ctl:21]] | Какую долю цвета команды использует свет по краям. |
