# セルシェード作成

メッシュにアニメ調の輪郭線を付けます。このツールは、メッシュの周りに少し大きいコピーを作り、面を裏返します。すると、ゲームでモデルの周りに暗い線が見えます。

**WhiteoutDex > [[t:menu_cell_shade]]** で開きます。先にメッシュを選んでください。

[[shot:cell_shade|セルシェード作成。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | 輪郭線の色です。クリックすると、別の色を選べます。 |
| [[ctl:6]] | よく使う色です。クリックすると、その色を使います。 |
| [[ctl:19]] | 輪郭線の太さです。 |
| [[ctl:21]] | コピーの面を裏返します。これで輪郭線ができます（通常はこれを選びます）。 |
| [[ctl:22]] | 面をそのままにします。 |
| [[ctl:25]] | 輪郭線は不透明です。 |
| [[ctl:26]] | 輪郭線はテクスチャの透明度を使います。 |
| [[ctl:27]] | 輪郭線は光ります（光を加えます）。 |
| [[ctl:28]] | 輪郭線は光り、テクスチャの透明度も使います。 |
| [[ctl:30]] | 選んだメッシュに輪郭線を作成します。 |

!!! tip
    輪郭線は、*Wc3Material* の付いた普通のメッシュです。ほかのメッシュと同じように、後で色や太さを変更できます。
