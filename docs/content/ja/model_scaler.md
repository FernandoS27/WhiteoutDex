# アニメ：モデルスケーラー

モデル全体のスケールを変えます。ボーン、アニメーション、特別なオブジェクトも一緒に変わります。モデルがゲームには大きすぎるときや、小さすぎるときに使います。

**WhiteoutDex > [[t:menu_anim_scaler]]** で開きます。

[[shot:model_scaler|モデルスケーラー。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | ゲームの目標の高さです。たとえば *Footman* や *Townhall* です（クラシックまたは Reforged）。 |
| [[ctl:6]] | 選んだ高さにモデルのスケールを変えます。 |
| [[ctl:10]] | 自分で決める倍率です。2 にするとモデルが 2 倍の大きさに、0.5 にすると半分の大きさになります。 |
| [[ctl:11]] | 自分の倍率でモデルのスケールを変えます。 |

!!! warning
    **Biped** または **CAT** のリグと Skin モディファイヤがあるモデルは、この方法ではうまくスケールできません。WhiteoutDex が警告します。代わりに、リグ自身のツールでスケールを変えてください。

!!! tip
    スケールを変える前に、シーンを保存してください。結果がよくない場合に、元に戻せます。
