# オブジェクト設定

Warcraft III のオブジェクトには、3ds Max にない追加の設定があります。たとえば*ビルボード*です。オブジェクト設定は、選んだオブジェクトにこれらを設定します。WhiteoutDex は設定をオブジェクトの中に（ユーザープロパティとして）保存し、エクスポーターがモデルに書き込みます。

**WhiteoutDex > [[t:menu_object_settings]]** で開きます。先に 1 つ以上のオブジェクトを選んでください。

[[shot:object_settings|ボーンを選んだオブジェクト設定。]]

## フラグ

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | オブジェクトは親と一緒に移動しません。 |
| [[ctl:5]] | オブジェクトは親と一緒に回転しません。 |
| [[ctl:6]] | オブジェクトは親と一緒にスケールしません。 |
| [[ctl:7]] | オブジェクトは常にカメラの方を向きます。光や平らなエフェクトに向いています。 |
| [[ctl:8]] | カメラの方を向きますが、X 軸の周りだけで回ります。 |
| [[ctl:9]] | … Y 軸の周りだけで回ります。 |
| [[ctl:10]] | … Z 軸の周りだけで回ります。 |
| [[ctl:11]] | オブジェクトはカメラの画面の中で同じ場所にとどまります。 |

## メッシュ

| 番号 | 機能 |
|---|---|
| [[ctl:13]] | **通常のスキニング：** Skin モディファイヤまたはリンクしたボーンを使います。 |
| [[ctl:14]] | **ArtTools スキニング：** エクスポート時に、別々のメッシュの頂点をつなげます。互いになじませたいメッシュだけに使ってください。 |
| [[ctl:17]] | プレイヤーはゲームでこのメッシュをクリックできません。 |
