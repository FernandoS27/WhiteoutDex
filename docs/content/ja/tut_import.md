# チュートリアル：モデルをインポートする

このレッスンでは、Warcraft III のモデルを 3ds Max に読み込み、WhiteoutDex が作ったものを確認します。

**必要なもの：** モデルファイル。WhiteoutDex のソースコードの `samples` フォルダにサンプルがあります。たとえば `HeroPaladin.mdx` です。インターネットや自分のマップにある `.mdx` または `.mdl` も使えます。

## ステップ 1：インポートを開始する

1. **WhiteoutDex > [[t:menu_importer]]** を選びます。
2. ファイル `HeroPaladin.mdx` を選び、**Open** をクリックします。

インポートウィンドウが開きます。

![インポートウィンドウ。モデルの内容が表示されます。](importer.png)

## ステップ 2：オプションを選ぶ

1. *クイック設定* で **すべて** を選びます。
2. *モード* で **新規シーン** を選びます。
3. **インポート** をクリックします。

数秒後、モデルがシーンに読み込まれます。

![インポートしたパラディン。アタッチメントポイント（黄色）とイベントオブジェクト（緑）が付いています。](tut_model_helpers.png)

## ステップ 3：シーンを見る

シーンには、次のものが入っています。

- モデルの**メッシュ**。*Wc3Material* とテクスチャが付いています。
- メッシュを動かす**ボーン**。
- 黄色い名前の**アタッチメントポイント**。たとえば *Hand Right Ref* です。
- 緑の名前の**イベントオブジェクト**。たとえば足跡の *FPT…* とサウンドの *SND…* です。
- モデルにある場合は、**コリジョンシェイプ**、**パーティクルエミッター**、**リボン**。

## ステップ 4：アニメーションを再生する

1. **WhiteoutDex > [[t:menu_sequence_manager]]** を開きます。
2. シーケンスをダブルクリックします。たとえば *Walk* です。

3ds Max が歩くアニメーションを再生します。

!!! tip
    画面にヘルパーが多すぎる場合は、[[t:menu_node_manager]] を開きます。*ヘルパー / ダミー*、*アタッチメント*、*イベントオブジェクト* にチェックを入れ、**非表示** をクリックします。

**次のレッスン：** WhiteoutFlakes プレビューアでモデルを見ます。
