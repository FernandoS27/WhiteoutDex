# リボンエミッター

リボンエミッターは、動く点の後ろに**軌跡**を描きます。剣を振ったときの光の軌跡、彗星の尾、ロケットの煙などです。動くボーンにリンクしてください。たとえば武器です。

**Create > Geometry > Particle Systems > Wc3Ribbon** で作成します。

## リボンマテリアルパラメータ

[[shot:obj_ribbon_r1|リボンマテリアルパラメータ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:1079]] | 軌跡のマテリアル（*Wc3Material*）です。クリックすると、Material Editor に入れます。 |
| [[ctl:1073]] | テクスチャは絵の格子です。行の数（1、2、4、8 …）… |
| [[ctl:1075]] | … と列の数（1、2、4、8 …）です。 |
| [[ctl:1077]] | 軌跡が格子のどの絵を表示するかです。アニメーションさせると、軌跡がちらつきます。 |

## リボンプロパティ

[[shot:obj_ribbon_r2|リボンプロパティ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:1066]] | 軌跡の色です。 |
| [[ctl:1059]] | 軌跡がエミッターの上にどこまで伸びるかです。 |
| [[ctl:1067]] | エミッターの下にどこまで伸びるかです。上 + 下 = 軌跡の幅です。 |
| [[ctl:1080]] | 透明度です。0 = 見えない、1 = 不透明。0 になるようにアニメーションさせると、軌跡が隠れます。 |
| [[ctl:1069]] | 1 秒あたりに出る軌跡の部品の数です。部品が多いほど、軌跡がなめらかになります。 |
| [[ctl:1071]] | 1 つの部品が残る秒数です。長く残るほど、軌跡が長くなります。 |
| [[ctl:1082]] | 軌跡を下に引っぱります。 |
| [[ctl:1090]] | **コントローラー：** アニメーションする値が、キーとキーの間でどう変わるかです。各値に専用のコントローラーがあります。 |

!!! tip
    剣の軌跡の場合：エミッターを刃に置き、*Additive* のマテリアルを使います。アルファは振っている間以外は 0 にします。寿命はおよそ 0.2 秒にします。
