# 用語集

WhiteoutDex とこのマニュアルに出てくる言葉です。

| 言葉 | 意味 |
|---|---|
| **MDX / MDL** | Warcraft III のモデルファイルです。`.mdx` はバイナリで、小さいファイルです。`.mdl` はテキストで、読んだり編集したりできます。どちらも同じデータを持ちます。 |
| **クラシック** | Warcraft III バージョン 1.x とクラシックのグラフィックです。モデルは MDX バージョン 800 を使います。 |
| **Reforged** | HD グラフィックの Warcraft III: Reforged です。モデルは MDX バージョン 900～1800 を使います。WhiteoutDex はバージョン 1800 でエクスポートします。 |
| **MPQ** | クラシック版のゲームのアーカイブファイルです（たとえば `War3.mpq`）。 |
| **CASC** | Warcraft III: Reforged のストレージです。 |
| **BLP** | クラシック版のゲームのテクスチャ形式です。 |
| **DDS** | Reforged のテクスチャ形式です。 |
| **ジオセット** | モデルの 1 つのメッシュです。1 つのモデルに、たくさんのジオセットがあることがあります。 |
| **ボーン** | スキン付きメッシュの頂点を動かすノードです。 |
| **ヘルパー** | ほかのノードを動かすノードです。ゲームでは見えません。 |
| **スキン** | どのボーンがどの頂点を、どれだけの強さ（ウェイト）で動かすかを決めます。 |
| **シーケンス** | モデルの 1 つのアニメーションです。たとえば *Walk* です。名前、開始フレーム、終了フレームがあります。 |
| **グローバルシーケンス** | 現在のシーケンスに関係なく、ずっと繰り返すアニメーションです。回るクリスタルのように、いつも動くものに向いています。 |
| **キー / キーフレーム** | ある時点での値です。ゲームはキーとキーの間を動かします。 |
| **コントローラー** | ゲームがキーとキーの間をどう動かすかです。*なし*（ジャンプ）、*リニア*、*ベジェ*、*エルミート*（なめらか）があります。 |
| **アタッチメントポイント** | ゲームが物を付ける、モデルの上の場所です。武器、呪文エフェクト、選択の円などです。 |
| **イベントオブジェクト** | アニメーションのある瞬間に何かを起こします。サウンド、足跡、血、現れるモデルなどです。 |
| **パーティクルエミッター 1** | 小さなモデルを放出します。 |
| **パーティクルエミッター 2** | テクスチャの付いたパーティクルを放出します。炎、煙、火花などです。 |
| **リボンエミッター** | 動く点の後ろに軌跡を描きます。 |
| **Popcorn FX** | Reforged のパーティクルシステムです（`.pkfx` ファイル）。 |
| **コリジョンシェイプ** | ボックスまたはスフィアです。ゲームはこれを使って、モデルのどこをクリックできるかを判断します。 |
| **エクステント** | 1 つのシーケンスでのモデルの大きさです。ゲームはこれを使って、モデルが画面に入っているかを判断します。 |
| **置換可能テクスチャ** | ゲームが埋めるテクスチャです。たとえばチームカラーです。 |
| **チームカラー / チームグロー** | ユニットに付くプレイヤーの色です。 |
| **フィルターモード** | マテリアルの描き方です。不透明、透明、加算（光る）などがあります。 |
| **ビルボード** | いつもカメラの方を向くノードです。 |
| **シーンのアート** | プレビューアが表示するグラフィックです。クラシック、Reforged (HD)、Definitive のどれかです。 |
| **WhiteoutFlakes** | ゲームと同じようにモデルを表示するプレビューアです。 |
