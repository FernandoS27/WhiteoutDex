# Wc3Material

エクスポートするすべてのメッシュに、**Wc3Material** が必要です。Wc3Material はテクスチャを持ち、ゲームにその描き方を伝えます。インポーターは Wc3Material を自動で作成します。自分で作ったメッシュには、Material Editor で作成するか、*マテリアル修正* でマテリアルを変換してください。

図は、Compact Material Editor に表示したサンプルモデルのマテリアルです。

## マテリアル基本パラメータ

[[shot:mat_wc3material_r1|マテリアル基本パラメータ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:3]] | **シェーダー。** クラシックのモデルには *SD*、Reforged には *HD* を使います。*SD on HD* は Reforged のモデルでクラシックのテクスチャを使うとき、*Crystal* は Reforged のクリスタルシェーダーです。 |
| [[ctl:5]] | **フィルターモード** – マテリアルの描き方です（下の表を参照）。 |
| [[ctl:8]] | 面の両側を描きます。 |
| [[ctl:9]] | ライトを無視します。光る部分に向いています。 |
| [[ctl:10]] | フォグを無視します。 |
| [[ctl:11]] | メッシュ全体に 1 つの色を使います。 |
| [[ctl:12]] | マテリアルの *Full Resolution* フラグを設定します。 |
| [[ctl:13]] | ほかのものの上に描きます。 |
| [[ctl:14]] | 後ろにあるものを隠しません。 |
| [[ctl:15]] | プレイヤーはこの部分をクリックできません。 |
| [[ctl:16]] | アンビエントオクルージョンを使います（Reforged）。 |
| [[ctl:17]] | 裏面が影を落とします（Reforged）。 |
| [[ctl:18]] | まったくライティングしません（Reforged）。 |
| [[ctl:20]] | 透明なレイヤーの描画の順番です。近→遠、または遠→近です。 |
| [[ctl:24]] | マテリアルどうしの描画の順番です（−20～20）。値が大きいほど後で描かれます。 |
| [[ctl:26]] | ゲームが埋めるテクスチャを使います。チームカラー、チームグロー、崖、木のテクスチャのどれかです。 |

| フィルターモード | 見た目 | 用途 |
|---|---|---|
| なし（None） | 不透明。 | 通常の部分。 |
| 透明（Transparent） | アルファが低い所に穴があき、エッジが硬くなります。 | 葉、髪、柵。 |
| ブレンド（Blend） | なめらかな透明。 | ガラス、やわらかいエッジ、影。 |
| 加算（Additive） | 光を加え、光ります。黒は見えません。 | 炎、魔法、光線。 |
| 加算アルファ（AddAlpha） | 光を加え、アルファを使います。 | 形のある光。 |
| 乗算（Modulate） | 後ろにあるものを暗くします。 | 暗い跡、影。 |
| 乗算 2x（Modulate 2x） | 暗くしたり明るくしたりします。 | 特殊なエフェクト。 |

## レイヤーアニメーション

[[shot:mat_wc3material_r2|レイヤーアニメーション。]]

| 番号 | 機能 |
|---|---|
| [[ctl:6]] | レイヤーの不透明度（0～1）です。アニメーションさせると、マテリアルがフェードインしてフェードアウトします。 |
| [[ctl:7]] | キーとキーの間で、不透明度がどう変わるかです。 |
| [[ctl:9]] | 不透明度のアニメーションをモデルに書き込みます。 |
| [[ctl:11]] | テクスチャが、フリップブックのように時間とともに段階的に変わります。 |
| [[ctl:14]] | テクスチャが使う UV チャンネルです。 |
| [[ctl:15]] | テクスチャが変わるアニメーションをモデルに書き込みます。 |

動くテクスチャ（UV アニメーション）は、ここではなく *Wc3Bitmap* で設定します。

## マテリアルテクスチャマップ

[[shot:mat_wc3material_r3|マテリアルテクスチャマップ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | **ディフューズ：** 色のテクスチャです。クラシックのモデルは、これだけを使います。 |
| [[ctl:5]] | このスロット用のテクスチャブラウザ（ゲームのテクスチャ）を開きます。 |
| [[ctl:10]] | **ノーマル：** 表面の細かい形です（Reforged）。 |
| [[ctl:16]] | **ORM：** オクルージョン、粗さ、金属を 1 つにまとめたテクスチャです（Reforged）。 |
| [[ctl:22]] | **エミッシブ：** 自分で光る部分です（Reforged）。 |
| [[ctl:28]] | **チームカラー：** チームカラー用のマスクです（Reforged、任意）。 |
| [[ctl:34]] | **環境：** 映り込みのテクスチャです（Reforged）。 |

各スロットには **パスプレフィックス** があります。エクスポーターがファイル名の前に書き込むフォルダです。たとえば `Textures\` です。

## Reforged 設定

[[shot:mat_wc3material_r4|Reforged 設定。]]

| 番号 | 機能 |
|---|---|
| [[ctl:5]] | エミッシブテクスチャが光る強さです。 |
| [[ctl:9]] | フレネル（ふちの光）の色です。赤 … |
| [[ctl:12]] | … 緑 … |
| [[ctl:15]] | … と青です。 |
| [[ctl:18]] | ふちの光の強さです。 |
| [[ctl:21]] | ふちの光がチームカラーをどれだけ使うかです。 |
