# WhiteoutFlakes プレビューア

**WhiteoutFlakes** は、Warcraft III と同じ見た目でモデルを表示します。ゲームのシェーダー、チームカラー、ライティング、パーティクル、リボンを使います。3ds Max の変更をリアルタイムで追いかけます。タイムスライダーを動かしたり何かを変更したりすると、プレビューアが更新されます。

**WhiteoutDex > [[t:menu_renderer]]** を選ぶか、サイドバーの **Renderer** ボタンで開きます。

![3ds Max 2027 の横に表示した WhiteoutFlakes。Reforged のモデルをチームカラーで表示しています。](media_1.png)

## ツールバー

| 要素 | 機能 |
|---|---|
| **Animation** | モデルのシーケンスを再生します。*Free Range* を選ぶと、Max のタイムスライダーに従います。 |
| **Camera** | *Free Camera* またはシーンのカメラの 1 つです。たとえば、ポートレートカメラです。 |
| **Team color** | モデルのプレイヤーカラーです。 |
| **Lighting** | *InGame*（ゲームと同じ）、*Glue*（メニュー画面と同じ）、*Dynamic* です。 |
| **Sync Camera** | プレビューアが 3ds Max のアクティブなビューポートに従います。 |
| **Resync** | シーン全体をもう一度読み込みます。たとえば、オブジェクトを追加した後に使います。 |

## メニュー

| メニュー | 内容 |
|---|---|
| **View** | グリッド、パーティクル、リボン、イベントオブジェクトの表示と非表示です。*Warcraft III Art*：使うテクスチャです（*Follow Render Mode*、*Classic*、*Reforged (HD)*、*Definitive*）。*Tileset*：地面です。 |
| **Debug** | コリジョンシェイプとライトのマーカー、特別な表示（アルベド、法線、詳細レベル、ライトの数 …）、詳細レベルの選択です。 |
| **Settings** | 背景、明るさ、音量、時刻、イメージベースドライティング、影、フォグ、グラフィックバックエンド（Direct3D 11、Direct3D 12、Vulkan）、ゲームフォルダです。 |

## 知っておくと便利なこと

- パーティクルとリボンは、ゲームと同じようにシミュレーションされます。タイムスライダーで別の位置に移動すると、プレビューアは新しいフレームまでエフェクトを計算します。そのため、アニメーションがそこまで再生されたときと同じ見た目になります。
- プレビューアは設定を `3dsmax.exe` の横の `WhiteoutFlakes.ini` に保存します。
- プレビューアに何も表示されない場合や、プレビューアが落ちる場合は、`WhiteoutDex_render.log` を見てください（*ファイルと設定* を参照）。

!!! tip
    **View > Warcraft III Art** で *Classic* または *Reforged (HD)* を選ぶと、ゲームの各バージョンでモデルがどう見えるかを確認できます。
