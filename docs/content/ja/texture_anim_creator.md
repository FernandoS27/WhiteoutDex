# テクスチャアニメーション作成

テクスチャを動かします。流れる水、スプライトシートで作る燃える炎、たくさんの画像で作るフリップブックなどです。キーはツールが書き込みます。

**WhiteoutDex > [[t:menu_texture_anim_creator]]** で開きます。

アニメーションには 3 つの種類があります。

| 種類 | 用途 |
|---|---|
| **フロー**（Flow Anim） | テクスチャが滑る、回る、大きくなる動きです。水、溶岩、エネルギーに使います。 |
| **シーケンス（単体）**（SEQ Anim (Solo)） | 1 枚の画像に、たくさんの小さな絵が格子状に並んでいます（*スプライトシート*）。ツールはそれを 1 枚ずつ順番に表示します。 |
| **シーケンス（複数）**（SEQ Anim (Many)） | たくさんの画像が入ったフォルダです。ツールはそれを 1 枚ずつ順番に表示します（*フリップブック*）。 |

[[shot:texture_anim_creator|シーケンス（単体）を選んだテクスチャアニメーション作成。]]

## テクスチャを選ぶ

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | ビューポートでメッシュをクリックし、そのマテリアルを使います。 |
| [[ctl:5]] | 選んでいるメッシュを使います。 |
| [[ctl:6]] | Material Editor でアクティブなマテリアルを使います。 |
| [[ctl:8]] | マテリアルです。 |
| [[ctl:11]] | マテリアルのテクスチャです。下の行に、テクスチャの名前とサイズが表示されます。 |
| [[ctl:14]] | フローです。 |
| [[ctl:15]] | シーケンス（単体）です。 |
| [[ctl:16]] | シーケンス（複数）です。 |

## シーケンス（単体）：スプライトシート

| 番号 | 機能 |
|---|---|
| [[ctl:46]] | アニメーションが始まるフレームです。 |
| [[ctl:50]] | アニメーションを繰り返す回数です。 |
| [[ctl:54]] | シートの 1 行にある絵の数です。 |
| [[ctl:58]] | シートの行の数です。 |
| [[ctl:62]] | 最初に表示する絵です。 |
| [[ctl:66]] | 最後に表示する絵です。 |
| [[ctl:68]] | 2 つの絵の間で飛ばすフレームの数です（0 = フレームごとに新しい絵を表示）。 |
| [[ctl:71]] | 順再生または逆再生です。 |
| [[ctl:74]] | 1 秒あたりの絵の数です。10、15、30、60 から選びます。 |
| [[ctl:77]] | **オン：** アニメーションがグローバルシーケンスとしてずっと繰り返します。**オフ：** タイムラインの中で再生されます。 |
| [[ctl:80]] | **オン：** テクスチャにすでにあるキーを残します。**オフ：** キーを置き換えます。 |
| [[ctl:84]] | 画像の列と行の数を自動で見つけます。 |

## フロー

[[shot:texture_anim_flow|フロー。]]

1. 開始時間と終了時間を設定します。
2. テクスチャが動く方向の矢印をクリックします。回転（左、右）や、拡大と縮小（+、−）もできます。
3. ずっと動くテクスチャにするには、*グローバルアニメーション* をオンにします。
4. **アニメーションを生成** をクリックします。

## シーケンス（複数）

[[shot:texture_anim_many|シーケンス（複数）。]]

1. 画像の入ったフォルダを選びます（**...** ボタン）。画像は名前の順番で使われます。
2. 再生順、速度、開始フレームを設定します。
3. パスのプレフィックスを設定します。たとえば `Textures\` です。モデルは、各画像にこのパスを使います。
4. **アニメーションを生成** をクリックします。

!!! tip
    テクスチャのキーは、*Wc3Bitmap*（UV アニメーション）または *Wc3Material*（フリップブック）にあります。後で変更するときは、そこを見てください。
