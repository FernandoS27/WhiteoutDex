# チュートリアル：モデルをエクスポートする

ここでは、モデルをもう一度 Warcraft III のファイルとして保存します。

**必要なもの：** レッスン *モデルをインポートする* のシーン。

## ステップ 1：エクスポートを開始する

1. **WhiteoutDex > [[t:menu_exporter]]** を選びます。
2. フォルダとファイル名を選びます。たとえば `MyPaladin.mdx` です。**Save** をクリックします。

エクスポートウィンドウが開きます。

![エクスポートウィンドウ。クラシックが選ばれています。](exporter.png)

## ステップ 2：ゲームを選ぶ

- クラシック版のゲーム用には **クラシック** を選びます。テクスチャは `.blp` になります。
- Reforged 用には **Reforged** を選びます。テクスチャは `.dds` になります。

パラディンはクラシックのモデルなので、**クラシック** を選びます。

## ステップ 3：シーンをチェックする

ボタンの上にある枠を見ます。

- **緑 – 問題なし：** そのまま進みます。
- **黄色 – 問題あり：** [[t:exp_fix_all_btn]] をクリックします。WhiteoutDex がシーンを修正します。*シーンの問題と「すべて修正」* を参照してください。

## ステップ 4：エクスポートする

1. *テクスチャ* タブで、*エクスポート時にテクスチャを変換* がオンになっていることを確認します。
2. **エクスポート** をクリックします。

フォルダに、ファイル `MyPaladin.mdx` とそのテクスチャができます。確認が必要なことがあると、エクスポートレポートが開きます（*エクスポートレポート* を参照）。

## ステップ 5：ゲームでテストする

1. モデルとテクスチャをマップのフォルダにコピーします。または、World Editor の **Import Manager** でインポートします。
2. World Editor の *Object Editor* で、ユニットにモデルを設定します（フィールド *Art – Model File*）。
3. マップをテストします。

!!! tip
    エクスポーターは、すべてのオプションを覚えています。同じモデルの次のエクスポートは、1 回クリックするだけです。
