# チュートリアル：炎のエフェクト

このレッスンでは、**パーティクルエミッター 2** を使って、たいまつに炎を付けます。

## ステップ 1：エミッターを作成する

1. *Create > Geometry > Particle Systems > Wc3Particles2* を選びます。
2. ビューポートをクリックして置きます。たいまつの上に動かします。
3. たいまつ（またはたいまつを持つボーン）にリンクし、一緒に動くようにします。

## ステップ 2：テクスチャ

1. **Texture Options** ロールアウトを開きます。
2. **MPQ / CASC を参照** をクリックし、ゲームの炎のテクスチャを選びます（`fire` または `flare` で検索します）。
3. **テクスチャブレンドモード** を **Additive** にします。Additive のパーティクルは光ります。

## ステップ 3：動き

**Emitter Options** と **Timing Options** で、次のように設定します。

1. **速度：** 小さい値にします。炎がゆっくり上がります。
2. **コーン角：** 小さくします。炎がまとまったままになります。
3. **寿命：** およそ 1 秒にします。
4. **放出レート：** 1 秒あたりおよそ 20 個にします。

パーティクルはビューポートにすぐ表示されます。気に入る炎になるまで値を変えてください。

## ステップ 4：色とフェード

**Particle Options** で、次のように設定します。

1. **カラー：** 開始を黄色、中間をオレンジ、終了を暗い赤にします。
2. **アルファ：** 開始を 0、中間を 255、終了を 0 にします。炎がフェードインしてフェードアウトします。
3. **スケール：** 開始を小さく、中間を大きく、終了を小さくします。

![エミッターの Particle Options。](obj_particles2_r6.png)

## ステップ 5：確認する

プレビューアを開きます（**WhiteoutDex > [[t:menu_renderer]]**）。ゲームと同じように炎を表示します。

!!! tip
    気に入った炎は、*Particle Configuration* の **エクスポート** で保存します。ほかのモデルでは **インポート** で読み込みます。
