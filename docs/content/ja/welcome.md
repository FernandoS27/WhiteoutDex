# WhiteoutDex へようこそ

WhiteoutDex は **3ds Max** 用のツールセットです。**Warcraft III** のモデルを作成、変更、テストできます。クラシック版のゲーム（Warcraft III バージョン 1.x）と **Warcraft III: Reforged** の両方に対応しています。

![3ds Max 2027 の WhiteoutDex。左：WhiteoutFlakes プレビューア。右：ノードマネージャーとビューポートのモデル。](media_1.png)

## できること

- Warcraft III のモデル（`.mdx` または `.mdl`）を 3ds Max に**インポート**します。WhiteoutDex はゲームからテクスチャも読み込みます。
- ほかの 3ds Max オブジェクトと同じようにモデルを**編集**します。メッシュ、ボーン、アニメーション、マテリアルを変更できます。
- **WhiteoutFlakes** でモデルを**プレビュー**します。このウィンドウは、ゲームと同じ見た目でモデルを表示します。
- モデルを `.mdx` または `.mdl` に**エクスポート**します。クラシック版用にも Reforged 用にも出力できます。テクスチャは WhiteoutDex が変換します。
- Warcraft III だけにある**特別なオブジェクト**を使います。パーティクルエミッター、リボン、アタッチメントポイント、イベントオブジェクト、コリジョンシェイプなどです。

## 必要なもの

| | |
|---|---|
| Windows | Windows 10 以降 |
| 3ds Max | 2016 から 2027 までのすべてのバージョン |
| Warcraft III | なくても使えますが、あるほうがよいです。WhiteoutDex はゲームフォルダからテクスチャとモデルを読み込みます。 |

## このマニュアルの読み方

このマニュアルには 4 種類のページがあります。

- **はじめに**：WhiteoutDex のインストールと設定を説明します。
- **チュートリアル**：短いレッスンです。初めての方は順番に進めてください。
- **ツールとオブジェクトのページ**：1 つのウィンドウまたは 1 つのオブジェクトを説明します。図には番号が付いています。図の下の表で、各番号の機能を説明します。
- **付録**：調べものに使う一覧です。

[[t:menu_importer]] のような**青い枠**の言葉は、3ds Max の画面に表示される言葉です。キーは [[key:Ctrl+Z]] のように表示します。

!!! tip
    マニュアルの言語は WhiteoutDex の言語と同じです。WhiteoutDex の言語は [[t:menu_settings]] で変更できます。*設定* を参照してください。
