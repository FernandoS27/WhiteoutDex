# グローバルシーケンス

**グローバルシーケンス**は、ずっと繰り返し再生されるアニメーションです。ユニットがどのアニメーションを再生していても動きます。止まらないものに使います。たとえば、回るクリスタル、燃えるたいまつ、風になびく旗です。

各グローバルシーケンスには、フレーム単位の長さがあります。オブジェクトのキーは、通常のタイムラインの代わりに、グローバルシーケンスに属することができます。

*シーケンスマネージャー* の [[t:seq_globals_btn]] ボタンで、グローバルシーケンスマネージャーを開きます。

[[shot:global_sequences|サンプルモデルの 2 つのグローバルシーケンスを表示したグローバルシーケンスマネージャー。]]

上部の一覧に、すべてのグローバルシーケンスが表示されます。番号、フレーム、種類、それを使うオブジェクトです。

| 番号 | 機能 |
|---|---|
| [[ctl:7]] | 選んだグローバルシーケンスの終了フレーム（長さ）です。 |
| [[ctl:8]] | シーンをもう一度読み込みます。 |
| [[ctl:9]] | 選んだグローバルシーケンスを削除します。 |
| [[ctl:15]] | 新しいグローバルシーケンスの長さです（フレーム単位）。 |
| [[ctl:24]] | 選んだオブジェクトに、新しいグローバルシーケンスを作成します。 |
| [[ctl:25]] | 選んだグローバルシーケンスを変更します。 |

## オブジェクトをずっと回転させる

1. オブジェクトを選びます。
2. **継続時間** を設定します。たとえば 60 フレームです。
3. **新規** をクリックします。タイムスライダーがフレーム 0 に移動し、コントローラー、チャンネル、回転のオプションが表示されます。
4. **コントローラー** と軸を選びます。たとえば *リニア* です。
5. タイムスライダーを 1 回転の最後のフレームに動かします。たとえば 60 です。
6. **> CW**（時計回り）または **CCW <**（反時計回り）をクリックします。
7. **完了** をクリックします。

これで、オブジェクトはすべてのアニメーションで、60 フレームに 1 回転します。

手でアニメーションを付けることもできます。**新規** の後、継続時間の範囲内で、いつもどおりオブジェクトにキーを設定します。その後、**完了** をクリックします。WhiteoutDex は、これらのキーを新しいグローバルシーケンスに移します。

!!! note
    ゲームはグローバルシーケンスをミリ秒で数えます。WhiteoutDex がフレームを変換します。
