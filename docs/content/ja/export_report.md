# エクスポートレポート

エクスポートの後、WhiteoutDex は確認が必要なことだけを知らせます。問題がなければ何も表示されず、ファイルができあがっています。

確認が必要なことがあると、**WhiteoutDex エクスポート** ウィンドウが開きます。

- 1 行目は、エラーと警告の数です。*エクスポートが完了しました。エラー 0 件、警告 2 件。*
- 続く各行には、1 つのオブジェクトとその問題が書かれています。たとえば `警告: [Cape] …` です。
- 表示されるのは最大 50 行です。完全な一覧はファイル `mdlx_export_debug.log` にあります（*ファイルと設定* を参照）。

## エラーと警告

| 種類 | 意味 | すること |
|---|---|---|
| **エラー** | 何かをエクスポートできませんでした。モデルが壊れている可能性があります。 | 名前の出たオブジェクトを修正し、もう一度エクスポートします。 |
| **警告** | モデルは動きますが、3ds Max と見た目が違う可能性があります。 | その行を読みます。多くの場合、シーンのチェック（*すべて修正*）で直ります。 |

!!! tip
    先にエクスポートウィンドウで [[t:exp_fix_all_btn]] を実行してください。よくある問題をエクスポート前に修正するので、レポートが短くなります。

インポーターにも同じ種類のレポートがあります。タイトルは **WhiteoutDex インポート** です。
