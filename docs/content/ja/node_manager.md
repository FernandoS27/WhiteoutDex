# ノードマネージャー

モデルには、たくさんの種類のオブジェクトがあります。メッシュ、ボーン、ヘルパー、エミッターなどです。ノードマネージャーは、1 つの種類のオブジェクトをすべてまとめて、表示、非表示、フリーズします。

**WhiteoutDex > [[t:menu_node_manager]]** で開きます。

[[shot:node_manager|ノードマネージャー。]]

## 1. 種類を選ぶ

| 番号 | 種類 |
|---|---|
| [[ctl:4]] | メッシュ。 |
| [[ctl:5]] | 3ds Max のボーン。 |
| [[ctl:6]] | Biped リグのボーン。 |
| [[ctl:7]] | CAT リグのボーン。 |
| [[ctl:8]] | ヘルパーとダミー。 |
| [[ctl:9]] | アタッチメントポイント。 |
| [[ctl:10]] | イベントオブジェクト。 |
| [[ctl:11]] | ライト。 |
| [[ctl:12]] | カメラ。 |
| [[ctl:13]] | パーティクルエミッター 1。 |
| [[ctl:14]] | パーティクルエミッター 2。 |
| [[ctl:15]] | リボンエミッター。 |
| [[ctl:16]] | Popcorn FX エミッター。 |
| [[ctl:17]] | FaceFX オブジェクト。 |
| [[ctl:18]] | コリジョンシェイプ。 |
| [[ctl:27]] | すべての種類にチェックを入れます。[[ctl:28]] はすべてのチェックを外し、[[ctl:29]] はすべてのチェックを反転します。 |

## 2. 操作する

| 番号 | 機能 |
|---|---|
| [[ctl:20]] | オブジェクトを表示します。 |
| [[ctl:21]] | オブジェクトを隠します。 |
| [[ctl:22]] | オブジェクトをフリーズします。間違えて選ぶことがなくなります。 |
| [[ctl:23]] | オブジェクトのフリーズを解除します。 |
| [[ctl:24]] | オブジェクトを透けて見えるように表示します。 |
| [[ctl:25]] | オブジェクトを元のソリッド表示に戻します。 |

!!! tip
    メッシュの作業中は、ヘルパー、ボーン、エミッターをすべて隠してください。スキンのウェイトをペイントするときは、ボーンをフリーズしてください。
