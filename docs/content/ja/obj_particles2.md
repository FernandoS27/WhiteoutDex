# パーティクルエミッター 2

Warcraft III のエフェクトのほとんどは、パーティクルエミッター 2 で作られています。炎、煙、火花、ほこり、魔法などです。このエミッターは、小さな平たい絵（パーティクル）をたくさん放出します。各パーティクルは短い時間だけ存在し、その間に色、大きさ、透明度が変わります。

**Create > Geometry > Particle Systems > Wc3Particles2** で作成します。WhiteoutDex は、パーティクルをビューポートにそのまま表示します。

下の図は、サンプルモデル *HeroPaladin* のエミッターです。

## Particle Configuration

[[shot:obj_particles2_r1|Particle Configuration ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:1030]] | `.ini` ファイルからすべての設定を読み込みます。 |
| [[ctl:1031]] | すべての設定を `.ini` ファイルに保存します。エフェクトをほかのモデルにコピーするときに使います。 |
| [[ctl:1032]] | オンにすると、*インポート* で固定の値だけでなく、値のアニメーションキーも読み込みます。 |

## Texture Options

[[shot:obj_particles2_r2|Texture Options ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:1047]] | ゲームの中でのテクスチャのフォルダです。たとえば `Textures\` です。 |
| [[ctl:3075]] | テクスチャのファイル名です。 |
| [[ctl:1033]] | ディスク上のテクスチャファイルを選びます。 |
| [[ctl:1034]] | ゲームのアーカイブからテクスチャを選びます。 |
| [[ctl:1035]] | パーティクルの描き方です。*Blend*（通常の透明）、*Additive*（光る。炎や魔法に向いています）、*Modulate*、*Modulate 2X*（暗くする）、*Alpha Key*（硬いエッジ）から選びます。 |
| [[ctl:4113]] | パーティクルはライトを無視します。 |
| [[ctl:4115]] | パーティクルはフォグを無視します。 |
| [[ctl:4112]] | パーティクルを距離で並べ替えます。透明なパーティクルの重なり方がおかしいときに使います。 |
| [[ctl:4114]] | チームカラーまたはチームグローをテクスチャとして使います。 |
| [[ctl:3094]] | テクスチャは絵の格子です。行の数 … |
| [[ctl:3096]] | … と列の数です。パーティクルは絵を 1 枚ずつ順番に表示します。 |

## Emitter Options

[[shot:obj_particles2_r3|Emitter Options ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:3048]] | パーティクルが飛んでいく速さです。 |
| [[ctl:3050]] | パーティクルごとに速さがどれだけ違うかです（0 = すべて同じ）。 |
| [[ctl:3052]] | パーティクルが飛ぶ円すいの角度です。小さい角度では細い光線に、大きい角度では広いしぶきになります。 |
| [[ctl:3057]] | パーティクルを下に引っぱります（負の値では上に引っぱります）。 |
| [[ctl:1040]] | **コントロール：** アニメーションする値が、キーとキーの間でどう変わるかです（*用語集* を参照）。各値に専用のコントロールがあります。 |

## Timing Options

[[shot:obj_particles2_r4|Timing Options ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:3042]] | 1 つのパーティクルが存在する秒数です。 |
| [[ctl:3053]] | 1 秒あたりに出るパーティクルの数です。0 になるようにアニメーションさせると、エフェクトが止まります。 |
| [[ctl:1020]] | キーの時点で、すべてのパーティクルを一度に出します。爆発のような出方です。 |

## Particle Options

[[shot:obj_particles2_r6|Particle Options ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:1023]] | パーティクルは平たい絵です（ヘッド）。 |
| [[ctl:1024]] | パーティクルは、動きの後ろに伸びる軌跡です（テール）。 |
| [[ctl:1025]] | ヘッドとテールの両方です。 |
| [[ctl:3073]] | テールの長さです。 |
| [[ctl:6027]] | パーティクルが、存在する時間のどの時点で*中間*の値になるかです（0.5 = 存在する時間の半分）。 |
| [[ctl:6033]] | 存在する時間の開始、中間、終了の色です。枠をクリックすると、色を選べます。 |
| [[ctl:6037]] | 開始、中間、終了の透明度です。0 = 見えない、255 = 不透明。 |
| [[ctl:6041]] | 開始、中間、終了の大きさです。 |
| [[ctl:6045]] | 存在している間に、ヘッドがテクスチャの格子のどの絵を表示するか … |
| [[ctl:6049]] | … とフェードしている間です。 |
| [[ctl:6053]] | テールについて同じことを、存在している間 … |
| [[ctl:6057]] | … とフェードしている間で設定します。 |

## Other Options

[[shot:obj_particles2_r7|Other Options ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:3059]] | 描画の順番です。値が大きいほど後で描かれます（上に重なります）。 |
| [[ctl:4116]] | パーティクルがモデルと一緒に動きます。オフにすると、出た場所にとどまります。 |
| [[ctl:4117]] | パーティクルがカメラの方を向かず、地面に平らに置かれます。輪や波に向いています。 |

!!! tip
    炎や魔法には、*Additive*、小さいコーン角、短い寿命を使ってください。アルファを 0 から 255 にして 0 に戻すと、パーティクルがやわらかくフェードインしてフェードアウトします。
