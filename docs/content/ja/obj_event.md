# イベントオブジェクト

イベントオブジェクトは、アニメーションの決まった瞬間に何かを起こします。剣が当たったときのサウンド、足が地面に着いたときの足跡、ユニットが死んだときの血、現れるモデルなどです。

**Create > Helpers > Warcraft III Plugins > Wc3 Event Object** で作成します。イベントを起こしたい場所に置き、動かす必要があればボーンにリンクします。

ビューポートでは、各イベントオブジェクトの名前が緑で表示されます。

[[shot:obj_event_r2|サンプルモデルの死亡サウンドのイベントオブジェクトロールアウト。]]

## イベントを選ぶ

| 番号 | 機能 |
|---|---|
| [[ctl:5]] | イベントの種類です（下の表を参照）。 |
| [[ctl:8]] | ゲームの一覧にある具体的なイベントです。たとえば、サウンドや血の色です。 |
| [[ctl:13]] | 選んだ内容を使い、オブジェクトに名前を付けます。ボタンの下の行に、イベントコードが表示されます。 |

イベントコードは、*カスタムデータ* に自分で入力することもできます。

| 種類 | コードの始まり | 起きること |
|---|---|---|
| 足跡（FootPrint） | `FPT` | 地面に足跡が付きます。 |
| 血痕（BloodSplat） | `SPL` | 地面に跡が付きます。たとえば血です。 |
| 地面跡（UberSplat） | `UBR` | 地面に大きな跡が付きます。たとえばクレーターや建物の土台です。 |
| サウンド（Sound） | `SND` | サウンドが鳴ります。 |
| スポーン（SpawnObject） | `SPN` | モデルが現れます。たとえば、落ちる体の一部です。 |

## 起きるタイミング

| 番号 | 機能 |
|---|---|
| [[ctl:19]] | イベントが起きる時間です。 |
| [[ctl:20]] | タイムスライダーを正しいフレームに動かし、これをクリックして時間を追加します。 |
| [[ctl:21]] | 選んだ時間を削除します。 |
| [[ctl:22]] | すべての時間を削除します。 |

!!! tip
    *シーケンスマネージャー* でアニメーションに移動し、スライダーを 1 フレームずつ動かして正しい瞬間を探してください。たとえば、足が地面に着く瞬間です。
