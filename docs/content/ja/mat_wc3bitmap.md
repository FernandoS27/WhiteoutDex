# Wc3Bitmap

**Wc3Bitmap** は、WhiteoutDex のテクスチャマップです。*Wc3Material* のスロットに入れて使います。`.blp`、`.dds`、`.tga`、`.png` と、3ds Max のほかの画像形式を読み込めます。テクスチャアニメーション（UV アニメーション）と、ゲームの中でのテクスチャのパスも持っています。

## WC3 テクスチャパラメータ

[[shot:mat_wc3bitmap_r1|WC3 テクスチャパラメータ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:6]] | ディスク上の画像ファイルを選びます。 |
| [[ctl:7]] | ゲームのアーカイブからテクスチャを選びます。 |
| [[ctl:9]] | ゲームが埋めるテクスチャを使います（チームカラー、チームグロー、崖、木）。 |
| [[ctl:12]] | テクスチャを横方向に繰り返します。 |
| [[ctl:13]] | テクスチャを縦方向に繰り返します。 |
| [[ctl:14]] | テクスチャを映り込みとして使います（球状環境マップ）。 |

## UV アニメーション（TXAN）

[[shot:mat_wc3bitmap_r2|UV アニメーション。]]

これらの値をアニメーションさせると、テクスチャが動きます。*テクスチャアニメーション作成* で設定することもできます。

| 番号 | 機能 |
|---|---|
| [[ctl:3]] | キーとキーの間で、値がどう変わるかです。 |
| [[ctl:8]] | テクスチャを横（U）に動かします。 |
| [[ctl:11]] | テクスチャを縦（V）に動かします。 |
| [[ctl:14]] | W オフセットです。 |
| [[ctl:17]] | テクスチャを回転させます。 |
| [[ctl:20]] | 横方向にテクスチャを繰り返す回数を増やしたり減らしたりします。 |
| [[ctl:23]] | 縦方向にテクスチャを繰り返す回数を増やしたり減らしたりします。 |

## パスプレフィックス

[[shot:mat_wc3bitmap_r3|パスプレフィックス。]]

プレフィックスは、エクスポーターがテクスチャ名の前に書き込むフォルダです。たとえば `Textures\` や `war3mapImported\` です。

| 番号 | 機能 |
|---|---|
| [[ctl:5]] | 保存したプレフィックスを選びます。 |
| [[ctl:6]] | 保存したプレフィックスの一覧を編集します。 |

!!! tip
    マップの中のテクスチャには、そのマップが使うプレフィックスを付けてください。マップの自作モデルでは、通常 `war3mapImported\` です。
