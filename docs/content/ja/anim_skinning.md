# アニメ：スキニング

メッシュがボーンにリンクされていて、ボーンを変更したいことがあります。ボーンを動かすと、リンクされたメッシュも動きます。このツールは、メッシュのリンクを一時的に外し、後で元に戻します。

**WhiteoutDex > [[t:menu_anim_skin]]** で開きます。

[[shot:anim_skinning|スキニングツール。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | 選んだ各オブジェクトの親を保存し、リンクを外します。 |
| [[ctl:5]] | 選んだオブジェクトを、保存した親にもう一度リンクします。 |

## 使い方

1. ボーンにリンクされているメッシュを選びます。
2. [[ctl:4]] をクリックします。
3. ボーンを変更します。たとえば、IK から FK に変換します。
4. もう一度メッシュを選び、[[ctl:5]] をクリックします。
