# オブジェクト操作ツール

オブジェクトの間で、位置、リンク、頂点の位置をコピーして貼り付けます。左右対称のモデルに便利です。左側を作り、それを右側にコピーします。

**WhiteoutDex > [[t:menu_object_tools]]** で開きます。

[[shot:object_tools|メッシュを選んだオブジェクト操作ツール。]]

## オブジェクト

| 番号 | 機能 |
|---|---|
| [[ctl:5]] | **階層：** 選んだオブジェクトの親へのリンクを保存し、リンクを外します。 |
| [[ctl:6]] | オブジェクトを、保存した親にもう一度リンクします。 |
| [[ctl:8]] | **位置：** 最初に選んだオブジェクトの位置をコピーします。 |
| [[ctl:9]] | 選んだオブジェクトを、コピーした位置に動かします。 |
| [[ctl:11]] | **構造 (L↔R)：** 選んだすべてのオブジェクトの位置を、名前と一緒にコピーします。 |
| [[ctl:12]] | 左右を入れ替えた名前のオブジェクトに貼り付けます。`Arm_L` からコピーした位置は `Arm_R` に入ります。 |
| [[ctl:14]] | 貼り付けている間、オブジェクトのリンクを一時的に外します。子オブジェクトが一緒に動きません。 |
| [[ctl:15]] | 貼り付けるときに、チェックを入れた軸で位置を反転します：[[ctl:16]]、[[ctl:17]]、[[ctl:18]]。 |

## 頂点（ポリツール）

先に、Editable Poly または Editable Mesh の頂点を選んでください。ボタンの上の行に、オブジェクトと選んだ頂点の数が表示されます。

| 番号 | 機能 |
|---|---|
| [[ctl:22]] | 選んだ頂点の位置をコピーします。 |
| [[ctl:23]] | 頂点に位置を貼り付けます。 |
| [[ctl:26]] | 貼り付けるときに X の値を反転します。[[ctl:27]] と [[ctl:28]] は、Y と Z で同じことをします。 |
| [[ctl:29]] | ワールドの中心を基準に反転します。 |
| [[ctl:30]] | オブジェクトのピボットを基準に反転します。 |
| [[ctl:31]] | 選択範囲の中心を基準に反転します。 |
| [[ctl:35]] | 同じ番号の頂点に貼り付けます。同じメッシュか、そのコピーに使います。 |
| [[ctl:36]] | 選んだ頂点に貼り付けます。別のメッシュにも使えます。 |

!!! tip
    オブジェクトの名前に `_L` と `_R`（または `Left` と `Right`）を付けてください。そうすると、*構造 (L↔R)* が各オブジェクトの相手を自動で見つけます。
