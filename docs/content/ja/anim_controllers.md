# アニメ：コントローラー

Warcraft III には、キーとキーの間を動く方法が 4 つあります。*なし*（ジャンプ）、*リニア*、*ベジェ*、*エルミート*（TCB）です。このツールは、選んだオブジェクトに、選んだコントローラーを付けます。位置、回転、スケールを一度に設定します。

**WhiteoutDex > [[t:menu_anim_controllers]]** で開きます。

[[shot:anim_controllers|コントローラーツール。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | 位置が、キーとキーの間をまっすぐ動きます。 |
| [[ctl:5]] | 位置が、なめらかな曲線で動きます。 |
| [[ctl:6]] | 位置に TCB キーを使います（なめらかで、テンション、連続性、バイアスがあります）。 |
| [[ctl:7]] | 位置のコントローラーをそのままにします。 |
| [[ctl:10]] | 回転が、キーとキーの間を一定の速さで回ります。 |
| [[ctl:11]] | 回転が、なめらかに回ります。 |
| [[ctl:12]] | 回転に TCB キーを使います。 |
| [[ctl:13]] | 回転のコントローラーをそのままにします。 |
| [[ctl:16]] | スケールが一定の速さで変わります。 |
| [[ctl:17]] | スケールがなめらかな曲線で変わります。 |
| [[ctl:18]] | スケールに TCB キーを使います。 |
| [[ctl:19]] | スケールのコントローラーをそのままにします。 |
| [[ctl:22]] | 選んだオブジェクトに、これらのコントローラーを付けます。 |

!!! note
    エクスポーターも、ゲームが読めないコントローラーを置き換えます（*シーンの問題と「すべて修正」* を参照）。このツールでは、種類を自分で選べます。
