# マテリアル修正

エクスポーターは **Wc3Material** しか読めません。マテリアル修正は、ほかのマテリアル（Standard、Physical、PBR）を Wc3Material に変換します。テクスチャはそのまま残し、ここで選んだ Warcraft III のオプションを設定します。

エクスポートウィンドウの [[t:exp_fix_all_btn]] も、同じ設定を使います。

**WhiteoutDex > [[t:menu_material_fix]]** で開きます。

[[shot:material_fix|クラシックのモデル（SD）用の設定を表示したマテリアル修正。]]

設定は 2 組あります。クラシックのモデル用（**SD**）と Reforged 用（**HD**）です。

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | クラシックのモデル用の設定です。 |
| [[ctl:5]] | Reforged のモデル用の設定です。 |

## レンダリング

| 番号 | 機能 |
|---|---|
| [[ctl:8]] | マテリアルの描き方です。*自動* は、アルファチャンネルのあるマテリアルを透明にします。すべてのモードについては *Wc3Material* を参照してください。 |
| [[ctl:10]] | 面の両側を描きます。 |
| [[ctl:11]] | マテリアルはライトを無視します。 |
| [[ctl:12]] | マテリアルはフォグを無視します。 |
| [[ctl:13]] | メッシュ全体に 1 つの色を使います。 |
| [[ctl:14]] | すべてのものの上に描きます（深度テストなし）。 |
| [[ctl:15]] | 後ろにあるものを隠しません。 |
| [[ctl:16]] | アンビエントオクルージョンを使います（Reforged のみ）。 |
| [[ctl:17]] | 裏面が影を落とします（Reforged のみ）。 |
| [[ctl:18]] | *両面*、*シェーディングなし*、*透明度* を、上のチェックボックスではなく元のマテリアルから取ります。 |

## テクスチャ

| 番号 | 機能 |
|---|---|
| [[ctl:23]] | モデルの中で、テクスチャ名の前に付くフォルダです。たとえば `Textures\` です。 |
| [[ctl:26]] | テクスチャの繰り返し方です。元のマテリアルと同じ、両方向、U だけ、V だけ、繰り返さない、から選びます。 |
| [[ctl:28]] | ノーマルマップまたはバンプマップを *ノーマル* マップにします（Reforged）。 |
| [[ctl:29]] | 放射マップを *エミッシブ* マップにします（Reforged）。 |

## すべて修正と今すぐ変換

| 番号 | 機能 |
|---|---|
| [[ctl:32]] | エクスポートウィンドウの [[t:exp_fix_all_btn]] が使う設定です。SD または HD です。 |
| [[ctl:34]] | 変換した各マテリアルの名前に `_wc3` を付けます。 |
| [[ctl:39]] | 選んだオブジェクトのマテリアルを、今すぐ変換します。 |
| [[ctl:40]] | シーンのすべてのマテリアルを、今すぐ変換します。 |
| [[ctl:42]] | このタブを初期値に戻します。 |
| [[ctl:43]] | ウィンドウを閉じます。設定は保存されます。 |

!!! tip
    シーン全体を変換する前に、シーンを保存してください。
