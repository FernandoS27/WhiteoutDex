# エクスポーター

エクスポーターは、シーンを Warcraft III のモデル（`.mdx` または `.mdl`）として保存します。テクスチャをゲームの形式に変換することもできます。

## エクスポーターを開く

- メニュー **WhiteoutDex > [[t:menu_exporter]]**
- WhiteoutDex サイドバーの **Export** ボタン
- **File > Export** を選び、*Warcraft III MDX/MDL Model* を選ぶ

ファイル名を選びます。すると、エクスポートウィンドウが開きます。

## エクスポートウィンドウ

[[shot:exporter|エクスポートウィンドウの「ジオメトリ」タブ。]]

ウィンドウの上部にファイル名が表示されます。その下に、新しいファイルか、同じ名前のファイルがすでにあるかが表示されます。

| 番号 | 機能 |
|---|---|
| [[ctl:1001]] | **モデル名。** ファイルの中に書かれる名前です。ゲームには表示されませんが、ほかのツールには表示されます。 |
| [[ctl:1011]] | クラシック版のゲーム用にエクスポートします（MDX バージョン 800）。テクスチャは `.blp` ファイルになります。 |
| [[ctl:1012]] | Reforged 用にエクスポートします（MDX バージョン 1800）。テクスチャは `.dds` ファイルになります。 |
| [[ctl:1015]] | メッシュのオプションを表示します（この図）。 |
| [[ctl:1016]] | テクスチャのオプションを表示します。 |
| [[ctl:1021]] | 同じマテリアルを使うメッシュを 1 つにまとめます。モデルが小さく、速くなります。 |
| [[ctl:1027]] | 2 つのメッシュが接する場所で法線をそろえます。継ぎ目が見えなくなります。スムージンググループで硬いエッジを作っている場合は使わないでください。 |
| [[ctl:1028]] | 何にも使われていないボーンとヘルパーもエクスポートします。通常、エクスポーターはこれらを出力しません。 |
| [[ctl:1032]] | スキンのウェイトを、クラシック版のゲームで動くように変更します。クラシック版のゲームは単純なウェイトしか使えません。[[t:exp_format_classic_title]] でのみ使います。 |
| [[ctl:1030]] | ファイルがすでにある場合、エクスポーターは名前に `_1`、`_2` などを付けます。古いファイルは残ります。 |
| [[ctl:1031]] | エクスポートの後、ファイルのフォルダを開きます。 |
| [[ctl:1]] | エクスポートを開始します。 |
| [[ctl:2]] | エクスポートせずにウィンドウを閉じます。 |

オプションの下の緑の枠は、WhiteoutDex がシーンに問題を見つけなかったことを示します。問題を見つけると、枠は黄色になります。*シーンの問題と「すべて修正」* を参照してください。

### 「テクスチャ」タブ

[[shot:exporter_textures|「テクスチャ」タブ。ここではクラシック用のエクスポートです。]]

| 番号 | 機能 |
|---|---|
| [[ctl:1060]] | マテリアルのテクスチャを `.blp`（クラシック）または `.dds`（Reforged）に変換し、モデルの横に保存します。 |
| [[ctl:1071]] | **クラシックのみ。** [[t:exp_blp_paletted_item]] または *JPEG* です。JPEG のほうが色が多くなります。パレットのファイルのほうが小さくなります。JPEG では品質（1～100）も設定します。 |
| [[ctl:1075]] | 色を少し混ぜます。パレットのテクスチャで、色と色の間の硬い段差が目立たなくなります。 |
| [[ctl:1061]] | 遠くのモデルにゲームが使う、小さいサイズのテクスチャを作成します。オンのままにしてください。 |
| [[ctl:1062]] | すでにあるテクスチャファイルを置き換えます。オフにすると、エクスポーターは既存のファイルをそのまま残します。 |

**Reforged** では、代わりに DDS の形式を選びます。*BC3 (DXT5)* または *BC7* です。BC7 のほうがきれいに見えます。BC3 は古いグラフィックカードでも動きます。

## クラシックか Reforged か

| | クラシック | Reforged |
|---|---|---|
| ゲーム | Warcraft III 1.x と Reforged のクラシックグラフィック | Reforged のグラフィック（HD） |
| MDX バージョン | 800 | 1800 |
| テクスチャ | `.blp` | `.dds` |
| スキン | 単純なウェイト（[[t:exp_quantize_skin_weights_chk]] を使う） | 完全なウェイト |

!!! tip
    エクスポーターは、すべてのオプションを次のエクスポートのために覚えています。
