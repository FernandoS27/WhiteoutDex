# キーフレーム最適化

ほかのプログラムやモーションキャプチャーのアニメーションには、すべてのフレームにキーがあることがよくあります。そのため、モデルが大きくなります。キーフレーム最適化は、必要のないキーを削除します。動きはほとんど変わりません。

**WhiteoutDex > [[t:menu_keyframe_optimizer]]** で開きます。先に、アニメーションの付いたオブジェクトを選んでください。

[[shot:keyframe_optimizer|キーフレーム最適化。]]

## 設定

| 番号 | 機能 |
|---|---|
| [[ctl:7#2]] | **しきい値：** カーブがどれだけ変わってよいかです。値が大きいほど、多くのキーを削除します。0.5 から始めてください。 |
| [[ctl:11#2]] | **ステップ：** ツールがどれだけ細かく測るかです（フレーム単位）。0.49 より小さくしてください。 |
| [[ctl:13#2]] | MAXScript Listener に詳しい情報を書き出します。オフのままにしてください。オンにすると遅くなります。 |

## 最適化する

| 番号 | 機能 |
|---|---|
| [[ctl:3]] | 一覧を時間順または名前順に並べます。 |
| [[ctl:5]] | モデルのシーケンスです。最適化したいものを選びます。 |
| [[ctl:7]] | 位置キーを最適化します。 |
| [[ctl:8]] | 回転キーを最適化します。 |
| [[ctl:9]] | スケールキーを最適化します。 |
| [[ctl:14]] | 選んだシーケンスを最適化します。 |
| [[ctl:15]] | すべてのシーケンスを最適化します。 |
| [[ctl:16]] | どのシーケンスにも入っていないキーを削除します。これらのキーは、ゲームでは何もしません。 |

!!! tip
    最適化の前に、シーンを保存してください。最適化の後でアニメーションを確認します。おかしく見える場合は、元に戻し、もっと小さいしきい値で試してください。
