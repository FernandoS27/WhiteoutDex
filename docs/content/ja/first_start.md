# 最初のステップ

インストールすると、WhiteoutDex は 3ds Max に 2 つのものを追加します。**WhiteoutDex メニュー**と**サイドバー**です。

![3ds Max 2016 の WhiteoutDex。左にサイドバー、中央に WhiteoutFlakes プレビューア。](media_2.png)

すべてのツールは、3ds Max の上部にある **WhiteoutDex** メニューにあります。

|---|---|
| インポートとエクスポート | [[t:menu_importer]]、[[t:menu_import_casc]]、[[t:menu_exporter]] |
| シーケンス | [[t:menu_sequence_manager]]、[[t:menu_visibility_keyer]]、[[t:menu_node_manager]] |
| アニメーション | [[t:menu_anim_general]]、[[t:menu_anim_controllers]]、[[t:menu_anim_skin]]、[[t:menu_anim_scaler]] |
| ツール | [[t:menu_skin_changer]]、[[t:menu_grid_dummy]]、[[t:menu_object_tools]]、[[t:menu_object_settings]]、[[t:menu_keyframe_optimizer]]、[[t:menu_cell_shade]]、[[t:menu_material_fix]]、[[t:menu_texture_anim_creator]] |

## Warcraft III オブジェクト

WhiteoutDex は、3ds Max の **Create** パネルに新しいオブジェクトを追加します。

- **Create > Helpers > Warcraft III Plugins**：アタッチメントポイント、コリジョンシェイプ、ライト、イベントオブジェクト、Popcorn FX、FaceFX。
- **Create > Geometry > Particle Systems**：Particle Emitter 1、Particle Emitter 2、Ribbon Emitter。
- **Material Editor**：マテリアル *Wc3Material* とマップ *Wc3Bitmap*。
- **Modifier list**：*Wc3 Vertex Color*。

これらは *Warcraft III オブジェクト* と *マテリアル* の章で説明します。

## 最初にすること

1. [[t:menu_settings]] を開き、ゲームフォルダを設定します（*設定* を参照）。
2. チュートリアル *モデルをインポートする* を行います。
3. プレビューアでモデルを見ます。チュートリアル *モデルをプレビューする* を参照してください。
4. モデルをもう一度エクスポートします。チュートリアル *モデルをエクスポートする* を参照してください。
