# ゲームからインポート

ディスク上のファイルを使わずに、Warcraft III のゲームから直接モデルをインポートできます。

1. **WhiteoutDex > [[t:menu_import_casc]]** を選びます。
2. ゲームブラウザーが開きます。モデルを探します。たとえば `footman` で検索します。
3. モデルをクリックし、**Select** をクリックします。
4. 通常のインポートウィンドウが開きます（*インポーター* を参照）。オプションを選び、**インポート** をクリックします。

WhiteoutDex は、モデルとそのテクスチャを一時フォルダにコピーし、そこからインポートします。ゲームのファイルは変更されません。

!!! tip
    ゲームのモデルを変更するには、この方法でインポートし、変更し、新しい名前でマップまたは MOD のフォルダにエクスポートします。

!!! note
    ゲームのモデルは Blizzard Entertainment のものです。Blizzard が許可する範囲でのみ使ってください。たとえば、Warcraft III のマップや MOD です。
