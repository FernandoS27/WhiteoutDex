# 表示キーヤー

Warcraft III では、**表示キー**でモデルの部分を表示したり隠したりします。たとえば、攻撃アニメーションのときだけ現れる武器や、ユニットが呪文を唱えている間だけ現れる光です。表示キーヤーは、これらのキーを設定します。

**WhiteoutDex > [[t:menu_visibility_keyer]]** で開きます。先にオブジェクトを選んでください。

[[shot:visibility_keyer|表示キーヤー。]]

| 番号 | 機能 |
|---|---|
| [[ctl:3]] | 現在のフレームで、選んだオブジェクトを表示または非表示にします。 |
| [[ctl:5]] | 選んだすべてのオブジェクトに表示コントローラーを追加します。 |
| [[ctl:6]] | 選んだオブジェクトから表示コントローラーを削除します。 |
| [[ctl:7]] | 選んだオブジェクトの表示キーをコピーします。 |
| [[ctl:8]] | 選んだオブジェクトに貼り付けます。 |
| [[ctl:9]] | キーとキーの間で、ゲームがどう変化させるかです。*なし* はすぐに切り替わります。ほかの種類はフェードします。 |
| [[ctl:11]] | 既存のコントローラーを、選んだ種類にします。 |
| [[ctl:13]] | 現在のフレームに*表示*キーを設定します。 |
| [[ctl:14]] | 現在のフレームに*非表示*キーを設定します。 |
| [[ctl:16]] | アニメーションの範囲全体で、オブジェクトを表示します。 |
| [[ctl:17]] | アニメーションの範囲全体で、オブジェクトを隠します。 |
| [[ctl:19]] | *シーケンスマネージャー* で選んだシーケンスで、オブジェクトを表示します。 |
| [[ctl:20]] | 選んだシーケンスで、オブジェクトを隠します。 |

## 例：攻撃のときだけ表示する武器

1. 武器を選びます。
2. [[ctl:17]] をクリックし、すべての場所で隠します。
3. *シーケンスマネージャー* で *Attack* シーケンスを選びます。
4. [[ctl:19]] をクリックします。

!!! tip
    ほとんどの表示キーには、補間 *なし* を使ってください。ほかの種類では、ゲームがオブジェクトをフェードさせます。ほとんどの部分では、それは不自然に見えます。
