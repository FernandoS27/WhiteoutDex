# ライト

Warcraft III のライトは、モデルとその周りの地面を照らします。たとえば、たいまつや魔法のクリスタルの光です。

**Create > Helpers > Warcraft III Plugins > Wc3 Light** で作成します。

## 一般機能

[[shot:obj_light_r1|一般機能。]]

| 番号 | 機能 |
|---|---|
| [[ctl:3]] | これをクリックし、次にオブジェクトをクリックします。ライトがそのオブジェクトに移動し、リンクします。 |

## 基本パラメータ

[[shot:obj_light_r3|基本パラメータ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | *全方向* は、1 点からすべての方向を照らします。*指向性* は、太陽のように 1 つの方向を照らします。*アンビエント* は、すべてを均一に照らします。 |
| [[ctl:9]] | ライトが弱くなり始める距離です。 |
| [[ctl:16]] | ライトが届かなくなる距離です。 |
| [[ctl:21]] | ライトの色です。 |
| [[ctl:29]] | ライトの強さです。 |
| [[ctl:35]] | アンビエント部分の色です。 |
| [[ctl:43]] | アンビエント部分の強さです。 |
| [[ctl:11]] | **コントロール：** アニメーションする値が、キーとキーの間でどう変わるかです。各値に専用のコントロールがあります。 |

## Reforged パラメータ

[[shot:obj_light_r2|Reforged パラメータ。]]

これらの値は、Reforged のモデルだけが使います。

| 番号 | 機能 |
|---|---|
| [[ctl:6]] | 影の強さです。シーンのメインライトでは、イメージベースドライティングの強さも変えます。 |
| [[ctl:8]] | ライトが影を落とします。 |
| [[ctl:12]] | 影が始まる距離です。 |
| [[ctl:16]] | 影が終わる距離です。 |
| [[ctl:21]] | ライトが弱くなる速さです。二次の部分 … |
| [[ctl:25]] | … 一次の部分 … |
| [[ctl:29]] | … と減衰です。 |
