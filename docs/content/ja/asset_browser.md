# ゲームブラウザー

ゲームブラウザーは、Warcraft III のゲームの中にあるファイルを表示します。モデル、テクスチャ、パーティクルエフェクトです。各ファイルの小さな画像が表示されるので、必要なものがすぐに見つかります。

いろいろな場所から開きます。

| 場所 | ボタン | 選ぶもの |
|---|---|---|
| WhiteoutDex メニュー | [[t:menu_import_casc]] | インポートするモデル |
| アタッチメントポイント | *ゲームアーカイブを参照* | アタッチメント用のモデル |
| パーティクルエミッター 1 | *ゲームアーカイブを参照* | パーティクル用のモデル |
| パーティクルエミッター 2 | *MPQ / CASC を参照* | パーティクル用のテクスチャ |
| Popcorn FX | *ゲームアーカイブを参照* | `.pkb` または `.pkfx` のエフェクト |
| Wc3Bitmap | *テクスチャブラウザを開く* | テクスチャ |
| Wc3Material | マップの横の ⚙ ボタン | このスロット用のテクスチャ |

## 使い方

1. 検索欄に名前の一部を入力します。たとえば `footman` です。
2. **グリッド**（画像）と**ツリー**（フォルダ）を切り替えます。
3. 画像を拡大または縮小します。
4. ファイルをクリックします。一番下の行に、選んだファイルが表示されます。
5. **Select** をクリックします。

!!! note
    ブラウザーにはゲームフォルダの設定が必要です。[[t:menu_settings]] で設定してください。クラシックのモデルは MPQ アーカイブから、Reforged のファイルは CASC から読み込みます。
