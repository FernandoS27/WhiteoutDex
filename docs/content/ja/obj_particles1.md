# パーティクルエミッター 1

パーティクルエミッター 1 は、絵ではなく**小さなモデル**を放出します。それ自体がモデルになっているもの、たとえば落ち葉、石、矢などに使います。

**Create > Geometry > Particle Systems > Wc3Particles1** で作成します。

## Particle Configuration

[[shot:obj_particles1_r1|Particle Configuration ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:2020]] | `.ini` ファイルからすべての設定を読み込みます。 |
| [[ctl:2021]] | すべての設定を `.ini` ファイルに保存します。 |
| [[ctl:2022]] | オンにすると、*インポート* で値のアニメーションキーも読み込みます。 |

## Emitter Options

[[shot:obj_particles1_r2|Emitter Options ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:5002]] | モデルが飛んでいく速さです。 |
| [[ctl:5004]] | 方向の上下の角度です。 |
| [[ctl:5006]] | 方向の横の角度です。 |
| [[ctl:5008]] | モデルを下に引っぱります。 |
| [[ctl:2030]] | **コントロール：** アニメーションする値が、キーとキーの間でどう変わるかです。各値に専用のコントロールがあります。 |

## Timing Options

[[shot:obj_particles1_r3|Timing Options ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:5010]] | 1 つのモデルが存在する秒数です。 |
| [[ctl:5012]] | 1 秒あたりに出るモデルの数です。 |

## Model Options

[[shot:obj_particles1_r4|Model Options ロールアウト。]]

| 番号 | 機能 |
|---|---|
| [[ctl:5017]] | ゲームの中でのモデルのフォルダです。 |
| [[ctl:5016]] | モデルのファイル名です。たとえば `Abilities\Weapons\Arrow\ArrowMissile.mdl` です。 |
| [[ctl:2024]] | ゲームのアーカイブからモデルを選びます。 |
| [[ctl:2023]] | ディスク上のモデルファイルを選びます。 |
| [[ctl:5014]] | ビューポートのプレビューでのモデルの大きさです。 |

!!! note
    クラシックのモデルでは、ゲームの中のファイルが `.mdx` でも、このパスに拡張子 `.mdl` が書かれていることがよくあります。ゲームはどちらでも見つけます。
