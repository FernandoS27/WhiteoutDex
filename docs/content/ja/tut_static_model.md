# チュートリアル：初めての自作モデル

このレッスンでは、簡単なオブジェクトを一から作ります。木箱です。たとえば、マップのドゥードゥーに使えます。

## ステップ 1：木箱をモデリングする

1. **Box** を作成します。*Create > Geometry > Box* を使います。大きさはおよそ 60 × 60 × 60 単位にします。3ds Max の 1 単位は、ゲームの 1 単位と同じです。
2. 地面の上に立つように置きます（底の高さを 0 にします）。中心は 0, 0 に置きます。

## ステップ 2：マテリアルを付ける

1. Material Editor を開きます（[[key:M]]）。
2. 空いているスロットを選び、マテリアルの種類のボタンをクリックし、**Wc3Material** を選びます。
3. *マテリアルテクスチャマップ* で **ディフューズ** のボタンをクリックし、**Wc3Bitmap** を選びます。
4. **ビットマップを選択...** をクリックしてテクスチャを選びます。または **テクスチャブラウザを開く** をクリックし、ゲームのテクスチャを使います（`crate` または `wood` で検索します）。
5. マテリアルを箱の上にドラッグします。

![テクスチャスロットのある Wc3Material。](mat_wc3material_r3.png)

!!! tip
    Standard や Physical のマテリアルがすでにある場合は、*マテリアル修正* で Wc3Material に変換できます。

## ステップ 3：コリジョン

プレイヤーが木箱をクリックできるようにします。

1. 箱を選びます。
2. **WhiteoutDex > [[t:menu_anim_general]]** を開き、**ワンクリック 衝突ボックス** をクリックします。

## ステップ 4：Stand アニメーション

何も動かないモデルでも、少なくとも 1 つのシーケンスが必要です。

1. **WhiteoutDex > [[t:menu_sequence_manager]]** を開きます。
2. **新規...** をクリックし、プリセット *Stand* を選んで **OK** をクリックします。

## ステップ 5：エクスポートしてテストする

1. 木箱を `Crate.mdx` としてエクスポートします（レッスン *モデルをエクスポートする* を参照）。
2. エクスポートウィンドウの枠を見ます。黄色の場合は、[[t:exp_fix_all_btn]] をクリックします。
3. プレビューアで結果を見ます。**WhiteoutDex > [[t:menu_renderer]]** を選びます。

これで、初めての Warcraft III モデルができました。
