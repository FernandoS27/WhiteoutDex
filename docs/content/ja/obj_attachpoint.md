# アタッチメントポイント

アタッチメントポイントは、モデルの上の場所に印を付けます。ゲームはそこに物を付けます。ヒーローの武器、手の呪文エフェクト、胸に当たる矢、頭の上の体力バーなどです。

**Create > Helpers > Warcraft III Plugins > Wc3 AttachPoint** で作成します。追従させたいボーンにリンクしてください。

ビューポートでは、各アタッチメントポイントの名前が黄色で表示されます。

## 一般機能

[[shot:obj_attachpoint_r1|一般機能。]]

| 番号 | 機能 |
|---|---|
| [[ctl:3]] | これをクリックし、次にビューポートでオブジェクトをクリックします。アタッチメントポイントがそのオブジェクトに移動し、リンクします。 |

## モデルマップパラメータ

[[shot:obj_attachpoint_r2|モデルマップパラメータ。]]

アタッチメントポイントは、専用のモデルを持てます。たとえば、ユニットがいつも持っている剣です。

| 番号 | 機能 |
|---|---|
| [[ctl:9]] | ディスク上のモデルファイルを選びます。 |
| [[ctl:10]] | ゲームのアーカイブからモデルを選びます。 |

ボタンの上の 2 つの欄に、フォルダとファイル名が入ります。パスは Warcraft III のフォルダからの相対パスです。たとえば `Textures\Model.mdx` です。

## アタッチメントパラメータ

[[shot:obj_attachpoint_r3|アタッチメントパラメータ。]]

ゲームは、アタッチメントポイントを**名前**で見つけます。名前は 4 つの部分から作ります。

| 番号 | 機能 |
|---|---|
| [[ctl:5]] | **タイプ：** 主な場所です。*Head*、*Overhead*、*Origin*、*Foot*、*Chest*、*Hand*、*Weapon*、*Sprite* から選びます。 |
| [[ctl:8]] | **騎乗：** 乗り物に乗るユニット用です。 |
| [[ctl:11]] | **左右：** *Left* または *Right* です。手と足に使います。 |
| [[ctl:14]] | **追加：** 追加の言葉です。たとえば *Rear*、*Alternate*、*RallyPoint*、*Gold*、建物用の *First* … *Sixth* です。 |
| [[ctl:22]] | *モデルマップパラメータ* のモデルを使います。 |
| [[ctl:26]] | 表示（0～1）です。アニメーションさせると、付けたモデルを表示したり隠したりします。 |
| [[ctl:27]] | モデルのパスが何を基準にしているかを表示します。 |
| [[ctl:34]] | アタッチメントポイントの番号です。 |
| [[ctl:36]] | この番号をモデルに書き込みます。 |

例：タイプ *Hand*、左右 *Right* では、名前は `Hand Right Ref` になります。ゲームは、右手用の呪文エフェクトをそこに付けます。

!!! tip
    *アニメ：一般ツール* の *ワンクリック アタッチメントポイント* ツールは、ボーンによく知られた名前が付いていれば、よく使うアタッチメントポイントを作成します。
