# インポーター

インポーターは、Warcraft III のモデル（`.mdx` または `.mdl`）を 3ds Max に読み込みます。モデルのテクスチャもゲームから読み込みます。

## インポーターを開く

次のどれかの方法を使います。

- メニュー **WhiteoutDex > [[t:menu_importer]]**
- WhiteoutDex サイドバーの **Import** ボタン
- **File > Import** を選び、ファイルの種類 *Warcraft III MDX/MDL Model* を選ぶ

ファイルを選びます。すると、インポートウィンドウが開きます。

## インポートウィンドウ

[[shot:importer|インポートウィンドウの「オブジェクト」タブ。]]

ウィンドウの上部には、ファイル名、モデルのゲームバージョン（*クラシック* または *Reforged*）、ボーン、メッシュ（ジオセット）、アニメーションの数が表示されます。

| 番号 | 機能 |
|---|---|
| [[ctl:1052]] | **クイック設定。** プリセットを選びます。下にあるすべてのスイッチが自動で設定されます。すべてをインポートするには *すべて* を選びます。ほかのプリセットは、インポートする内容が少なくなります。たとえば、マテリアルなしのメッシュだけです。 |
| [[ctl:1059]] | 今開いているシーンを削除し、空のシーンにモデルをインポートします。 |
| [[ctl:1060]] | 今開いているシーンにモデルを追加します。モデルを組み合わせるときに使います。 |
| [[ctl:1061]] | モデルのオブジェクトを表示します（この図）。 |
| [[ctl:1062]] | アニメーションのオプションを表示します。 |
| [[ctl:1063]] | メッシュ、マテリアル、テクスチャのオプションを表示します。 |
| [[ctl:1021]] | すべてのオブジェクトのスイッチです。オフにすると、オブジェクトはインポートされません。 |
| [[ctl:1022]] | スケルトンです。アニメーションとスキン付きメッシュに必要です。 |
| [[ctl:1023]] | ヘルパーオブジェクトです。ほかのオブジェクトを動かしますが、ゲームでは見えません。 |
| [[ctl:1024]] | ライトです。 |
| [[ctl:1025]] | アタッチメントポイントです。たとえば、武器や呪文エフェクトに使います。 |
| [[ctl:1028]] | イベントオブジェクトです。たとえば、サウンド、足跡、血です。 |
| [[ctl:1026]] | パーティクルエミッター 1：小さなモデルを生み出すエミッターです。 |
| [[ctl:1027]] | パーティクルエミッター 2：炎、煙、火花などのエフェクト用のエミッターです。 |
| [[ctl:1029]] | リボンエミッター：軌跡です。たとえば、剣の後ろに残る光です。 |
| [[ctl:1030]] | コリジョンシェイプ（ボックスと球）です。ゲームはこれを使って、モデルのどこをクリックできるかを判断します。 |
| [[ctl:1031]] | カメラです。たとえば、ポートレートカメラです。 |
| [[ctl:1]] | インポートを開始します。 |
| [[ctl:2]] | インポートせずにウィンドウを閉じます。 |

各オブジェクトの種類の横の数字は、モデルにいくつあるかを示します。モデルにない種類はグレーで表示されます。

!!! note
    Reforged のモデルには、さらに 2 種類のオブジェクトがあることがあります。*Popcorn FX* エミッターと *FaceFX* です。モデルにある場合だけ表示されます。

### 「アニメーション」タブ

[[shot:importer_animations|「アニメーション」タブ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:1041]] | すべてのアニメーションのスイッチです。オフにすると、モデルは動きなしで読み込まれます。 |
| [[ctl:1042]] | 移動（位置キー）です。 |
| [[ctl:1043]] | 回転キーです。 |
| [[ctl:1044]] | スケールキーです。 |
| [[ctl:1048]] | 表示と非表示のキーです。 |
| [[ctl:1045]] | オブジェクトのアニメーションする値です。たとえば、ライトの強さやパーティクルの放出レートです。 |
| [[ctl:1046]] | 動くテクスチャ座標（UV アニメーション）です。 |
| [[ctl:1047]] | 時間とともに変わるテクスチャ（フリップブック）です。 |
| [[ctl:1049]] | 時間とともに変わるカラーです。 |

### 「モデル」タブ

[[shot:importer_model|「モデル」タブ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:1001]] | スキンをインポートします。スキンは、どのボーンがどの頂点を動かすかを決めます。スキンがないと、メッシュはボーンについて動きません。 |
| [[ctl:1011]] | モデル用に WhiteoutDex のマテリアルを作成します。 |
| [[ctl:1012]] | テクスチャを読み込みます。WhiteoutDex はゲームフォルダの中を探します（*設定* を参照）。 |
| [[ctl:1071]] | ヘルパーを *Point* オブジェクトとしてインポートします。オフにすると、ヘルパーはボーンとして読み込まれます。 |
| [[ctl:1081]] | 同じ位置にある頂点を結合し、メッシュを単純にします。 |
| [[ctl:1082]] | アニメーションがなく、必要のないボーンとヘルパーを削除します。 |

## テクスチャの読み込み元

WhiteoutDex は、各テクスチャを次の順番で探します。

1. モデルのフォルダとそのサブフォルダ。
2. ゲームのアーカイブ。クラシックのモデル（バージョン 800）では、先に **MPQ** アーカイブを探し、次に **CASC** を探します。Reforged のモデルでは逆の順番です。

ウィンドウの一番下の行に、使っているアーカイブが表示されます。ゲームフォルダは [[t:menu_settings]] で設定します。

!!! tip
    インポーターは、ゲームのアーカイブから取り出したテクスチャをモデルファイルの横に保存します。そのため、次回はすぐに見つかります。

## 知っておくと便利なこと

- インポーターは、選んだ設定を次回のために覚えています。
- ディスク上のファイルを使わずに、ゲームからモデルをインポートできます。*ゲームからインポート* を参照してください。
