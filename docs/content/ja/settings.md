# 設定

設定では、WhiteoutDex の言語を選び、ゲームの場所を指定します。

**WhiteoutDex > [[t:menu_settings]]** を選ぶか、サイドバーの一番下にある歯車ボタンで開きます。

[[shot:settings|WhiteoutDex の設定。]]

## 言語

| 番号 | 機能 |
|---|---|
| [[ctl:5]] | すべての WhiteoutDex ウィンドウの言語です。開いているウィンドウは、もう一度開くと変わります。WhiteoutDex メニューは、3ds Max を再起動すると変わります。 |

## クラシック版のゲーム（MPQ）

クラシック版の Warcraft III（バージョン 1.x）は、ファイルを **MPQ** アーカイブに保存しています。WhiteoutDex はそこからテクスチャとモデルを読み込みます。

| 番号 | 機能 |
|---|---|
| [[ctl:10]] | クラシック版 Warcraft III のフォルダです。 |
| [[ctl:12]] | フォルダを自分で選びます。 |
| [[ctl:14]] | フォルダを自動で見つけます。 |
| [[ctl:15]] | フォルダの指定を消します。 |
| [[ctl:16]] | MPQ アーカイブの順番を設定します。ファイルを最初に持っているアーカイブが使われます。通常は必要ありません。 |

## Reforged（CASC）

Warcraft III: Reforged は、ファイルを **CASC** ストレージに保存しています。

| 番号 | 機能 |
|---|---|
| [[ctl:20]] | Warcraft III: Reforged のフォルダです。通常は `C:\Program Files (x86)\Warcraft III` です。 |
| [[ctl:24]] | フォルダを自動で見つけます。 |
| [[ctl:25]] | フォルダの指定を消します。 |
| [[ctl:27]] | **シーンのアート。** プレビューアが使うテクスチャです。[[t:set_art_tier_items#2]]、[[t:set_art_tier_items#3]]、[[t:set_art_tier_items#4]] から選びます。[[t:set_art_tier_items#1]] は自動で選びます。この設定はシーンと一緒に保存されます。 |

!!! note
    必要なのは、作業するゲームだけです。クラシックのモデルには MPQ フォルダを設定します。Reforged のモデルには CASC フォルダを設定します。両方を設定すると、WhiteoutDex が見つけられるものが一番多くなります。
