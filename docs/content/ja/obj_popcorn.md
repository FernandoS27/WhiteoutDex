# Popcorn FX

**Popcorn FX** は、Warcraft III: Reforged のパーティクルシステムです。エフェクトそのものは、PopcornFX エディターで作った `.pkfx`（または `.pkb`）ファイルです。3ds Max の Popcorn オブジェクトは、このエフェクトをモデルに置き、いつ再生するかを制御します。

**Create > Helpers > Warcraft III Plugins > Wc3 Popcorn** で作成します。Popcorn は **Reforged** のモデルでのみ動きます。

## Popcorn FX ファイル

[[shot:obj_popcorn_r2|Popcorn FX ファイル。]]

| 番号 | 機能 |
|---|---|
| [[ctl:9]] | ゲームのアーカイブから `.pkb` または `.pkfx` のエフェクトを選びます。 |
| [[ctl:10]] | ディスク上のエフェクトファイルを選びます。 |
| [[ctl:11]] | 短い説明を表示します。 |

ボタンの上の 2 つの欄に、エフェクトのパスと、その前に付くフォルダが入ります。

## アニメーション表示ガイド

[[shot:obj_popcorn_r3|アニメーション表示ガイド。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | **オン：** エフェクトはすべてのアニメーションで再生されます。**オフ：** どのアニメーションでも再生されません。 |
| [[ctl:6]] | 例外です。これらのアニメーションでは、エフェクトは逆の動きをします。 |
| [[ctl:8]] | 選んだ例外を削除します。 |
| [[ctl:10]] | シーンのアニメーションを選び … |
| [[ctl:12]] | … 例外として追加します。 |

## 放出設定

[[shot:obj_popcorn_r4|放出設定。]]

| 番号 | 機能 |
|---|---|
| [[ctl:6]] | パーティクルの透明度です。 |
| [[ctl:10]] | 1 秒あたりのパーティクルの数です。 |
| [[ctl:14]] | 1 つのパーティクルが存在する秒数です。 |
| [[ctl:18]] | パーティクルの速さです。 |

## カラー設定

[[shot:obj_popcorn_r5|カラー設定。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | エフェクトの基本の色です。 |
| [[ctl:12]] | 色に掛け算をします。エフェクトが明るくなったり、暗くなったりします。 |

## レンダーフラグ

[[shot:obj_popcorn_r6|レンダーフラグ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | パーティクルはシーンのライトを無視します。 |
| [[ctl:6]] | パーティクルはフォグを無視します。 |
| [[ctl:8]] | パーティクルがモデルと一緒に大きくなったり、小さくなったりします。 |
