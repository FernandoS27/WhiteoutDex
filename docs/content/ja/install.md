# インストール

1 つのインストーラーで、パソコンにあるすべての 3ds Max バージョン（2016～2027）に WhiteoutDex を入れます。

## インストールする

1. 3ds Max を閉じます。
2. 最新の `WhiteoutDex_Setup_v<version>.exe` をダウンロードします。GitHub の **Releases** ページと Hive Workshop にあります。
3. インストーラーを起動します。Windows が管理者権限を求めます。**はい** をクリックします。
4. 言語を選び、手順に従います。インストーラーはすべての 3ds Max バージョンを自動で見つけます。
5. 3ds Max を起動します。**WhiteoutDex** メニューと WhiteoutDex サイドバーが表示されます。

!!! note
    3ds Max 2026 以降には **.NET 8** が必要です。足りない場合は、インストーラーが知らせます。

## ファイルの場所

WhiteoutDex は 1 つのフォルダにインストールされます。

`C:\ProgramData\Autodesk\ApplicationPlugins\WhiteoutDex`

3ds Max はすべてをここから読み込みます。自分でファイルをコピーする必要はありません。

個人の設定（言語、ゲームフォルダ、前回のエクスポートオプション）は、3ds Max の設定フォルダ `plugcfg` にあります。WhiteoutDex を更新しても、設定は残ります。

## 更新する

WhiteoutDex は、3ds Max の起動時に新しいバージョンを確認できます（3ds Max 2018 以降）。新しいバージョンがあると、次のように尋ねます。

- **はい** をクリックすると、ダウンロードしてインストールします。更新のために 3ds Max が閉じます。
- **いいえ** をクリックすると、作業を続けます。翌日にもう一度尋ねます。

この確認は [[t:menu_settings]] でオフにしたり、すぐに実行したりできます。

## アンインストールする

**Windows の設定 > アプリ** を開き、**WhiteoutDex** を探して **アンインストール** をクリックします。
