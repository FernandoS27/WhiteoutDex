# スキンチェンジャー

メッシュのスキンを Warcraft III 用に準備します。

**WhiteoutDex > [[t:menu_skin_changer]]** で開きます。先に、スキンの付いたメッシュを選んでください。

[[shot:skin_changer|スキンチェンジャー。]]

| 番号 | 機能 |
|---|---|
| [[ctl:3]] | すべての頂点が、整理されたウェイトで最大 5 個のボーンを持つように、スキンを変更します。元に戻せます。 |
| [[ctl:7]] | この値以下のウェイトを削除します。0.0 では、ちょうどゼロのウェイトだけを削除します。 |
| [[ctl:8]] | 小さいウェイトを削除し、その分を頂点のほかのボーンに分けます。 |
| [[ctl:11]] | 同じマテリアルを使う、選んだスキン付きメッシュを、1 つの Skin を持つ 1 つのメッシュにまとめます。ボーン、ウェイト、ポーズは変わりません。そのため、メッシュは前とまったく同じように動きます。元に戻せます。 |

!!! tip
    メッシュが少ないほど、モデルは速くなります。同じテクスチャの小さな部品がたくさんあるモデルには、*メッシュ + スキンを結合* を使ってください。
