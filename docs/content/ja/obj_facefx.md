# FaceFX

**FaceFX** は、Reforged のヒーローが話すときに顔を動かします。口、目、まゆが声に合わせて動きます。データは `.facefx_ingame` ファイルにあります。FaceFX オブジェクトは、このファイルをモデルに結び付けます。

**Create > Helpers > Warcraft III Plugins > Wc3 FaceFX** で作成します。FaceFX は **Reforged** のモデルでのみ動きます。

[[shot:obj_facefx_r2|FaceFX 設定。]]

| 番号 | 機能 |
|---|---|
| [[ctl:9]] | `.facefx_ingame` ファイルを選びます。 |
| [[ctl:10]] | 短い説明を表示します。 |

2 つの欄には、**ターゲット名**（ゲームがこの顔に使う名前）と**ファイルパス**が入ります。

!!! note
    インポーターは、Reforged のモデルの FaceFX オブジェクトをシーンに読み込みます。エクスポーターは、それを変更せずに書き戻します。
