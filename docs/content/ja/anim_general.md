# アニメ：一般ツール

アニメーションを付けるときや、モデルを仕上げるときに、時間を節約できる小さなツールです。

**WhiteoutDex > [[t:menu_anim_general]]** で開きます。

[[shot:anim_general|一般ツール。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | 選んだオブジェクトに、フレーム 0 と、各シーケンスの開始と終了のキーを追加します。そうすると、1 つのアニメーションが次のアニメーションを変えません。 |
| [[ctl:6]] | 位置キーに TCB ツールを使います。 |
| [[ctl:7]] | … 回転キーに使います。 |
| [[ctl:8]] | … スケールキーに使います。 |
| [[ctl:9]] | 選んだオブジェクトの現在のキーで、*Continuity*（連続性）を 0 にします。TCB キーの行き過ぎがなくなります。 |
| [[ctl:11]] | 2 つのキーの間で 90° を超えて回る回転キーは、ゲームで正しく見えないことがあります。このツールは、間にキーを 1 つ追加します。とても大きな回転（180° を超える）では、もう一度実行してください。 |
| [[ctl:13]] | よく知られた名前のボーン（たとえば *Head*、*Chest*、*Hand*）に、アタッチメントポイントを作成します。 |
| [[ctl:14]] | 選んだオブジェクトを見るポートレートカメラを作成します。何も選んでいないときは、モデルの上部を見ます。 |
| [[ctl:15]] | モデルに合う 2 つのコリジョンスフィアを作成します。Blizzard がユニットに使う方法と同じです。 |
| [[ctl:16]] | モデルに合う 1 つのコリジョンボックスを作成します。Blizzard が建物に使う方法と同じです。 |

!!! tip
    **ワンクリック** ツールは、完成したモデルに使ってください。モデルの大きさを測るので、最終的な大きさのときに一番うまく動きます。
