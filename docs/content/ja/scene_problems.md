# シーンの問題と「すべて修正」

エクスポートの前に、WhiteoutDex はシーンをチェックします。ゲームでモデルを壊すものや、エクスポートを失敗させるものを探します。結果はエクスポートウィンドウに表示されます。

[[shot:exporter_problems|エクスポートウィンドウが 3 つの問題を見つけました。]]

| 番号 | 機能 |
|---|---|
| [[ctl:1092]] | すべての問題を一度に修正します。シーンが変更されます。修正の種類ごとに 1 回の元に戻す操作になるので、[[key:Ctrl+Z]] で取り消せます。 |
| [[ctl:1093]] | すべての問題の一覧を開きます。 |

## 問題の一覧

[[shot:scene_problems|各行が 1 つの問題です。]]

| 番号 | 機能 |
|---|---|
| [[ctl:2000]] | 問題です。行をダブルクリックすると、シーンでそのオブジェクトが選択されます。 |
| [[ctl:2004]] | シーンをもう一度チェックします。たとえば、手で何かを修正した後に使います。 |
| [[ctl:2002]] | 一覧で選んだ問題だけを修正します。 |
| [[ctl:2003]] | 一覧のすべての問題を修正します。 |
| [[ctl:1]] | 一覧を閉じます。 |

## WhiteoutDex が修正するもの

| 問題 | [[t:exp_fix_all_btn]] がすること |
|---|---|
| 2 つのオブジェクトが同じ名前 | 名前を `_2`、`_3` などに変えます。ゲームには重複しない名前が必要です。 |
| 空のメッシュ | 削除します。 |
| Editable Poly | *Edit Mesh* モディファイヤを追加し、エクスポーターが三角形を受け取れるようにします。 |
| *Skin* の上にある *Edit Mesh* | 集約して、スキンが正しいままになるようにします。 |
| ゲームが読めないコントローラー | リニアコントローラーに置き換えます。 |
| Multi/Sub-Object マテリアルを使うメッシュ | メッシュを分割し、各部分が 1 つのマテリアルを持つようにします。 |
| マテリアルが Wc3Material ではない | 変換します。設定は *マテリアル修正* から取ります（そのページを参照）。 |
| 2 つのマテリアルが同じ | 1 つにまとめます。 |

!!! tip
    問題を修正しなくてもかまいません。エクスポーターは修正しなくても動きます。ただし、ゲームでモデルの見た目がおかしくなることがあります。
