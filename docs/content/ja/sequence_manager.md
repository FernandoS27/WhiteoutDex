# シーケンスマネージャー

Warcraft III のモデルは、すべてのアニメーションを 1 本のタイムラインに持っています。各アニメーションは**シーケンス**です。シーケンスには、名前、開始フレーム、終了フレームがあります。シーケンスマネージャーは、これらのシーケンスを作成し、変更します。

**WhiteoutDex > [[t:menu_sequence_manager]]** を選ぶか、サイドバーの **Sequence** ボタンで開きます。

[[shot:sequence_manager_selected|シーケンス「Stand - 1」を選んだシーケンスマネージャー。]]

## 一覧

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | 言葉を入力すると、名前にその言葉を含むシーケンスだけを表示します。 |
| [[ctl:6]] | 検索欄を空にし、すべてのシーケンスをもう一度表示します。 |
| [[ctl:7]] | モデルのすべてのシーケンスです。クリックすると 1 つを選びます。[[key:Ctrl]] を押したままにすると、複数を選べます。シーケンスを**ダブルクリック**すると、ビューポートで再生します。`[GLOBAL 1]` のような行はグローバルシーケンスです。 |
| [[ctl:10]] | すべてのシーケンスを選びます。 |
| [[ctl:11]] | 選択をすべて解除します。 |
| [[ctl:12]] | 選んでいないものを選び、選んでいるものを解除します。 |

## 作成と削除

| 番号 | 機能 |
|---|---|
| [[ctl:14]] | 新しいシーケンスを作成します（下を参照）。 |
| [[ctl:15]] | 選んだシーケンスを削除します。アニメーションキーはタイムラインに残ります。 |
| [[ctl:16]] | 選んだシーケンスを複製します。 |
| [[ctl:17]] | *グローバルシーケンスマネージャー* を開きます。 |

## 選んだシーケンスを変更する

| 番号 | 機能 |
|---|---|
| [[ctl:20]] | 名前です。ゲームは名前を見て、いつアニメーションを再生するかを決めます。*アニメーション名* を参照してください。 |
| [[ctl:23]] | タイムスライダーの現在のフレームを開始フレームにします。 |
| [[ctl:26]] | シーケンスの最初のフレームです。 |
| [[ctl:28]] | 現在のフレームを終了フレームにします。 |
| [[ctl:31]] | シーケンスの最後のフレームです。 |
| [[ctl:32]] | **レアリティ**（0～40）。同じ名前のアニメーションの中で、値が大きいほど、ゲームがこのアニメーションを再生する回数が少なくなります。 |
| [[ctl:36]] | **移動速度**（0～700）。この歩くアニメーションを再生するときに、ユニットが動く速さです。ほとんどのユニットは 250～400 です。 |
| [[ctl:40]] | アニメーションを 1 回だけ再生し、繰り返しません。*Death*、*Attack*、*Spell* に使います。 |
| [[ctl:41]] | エクスポーターはこのシーケンスを出力しません。 |
| [[ctl:44]] | 開始フレームを 1 フレーム前に動かします。[[ctl:45]] ボタンは 1 フレーム後ろに動かします。 |
| [[ctl:47]] | 終了フレームを 1 フレーム前に動かします。[[ctl:48]] ボタンは 1 フレーム後ろに動かします。 |

## 保存と読み込み

| 番号 | 機能 |
|---|---|
| [[ctl:50]] | テキストファイルからシーケンスを読み込みます。 |
| [[ctl:51]] | シーケンスをテキストファイルに保存します。ほかのシーンにコピーするときに使います。 |

## シーケンスを作成する

[[shot:sequence_new|新しいシーケンスのウィンドウ。]]

1. [[t:seq_new_btn]] をクリックします。
2. プリセットを選びます。たとえば *Walk* です。プリセットが、適切な名前と長さを設定します。
3. 名前とフレームを確認します。新しいシーケンスは、最後のシーケンスの後から始まります。
4. **OK** をクリックします。

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | よく使うアニメーションのプリセット、または *カスタム* です。 |
| [[ctl:7]] | 新しいシーケンスの名前です。 |
| [[ctl:12]] | 最初のフレームです。 |
| [[ctl:16]] | 最後のフレームです。 |
| [[ctl:17]] | レアリティの値をオンにします。 |
| [[ctl:21]] | 移動速度をオンにします。 |
| [[ctl:25]] | アニメーションを 1 回だけ再生します。 |

!!! tip
    2 つのシーケンスの間には、数フレームの空きを残してください。そうすると、1 つのアニメーションのキーが次のアニメーションを変えません。

!!! note
    WhiteoutDex は、シーケンスを `.max` ファイルに保存します。*ノートトラック* にシーケンスがある古いシーンも使えます。WhiteoutDex はそれも読み込みます。
