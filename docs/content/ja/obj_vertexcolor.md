# Wc3 Vertex Color

**Wc3 Vertex Color** モディファイヤは、メッシュ全体に色を付けます。色はアニメーションできます。たとえば、クリスタルを脈打たせたり、ユニットが攻撃を受けたときに部分を赤く光らせたりできます。エクスポーターは、これをメッシュの*ジオセットアニメーション*の色として書き込みます。

モディファイヤの一覧から追加します。メッシュを選び、**Wc3 Vertex Color** を選びます。

[[shot:obj_vertexcolor_r1|モディファイヤの基本パラメータ。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | メッシュに付ける色です。白では、テクスチャはそのままです。**Auto Key** でアニメーションさせます。 |
| [[ctl:7]] | メッシュの *Drop Shadow* フラグを設定します。 |
| [[ctl:9]] | 色を使います。オフにすると、フラグだけが書き込まれます。 |

!!! tip
    部分をフェードインやフェードアウトさせるには、代わりに表示キー（*表示キーヤー*）または Wc3Material の *不透明度* を使ってください。
