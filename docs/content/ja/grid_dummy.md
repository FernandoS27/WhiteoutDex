# グリッド & ダミー作成

大きさの目安になるグリッドと、ポイントヘルパーを作成します。

**WhiteoutDex > [[t:menu_grid_dummy]]** で開きます。

[[shot:grid_dummy|グリッド & ダミー作成。]]

| 番号 | 機能 |
|---|---|
| [[ctl:4]] | グリッドの色です。 |
| [[ctl:8]] | グリッドの大きさです（ワールド単位）。 |
| [[ctl:9]] | シーンの中心（0, 0, 0）にグリッドを作成します。 |
| [[ctl:11]] | ポイントの色です。 |
| [[ctl:15]] | ポイントの大きさです。 |
| [[ctl:16]] | 選んだ各オブジェクトの位置にポイントを作成します。何も選んでいないときは、中心にポイントを 1 つ作成します。 |
