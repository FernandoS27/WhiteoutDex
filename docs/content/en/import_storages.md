# Import from the game

You can import a model straight from your Warcraft III game, without a file on your disk.

1. Choose **WhiteoutDex > [[t:menu_import_casc]]**.
2. The game browser opens. Find the model, for example search for `footman`.
3. Click the model and then **Select**.
4. The normal import window opens (see *The Importer*). Choose your options and click **Import**.

WhiteoutDex copies the model and its textures into a temporary folder and imports it from there. Your game files do not change.

!!! tip
    To change a model of the game, import it this way, change it, and export it under a new name into your map or mod folder.

!!! note
    Models from the game belong to Blizzard Entertainment. Use them only as Blizzard allows, for example in maps and mods for Warcraft III.
