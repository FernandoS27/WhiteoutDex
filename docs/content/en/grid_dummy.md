# Grid & Dummy Creator

Creates a grid as a size guide and point helpers.

Open it with **WhiteoutDex > [[t:menu_grid_dummy]]**.

[[shot:grid_dummy|The Grid & Dummy Creator.]]

| No. | What it does |
|---|---|
| [[ctl:4]] | Color of the grid. |
| [[ctl:8]] | Size of the grid in world units. |
| [[ctl:9]] | Creates the grid at the center of the scene (0, 0, 0). |
| [[ctl:11]] | Color of the points. |
| [[ctl:15]] | Size of the points. |
| [[ctl:16]] | Creates a point at each selected object. With nothing selected, it creates one point at the center. |
