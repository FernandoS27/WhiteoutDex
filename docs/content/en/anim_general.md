# Anim: General Tools

Small helpers that save time when you animate or finish a model.

Open them with **WhiteoutDex > [[t:menu_anim_general]]**.

[[shot:anim_general|The General Tools.]]

| No. | What it does |
|---|---|
| [[ctl:4]] | Adds keys at frame 0 and at the start and end of every sequence, for the selected objects. Then one animation does not change the next one. |
| [[ctl:6]] | Use the TCB tool on position keys. |
| [[ctl:7]] | … on rotation keys. |
| [[ctl:8]] | … on scale keys. |
| [[ctl:9]] | Sets *Continuity* to 0 on the current keys of the selected objects. This removes the overshoot of TCB keys. |
| [[ctl:11]] | Rotation keys that turn more than 90° between two keys can look wrong in the game. This tool adds a key in the middle. Run it again for very large turns (over 180°). |
| [[ctl:13]] | Creates attachment points for bones with known names (for example *Head*, *Chest*, *Hand*). |
| [[ctl:14]] | Creates a portrait camera that looks at the selected object. With nothing selected, it looks at the top of the model. |
| [[ctl:15]] | Creates two collision spheres that fit the model, as Blizzard does for units. |
| [[ctl:16]] | Creates one collision box that fits the model, as Blizzard does for buildings. |

!!! tip
    Use the **One Click** tools on a finished model. They measure the model, so they work best when it has its final size.
