# FaceFX

**FaceFX** moves the face of Reforged heroes when they talk: mouth, eyes and brows follow the voice. The data is in a `.facefx_ingame` file. The FaceFX object links this file to the model.

Create it with **Create > Helpers > Warcraft III Plugins > Wc3 FaceFX**. FaceFX only works in **Reforged** models.

[[shot:obj_facefx_r2|FaceFX Settings.]]

| No. | What it does |
|---|---|
| [[ctl:9]] | Choose the `.facefx_ingame` file. |
| [[ctl:10]] | Shows a short explanation. |

The two fields hold the **target name** (the name the game uses for this face) and the **file path**.

!!! note
    The importer brings FaceFX objects from Reforged models into the scene. The exporter writes them back unchanged.
