# Cell Shade Creator

Gives a mesh a cartoon outline. The tool makes a slightly bigger copy of the mesh around it, with the faces turned inside out. In the game you then see a dark line around the model.

Open it with **WhiteoutDex > [[t:menu_cell_shade]]**. Select the meshes first.

[[shot:cell_shade|The Cell Shade Creator.]]

| No. | What it does |
|---|---|
| [[ctl:4]] | The color of the outline. Click to choose another color. |
| [[ctl:6]] | Quick colors. Click one to use it. |
| [[ctl:19]] | How thick the outline is. |
| [[ctl:21]] | Turns the faces of the copy inside out. This makes the outline (normal choice). |
| [[ctl:22]] | Keeps the faces as they are. |
| [[ctl:25]] | The outline is solid. |
| [[ctl:26]] | The outline uses the transparency of the texture. |
| [[ctl:27]] | The outline glows (adds light). |
| [[ctl:28]] | The outline glows and uses the transparency of the texture. |
| [[ctl:30]] | Creates the outline for the selected meshes. |

!!! tip
    The outline is a normal mesh with a *Wc3Material*. You can change its color or thickness later like any other mesh.
