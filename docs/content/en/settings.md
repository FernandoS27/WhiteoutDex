# Settings

In the settings you choose the language of WhiteoutDex and tell it where your game is.

Open them with **WhiteoutDex > [[t:menu_settings]]** or with the gear button at the bottom of the sidebar.

[[shot:settings|The WhiteoutDex settings.]]

## Language

| No. | What it does |
|---|---|
| [[ctl:5]] | The language of all WhiteoutDex windows. Windows that are open change when you open them again. The WhiteoutDex menu changes after you restart 3ds Max. |

## Classic game (MPQ)

Classic Warcraft III (version 1.x) keeps its files in **MPQ** archives. WhiteoutDex reads textures and models from there.

| No. | What it does |
|---|---|
| [[ctl:10]] | The folder of your classic Warcraft III. |
| [[ctl:12]] | Choose the folder yourself. |
| [[ctl:14]] | Finds the folder by itself. |
| [[ctl:15]] | Removes the folder. |
| [[ctl:16]] | Sets the order of the MPQ archives. The first archive that has a file wins. Normally you do not need this. |

## Reforged (CASC)

Warcraft III: Reforged keeps its files in **CASC** storage.

| No. | What it does |
|---|---|
| [[ctl:20]] | The folder of Warcraft III: Reforged, normally `C:\Program Files (x86)\Warcraft III`. |
| [[ctl:24]] | Finds the folder by itself. |
| [[ctl:25]] | Removes the folder. |
| [[ctl:27]] | **Scene art tier.** Which textures the previewer uses: [[t:set_art_tier_items#2]], [[t:set_art_tier_items#3]] or [[t:set_art_tier_items#4]]. [[t:set_art_tier_items#1]] chooses by itself. This is saved with your scene. |

!!! note
    You only need the game you work for. For classic models set the MPQ folder. For Reforged models set the CASC folder. With both, WhiteoutDex finds the most.
