# Game browser

The game browser shows the files inside your Warcraft III game: models, textures and particle effects. You see a small picture of each file, so you find what you need fast.

It opens from many places:

| Where | Button | You choose |
|---|---|---|
| WhiteoutDex menu | [[t:menu_import_casc]] | a model to import |
| Attachment point | *Browse Game Archives* | a model for the attachment |
| Particle Emitter 1 | *Browse Game Archives* | a model for the particles |
| Particle Emitter 2 | *Browse MPQ / CASC* | a texture for the particles |
| Popcorn FX | *Browse Game Archives* | a `.pkb` or `.pkfx` effect |
| Wc3Bitmap | *Open Texture Browser* | a texture |
| Wc3Material | the ⚙ button next to a map | a texture for this slot |

## How to use it

1. Type a part of the name in the search field, for example `footman`.
2. Switch between the **grid** (pictures) and the **tree** (folders).
3. Zoom the pictures bigger or smaller.
4. Click a file. The line at the bottom shows the selected file.
5. Click **Select**.

!!! note
    The browser needs your game folders. Set them in [[t:menu_settings]]. Classic models come from the MPQ archives, Reforged files from CASC.
