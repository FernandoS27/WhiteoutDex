# Welcome to WhiteoutDex

WhiteoutDex is a set of tools for **3ds Max**. With it you can make, change and test models for **Warcraft III**. It works with the classic game (Warcraft III, version 1.x) and with **Warcraft III: Reforged**.

![WhiteoutDex in 3ds Max 2027. Left: the WhiteoutFlakes previewer. Right: the Node Manager and the model in the viewport.](media_1.png)

## What you can do

- **Import** a Warcraft III model (`.mdx` or `.mdl`) into 3ds Max. WhiteoutDex also loads the textures from your game.
- **Edit** the model like any other 3ds Max object: change the mesh, the bones, the animations and the materials.
- **Preview** the model in **WhiteoutFlakes**. This window shows the model the same way the game shows it.
- **Export** the model back to `.mdx` or `.mdl`, for the classic game or for Reforged. WhiteoutDex converts the textures for you.
- Use **special objects** that only Warcraft III has: particle emitters, ribbons, attachment points, event objects, collision shapes and more.

## What you need

| | |
|---|---|
| Windows | Windows 10 or newer |
| 3ds Max | Any version from 2016 to 2027 |
| Warcraft III | Optional, but recommended: WhiteoutDex takes textures and models from your game folder. |

## How to read this manual

The manual has four kinds of pages:

- **Getting Started** helps you install and set up WhiteoutDex.
- **Tutorials** are short lessons. Do them in order if you are new.
- **Tool and object pages** explain one window or one object. Each picture has numbers. The table under the picture tells you what each number does.
- **Appendix** pages are lists to look up things.

Words in a **blue box**, like [[t:menu_importer]], are the words you see in 3ds Max. Keys look like this: [[key:Ctrl+Z]].

!!! tip
    The manual is in the same language as WhiteoutDex. You can change the language of WhiteoutDex in [[t:menu_settings]]. See *Settings*.
