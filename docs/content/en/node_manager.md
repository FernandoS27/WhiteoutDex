# Node Manager

A model has many kinds of objects: meshes, bones, helpers, emitters and more. The Node Manager shows, hides or freezes all objects of one kind at once.

Open it with **WhiteoutDex > [[t:menu_node_manager]]**.

[[shot:node_manager|The Node Manager.]]

## 2. Do something with them

| No. | What it does |
|---|---|
| [[ctl:20]] | Shows the objects. |
| [[ctl:21]] | Hides the objects. |
| [[ctl:22]] | Freezes the objects, so you cannot select them by mistake. |
| [[ctl:23]] | Unfreezes the objects. |
| [[ctl:24]] | Shows the objects see-through. |
| [[ctl:25]] | Shows the objects solid again. |

!!! tip
    Hide all helpers, bones and emitters while you work on the mesh. Freeze the bones while you paint skin weights.
