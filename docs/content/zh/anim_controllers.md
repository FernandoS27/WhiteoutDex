# 动画：控制器

魔兽争霸 III 有四种在关键帧之间过渡的方式：*无*（跳变）、*线性*、*贝塞尔* 和 *埃尔米特*（TCB）。这个工具一次性给选中的对象设置你选择的位置、旋转和缩放控制器。

用 **WhiteoutDex > [[t:menu_anim_controllers]]** 打开它。

[[shot:anim_controllers|控制器工具。]]

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 位置在关键帧之间沿直线移动。 |
| [[ctl:5]] | 位置沿平滑曲线移动。 |
| [[ctl:6]] | 位置使用 TCB 关键帧（平滑，带张力、连续性和偏移）。 |
| [[ctl:7]] | 保持位置控制器不变。 |
| [[ctl:10]] | 旋转在关键帧之间均匀转动。 |
| [[ctl:11]] | 旋转平滑地转动。 |
| [[ctl:12]] | 旋转使用 TCB 关键帧。 |
| [[ctl:13]] | 保持旋转控制器不变。 |
| [[ctl:16]] | 缩放均匀变化。 |
| [[ctl:17]] | 缩放沿平滑曲线变化。 |
| [[ctl:18]] | 缩放使用 TCB 关键帧。 |
| [[ctl:19]] | 保持缩放控制器不变。 |
| [[ctl:22]] | 给选中的对象设置这些控制器。 |

!!! note
    导出器也会替换游戏无法读取的控制器（请参阅 *场景问题与全部修复*）。用这个工具，你可以自己选择类型。
