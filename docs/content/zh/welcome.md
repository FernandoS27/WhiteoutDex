# 欢迎使用 WhiteoutDex

WhiteoutDex 是一套用于 **3ds Max** 的工具。你可以用它制作、修改和测试 **魔兽争霸 III** 的模型。它支持经典版游戏（魔兽争霸 III 1.x 版本），也支持 **魔兽争霸 III：重制版**。

![3ds Max 2027 中的 WhiteoutDex。左边：WhiteoutFlakes 预览器。右边：节点管理器和视口中的模型。](media_1.png)

## 你可以做什么

- **导入** 魔兽争霸 III 模型（`.mdx` 或 `.mdl`）到 3ds Max。WhiteoutDex 还会从你的游戏中加载纹理。
- **编辑** 模型，就像编辑其他 3ds Max 对象一样：修改网格、骨骼、动画和材质。
- 在 **WhiteoutFlakes** 中 **预览** 模型。这个窗口显示模型的方式和游戏一样。
- 把模型 **导出** 回 `.mdx` 或 `.mdl`，用于经典版或重制版。WhiteoutDex 会替你转换纹理。
- 使用魔兽争霸 III 独有的 **特殊对象**：粒子发射器、飘带、附着点、事件对象、碰撞形状等。

## 你需要什么

| | |
|---|---|
| Windows | Windows 10 或更新版本 |
| 3ds Max | 2016 到 2027 的任意版本 |
| 魔兽争霸 III | 可选，但推荐安装：WhiteoutDex 会从你的游戏文件夹读取纹理和模型。 |

## 如何阅读本手册

本手册有四类页面：

- **入门** 帮你安装和设置 WhiteoutDex。
- **教程** 是简短的课程。如果你是新手，请按顺序完成。
- **工具和对象页面** 讲解一个窗口或一个对象。每张图片上都有编号。图片下面的表格告诉你每个编号的作用。
- **附录** 页面是可供查阅的列表。

**蓝框** 中的文字，例如 [[t:menu_importer]]，就是你在 3ds Max 中看到的文字。按键的样子是这样的：[[key:Ctrl+Z]]。

!!! tip
    本手册的语言与 WhiteoutDex 的语言相同。你可以在 [[t:menu_settings]] 中更改 WhiteoutDex 的语言。请参阅 *设置*。
