# Popcorn FX

**Popcorn FX** 是魔兽争霸 III：重制版的粒子系统。特效本身是一个用 PopcornFX 编辑器制作的 `.pkfx`（或 `.pkb`）文件。3ds Max 中的 Popcorn 对象把这个特效放在模型上，并控制它什么时候播放。

用 **Create > Helpers > Warcraft III Plugins > Wc3 Popcorn** 创建它。Popcorn 只在 **重制版** 模型中有效。

## Popcorn FX 文件

[[shot:obj_popcorn_r2|Popcorn FX 文件。]]

| 编号 | 作用 |
|---|---|
| [[ctl:9]] | 从游戏档案中选择一个 `.pkb` 或 `.pkfx` 特效。 |
| [[ctl:10]] | 选择磁盘上的一个特效文件。 |
| [[ctl:11]] | 显示一段简短的说明。 |

按钮上方的两个字段保存特效的路径和它前面的文件夹。

[[shot:obj_popcorn_r3|动画可见性指南。]]

| 编号 | 作用 |

| [[ctl:6]] | 例外：在这些动画中，特效的行为正好相反。 |
| [[ctl:8]] | 移除选中的例外。 |

| [[ctl:12]] | … 并把它添加为例外。 |
