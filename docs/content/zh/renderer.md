# WhiteoutFlakes 预览器

**WhiteoutFlakes** 按魔兽争霸 III 的方式显示你的模型：使用游戏的着色器、队伍颜色、光照、粒子和飘带。它实时跟随 3ds Max：你移动时间滑块或修改了什么，预览器都会更新。

用 **WhiteoutDex > [[t:menu_renderer]]** 或侧边栏中的 **Renderer** 按钮打开它。

![3ds Max 2027 旁边的 WhiteoutFlakes，显示一个带队伍颜色的重制版模型。](media_1.png)

## 工具栏

| 元素 | 作用 |
|---|---|
| **动画** | 播放模型的一个序列，或选择 *自由范围* 跟随 Max 的时间滑块。 |
| **镜头** | *自由镜头*，或场景中的某个摄影机，例如头像摄影机。 |
| **队伍颜色** | 模型的玩家颜色。 |
| **光照** | *游戏内*（和游戏中一样）、*界面*（和菜单中一样）或 *动态*。 |
| **同步摄影机** | 预览器跟随 3ds Max 的活动视口。 |
| **重新同步** | 重新读取整个场景，例如在你添加对象之后。 |

## 菜单

| 菜单 | 包含的内容 |
|---|---|
| **视图** | 显示或隐藏网格、粒子、飘带和事件对象。*Warcraft III 美术资源*：使用哪套纹理（*跟随渲染模式*、*Classic*、*Reforged (HD)*、*Definitive*）。*地形纹理集*：地面。 |
| **调试** | 碰撞形状和灯光的标记、特殊视图（反射率、法线、细节层次、光源数量 …），以及细节层次的选择。 |
| **设置** | 背景、亮度、音量、一天中的时间、基于图像的光照、阴影、雾、图形后端（Direct3D 11、Direct3D 12、Vulkan）以及游戏文件夹。 |

## 须知

- 粒子和飘带按游戏中的方式模拟。当你在时间滑块上跳到别的位置时，预览器会把特效一直计算到新的帧，所以它们看起来就像动画一直播放到了那里。
- 预览器把它的设置保存在 `3dsmax.exe` 旁边的 `WhiteoutFlakes.ini` 中。
- 如果预览器什么也不显示或者崩溃，请查看 `WhiteoutDex_render.log`（请参阅 *文件与设置*）。

!!! tip
    在 **视图 > Warcraft III 美术资源** 中选择 *Classic* 或 *Reforged (HD)*，看看你的模型在两个版本的游戏中分别是什么样子。
