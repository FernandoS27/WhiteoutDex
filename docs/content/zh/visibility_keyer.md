# 可见性关键帧工具

在魔兽争霸 III 中，你用 **可见性关键帧** 显示和隐藏模型的某些部分：例如只在攻击动画中出现的武器，或只在单位施法时出现的光晕。可见性关键帧工具替你设置这些关键帧。

用 **WhiteoutDex > [[t:menu_visibility_keyer]]** 打开它。请先选择对象。

[[shot:visibility_keyer|可见性关键帧工具。]]

| 编号 | 作用 |
|---|---|
| [[ctl:3]] | 在当前帧显示或隐藏选中的对象。 |
| [[ctl:5]] | 给所有选中的对象添加可见性控制器。 |
| [[ctl:6]] | 从选中的对象上移除可见性控制器。 |
| [[ctl:7]] | 复制选中对象的可见性关键帧。 |
| [[ctl:8]] | 把它们粘贴到选中的对象上。 |
| [[ctl:9]] | 游戏在关键帧之间如何变化：*无* 会立即跳变，其他类型会淡入淡出。 |
| [[ctl:11]] | 把现有控制器改为你选择的类型。 |
| [[ctl:13]] | 在当前帧设置一个 *显示* 关键帧。 |
| [[ctl:14]] | 在当前帧设置一个 *隐藏* 关键帧。 |
| [[ctl:16]] | 让对象在整个动画范围内可见。 |
| [[ctl:17]] | 在整个动画范围内隐藏对象。 |
| [[ctl:19]] | 在你于 *序列管理器* 中选中的序列里显示对象。 |
| [[ctl:20]] | 在选中的序列里隐藏对象。 |

## 示例：只在攻击时出现的武器

1. 选择武器。
2. 点击 [[ctl:17]]，在所有地方隐藏它。
3. 在 *序列管理器* 中选择 *Attack* 序列。
4. 点击 [[ctl:19]]。

!!! tip
    大多数可见性关键帧请使用插值类型 *无*。使用其他类型时，游戏会让对象淡入淡出，这对大多数部件来说看起来不对。
