# 导出器

导出器把你的场景保存为魔兽争霸 III 模型（`.mdx` 或 `.mdl`）。它还能把你的纹理转换为游戏使用的格式。

## 打开导出器

- 菜单 **WhiteoutDex > [[t:menu_exporter]]**
- WhiteoutDex 侧边栏中的 **Export** 按钮
- **File > Export**，然后选择 *Warcraft III MDX/MDL Model*

选择一个文件名。然后导出窗口会打开。

## 导出窗口

[[shot:exporter|导出窗口，显示“几何”选项卡。]]

窗口顶部显示文件名。在它下面，你可以看到文件是新文件，还是已经有同名文件。

| 编号 | 作用 |
|---|---|
| [[ctl:1001]] | **模型名称。** 文件内部的名称。游戏不显示它，但其他工具会显示。 |
| [[ctl:1011]] | 为经典版游戏导出（MDX 版本 800）。纹理变成 `.blp` 文件。 |
| [[ctl:1012]] | 为重制版导出（MDX 版本 1800）。纹理变成 `.dds` 文件。 |
| [[ctl:1015]] | 显示网格选项（即这张图）。 |
| [[ctl:1016]] | 显示纹理选项。 |
| [[ctl:1021]] | 把使用相同材质的网格合并为一个。模型会更小、更快。 |
| [[ctl:1027]] | 让两个网格相接处的法线保持一致。这样可以隐藏接缝。如果你用平滑组做硬边，就不要使用它。 |
| [[ctl:1028]] | 也导出没有被使用的骨骼和辅助对象。通常导出器会把它们去掉。 |
| [[ctl:1032]] | 修改蒙皮权重，使它们能在经典版游戏中使用。经典版游戏只能使用简单的权重。仅用于 [[t:exp_format_classic_title]]。 |
| [[ctl:1030]] | 文件已存在时，导出器会在文件名后加上 `_1`、`_2` 等。你的旧文件会保留。 |
| [[ctl:1031]] | 导出后打开文件所在的文件夹。 |
| [[ctl:1]] | 开始导出。 |
| [[ctl:2]] | 关闭窗口，不导出。 |

选项下面的绿色框表示 WhiteoutDex 在你的场景中没有发现问题。发现问题时，这个框是黄色的。请参阅 *场景问题与全部修复*。

### 纹理选项卡

[[shot:exporter_textures|“纹理”选项卡，这里是经典版导出的设置。]]

| 编号 | 作用 |
|---|---|
| [[ctl:1060]] | 把材质中的纹理转换为 `.blp`（经典版）或 `.dds`（重制版），并保存在模型旁边。 |
| [[ctl:1071]] | **仅限经典版。** [[t:exp_blp_paletted_item]] 或 *JPEG*。JPEG 的颜色更多。调色板文件更小。使用 JPEG 时，你还要设置质量（1–100）。 |
| [[ctl:1075]] | 把颜色稍微混合一下。这样可以隐藏调色板纹理中颜色之间的生硬过渡。 |
| [[ctl:1061]] | 生成纹理的较小版本，游戏在远处显示模型时使用它们。请保持开启。 |
| [[ctl:1062]] | 替换已经存在的纹理文件。关闭时，导出器保留现有文件。 |

对于 **重制版**，你要选择 DDS 格式：*BC3 (DXT5)* 或 *BC7*。BC7 效果更好。BC3 可以在较旧的显卡上使用。

## 经典版还是重制版？

| | 经典版 | 重制版 |
|---|---|---|
| 游戏 | 魔兽争霸 III 1.x，以及重制版中的经典画面 | 重制版画面（HD） |
| MDX 版本 | 800 | 1800 |
| 纹理 | `.blp` | `.dds` |
| 蒙皮 | 简单权重（使用 [[t:exp_quantize_skin_weights_chk]]） | 完整权重 |

!!! tip
    导出器会记住所有选项，下次导出时继续使用。
