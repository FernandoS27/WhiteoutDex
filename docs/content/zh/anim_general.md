# 动画：通用工具

一些小工具，帮你在制作动画或完善模型时节省时间。

用 **WhiteoutDex > [[t:menu_anim_general]]** 打开它们。

[[shot:anim_general|通用工具。]]

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 给选中的对象在第 0 帧以及每个序列的起点和终点添加关键帧。这样一个动画不会影响下一个动画。 |
| [[ctl:6]] | 对位置关键帧使用 TCB 工具。 |
| [[ctl:7]] | … 对旋转关键帧使用。 |
| [[ctl:8]] | … 对缩放关键帧使用。 |
| [[ctl:9]] | 把选中对象当前关键帧的 *Continuity*（连续性）设为 0。这样可以去掉 TCB 关键帧的过冲。 |
| [[ctl:11]] | 两个关键帧之间旋转超过 90° 时，在游戏中可能看起来不对。这个工具会在中间添加一个关键帧。旋转角度很大时（超过 180°），请再运行一次。 |
| [[ctl:13]] | 为名称已知的骨骼（例如 *Head*、*Chest*、*Hand*）创建附着点。 |
| [[ctl:14]] | 创建一个对准选中对象的头像摄影机。没有选中对象时，它对准模型的顶部。 |
| [[ctl:15]] | 创建两个贴合模型的碰撞球，和暴雪对单位的做法一样。 |
| [[ctl:16]] | 创建一个贴合模型的碰撞盒，和暴雪对建筑的做法一样。 |

!!! tip
    请在完成的模型上使用 **一键工具**。它们会测量模型，所以在模型达到最终尺寸时效果最好。
