# 术语表

你在 WhiteoutDex 和本手册中会遇到的词语。

| 词语 | 含义 |
|---|---|
| **MDX / MDL** | 魔兽争霸 III 的模型文件。`.mdx` 是二进制文件，体积小。`.mdl` 是文本，你可以阅读和编辑。两者保存相同的数据。 |
| **经典版（Classic）** | 魔兽争霸 III 1.x 版本和经典画面。模型使用 MDX 版本 800。 |
| **重制版（Reforged）** | 带有 HD 画面的魔兽争霸 III：重制版。模型使用 MDX 版本 900 到 1800。WhiteoutDex 导出版本 1800。 |
| **MPQ** | 经典版游戏的档案文件（例如 `War3.mpq`）。 |
| **CASC** | 魔兽争霸 III：重制版的存储。 |
| **BLP** | 经典版游戏的纹理格式。 |
| **DDS** | 重制版的纹理格式。 |
| **Geoset** | 模型中的一个网格。一个模型可以有很多 Geoset。 |
| **骨骼** | 带动蒙皮网格顶点的节点。 |
| **辅助对象** | 带动其他节点的节点，但在游戏中看不到。 |
| **蒙皮** | 说明哪根骨骼带动哪个顶点，以及影响有多强（权重）。 |
| **序列** | 模型的一个动画，例如 *Walk*。它有一个名称、一个起始帧和一个结束帧。 |
| **全局序列** | 一直循环的动画，与当前序列无关。适合一直在动的东西，例如旋转的水晶。 |
| **关键帧** | 某个时间点上的一个数值。游戏在关键帧之间过渡。 |
| **控制器** | 游戏如何在关键帧之间过渡：*无*（跳变）、*线性*、*贝塞尔* 或 *埃尔米特*（平滑）。 |
| **附着点** | 模型上的一个位置，游戏会把东西附着在那里：武器、法术特效、选择圈。 |
| **事件对象** | 在动画的某个时刻触发一件事：声音、脚印、血迹、生成的模型。 |
| **粒子发射器 1** | 发射小模型。 |
| **粒子发射器 2** | 发射带纹理的粒子：火焰、烟雾、火花。 |
| **飘带发射器** | 在一个移动的点后面画出拖尾。 |
| **Popcorn FX** | 重制版的粒子系统（`.pkfx` 文件）。 |
| **碰撞形状** | 一个盒体或球体。游戏用它判断你可以点击模型的哪里。 |
| **范围（Extents）** | 模型在一个序列中的尺寸。游戏用它判断模型什么时候在屏幕上。 |
| **可替换纹理** | 由游戏填充的纹理，例如队伍颜色。 |
| **队伍颜色 / 队伍光晕** | 单位身上的玩家颜色。 |
| **过滤模式** | 材质的绘制方式：不透明、透明、叠加（发光）等。 |
| **公告板（Billboard）** | 始终转向摄影机的节点。 |
| **美术资源（Art tier）** | 预览器显示哪套画面：Classic、Reforged (HD) 或 Definitive。 |
| **WhiteoutFlakes** | 按游戏的方式显示你的模型的预览器。 |
