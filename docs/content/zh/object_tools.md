# 对象操作工具

在对象之间复制和粘贴位置、链接和顶点位置。适合对称的模型：先做好左边，再复制到右边。

用 **WhiteoutDex > [[t:menu_object_tools]]** 打开这些工具。

[[shot:object_tools|对象操作工具，已选中一个网格。]]

## 对象

| 编号 | 作用 |
|---|---|
| [[ctl:5]] | **层级：** 保存选中对象的父级链接，并取消它们的链接。 |
| [[ctl:6]] | 把对象链接回它们保存的父级。 |
| [[ctl:8]] | **位置：** 复制第一个选中对象的位置。 |
| [[ctl:9]] | 把选中的对象移到复制的位置。 |
| [[ctl:11]] | **结构 (L↔R)：** 复制所有选中对象的位置和名称。 |
| [[ctl:12]] | 把位置粘贴到名称镜像对应的对象上：从 `Arm_L` 复制的位置会粘贴到 `Arm_R`。 |
| [[ctl:14]] | 粘贴时暂时取消对象的链接，这样它们的子对象不会跟着移动。 |
| [[ctl:15]] | 粘贴时镜像位置，沿你勾选的轴：[[ctl:16]]、[[ctl:17]]、[[ctl:18]]。 |

## 顶点（多边形工具）

请先选择 Editable Poly 或 Editable Mesh 的顶点。按钮上方的一行显示对象名称，以及你选中了多少个顶点。

| 编号 | 作用 |
|---|---|
| [[ctl:22]] | 复制选中顶点的位置。 |
| [[ctl:23]] | 把位置粘贴到顶点上。 |
| [[ctl:26]] | 粘贴时镜像 X 值。[[ctl:27]] 和 [[ctl:28]] 对 Y 和 Z 做同样的事。 |
| [[ctl:29]] | 以世界中心为镜像中心。 |
| [[ctl:30]] | 以对象的轴心为镜像中心。 |
| [[ctl:31]] | 以选择集的中心为镜像中心。 |
| [[ctl:35]] | 粘贴到编号相同的顶点上。在同一个网格或它的副本上使用。 |
| [[ctl:36]] | 粘贴到你选中的顶点上，也可以是另一个网格。 |

!!! tip
    用 `_L` 和 `_R`（或 `Left` 和 `Right`）命名你的对象。这样 *结构 (L↔R)* 会自动找到每个对象的对应对象。
