# 教程：火焰特效

在本课中，你用一个 **粒子发射器 2** 在火把上做出火焰。

## 第 1 步：创建发射器

1. 选择 *Create > Geometry > Particle Systems > Wc3Particles2*。
2. 在视口中点击以放置它。把它移到火把顶端。
3. 把它链接到火把（或握着火把的骨骼）上，让它跟着一起移动。

## 第 2 步：纹理

1. 打开 **Texture Options** 卷展栏。
2. 点击 **浏览 MPQ / CASC**，选择一张游戏中的火焰纹理（搜索 `fire` 或 `flare`）。
3. 把 **纹理混合模式** 设为 **Additive**。Additive 粒子会发光。

## 第 3 步：运动

在 **Emitter Options** 和 **Timing Options** 中：

1. **速度：** 设一个较小的值，让火焰慢慢上升。
2. **锥角：** 设小一点，让火焰聚在一起。
3. **生命周期：** 大约 1 秒。
4. **发射速率：** 大约每秒 20 个粒子。

你会立即在视口中看到粒子。调整这些数值，直到你满意为止。

## 第 4 步：颜色和淡入淡出

在 **Particle Options** 中：

1. **颜色：** 开始为黄色，中间为橙色，结束为暗红色。
2. **透明度：** 开始为 0，中间为 255，结束为 0。火焰会淡入再淡出。
3. **缩放：** 开始小，中间大一些，结束小。

![发射器的 Particle Options。](obj_particles2_r6.png)

## 第 5 步：检查效果

打开预览器（**WhiteoutDex > [[t:menu_renderer]]**）。它显示的火焰和游戏中的一样。

!!! tip
    用 *Particle Configuration* 中的 **导出** 保存你喜欢的火焰。用 **导入** 把它加载到其他模型上。
