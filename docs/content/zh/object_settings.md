# 对象设置

魔兽争霸 III 对象有一些 3ds Max 没有的额外设置，例如 *公告板*。对象设置把它们设置到选中的对象上。WhiteoutDex 把它们保存在对象中（作为用户属性），导出器会把它们写入模型。

用 **WhiteoutDex > [[t:menu_object_settings]]** 打开它。请先选择一个或多个对象。

[[shot:object_settings|对象设置，已选中一根骨骼。]]

## 标志

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 对象不随父级移动。 |
| [[ctl:5]] | 对象不随父级旋转。 |
| [[ctl:6]] | 对象不随父级缩放。 |
| [[ctl:7]] | 对象始终朝向摄影机。适合光晕和平面特效。 |
| [[ctl:8]] | 朝向摄影机，但只绕 X 轴旋转。 |
| [[ctl:9]] | … 只绕 Y 轴。 |
| [[ctl:10]] | … 只绕 Z 轴。 |
| [[ctl:11]] | 对象在摄影机视图中保持在固定位置。 |

## 网格

| 编号 | 作用 |
|---|---|
| [[ctl:13]] | **普通蒙皮：** 使用 Skin 修改器或链接的骨骼。 |
| [[ctl:14]] | **ArtTools 蒙皮：** 导出时把不同网格的顶点连接起来。只在你想让它们互相融合的网格上使用。 |
| [[ctl:17]] | 玩家在游戏中无法点击这个网格。 |
