# Wc3Material

你导出的每个网格都需要一个 **Wc3Material**。它保存纹理，并告诉游戏如何绘制这些纹理。导入器会替你创建 Wc3Material。对于你自己的网格，请在 Material Editor 中创建一个，或者用 *材质修复* 转换你的材质。

这些图片显示的是示例模型中的一个材质，位于 Compact Material Editor 中。

## 材质基础参数

[[shot:mat_wc3material_r1|材质基础参数。]]

| 编号 | 作用 |
|---|---|
| [[ctl:3]] | **着色器。** *SD* 用于经典版模型，*HD* 用于重制版，*SD on HD* 用于重制版模型中的经典版纹理，*Crystal* 用于重制版的水晶着色器。 |
| [[ctl:5]] | **过滤模式**——材质的绘制方式（见下表）。 |
| [[ctl:8]] | 面的两面都会绘制。 |
| [[ctl:9]] | 忽略光照。适合发光的部分。 |
| [[ctl:10]] | 忽略雾。 |
| [[ctl:11]] | 整个网格使用一种颜色。 |
| [[ctl:12]] | 设置材质的 *Full Resolution* 标志。 |
| [[ctl:13]] | 绘制在其他东西的上面。 |
| [[ctl:14]] | 不遮挡它后面的东西。 |
| [[ctl:15]] | 玩家无法点击这个部分。 |
| [[ctl:16]] | 使用环境光遮蔽（重制版）。 |
| [[ctl:17]] | 背面投射阴影（重制版）。 |
| [[ctl:18]] | 完全不受光照（重制版）。 |
| [[ctl:20]] | 透明图层的绘制顺序：由近及远，或由远及近。 |
| [[ctl:24]] | 材质之间的绘制顺序（−20 到 20）。数值越高，绘制得越晚。 |
| [[ctl:26]] | 使用由游戏填充的纹理：队伍颜色、队伍光晕、悬崖或某种树木纹理。 |

| 过滤模式 | 效果 | 用途 |
|---|---|---|
| None(无) | 不透明。 | 普通部件。 |
| Transparent(透明) | Alpha 低的地方出现镂空，边缘生硬。 | 树叶、头发、栅栏。 |
| Blend(混合) | 平滑的透明效果。 | 玻璃、柔和的边缘、阴影。 |
| Additive(叠加) | 叠加光亮，会发光。黑色不可见。 | 火焰、魔法、光线。 |
| AddAlpha(叠加Alpha) | 叠加光亮，并使用 Alpha。 | 有形状的光晕。 |
| Modulate(正片叠底) | 让后面的东西变暗。 | 暗色印记、阴影。 |
| Modulate 2X(正片叠底 2X) | 变暗或变亮。 | 特殊效果。 |

## 图层动画

[[shot:mat_wc3material_r2|图层动画。]]

| 编号 | 作用 |
|---|---|
| [[ctl:6]] | 图层的不透明度（0 到 1）。给它设置动画，可以让材质淡入和淡出。 |
| [[ctl:7]] | 不透明度在关键帧之间如何变化。 |
| [[ctl:9]] | 把不透明度动画写入模型。 |
| [[ctl:11]] | 纹理随时间逐步切换，就像翻页动画。 |
| [[ctl:14]] | 纹理使用哪个 UV 通道。 |
| [[ctl:15]] | 把纹理切换动画写入模型。 |

移动的纹理（UV 动画）在 *Wc3Bitmap* 上设置，而不是在这里。

## 材质纹理贴图

[[shot:mat_wc3material_r3|材质纹理贴图。]]

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | **漫反射：** 颜色纹理。经典版模型只使用这一张。 |
| [[ctl:5]] | 为这个贴图槽打开纹理浏览器（游戏中的纹理）。 |
| [[ctl:10]] | **法线：** 表面细节（重制版）。 |
| [[ctl:16]] | **ORM：** 遮蔽、粗糙度和金属度合在一张纹理中（重制版）。 |
| [[ctl:22]] | **自发光：** 自己会发光的部分（重制版）。 |
| [[ctl:28]] | **队伍颜色：** 队伍颜色的遮罩（重制版，可选）。 |
| [[ctl:34]] | **环境：** 反射纹理（重制版）。 |

每个贴图槽都有一个 **路径前缀**：导出器写在文件名前面的文件夹，例如 `Textures\`。
