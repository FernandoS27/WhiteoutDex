# 序列管理器

魔兽争霸 III 模型把所有动画都放在一条时间轴上。每个动画是一个 **序列**：一个名称、一个起始帧和一个结束帧。序列管理器用来创建和修改这些序列。

用 **WhiteoutDex > [[t:menu_sequence_manager]]** 或侧边栏中的 **Sequence** 按钮打开它。

[[shot:sequence_manager_selected|序列管理器，已选中序列“Stand - 1”。]]

## 列表

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 输入一个词，只显示名称中包含这个词的序列。 |
| [[ctl:6]] | 清空搜索框，再次显示所有序列。 |
| [[ctl:7]] | 模型的所有序列。点击选择一个序列。按住 [[key:Ctrl]] 可以选择多个。**双击** 一个序列，即可在视口中播放它。像 `[GLOBAL 1]` 这样的行是全局序列。 |
| [[ctl:10]] | 选择所有序列。 |
| [[ctl:11]] | 全部不选。 |
| [[ctl:12]] | 选择未选中的序列，并取消选择已选中的序列。 |

## 创建和移除

| 编号 | 作用 |
|---|---|
| [[ctl:14]] | 创建一个新序列（见下文）。 |
| [[ctl:15]] | 删除选中的序列。动画关键帧仍留在时间轴上。 |
| [[ctl:16]] | 复制选中的序列。 |
| [[ctl:17]] | 打开 *全局序列管理器*。 |

## 修改选中的序列

| 编号 | 作用 |
|---|---|
| [[ctl:20]] | 名称。名称告诉游戏什么时候播放这个动画。请参阅 *动画名称*。 |
| [[ctl:23]] | 把时间滑块的当前帧用作起始帧。 |
| [[ctl:26]] | 序列的第一帧。 |
| [[ctl:28]] | 把当前帧用作结束帧。 |
| [[ctl:31]] | 序列的最后一帧。 |
| [[ctl:32]] | **稀有度**（0–40）。对于同名的动画，数值越高，游戏播放这个动画的次数越少。 |
| [[ctl:36]] | **移动速度**（0–700）。单位播放这个行走动画时移动的速度。大多数单位为 250 到 400。 |
| [[ctl:40]] | 动画只播放一次，不重复。用于 *Death*、*Attack* 和 *Spell*。 |
| [[ctl:41]] | 导出器会跳过这个序列。 |
| [[ctl:44]] | 把起始帧提前一帧。[[ctl:45]] 按钮把它推后一帧。 |
| [[ctl:47]] | 把结束帧提前一帧。[[ctl:48]] 按钮把它推后一帧。 |

## 保存和加载

| 编号 | 作用 |
|---|---|
| [[ctl:50]] | 从文本文件加载序列。 |
| [[ctl:51]] | 把序列保存到文本文件。用它把序列复制到另一个场景。 |

## 创建序列

[[shot:sequence_new|新建序列的窗口。]]

1. 点击 [[t:seq_new_btn]]。
2. 选择一个预设，例如 *Walk*。预设会设置合适的名称和长度。
3. 检查名称和帧。新序列从上一个序列之后开始。
4. 点击 **确定**。

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 常见动画的预设，或 *Custom*。 |
| [[ctl:7]] | 新序列的名称。 |
| [[ctl:12]] | 第一帧。 |
| [[ctl:16]] | 最后一帧。 |
| [[ctl:17]] | 开启稀有度数值。 |
| [[ctl:21]] | 开启移动速度。 |
| [[ctl:25]] | 动画只播放一次。 |

!!! tip
    在两个序列之间留出几帧空白。这样一个动画的关键帧不会影响下一个动画。

!!! note
    WhiteoutDex 把序列保存在你的 `.max` 文件中。序列保存在 *note tracks* 中的旧场景仍然可用：WhiteoutDex 也会读取它们。
