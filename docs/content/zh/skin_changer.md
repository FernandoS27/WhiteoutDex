# 皮肤替换器

为魔兽争霸 III 准备网格的蒙皮。

用 **WhiteoutDex > [[t:menu_skin_changer]]** 打开它。请先选择带蒙皮的网格。

[[shot:skin_changer|皮肤替换器。]]

| 编号 | 作用 |
|---|---|
| [[ctl:3]] | 修改蒙皮，让每个顶点最多受 5 根骨骼影响，并且权重干净。你可以撤销此操作。 |
| [[ctl:7]] | 小于或等于这个值的权重会被移除。0.0 只移除正好为零的权重。 |
| [[ctl:8]] | 移除较小的权重，并把它们的份额分给该顶点的其他骨骼。 |
| [[ctl:11]] | 把选中的、使用相同材质的蒙皮网格合并为一个网格，只用一个 Skin。骨骼、权重和姿势保持不变，所以网格的运动和之前完全一样。你可以撤销此操作。 |

!!! tip
    网格越少，模型越快。当模型有很多使用相同纹理的小部件时，请使用 *合并网格 + 蒙皮*。
