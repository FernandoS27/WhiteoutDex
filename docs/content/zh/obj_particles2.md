# 粒子发射器 2

魔兽争霸 III 中的大部分特效都由粒子发射器 2 制作：火焰、烟雾、火花、尘土、魔法。它发射许多扁平的小图片（粒子）。每个粒子只存在很短的时间，并在存在期间改变颜色、大小和透明度。

用 **Create > Geometry > Particle Systems > Wc3Particles2** 创建它。WhiteoutDex 会直接在视口中显示粒子。

下面的图片显示的是示例模型 *HeroPaladin* 的发射器。

## Emitter Options

[[shot:obj_particles2_r3|Emitter Options（发射器选项）。]]

## Other Options

[[shot:obj_particles2_r7|Other Options（其他选项）。]]

| 编号 | 作用 |
|---|---|
| [[ctl:3059]] | 绘制顺序。数值越高，绘制得越晚（在上层）。 |
| [[ctl:4116]] | 粒子随模型一起移动。没有它，粒子会停留在发射时的位置。 |
| [[ctl:4117]] | 粒子平躺在地面上，而不是朝向摄影机。适合光环和波纹。 |

!!! tip
    火焰和魔法请使用 *Additive*、较小的锥角和较短的生命周期。让透明度从 0 变到 255 再回到 0，这样粒子会柔和地淡入淡出。
