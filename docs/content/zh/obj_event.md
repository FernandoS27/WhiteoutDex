# 事件对象

事件对象在动画的某个精确时刻触发一件事：剑击中时的声音、脚接触地面时的脚印、单位死亡时的血迹、出现的一个模型。

用 **Create > Helpers > Warcraft III Plugins > Wc3 Event Object** 创建它。把它放在事件应该发生的位置；如果它需要移动，就把它链接到一根骨骼上。

在视口中，每个事件对象的名称都显示为绿色。

[[shot:obj_event_r2|示例模型中一个死亡声音的“事件对象”卷展栏。]]

## 选择事件

| 编号 | 作用 |
|---|---|
| [[ctl:5]] | 事件的种类（见下表）。 |
| [[ctl:8]] | 游戏列表中的具体事件，例如一个声音或一种血液颜色。 |
| [[ctl:13]] | 使用你的选择，并给对象命名。按钮下面的一行显示事件代码。 |

你也可以在 *自定义数据* 中自己输入事件代码。

| 类型 | 代码开头 | 发生什么 |
|---|---|---|
| 脚印（FootPrint） | `FPT` | 地面上出现一个脚印。 |
| 血迹（BloodSplat） | `SPL` | 地面上出现一片溅痕，例如血迹。 |
| 地基（UberSplat） | `UBR` | 一大块地面印记，例如弹坑或建筑地基。 |
| 声音（Sound） | `SND` | 一个声音。 |
| 产出物（SpawnObject） | `SPN` | 出现一个模型，例如掉落的身体部件。 |

## 什么时候发生

| 编号 | 作用 |
|---|---|
| [[ctl:19]] | 事件发生的时间点。 |
| [[ctl:20]] | 把时间滑块移到正确的帧，然后点击这个按钮添加一个时间点。 |
| [[ctl:21]] | 移除选中的时间点。 |
| [[ctl:22]] | 移除所有时间点。 |

!!! tip
    用 *序列管理器* 跳到对应的动画，然后逐帧移动滑块，找到精确的时刻，例如脚接触地面的那一刻。
