# 纹理动画生成器

让纹理动起来：流动的水、用精灵图（sprite sheet）做的燃烧火焰，或由很多图片组成的翻页动画。这个工具会替你写入关键帧。

用 **WhiteoutDex > [[t:menu_texture_anim_creator]]** 打开它。

有三种动画：

| 种类 | 用途 |
|---|---|
| **流动动画** | 纹理滑动、旋转或放大：水、熔岩、能量。 |
| **序列帧（单图）** | 一张图片里按网格排列着很多小图（*精灵图*）。工具会一张接一张地显示它们。 |
| **序列帧（多图）** | 一个装有很多图片的文件夹。工具会一张接一张地显示它们（*翻页动画*）。 |

[[shot:texture_anim_creator|纹理动画生成器，显示“序列帧（单图）”。]]

## 流动动画

[[shot:texture_anim_flow|流动动画。]]

1. 设置开始时间和结束时间。
2. 点击箭头，选择纹理移动的方向。你也可以让它旋转（逆时针、顺时针），或者放大、缩小（+、−）。
3. 如果纹理要一直移动，请把 *全局动画* 设为 ON。
4. 点击 **生成动画**。

## 序列帧（多图）

[[shot:texture_anim_many|序列帧（多图）。]]

1. 选择装有图片的文件夹（按钮 **...**）。图片按文件名的顺序使用。
2. 设置播放顺序、速度和起始帧。
3. 设置路径前缀，例如 `Textures\`。模型对每张图片都使用这个路径。
4. 点击 **生成动画**。

!!! tip
    纹理关键帧位于 *Wc3Bitmap*（UV 动画）或 *Wc3Material*（翻页动画）上。以后要修改它们，请到那里查看。
