# 场景问题与全部修复

导出前，WhiteoutDex 会检查你的场景。它查找会让模型在游戏中出错或让导出失败的问题。你可以在导出窗口中看到检查结果。

[[shot:exporter_problems|导出窗口发现了三个问题。]]

| 编号 | 作用 |
|---|---|
| [[ctl:1092]] | 一次修复所有问题。这会改变你的场景。每一类修复都是一个撤销步骤，所以你可以用 [[key:Ctrl+Z]] 撤销。 |
| [[ctl:1093]] | 打开所有问题的列表。 |

## 问题列表

[[shot:scene_problems|每一行是一个问题。]]

| 编号 | 作用 |
|---|---|
| [[ctl:2000]] | 问题列表。双击一行，即可在场景中选中该对象。 |
| [[ctl:2004]] | 再次检查场景，例如在你手动修复了某些问题之后。 |
| [[ctl:2002]] | 只修复你在列表中选中的问题。 |
| [[ctl:2003]] | 修复列表中的所有问题。 |
| [[ctl:1]] | 关闭列表。 |

## WhiteoutDex 修复哪些问题

| 问题 | [[t:exp_fix_all_btn]] 的做法 |
|---|---|
| 两个对象名称相同 | 重命名它们：`_2`、`_3` 等。游戏需要唯一的名称。 |
| 空网格 | 删除它。 |
| Editable Poly | 添加一个 *Edit Mesh* 修改器，让导出器得到三角形。 |
| *Edit Mesh* 位于 *Skin* 之上 | 塌陷它，让蒙皮保持正确。 |
| 游戏无法读取的控制器 | 替换为线性控制器。 |
| 使用 Multi/Sub-Object 材质的网格 | 拆分网格，让每个部分只有一个材质。 |
| 材质不是 Wc3Material | 转换它。设置来自 *材质修复*（请参阅该页）。 |
| 两个材质相同 | 把它们合并为一个。 |

!!! tip
    你不是必须修复这些问题。不修复，导出器也能工作。但模型在游戏中可能看起来不对。
