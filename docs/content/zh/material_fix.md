# 材质修复

导出器只能读取 **Wc3Material**。材质修复把其他材质（Standard、Physical、PBR）转换为 Wc3Material。它会保留纹理，并设置你在这里选择的魔兽争霸 III 选项。

导出窗口中的 [[t:exp_fix_all_btn]] 也使用同样的设置。

用 **WhiteoutDex > [[t:menu_material_fix]]** 打开它。

[[shot:material_fix|材质修复，显示经典版模型（SD）的设置。]]

有两套设置：一套用于经典版模型（**SD**），一套用于重制版（**HD**）。

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 经典版模型的设置。 |
| [[ctl:5]] | 重制版模型的设置。 |

## 渲染

| 编号 | 作用 |
|---|---|
| [[ctl:8]] | 材质的绘制方式。*自动* 会让带 Alpha 通道的材质变成透明。所有模式请参阅 *Wc3Material*。 |
| [[ctl:10]] | 面的两面都会绘制。 |
| [[ctl:11]] | 材质忽略光照。 |
| [[ctl:12]] | 材质忽略雾。 |
| [[ctl:13]] | 整个网格使用一种颜色。 |
| [[ctl:14]] | 绘制在所有东西的上面（无深度测试）。 |
| [[ctl:15]] | 不遮挡它后面的东西。 |
| [[ctl:16]] | 使用环境光遮蔽（仅限重制版）。 |
| [[ctl:17]] | 背面投射阴影（仅限重制版）。 |
| [[ctl:18]] | 从旧材质读取 *双面*、*无光照* 和 *透明度*，而不使用上面的复选框。 |

## 纹理

| 编号 | 作用 |
|---|---|
| [[ctl:23]] | 模型中写在纹理名称前面的文件夹，例如 `Textures\`。 |
| [[ctl:26]] | 纹理如何重复：和旧材质相同、两个方向、只沿 U、只沿 V，或完全不重复。 |
| [[ctl:28]] | 法线贴图或凹凸贴图会变成 *法线* 贴图（重制版）。 |
| [[ctl:29]] | 自发光贴图会变成 *自发光* 贴图（重制版）。 |

## 全部修复与立即转换

| 编号 | 作用 |
|---|---|
| [[ctl:32]] | 导出窗口中的 [[t:exp_fix_all_btn]] 使用哪套设置：SD 或 HD。 |
| [[ctl:34]] | 在每个转换后的材质名称后加上 `_wc3`。 |
| [[ctl:39]] | 立即转换选中对象的材质。 |
| [[ctl:40]] | 立即转换场景中的所有材质。 |
| [[ctl:42]] | 把这个选项卡恢复为默认值。 |
| [[ctl:43]] | 关闭窗口。你的设置会被保存。 |

!!! tip
    转换整个场景之前，请先保存场景。
