# 全局序列

**全局序列** 是一个一直循环的动画，不管单位正在播放哪个动画。用它制作永不停止的东西：旋转的水晶、燃烧的火把、风中的旗帜。

每个全局序列都有一个以帧为单位的长度。对象的关键帧可以属于某个全局序列，而不属于普通的时间轴。

在 *序列管理器* 中点击 [[t:seq_globals_btn]] 按钮，打开全局序列管理器。

[[shot:global_sequences|全局序列管理器，显示示例模型的两个全局序列。]]

顶部的列表显示所有全局序列：编号、帧、类型，以及使用它的对象。

| 编号 | 作用 |
|---|---|
| [[ctl:7]] | 选中的全局序列的结束帧（长度）。 |
| [[ctl:8]] | 重新读取场景。 |
| [[ctl:9]] | 移除选中的全局序列。 |
| [[ctl:15]] | 新全局序列的长度，以帧为单位。 |
| [[ctl:24]] | 在选中的对象上创建一个新的全局序列。 |
| [[ctl:25]] | 修改选中的全局序列。 |

## 让对象一直旋转

1. 选择对象。
2. 设置 **持续时间**，例如 60 帧。
3. 点击 **新建**。时间滑块会跳到第 0 帧，并出现控制器、通道和旋转的选项。
4. 选择 **控制器**，例如 *线性*，并选择轴向。
5. 把时间滑块移到转完一圈的最后一帧，例如 60。
6. 点击 **> 顺时针** 或 **逆时针 <**。
7. 点击 **完成**。

现在对象在每个动画中都会每 60 帧转一圈。

你也可以手动制作动画：点击 **新建** 后，像平常一样在持续时间内给对象设置关键帧，然后点击 **完成**。WhiteoutDex 会把这些关键帧移到新的全局序列中。

!!! note
    游戏以毫秒计算全局序列。WhiteoutDex 会替你把帧换算过去。
