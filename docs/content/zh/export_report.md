# 导出报告

导出后，WhiteoutDex 只告诉你需要你处理的事情。一切正常时，你什么也看不到，文件直接生成。

有需要你处理的事情时，会打开一个 **WhiteoutDex Export** 窗口：

- 第一行统计错误和警告的数量：*Export completed with 0 error(s) and 2 warning(s).*
- 后面的每一行列出一个对象和它的问题，例如 `WARNING: [Cape] …`。
- 最多显示 50 行。完整列表在文件 `mdlx_export_debug.log` 中（请参阅 *文件与设置*）。

## 错误和警告

| 类型 | 含义 | 你该怎么做 |
|---|---|---|
| **ERROR** | 有内容无法导出。模型可能已损坏。 | 修复所列出的对象，然后再导出一次。 |
| **WARNING** | 模型可以使用，但某些地方看起来可能和 3ds Max 中不同。 | 阅读这一行。场景检查（*全部修复*）通常能修复它。 |

!!! tip
    先在导出窗口中运行 [[t:exp_fix_all_btn]]。它会在导出前修复最常见的问题，这样报告就会很短。

导入器也有同样的报告，标题为 **WhiteoutDex Import**。
