# 灯光

魔兽争霸 III 的灯光照亮模型及其周围的地面，例如火把或魔法水晶的光芒。

用 **Create > Helpers > Warcraft III Plugins > Wc3 Light** 创建它。

## 通用功能

[[shot:obj_light_r1|通用功能。]]

| 编号 | 作用 |
|---|---|
| [[ctl:3]] | 先点击这个按钮，然后点击一个对象。灯光会跳到那个对象上并链接到它。 |

## 基本参数

[[shot:obj_light_r3|基本参数。]]

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | *全向光* 从一个点向所有方向照射。*平行光* 像太阳一样朝一个方向照射。*环境光* 均匀地照亮所有东西。 |
| [[ctl:9]] | 灯光开始变弱的距离。 |
| [[ctl:16]] | 灯光结束的距离。 |
| [[ctl:21]] | 灯光的颜色。 |
| [[ctl:29]] | 灯光的强度。 |
| [[ctl:35]] | 环境光部分的颜色。 |
| [[ctl:43]] | 环境光部分的强度。 |
| [[ctl:11]] | **控制器：** 动画数值在关键帧之间如何变化。每个数值都有自己的控制器。 |

## 重制版参数

[[shot:obj_light_r2|重制版参数。]]

这些数值只用于重制版模型。

| 编号 | 作用 |
|---|---|
| [[ctl:6]] | 阴影强度。在场景的主光源上，它还会缩放基于图像的光照。 |
| [[ctl:8]] | 灯光投射阴影。 |
| [[ctl:12]] | 阴影开始的距离。 |
| [[ctl:16]] | 阴影结束的距离。 |
| [[ctl:21]] | 灯光变弱的速度：二次项部分 … |
| [[ctl:25]] | … 线性部分 … |
| [[ctl:29]] | … 以及阻尼。 |
