# 从游戏导入

你可以直接从魔兽争霸 III 游戏中导入模型，不需要磁盘上的文件。

1. 选择 **WhiteoutDex > [[t:menu_import_casc]]**。
2. 游戏浏览器会打开。找到模型，例如搜索 `footman`。
3. 点击模型，然后点击 **选择**。
4. 普通的导入窗口会打开（请参阅 *导入器*）。选择你的选项，然后点击 **导入**。

WhiteoutDex 会把模型和它的纹理复制到一个临时文件夹，并从那里导入。你的游戏文件不会改变。

!!! tip
    要修改游戏中的模型，请用这种方式导入它，修改后再用新名称导出到你的地图或模组文件夹中。

!!! note
    游戏中的模型属于暴雪娱乐（Blizzard Entertainment）。请只在暴雪允许的范围内使用它们，例如用于魔兽争霸 III 的地图和模组。
