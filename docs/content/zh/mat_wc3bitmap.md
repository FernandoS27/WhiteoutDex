# Wc3Bitmap

**Wc3Bitmap** 是 WhiteoutDex 的纹理贴图。把它放进 *Wc3Material* 的贴图槽中。它可以读取 `.blp`、`.dds`、`.tga`、`.png` 以及 3ds Max 支持的其他图片格式，并保存纹理动画（UV 动画）和纹理在游戏中的路径。

## WC3 纹理参数

[[shot:mat_wc3bitmap_r1|WC3 纹理参数。]]

| 编号 | 作用 |
|---|---|
| [[ctl:6]] | 选择磁盘上的一个图片文件。 |
| [[ctl:7]] | 从游戏档案中选择一张纹理。 |
| [[ctl:9]] | 使用由游戏填充的纹理（队伍颜色、队伍光晕、悬崖、树木）。 |
| [[ctl:12]] | 纹理沿宽度方向重复。 |
| [[ctl:13]] | 纹理沿高度方向重复。 |
| [[ctl:14]] | 把纹理用作反射（球形环境贴图）。 |

## UV 动画（TXAN）

[[shot:mat_wc3bitmap_r2|UV 动画。]]

给这些数值设置动画，可以让纹理移动。*纹理动画生成器* 可以替你设置它们。

| 编号 | 作用 |
|---|---|
| [[ctl:3]] | 数值在关键帧之间如何变化。 |
| [[ctl:8]] | 横向移动纹理（U）。 |
| [[ctl:11]] | 上下移动纹理（V）。 |
| [[ctl:14]] | W 偏移。 |
| [[ctl:17]] | 旋转纹理。 |
| [[ctl:20]] | 让纹理在横向上重复得更多或更少。 |
| [[ctl:23]] | 让纹理在纵向上重复得更多或更少。 |

## 前缀路径

[[shot:mat_wc3bitmap_r3|前缀路径。]]

前缀是导出器写在纹理名称前面的文件夹，例如 `Textures\` 或 `war3mapImported\`。

| 编号 | 作用 |
|---|---|
| [[ctl:5]] | 选择一个已保存的前缀。 |
| [[ctl:6]] | 编辑已保存的前缀列表。 |

!!! tip
    地图中的纹理必须使用该地图所用的前缀。对于地图中的自定义模型，这通常是 `war3mapImported\`。
