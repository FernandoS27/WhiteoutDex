# 初次使用

安装完成后，WhiteoutDex 会在 3ds Max 中添加两样东西：**WhiteoutDex 菜单** 和 **侧边栏**。

![3ds Max 2016 中的 WhiteoutDex：左边是侧边栏，中间是 WhiteoutFlakes 预览器。](media_2.png)

## 魔兽争霸 III 对象

WhiteoutDex 在 3ds Max 的 **Create** 面板中添加了新对象：

- **Create > Helpers > Warcraft III Plugins**：附着点、碰撞形状、灯光、事件对象、Popcorn FX、FaceFX。
- **Create > Geometry > Particle Systems**：Particle Emitter 1、Particle Emitter 2 和 Ribbon Emitter。
- **Material Editor**：材质 *Wc3Material* 和贴图 *Wc3Bitmap*。
- **Modifier list**：*Wc3 Vertex Color*。

*魔兽争霸 III 对象* 和 *材质* 两章会讲解它们。

## 你的第一步

1. 打开 [[t:menu_settings]]，设置你的游戏文件夹（请参阅 *设置*）。
2. 完成教程 *教程：导入模型*。
3. 在预览器中查看模型：教程 *教程：预览模型*。
4. 再把它导出：教程 *教程：导出模型*。
