# 关键帧优化器

来自其他程序或动作捕捉的动画，常常每一帧都有一个关键帧。这会让模型变大。关键帧优化器会移除不需要的关键帧，而动作几乎保持不变。

用 **WhiteoutDex > [[t:menu_keyframe_optimizer]]** 打开它。请先选择有动画的对象。

[[shot:keyframe_optimizer|关键帧优化器。]]

## 设置

| 编号 | 作用 |
|---|---|
| [[ctl:7#2]] | **阈值：** 曲线允许改变多少。数值越高，移除的关键帧越多。从 0.5 开始。 |
| [[ctl:11#2]] | **步长：** 工具测量的精细程度，以帧为单位。请保持在 0.49 以下。 |
| [[ctl:13#2]] | 把详细信息写入 MAXScript Listener。请保持关闭；开启后会更慢。 |

## 优化

| 编号 | 作用 |
|---|---|
| [[ctl:3]] | 按时间或按名称排序列表。 |
| [[ctl:5]] | 模型的序列。选择你要优化的序列。 |
| [[ctl:7]] | 优化位置关键帧。 |
| [[ctl:8]] | 优化旋转关键帧。 |
| [[ctl:9]] | 优化缩放关键帧。 |
| [[ctl:14]] | 优化选中的序列。 |
| [[ctl:15]] | 优化所有序列。 |
| [[ctl:16]] | 删除不在任何序列内的关键帧。它们在游戏中没有作用。 |

!!! tip
    优化前请保存场景。优化后检查动画。如果有地方看起来不对，请撤销，然后用较小的阈值再试一次。
