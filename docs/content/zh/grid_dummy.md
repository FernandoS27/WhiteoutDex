# 网格与虚拟体创建器

创建一个用作尺寸参考的网格，以及点辅助对象。

用 **WhiteoutDex > [[t:menu_grid_dummy]]** 打开它。

[[shot:grid_dummy|网格与虚拟体创建器。]]

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 网格的颜色。 |
| [[ctl:8]] | 网格的大小，以世界单位计。 |
| [[ctl:9]] | 在场景中心（0, 0, 0）创建网格。 |
| [[ctl:11]] | 点的颜色。 |
| [[ctl:15]] | 点的大小。 |
| [[ctl:16]] | 在每个选中的对象处创建一个点。没有选中对象时，在中心创建一个点。 |
