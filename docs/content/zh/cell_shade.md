# 卡通描边创建器

给网格加上卡通风格的轮廓线。这个工具会在网格外面做一个稍大一点的副本，并把副本的面翻转过来。这样在游戏中，你会看到模型周围有一条深色的线。

用 **WhiteoutDex > [[t:menu_cell_shade]]** 打开它。请先选择网格。

[[shot:cell_shade|卡通描边创建器。]]

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 轮廓线的颜色。点击可以选择另一种颜色。 |
| [[ctl:6]] | 快捷颜色。点击一种即可使用。 |
| [[ctl:19]] | 轮廓线的粗细。 |
| [[ctl:21]] | 把副本的面翻转过来。这样就形成轮廓线（常用选项）。 |
| [[ctl:22]] | 保持面不变。 |
| [[ctl:25]] | 轮廓线是不透明的。 |
| [[ctl:26]] | 轮廓线使用纹理的透明度。 |
| [[ctl:27]] | 轮廓线会发光（叠加光亮）。 |
| [[ctl:28]] | 轮廓线会发光，并使用纹理的透明度。 |
| [[ctl:30]] | 为选中的网格创建轮廓线。 |

!!! tip
    轮廓线是一个普通网格，带有 *Wc3Material*。之后你可以像修改其他网格一样修改它的颜色或粗细。
