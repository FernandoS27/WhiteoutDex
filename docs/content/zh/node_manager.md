# 节点管理器

一个模型有很多种对象：网格、骨骼、辅助对象、发射器等。节点管理器可以一次显示、隐藏或冻结某一种类的所有对象。

用 **WhiteoutDex > [[t:menu_node_manager]]** 打开它。

[[shot:node_manager|节点管理器。]]

## 1. 选择种类

| 编号 | 种类 |
|---|---|
| [[ctl:4]] | 网格。 |
| [[ctl:5]] | 3ds Max 的骨骼。 |
| [[ctl:6]] | Biped 骨架的骨骼。 |
| [[ctl:7]] | CAT 骨架的骨骼。 |
| [[ctl:8]] | 辅助对象和虚拟体。 |
| [[ctl:9]] | 附着点。 |
| [[ctl:10]] | 事件对象。 |
| [[ctl:11]] | 灯光。 |
| [[ctl:12]] | 摄影机。 |
| [[ctl:13]] | 粒子发射器 1。 |
| [[ctl:14]] | 粒子发射器 2。 |
| [[ctl:15]] | 飘带发射器。 |
| [[ctl:16]] | Popcorn FX 发射器。 |
| [[ctl:17]] | FaceFX 对象。 |
| [[ctl:18]] | 碰撞形状。 |
| [[ctl:27]] | 勾选所有种类。[[ctl:28]] 取消所有勾选，[[ctl:29]] 反转每个勾选。 |

## 2. 对它们执行操作

| 编号 | 作用 |
|---|---|
| [[ctl:20]] | 显示这些对象。 |
| [[ctl:21]] | 隐藏这些对象。 |
| [[ctl:22]] | 冻结这些对象，这样你就不会误选它们。 |
| [[ctl:23]] | 解冻这些对象。 |
| [[ctl:24]] | 以透视方式显示这些对象。 |
| [[ctl:25]] | 再次以实体方式显示这些对象。 |

!!! tip
    编辑网格时，隐藏所有辅助对象、骨骼和发射器。绘制蒙皮权重时，冻结骨骼。
