# Wc3 Vertex Color

**Wc3 Vertex Color** 修改器给整个网格着色。你可以给颜色设置动画，例如让水晶脉动，或者让单位被击中时某个部分发出红光。导出器会把它写为网格的 *geoset animation* 颜色。

从修改器列表中添加它：选择一个网格，然后选择 **Wc3 Vertex Color**。

[[shot:obj_vertexcolor_r1|修改器的基本参数。]]

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 网格被染上的颜色。白色让纹理保持原样。用 **Auto Key** 给它设置动画。 |
| [[ctl:7]] | 设置网格的 *Drop Shadow* 标志。 |
| [[ctl:9]] | 使用这个颜色。关闭时，只写入标志。 |

!!! tip
    要让某个部分淡入淡出，请改用可见性关键帧（*可见性关键帧工具*）或 Wc3Material 的 *不透明度*。
