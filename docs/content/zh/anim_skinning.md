# 动画：蒙皮

有时网格链接在骨骼上，而你想修改骨骼。如果你移动骨骼，链接的网格也会跟着移动。这个工具会暂时取消网格的链接，之后再把它们链接回去。

用 **WhiteoutDex > [[t:menu_anim_skin]]** 打开它。

[[shot:anim_skinning|蒙皮工具。]]

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 保存每个选中对象的父级，并取消它的链接。 |
| [[ctl:5]] | 把选中的对象链接回它们保存的父级。 |

## 使用方法

1. 选择链接在骨骼上的网格。
2. 点击 [[ctl:4]]。
3. 修改骨骼，例如把它们从 IK 转换为 FK。
4. 再次选择这些网格，然后点击 [[ctl:5]]。
