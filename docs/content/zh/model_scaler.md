# 动画：模型缩放

缩放整个模型，包括它的骨骼、动画和特殊对象。模型对游戏来说太大或太小时，使用这个工具。

用 **WhiteoutDex > [[t:menu_anim_scaler]]** 打开它。

[[shot:model_scaler|模型缩放工具。]]

| 编号 | 作用 |
|---|---|
| [[ctl:4]] | 来自游戏的目标高度，例如 *Footman* 或 *Townhall*（经典版或重制版）。 |
| [[ctl:6]] | 把模型缩放到选择的高度。 |
| [[ctl:10]] | 你自己的缩放系数。2 让模型变为两倍大，0.5 让模型变为一半大。 |
| [[ctl:11]] | 按你的系数缩放模型。 |

!!! warning
    带有 **Biped** 或 **CAT** 骨架和 Skin 修改器的模型，用这种方式缩放效果不好。WhiteoutDex 会警告你。请改用骨架自带的工具缩放骨架。

!!! tip
    缩放前请保存场景。这样结果不对时，你可以回到之前的状态。
