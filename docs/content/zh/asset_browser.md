# 游戏浏览器

游戏浏览器显示你的魔兽争霸 III 游戏中的文件：模型、纹理和粒子特效。每个文件都有一张小预览图，所以你能很快找到需要的东西。

它可以从很多地方打开：

| 位置 | 按钮 | 你选择的内容 |
|---|---|---|
| WhiteoutDex 菜单 | [[t:menu_import_casc]] | 要导入的模型 |
| 附着点 | *浏览游戏存档* | 附着在该点上的模型 |
| 粒子发射器 1 | *浏览游戏档案* | 用作粒子的模型 |
| 粒子发射器 2 | *浏览 MPQ / CASC* | 粒子使用的纹理 |
| Popcorn FX | *浏览游戏档案* | 一个 `.pkb` 或 `.pkfx` 特效 |
| Wc3Bitmap | *打开纹理浏览器* | 一张纹理 |
| Wc3Material | 贴图旁边的 ⚙ 按钮 | 这个贴图槽使用的纹理 |

## 使用方法

1. 在搜索框中输入名称的一部分，例如 `footman`。
2. 在 **网格**（图片）和 **树**（文件夹）之间切换。
3. 把图片放大或缩小。
4. 点击一个文件。底部的一行显示选中的文件。
5. 点击 **选择**。

!!! note
    浏览器需要你的游戏文件夹。请在 [[t:menu_settings]] 中设置。经典版模型来自 MPQ 档案，重制版文件来自 CASC。
