# 飘带发射器

飘带发射器在一个移动的点后面画出一条 **拖尾**：挥剑时的光迹、彗星的尾巴、火箭的烟。把它链接到会移动的骨骼上，例如武器。

用 **Create > Geometry > Particle Systems > Wc3Ribbon** 创建它。

## Ribbon Material Parameters

[[shot:obj_ribbon_r1|Ribbon Material Parameters（飘带材质参数）。]]

| 编号 | 作用 |
|---|---|
| [[ctl:1079]] | 拖尾的材质（一个 *Wc3Material*）。点击可以把它放进 Material Editor。 |
| [[ctl:1073]] | 纹理是由多张小图组成的网格：行数（1、2、4、8 …）… |
| [[ctl:1075]] | … 和列数（1、2、4、8 …）。 |
| [[ctl:1077]] | 拖尾显示网格中的哪一张小图。给它设置动画，可以让拖尾闪烁。 |

## Ribbon Properties

[[shot:obj_ribbon_r2|Ribbon Properties（飘带属性）。]]

| 编号 | 作用 |
|---|---|
| [[ctl:1066]] | 拖尾的颜色。 |
| [[ctl:1059]] | 拖尾在发射器上方延伸多远。 |
| [[ctl:1067]] | 拖尾在发射器下方延伸多远。上方 + 下方 = 拖尾的宽度。 |
| [[ctl:1080]] | 透明度：0 = 不可见，1 = 完全不透明。把它的动画设为 0，可以隐藏拖尾。 |
| [[ctl:1069]] | 每秒生成多少段拖尾。段数越多，拖尾越平滑。 |
| [[ctl:1071]] | 一段拖尾保留多久，以秒为单位。生命越长，拖尾越长。 |
| [[ctl:1082]] | 把拖尾往下拉。 |
| [[ctl:1090]] | **控制器：** 动画数值在关键帧之间如何变化。每个数值都有自己的控制器。 |

!!! tip
    制作剑的拖尾：发射器放在剑刃上，使用 *Additive* 材质，除挥剑期间外透明度都为 0，生命周期约 0.2 秒。
