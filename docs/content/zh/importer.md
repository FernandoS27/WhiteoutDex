# 导入器

导入器把魔兽争霸 III 模型（`.mdx` 或 `.mdl`）加载到 3ds Max 中。它还会从你的游戏中加载模型的纹理。

## 打开导入器

使用以下任一方式：

- 菜单 **WhiteoutDex > [[t:menu_importer]]**
- WhiteoutDex 侧边栏中的 **Import** 按钮
- **File > Import**，然后选择文件类型 *Warcraft III MDX/MDL Model*

选择一个文件。然后导入窗口会打开。

## 导入窗口

[[shot:importer|导入窗口，显示“对象”选项卡。]]

窗口顶部显示文件名、模型的游戏版本（*经典版* 或 *重制版*），以及模型有多少骨骼、网格（Geoset）和动画。

| [[ctl:1059]] | 删除当前打开的场景，并把模型导入到一个空场景中。 |
| [[ctl:1060]] | 把模型添加到当前打开的场景中。用它来组合多个模型。 |
| [[ctl:1061]] | 显示模型的对象（即这张图）。 |
| [[ctl:1062]] | 显示动画选项。 |
| [[ctl:1063]] | 显示网格、材质和纹理的选项。 |
| [[ctl:1021]] | 所有对象的总开关。关闭时，不导入任何对象。 |
| [[ctl:1022]] | 骨架。动画和蒙皮网格都需要它。 |
| [[ctl:1023]] | 辅助对象。它们带动其他对象移动，但在游戏中看不到。 |
| [[ctl:1024]] | 灯光。 |
| [[ctl:1025]] | 附着点，例如用于武器和法术特效。 |
| [[ctl:1028]] | 事件对象，例如声音、脚印和血迹。 |
| [[ctl:1026]] | 粒子发射器 1：生成小模型的发射器。 |
| [[ctl:1027]] | 粒子发射器 2：用于火焰、烟雾、火花等效果的发射器。 |

每种对象类型旁边的数字告诉你模型有多少个该类型的对象。模型没有的类型显示为灰色。

!!! note
    重制版模型还可能有两种对象类型：*Popcorn FX* 发射器和 *FaceFX*。只有模型包含它们时，你才会看到。

## 纹理从哪里来

WhiteoutDex 按以下顺序查找每张纹理：

1. 在模型所在的文件夹及其子文件夹中。
2. 在游戏档案中。对于经典版模型（版本 800），它先在 **MPQ** 档案中查找，然后在 **CASC** 中查找。对于重制版模型，顺序相反。

窗口最下面一行告诉你它使用哪些档案。你在 [[t:menu_settings]] 中设置游戏文件夹。

!!! tip
    导入器会把从游戏档案中取出的纹理保存在模型文件旁边。这样下次它能立刻找到这些纹理。

## 须知

- 导入器会记住你的选择，下次继续使用。
- 不用磁盘上的文件，直接从游戏导入模型：请参阅 *从游戏导入*。
