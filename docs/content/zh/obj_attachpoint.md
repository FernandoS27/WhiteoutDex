# 附着点

附着点标记模型上的一个位置。游戏会把东西附着在那里：英雄的武器、手上的法术特效、射中胸口的箭、头顶上的生命条。

用 **Create > Helpers > Warcraft III Plugins > Wc3 AttachPoint** 创建它。把它链接到它应该跟随的骨骼上。

在视口中，每个附着点的名称都显示为黄色。

## 通用功能

[[shot:obj_attachpoint_r1|通用功能。]]

| 编号 | 作用 |
|---|---|
| [[ctl:3]] | 先点击这个按钮，然后在视口中点击一个对象。附着点会跳到那个对象上并链接到它。 |

## 模型贴图参数

[[shot:obj_attachpoint_r2|模型贴图参数。]]

附着点可以带有自己的模型，例如单位一直拿着的剑。

| 编号 | 作用 |
|---|---|
| [[ctl:9]] | 选择磁盘上的模型文件。 |
| [[ctl:10]] | 从游戏档案中选择一个模型。 |

按钮上方的两个字段保存文件夹和文件名。路径相对于魔兽争霸 III 文件夹，例如 `Textures\Model.mdx`。

## 附着点参数

[[shot:obj_attachpoint_r3|附着点参数。]]

游戏通过 **名称** 找到附着点。名称由四个部分组成：

| 编号 | 作用 |
|---|---|
| [[ctl:5]] | **类型：** 主要位置：*Head*、*Overhead*、*Origin*、*Foot*、*Chest*、*Hand*、*Weapon* 或 *Sprite*。 |
| [[ctl:8]] | **坐骑：** 用于骑在坐骑上的骑手。 |
| [[ctl:11]] | **左右：** *Left* 或 *Right*，用于手和脚。 |
| [[ctl:14]] | **额外的：** 更多的词，例如 *Rear*、*Alternate*、*RallyPoint*、*Gold*，或用于建筑的 *First* … *Sixth*。 |
| [[ctl:22]] | 使用 *模型贴图参数* 中的模型。 |
| [[ctl:26]] | 可见性（0 到 1）。给它设置动画，可以显示或隐藏附着的模型。 |
| [[ctl:27]] | 显示模型路径相对于哪里。 |
| [[ctl:34]] | 附着点的编号。 |
| [[ctl:36]] | 把这个编号写入模型。 |

示例：类型 *Hand*、左右 *Right*，得到的名称是 `Hand Right Ref`。游戏会把右手的法术特效放在那里。

!!! tip
    *动画：通用工具* 中的 *一键创建附加点* 工具会替你创建常用的附着点，前提是你的骨骼使用已知的名称。
