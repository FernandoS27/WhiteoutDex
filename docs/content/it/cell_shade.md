# Creatore di cell shading

Dà a una mesh un contorno da cartone animato. Lo strumento crea intorno alla mesh una sua copia un po' più grande, con le facce rivolte verso l'interno. Nel gioco vedi poi una linea scura intorno al modello.

Aprilo con **WhiteoutDex > [[t:menu_cell_shade]]**. Prima seleziona le mesh.

[[shot:cell_shade|Il Creatore di cell shading.]]

| N. | Cosa fa |
|---|---|
| [[ctl:4]] | Il colore del contorno. Clicca per scegliere un altro colore. |
| [[ctl:6]] | Colori rapidi. Cliccane uno per usarlo. |
| [[ctl:19]] | Lo spessore del contorno. |
| [[ctl:21]] | Rivolge verso l'interno le facce della copia. Questo crea il contorno (la scelta normale). |
| [[ctl:22]] | Lascia le facce come sono. |
| [[ctl:25]] | Il contorno è solido. |
| [[ctl:26]] | Il contorno usa la trasparenza della texture. |
| [[ctl:27]] | Il contorno brilla (aggiunge luce). |
| [[ctl:28]] | Il contorno brilla e usa la trasparenza della texture. |
| [[ctl:30]] | Crea il contorno per le mesh selezionate. |

!!! tip
    Il contorno è una mesh normale con un *Wc3Material*. Puoi cambiare più tardi il suo colore o il suo spessore come per qualsiasi altra mesh.
