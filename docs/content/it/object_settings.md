# Impostazioni oggetto

Gli oggetti di Warcraft III hanno impostazioni in più che 3ds Max non ha, per esempio *billboard*. Le Impostazioni oggetto le applicano agli oggetti selezionati. WhiteoutDex le salva nell'oggetto (come proprietà utente) e l'esportatore le scrive nel modello.

Aprile con **WhiteoutDex > [[t:menu_object_settings]]**. Prima seleziona uno o più oggetti.

[[shot:object_settings|Le Impostazioni oggetto con un osso selezionato.]]

## Flag

| N. | Cosa fa |
|---|---|
| [[ctl:4]] | L'oggetto non si sposta con il suo genitore. |
| [[ctl:5]] | L'oggetto non gira con il suo genitore. |
| [[ctl:6]] | L'oggetto non cambia scala con il suo genitore. |
| [[ctl:7]] | L'oggetto guarda sempre verso la telecamera. Adatto per bagliori ed effetti piatti. |
| [[ctl:8]] | Guarda verso la telecamera, ma gira solo intorno all'asse X. |
| [[ctl:9]] | … solo intorno all'asse Y. |
| [[ctl:10]] | … solo intorno all'asse Z. |
| [[ctl:11]] | L'oggetto resta fermo nella vista della telecamera. |

## Mesh

| N. | Cosa fa |
|---|---|
| [[ctl:13]] | **Skinning normale:** usa il modificatore Skin o le ossa collegate. |
| [[ctl:14]] | **Skinning ArtTools:** unisce i vertici di mesh separate durante l'esportazione. Usalo solo sulle mesh che vuoi fondere tra loro. |
| [[ctl:17]] | Il giocatore non può cliccare questa mesh nel gioco. |
