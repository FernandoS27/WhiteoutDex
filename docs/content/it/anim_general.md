# Anim.: strumenti generali

Piccoli aiuti che fanno risparmiare tempo quando animi o completi un modello.

Aprili con **WhiteoutDex > [[t:menu_anim_general]]**.

[[shot:anim_general|Gli strumenti generali.]]

| N. | Cosa fa |
|---|---|
| [[ctl:4]] | Aggiunge chiavi al fotogramma 0 e all'inizio e alla fine di ogni sequenza, per gli oggetti selezionati. Così un'animazione non cambia quella successiva. |
| [[ctl:6]] | Usa lo strumento TCB sulle chiavi di posizione. |
| [[ctl:7]] | … sulle chiavi di rotazione. |
| [[ctl:8]] | … sulle chiavi di scala. |
| [[ctl:9]] | Imposta *Continuity* a 0 sulle chiavi correnti degli oggetti selezionati. Così rimuove l'oscillazione oltre il valore delle chiavi TCB. |
| [[ctl:11]] | Le chiavi di rotazione che girano più di 90° tra due chiavi possono apparire sbagliate nel gioco. Questo strumento aggiunge una chiave nel mezzo. Eseguilo di nuovo per rotazioni molto grandi (oltre 180°). |
| [[ctl:13]] | Crea punti di attacco per le ossa con nomi noti (per esempio *Head*, *Chest*, *Hand*). |
| [[ctl:14]] | Crea una telecamera per il ritratto che guarda l'oggetto selezionato. Se non c'è niente di selezionato, guarda la parte alta del modello. |
| [[ctl:15]] | Crea due sfere di collisione adatte al modello, come fa Blizzard per le unità. |
| [[ctl:16]] | Crea un box di collisione adatto al modello, come fa Blizzard per gli edifici. |

!!! tip
    Usa gli strumenti **con un clic** su un modello finito. Misurano il modello, quindi funzionano meglio quando ha la sua dimensione finale.
