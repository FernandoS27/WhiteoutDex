# Gestore nodi

Un modello ha molti tipi di oggetti: mesh, ossa, helper, emettitori e altro. Il Gestore nodi mostra, nasconde o blocca in una volta tutti gli oggetti di un tipo.

Aprilo con **WhiteoutDex > [[t:menu_node_manager]]**.

[[shot:node_manager|Il Gestore nodi.]]

## 2. Fai qualcosa con loro

| N. | Cosa fa |
|---|---|
| [[ctl:20]] | Mostra gli oggetti. |
| [[ctl:21]] | Nasconde gli oggetti. |
| [[ctl:22]] | Blocca gli oggetti, così non puoi selezionarli per sbaglio. |
| [[ctl:23]] | Sblocca gli oggetti. |
| [[ctl:24]] | Mostra gli oggetti trasparenti. |
| [[ctl:25]] | Mostra di nuovo gli oggetti solidi. |

!!! tip
    Nascondi tutti gli helper, le ossa e gli emettitori mentre lavori sulla mesh. Blocca le ossa mentre dipingi i pesi dello skin.
