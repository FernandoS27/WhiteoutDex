# Glossario

Parole che incontri in WhiteoutDex e in questo manuale.

| Parola | Significato |
|---|---|
| **MDX / MDL** | I file dei modelli di Warcraft III. `.mdx` è binario e piccolo. `.mdl` è testo che puoi leggere e modificare. Entrambi contengono gli stessi dati. |
| **Classico** | Warcraft III versione 1.x e la grafica classica. I modelli usano MDX versione 800. |
| **Reforged** | Warcraft III: Reforged con grafica HD. I modelli usano MDX dalla versione 900 alla 1800. WhiteoutDex esporta la versione 1800. |
| **MPQ** | I file di archivio del gioco classico (per esempio `War3.mpq`). |
| **CASC** | L'archivio di Warcraft III: Reforged. |
| **BLP** | Il formato delle texture del gioco classico. |
| **DDS** | Il formato delle texture di Reforged. |
| **Geoset** | Una mesh di un modello. Un modello può avere molti geoset. |
| **Osso** | Un nodo che muove i vertici di una mesh con skin. |
| **Helper** | Un nodo che muove altri nodi, ma che non vedi nel gioco. |
| **Skin** | Dice quale osso muove quale vertice, e con quanta forza (peso). |
| **Sequenza** | Un'animazione del modello, per esempio *Walk*. Ha un nome, un fotogramma iniziale e un fotogramma finale. |
| **Sequenza globale** | Un'animazione che si ripete sempre, indipendentemente dalla sequenza corrente. Adatta per le cose che si muovono sempre, come un cristallo che gira. |
| **Chiave / fotogramma chiave** | Un valore in un momento preciso. Il gioco passa da una chiave all'altra. |
| **Controller** | Come il gioco passa da una chiave all'altra: *None* (salto), *Linear*, *Bezier* o *Hermite* (morbido). |
| **Punto di attacco** | Un posto sul modello dove il gioco attacca delle cose: armi, effetti degli incantesimi, il cerchio di selezione. |
| **Oggetto evento** | Avvia qualcosa in un momento di un'animazione: un suono, un'impronta, sangue, un modello che compare. |
| **Emettitore di particelle 1** | Emette piccoli modelli. |
| **Emettitore di particelle 2** | Emette particelle con texture: fuoco, fumo, scintille. |
| **Emettitore di scie** | Disegna una scia dietro un punto che si muove. |
| **Popcorn FX** | Il sistema di particelle di Reforged (file `.pkfx`). |
| **Forma di collisione** | Un box o una sfera. Il gioco la usa per sapere dove puoi cliccare il modello. |
| **Estensioni** | La dimensione del modello in una sequenza. Il gioco le usa per sapere quando il modello è sullo schermo. |
| **Texture sostituibile** | Una texture che il gioco riempie, per esempio il colore della squadra. |
| **Colore squadra / bagliore squadra** | Il colore del giocatore su un'unità. |
| **Modalità filtro** | Come viene disegnato un materiale: solido, trasparente, additivo (brilla) e altro. |
| **Billboard** | Un nodo che si gira sempre verso la telecamera. |
| **Grafica della scena** | Quale grafica mostra l'anteprima: Classic, Reforged (HD) o Definitive. |
| **WhiteoutFlakes** | L'anteprima che mostra il tuo modello come il gioco. |
