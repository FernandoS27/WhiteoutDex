# Browser del gioco

Il browser del gioco mostra i file dentro il tuo Warcraft III: modelli, texture ed effetti di particelle. Vedi una piccola immagine di ogni file, così trovi subito ciò che ti serve.

Si apre da molti punti:

| Dove | Pulsante | Cosa scegli |
|---|---|---|
| Menu WhiteoutDex | [[t:menu_import_casc]] | un modello da importare |
| Punto di attacco | *Sfoglia gli archivi del gioco* | un modello per il punto di attacco |
| Emettitore di particelle 1 | *Sfoglia gli archivi del gioco* | un modello per le particelle |
| Emettitore di particelle 2 | *Sfoglia MPQ / CASC* | una texture per le particelle |
| Popcorn FX | *Sfoglia gli archivi del gioco* | un effetto `.pkb` o `.pkfx` |
| Wc3Bitmap | *Apri il Browser texture* | una texture |
| Wc3Material | il pulsante ⚙ accanto a una mappa | una texture per questo slot |

## Come usarlo

1. Scrivi una parte del nome nel campo di ricerca, per esempio `footman`.
2. Passa dalla **griglia** (immagini) all'**albero** (cartelle) e viceversa.
3. Ingrandisci o rimpicciolisci le immagini.
4. Clicca un file. La riga in basso mostra il file selezionato.
5. Clicca **Seleziona**.

!!! note
    Il browser ha bisogno delle cartelle del tuo gioco. Impostale in [[t:menu_settings]]. I modelli classici vengono dagli archivi MPQ, i file di Reforged da CASC.
