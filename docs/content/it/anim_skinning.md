# Anim.: skinning

A volte le mesh sono collegate alle ossa e vuoi modificare le ossa. Se sposti le ossa, si spostano anche le mesh collegate. Questo strumento scollega le mesh per un momento e le ricollega più tardi.

Aprilo con **WhiteoutDex > [[t:menu_anim_skin]]**.

[[shot:anim_skinning|Lo strumento Skinning.]]

| N. | Cosa fa |
|---|---|
| [[ctl:4]] | Salva il genitore di ogni oggetto selezionato e lo scollega. |
| [[ctl:5]] | Ricollega gli oggetti selezionati ai loro genitori salvati. |

## Come usarlo

1. Seleziona le mesh collegate alle ossa.
2. Clicca [[ctl:4]].
3. Modifica le ossa, per esempio convertile da IK a FK.
4. Seleziona di nuovo le mesh e clicca [[ctl:5]].
