# Anim.: controller

Warcraft III conosce quattro modi per passare da una chiave all'altra: *None* (salto), *Linear*, *Bezier* e *Hermite* (TCB). Questo strumento dà agli oggetti selezionati i controller che scegli, per posizione, rotazione e scala in una volta.

Aprilo con **WhiteoutDex > [[t:menu_anim_controllers]]**.

[[shot:anim_controllers|Lo strumento Controller.]]

| N. | Cosa fa |
|---|---|
| [[ctl:4]] | La posizione si muove in linea retta tra le chiavi. |
| [[ctl:5]] | La posizione si muove su curve morbide. |
| [[ctl:6]] | La posizione usa chiavi TCB (morbide, con tensione, continuità e bias). |
| [[ctl:7]] | Lascia il controller di posizione com'è. |
| [[ctl:10]] | La rotazione gira in modo uniforme tra le chiavi. |
| [[ctl:11]] | La rotazione gira in modo morbido. |
| [[ctl:12]] | La rotazione usa chiavi TCB. |
| [[ctl:13]] | Lascia il controller di rotazione com'è. |
| [[ctl:16]] | La scala cambia in modo uniforme. |
| [[ctl:17]] | La scala cambia su curve morbide. |
| [[ctl:18]] | La scala usa chiavi TCB. |
| [[ctl:19]] | Lascia il controller di scala com'è. |
| [[ctl:22]] | Dà questi controller agli oggetti selezionati. |

!!! note
    Anche l'esportatore sostituisce i controller che il gioco non può leggere (vedi *Problemi della scena e Correggi tutto*). Con questo strumento scegli tu il tipo.
