# FaceFX

**FaceFX** muove il viso degli eroi di Reforged quando parlano: bocca, occhi e sopracciglia seguono la voce. I dati si trovano in un file `.facefx_ingame`. L'oggetto FaceFX collega questo file al modello.

Crealo con **Create > Helpers > Warcraft III Plugins > Wc3 FaceFX**. FaceFX funziona solo nei modelli **Reforged**.

[[shot:obj_facefx_r2|Impostazioni FaceFX.]]

| N. | Cosa fa |
|---|---|
| [[ctl:9]] | Scegli il file `.facefx_ingame`. |
| [[ctl:10]] | Mostra una breve spiegazione. |

I due campi contengono il **nome del target** (il nome che il gioco usa per questo viso) e il **percorso del file**.

!!! note
    L'importatore porta nella scena gli oggetti FaceFX dei modelli Reforged. L'esportatore li riscrive senza modifiche.
