# Popcorn FX

**Popcorn FX** è il sistema di particelle di Warcraft III: Reforged. L'effetto stesso è un file `.pkfx` (o `.pkb`) creato con l'editor PopcornFX. L'oggetto Popcorn in 3ds Max mette questo effetto sul modello e controlla quando si riproduce.

Crealo con **Create > Helpers > Warcraft III Plugins > Wc3 Popcorn**. Popcorn funziona solo nei modelli **Reforged**.

## File Popcorn FX

[[shot:obj_popcorn_r2|File Popcorn FX.]]

| N. | Cosa fa |
|---|---|
| [[ctl:9]] | Scegli un effetto `.pkb` o `.pkfx` dagli archivi del gioco. |
| [[ctl:10]] | Scegli un file di effetto sul tuo disco. |

I due campi sopra i pulsanti contengono il percorso dell'effetto e la cartella davanti a esso.
