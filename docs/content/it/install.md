# Installazione

Un solo programma di installazione mette WhiteoutDex in ogni versione di 3ds Max del tuo computer (dalla 2016 alla 2027).

## Installare

1. Chiudi 3ds Max.
2. Scarica il file `WhiteoutDex_Setup_v<version>.exe` più recente. Lo trovi nella pagina **Releases** di GitHub e su Hive Workshop.
3. Avvia il programma di installazione. Windows chiede i diritti di amministratore. Clicca **Sì**.
4. Scegli la tua lingua e segui i passaggi. Il programma di installazione trova da solo tutte le tue versioni di 3ds Max.
5. Avvia 3ds Max. Ora vedi il menu **WhiteoutDex** e la barra laterale di WhiteoutDex.

!!! note
    3ds Max 2026 e le versioni più recenti richiedono **.NET 8**. Il programma di installazione ti avvisa se manca.

## Dove vanno i file

WhiteoutDex si installa in una sola cartella:

`C:\ProgramData\Autodesk\ApplicationPlugins\WhiteoutDex`

3ds Max carica tutto da lì. Non devi copiare nessun file a mano.

Le tue impostazioni personali (lingua, cartelle del gioco, ultime opzioni di esportazione) si trovano nella cartella delle impostazioni di 3ds Max `plugcfg`. Restano quando aggiorni WhiteoutDex.

## Aggiornare

WhiteoutDex può cercare nuove versioni all'avvio di 3ds Max (3ds Max 2018 e versioni più recenti). Quando esce una nuova versione, ti fa una domanda:

- Clicca **Sì** per scaricarla e installarla. 3ds Max si chiude per l'aggiornamento.
- Clicca **No** per continuare a lavorare. WhiteoutDex chiede di nuovo il giorno dopo.

Puoi disattivare questa funzione o cercare subito in [[t:menu_settings]].

## Disinstallare

Apri **Impostazioni di Windows > App**, cerca **WhiteoutDex** e clicca **Disinstalla**.
