# Anim: Allgemeine Werkzeuge

Kleine Helfer, die dir Zeit sparen, wenn du animierst oder ein Modell fertig machst.

Öffne sie über **WhiteoutDex > [[t:menu_anim_general]]**.

[[shot:anim_general|Die Allgemeinen Werkzeuge.]]

| Nr. | Was es macht |
|---|---|
| [[ctl:4]] | Fügt für die ausgewählten Objekte Keys in Frame 0 und am Anfang und Ende jeder Sequenz hinzu. Dann ändert eine Animation nicht die nächste. |
| [[ctl:6]] | Nutzt das TCB-Werkzeug auf Positions-Keys. |
| [[ctl:7]] | … auf Rotations-Keys. |
| [[ctl:8]] | … auf Skalierungs-Keys. |
| [[ctl:9]] | Setzt *Continuity* auf den aktuellen Keys der ausgewählten Objekte auf 0. Das entfernt das Überschwingen von TCB-Keys. |
| [[ctl:11]] | Rotations-Keys, die sich zwischen zwei Keys um mehr als 90° drehen, können im Spiel falsch aussehen. Dieses Werkzeug fügt in der Mitte einen Key hinzu. Starte es bei sehr großen Drehungen (über 180°) noch einmal. |
| [[ctl:13]] | Erstellt Anhangspunkte für Knochen mit bekannten Namen (zum Beispiel *Head*, *Chest*, *Hand*). |
| [[ctl:14]] | Erstellt eine Porträt-Kamera, die auf das ausgewählte Objekt schaut. Ist nichts ausgewählt, schaut sie auf den oberen Teil des Modells. |
| [[ctl:15]] | Erstellt zwei Kollisionskugeln, die zum Modell passen. So macht es Blizzard bei Einheiten. |
| [[ctl:16]] | Erstellt eine Kollisionsbox, die zum Modell passt. So macht es Blizzard bei Gebäuden. |

!!! tip
    Nutze die [[t:anim_one_click_tools_grp]] an einem fertigen Modell. Sie messen das Modell aus. Darum funktionieren sie am besten, wenn das Modell seine endgültige Größe hat.
