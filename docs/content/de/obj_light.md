# Licht

Ein Warcraft-III-Licht scheint auf das Modell und auf den Boden um es herum. Beispiele sind das Leuchten einer Fackel oder eines magischen Kristalls.

Erstelle es über **Create > Helpers > Warcraft III Plugins > Wc3 Light**.

## Allgemeine Funktionen

[[shot:obj_light_r1|Allgemeine Funktionen.]]

| Nr. | Was es macht |
|---|---|
| [[ctl:3]] | Klicke hierauf und dann auf ein Objekt. Das Licht springt zu diesem Objekt und wird mit ihm verbunden. |

## Grundparameter

[[shot:obj_light_r3|Grundparameter.]]

| Nr. | Was es macht |
|---|---|
| [[ctl:4]] | [[t:light_type_items#1]] scheint von einem Punkt in alle Richtungen. [[t:light_type_items#2]] scheint in eine Richtung, wie die Sonne. [[t:light_type_items#3]] beleuchtet alles gleichmäßig. |
| [[ctl:9]] | Die Entfernung, ab der das Licht schwächer wird. |
| [[ctl:16]] | Die Entfernung, an der das Licht endet. |
| [[ctl:21]] | Die Farbe des Lichts. |
| [[ctl:29]] | Die Stärke des Lichts. |
| [[ctl:35]] | Die Farbe des Umgebungsanteils. |
| [[ctl:43]] | Die Stärke des Umgebungsanteils. |
| [[ctl:11]] | **Steuerung:** wie sich ein animierter Wert zwischen den Keys ändert. Jeder Wert hat seine eigene Steuerung. |
