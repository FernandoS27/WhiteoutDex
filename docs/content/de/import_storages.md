# Aus dem Spiel importieren

Du kannst ein Modell direkt aus deinem Warcraft III importieren, ohne Datei auf deiner Festplatte.

1. Wähle **WhiteoutDex > [[t:menu_import_casc]]**.
2. Der Spiel-Browser öffnet sich. Suche das Modell, zum Beispiel mit dem Suchwort `footman`.
3. Klicke auf das Modell und dann auf **Select**.
4. Das normale Import-Fenster öffnet sich (siehe *Der Importer*). Wähle deine Optionen und klicke auf [[t:imp_import_btn]].

WhiteoutDex kopiert das Modell und seine Texturen in einen temporären Ordner und importiert es von dort. Deine Spieldateien ändern sich nicht.

!!! tip
    So änderst du ein Modell aus dem Spiel: Importiere es auf diesem Weg, ändere es und exportiere es unter einem neuen Namen in den Ordner deiner Karte oder deiner Mod.

!!! note
    Modelle aus dem Spiel gehören Blizzard Entertainment. Nutze sie nur so, wie Blizzard es erlaubt, zum Beispiel in Karten und Mods für Warcraft III.
