# Anim: Controller

Warcraft III kennt vier Arten, sich zwischen Keys zu bewegen: *None* (Sprung), *Linear*, *Bezier* und *Hermite* (TCB). Dieses Werkzeug gibt den ausgewählten Objekten die Controller, die du wählst. Es macht das für Position, Rotation und Skalierung auf einmal.

Öffne es über **WhiteoutDex > [[t:menu_anim_controllers]]**.

[[shot:anim_controllers|Das Werkzeug Controller.]]

| Nr. | Was es macht |
|---|---|
| [[ctl:4]] | Die Position bewegt sich in geraden Linien zwischen den Keys. |
| [[ctl:5]] | Die Position bewegt sich auf weichen Kurven. |
| [[ctl:6]] | Die Position nutzt TCB-Keys (weich, mit Tension, Continuity und Bias). |
| [[ctl:7]] | Lässt den Positions-Controller, wie er ist. |
| [[ctl:10]] | Die Rotation dreht sich gleichmäßig zwischen den Keys. |
| [[ctl:11]] | Die Rotation dreht sich weich. |
| [[ctl:12]] | Die Rotation nutzt TCB-Keys. |
| [[ctl:13]] | Lässt den Rotations-Controller, wie er ist. |
| [[ctl:16]] | Die Skalierung ändert sich gleichmäßig. |
| [[ctl:17]] | Die Skalierung ändert sich auf weichen Kurven. |
| [[ctl:18]] | Die Skalierung nutzt TCB-Keys. |
| [[ctl:19]] | Lässt den Skalierungs-Controller, wie er ist. |
| [[ctl:22]] | Gibt den ausgewählten Objekten diese Controller. |

!!! note
    Der Exporter ersetzt auch Controller, die das Spiel nicht lesen kann (siehe *Szenenprobleme und Alle beheben*). Mit diesem Werkzeug wählst du den Typ selbst.
