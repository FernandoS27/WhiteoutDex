# Node-Manager

Ein Modell hat viele Arten von Objekten: Meshes, Knochen, Helfer, Emitter und mehr. Der Node-Manager zeigt, versteckt oder friert alle Objekte einer Art auf einmal ein.

Öffne ihn über **WhiteoutDex > [[t:menu_node_manager]]**.

[[shot:node_manager|Der Node-Manager.]]

## 1. Die Arten wählen

| Nr. | Art |
|---|---|
| [[ctl:4]] | Meshes. |
| [[ctl:5]] | Knochen von 3ds Max. |
| [[ctl:6]] | Knochen eines Biped-Rigs. |
| [[ctl:7]] | Knochen eines CAT-Rigs. |
| [[ctl:8]] | Helfer und Dummys. |
| [[ctl:9]] | Anhangspunkte. |
| [[ctl:10]] | Event-Objekte. |
| [[ctl:11]] | Lichter. |
| [[ctl:12]] | Kameras. |
| [[ctl:13]] | Partikelemitter 1. |
| [[ctl:14]] | Partikelemitter 2. |
| [[ctl:15]] | Bandemitter (Ribbons). |
| [[ctl:16]] | Popcorn-FX-Emitter. |
| [[ctl:17]] | FaceFX-Objekte. |
| [[ctl:18]] | Kollisionsformen. |
| [[ctl:27]] | Hakt alle Arten an. [[ctl:28]] nimmt alle Haken weg, [[ctl:29]] kehrt jeden Haken um. |

## 2. Etwas mit ihnen machen

| Nr. | Was es macht |
|---|---|
| [[ctl:20]] | Zeigt die Objekte. |
| [[ctl:21]] | Versteckt die Objekte. |
| [[ctl:22]] | Friert die Objekte ein. So kannst du sie nicht aus Versehen auswählen. |
| [[ctl:23]] | Taut die Objekte wieder auf. |
| [[ctl:24]] | Zeigt die Objekte durchsichtig. |
| [[ctl:25]] | Zeigt die Objekte wieder massiv. |

!!! tip
    Verstecke alle Helfer, Knochen und Emitter, während du am Mesh arbeitest. Friere die Knochen ein, während du Skin-Gewichte malst.
