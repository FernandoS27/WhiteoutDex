# Glossar

Wörter, die dir in WhiteoutDex und in diesem Handbuch begegnen.

| Wort | Bedeutung |
|---|---|
| **MDX / MDL** | Die Modelldateien von Warcraft III. `.mdx` ist binär und klein. `.mdl` ist Text, den du lesen und bearbeiten kannst. Beide enthalten dieselben Daten. |
| **Klassisch** | Warcraft III Version 1.x und die klassische Grafik. Die Modelle nutzen MDX-Version 800. |
| **Reforged** | Warcraft III: Reforged mit HD-Grafik. Die Modelle nutzen MDX-Version 900 bis 1800. WhiteoutDex exportiert Version 1800. |
| **MPQ** | Die Archivdateien des klassischen Spiels (zum Beispiel `War3.mpq`). |
| **CASC** | Der Speicher von Warcraft III: Reforged. |
| **BLP** | Das Texturformat des klassischen Spiels. |
| **DDS** | Das Texturformat von Reforged. |
| **Geoset** | Ein Mesh eines Modells. Ein Modell kann viele Geosets haben. |
| **Knochen** | Ein Node, der Vertices eines geskinnten Meshes bewegt. |
| **Helfer** | Ein Node, der andere Nodes bewegt. Im Spiel siehst du ihn nicht. |
| **Skin** | Sagt, welcher Knochen welchen Vertex bewegt und wie stark (Gewicht). |
| **Sequenz** | Eine Animation des Modells, zum Beispiel *Walk*. Sie hat einen Namen, einen Startframe und einen Endframe. |
| **Globale Sequenz** | Eine Animation, die ständig läuft, unabhängig von der aktuellen Sequenz. Gut für Dinge, die sich immer bewegen, wie ein drehender Kristall. |
| **Key / Keyframe** | Ein Wert an einem Zeitpunkt. Das Spiel bewegt sich zwischen den Keys. |
| **Controller** | Wie sich das Spiel zwischen den Keys bewegt: *None* (Sprung), *Linear*, *Bezier* oder *Hermite* (weich). |
| **Anhangspunkt** | Eine Stelle am Modell, an der das Spiel Dinge anhängt: Waffen, Zaubereffekte, den Auswahlkreis. |
| **Event-Objekt** | Startet etwas in einem Moment einer Animation: einen Sound, eine Fußspur, Blut, ein erzeugtes Modell. |
| **Partikelemitter 1** | Sendet kleine Modelle aus. |
| **Partikelemitter 2** | Sendet Partikel mit Textur aus: Feuer, Rauch, Funken. |
| **Bandemitter (Ribbon)** | Zeichnet eine Spur hinter einem Punkt, der sich bewegt. |
| **Popcorn FX** | Das Partikelsystem von Reforged (`.pkfx`-Dateien). |
| **Kollisionsform** | Eine Box oder Kugel. Daran erkennt das Spiel, wo du das Modell anklicken kannst. |
| **Extents** | Die Größe des Modells in einer Sequenz. Daran erkennt das Spiel, wann das Modell auf dem Bildschirm ist. |
| **Ersetzbare Textur** | Eine Textur, die das Spiel einsetzt, zum Beispiel die Teamfarbe. |
| **Teamfarbe / Team-Glühen** | Die Spielerfarbe an einer Einheit. |
| **Filtermodus** | Wie ein Material gezeichnet wird: undurchsichtig, transparent, additiv (leuchtet) und mehr. |
| **Billboard** | Ein Node, der sich immer zur Kamera dreht. |
| **Grafikstufe** | Welche Grafik die Vorschau zeigt: Classic, Reforged (HD) oder Definitive. |
| **WhiteoutFlakes** | Die Vorschau, die dein Modell wie das Spiel zeigt. |
