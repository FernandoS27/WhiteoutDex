# Willkommen bei WhiteoutDex

WhiteoutDex ist eine Sammlung von Werkzeugen für **3ds Max**. Damit kannst du Modelle für **Warcraft III** bauen, ändern und testen. Es funktioniert mit dem klassischen Spiel (Warcraft III, Version 1.x) und mit **Warcraft III: Reforged**.

![WhiteoutDex in 3ds Max 2027. Links: die Vorschau WhiteoutFlakes. Rechts: der Node Manager und das Modell im Viewport.](media_1.png)

## Was du damit machen kannst

- **Importieren:** Lade ein Warcraft-III-Modell (`.mdx` oder `.mdl`) in 3ds Max. WhiteoutDex holt auch die Texturen aus deinem Spiel.
- **Bearbeiten:** Ändere das Modell wie jedes andere 3ds-Max-Objekt: Mesh, Knochen, Animationen und Materialien.
- **Vorschau:** Sieh dir das Modell in **WhiteoutFlakes** an. Dieses Fenster zeigt das Modell so, wie das Spiel es zeigt.
- **Exportieren:** Speichere das Modell wieder als `.mdx` oder `.mdl`, für das klassische Spiel oder für Reforged. WhiteoutDex wandelt die Texturen für dich um.
- **Besondere Objekte:** Nutze Objekte, die es nur in Warcraft III gibt: Partikel-Emitter, Ribbons, Anhangspunkte, Event-Objekte, Kollisionsformen und mehr.

## Was du brauchst

| | |
|---|---|
| Windows | Windows 10 oder neuer |
| 3ds Max | Jede Version von 2016 bis 2027 |
| Warcraft III | Nicht nötig, aber empfohlen: WhiteoutDex holt Texturen und Modelle aus deinem Spielordner. |

## So liest du dieses Handbuch

Das Handbuch hat vier Arten von Seiten:

- **Erste Schritte** hilft dir beim Installieren und Einrichten.
- **Tutorials** sind kurze Lektionen. Mach sie der Reihe nach, wenn du neu bist.
- **Seiten zu Werkzeugen und Objekten** erklären ein Fenster oder ein Objekt. Jedes Bild hat Nummern. Die Tabelle unter dem Bild sagt dir, was jede Nummer macht.
- **Anhang**-Seiten sind Listen zum Nachschlagen.

Wörter in einem **blauen Kasten**, wie [[t:menu_importer]], sind die Wörter, die du in 3ds Max siehst. Tasten sehen so aus: [[key:Strg+Z]].

!!! tip
    Das Handbuch gibt es in denselben Sprachen wie WhiteoutDex. Die Sprache von WhiteoutDex stellst du unter [[t:menu_settings]] ein. Siehe *Einstellungen*.
