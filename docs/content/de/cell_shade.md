# Cel-Shading-Ersteller

Gibt einem Mesh einen Comic-Umriss. Das Werkzeug legt eine etwas größere Kopie des Meshes um das Mesh herum. Bei der Kopie sind die Flächen nach innen gedreht. Im Spiel siehst du dann eine dunkle Linie um das Modell.

Öffne ihn über **WhiteoutDex > [[t:menu_cell_shade]]**. Wähle vorher die Meshes aus.

[[shot:cell_shade|Der Cel-Shading-Ersteller.]]

| Nr. | Was es macht |
|---|---|
| [[ctl:4]] | Die Farbe des Umrisses. Klicke, um eine andere Farbe zu wählen. |
| [[ctl:6]] | Schnellfarben. Klicke auf eine, um sie zu nutzen. |
| [[ctl:19]] | Wie dick der Umriss ist. |
| [[ctl:21]] | Dreht die Flächen der Kopie nach innen. Das erzeugt den Umriss (normale Wahl). |
| [[ctl:22]] | Lässt die Flächen, wie sie sind. |
| [[ctl:25]] | Der Umriss ist undurchsichtig. |
| [[ctl:26]] | Der Umriss nutzt die Transparenz der Textur. |
| [[ctl:27]] | Der Umriss leuchtet (fügt Licht hinzu). |
| [[ctl:28]] | Der Umriss leuchtet und nutzt die Transparenz der Textur. |
| [[ctl:30]] | Erstellt den Umriss für die ausgewählten Meshes. |

!!! tip
    Der Umriss ist ein normales Mesh mit einem *Wc3Material*. Du kannst seine Farbe oder Dicke später ändern, wie bei jedem anderen Mesh.
