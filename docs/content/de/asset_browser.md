# Spiel-Browser

Der Spiel-Browser zeigt die Dateien in deinem Warcraft III: Modelle, Texturen und Partikeleffekte. Du siehst ein kleines Bild von jeder Datei. So findest du schnell, was du brauchst.

Er öffnet sich an vielen Stellen:

| Wo | Knopf | Du wählst |
|---|---|---|
| WhiteoutDex-Menü | [[t:menu_import_casc]] | ein Modell zum Importieren |
| Anhangspunkt | [[t:attach_browse_archives_btn]] | ein Modell für den Anhangspunkt |
| Partikelemitter 1 | [[t:attach_browse_archives_btn]] | ein Modell für die Partikel |
| Partikelemitter 2 | [[t:bp2_browse_archives_btn]] | eine Textur für die Partikel |
| Popcorn FX | [[t:popcorn_browse_game_archives_btn]] | einen `.pkb`- oder `.pkfx`-Effekt |
| Wc3Bitmap | [[t:bmp_open_browser_btn]] | eine Textur |
| Wc3Material | der Knopf ⚙ neben einer Map | eine Textur für diesen Slot |

## So nutzt du ihn

1. Gib einen Teil des Namens in das Suchfeld ein, zum Beispiel `footman`.
2. Wechsle zwischen dem **Raster** (Bilder) und dem **Baum** (Ordner).
3. Zoome die Bilder größer oder kleiner.
4. Klicke auf eine Datei. Die Zeile unten zeigt die ausgewählte Datei.
5. Klicke auf **Select**.

!!! note
    Der Browser braucht deine Spielordner. Stelle sie unter [[t:menu_settings]] ein. Klassische Modelle kommen aus den MPQ-Archiven, Reforged-Dateien aus CASC.
