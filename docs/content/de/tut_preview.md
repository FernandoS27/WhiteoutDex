# Tutorial: Dein Modell in der Vorschau

3ds Max kann ein Modell nicht genau so zeigen wie das Spiel. Das Spiel hat eigenes Licht, eigene Shader, Teamfarben und Effekte. Die Vorschau **WhiteoutFlakes** kann das.

**Du brauchst:** die Szene aus der Lektion *Ein Modell importieren*.

## Schritt 1: Die Vorschau öffnen

Wähle **WhiteoutDex > [[t:menu_renderer]]**. Ein neues Fenster öffnet sich und zeigt das Modell.

![Die Vorschau WhiteoutFlakes neben 3ds Max 2016.](media_2.png)

## Schritt 2: Eine Animation wählen

1. Öffne in der Werkzeugleiste der Vorschau die Liste **Animation**.
2. Wähle *Walk*. Der Paladin läuft.
3. Wähle **Freier Bereich**. Jetzt folgt die Vorschau dem Zeitschieber von 3ds Max. Bewege den Zeitschieber und sieh zu.

## Schritt 3: Das Aussehen ändern

1. Klicke neben **Team** auf das Farbfeld und wähle eine andere Teamfarbe. Der Umhang ändert seine Farbe.
2. Wähle unter **Beleuchtung** den Eintrag **Glue**. Das ist das Licht der Spielmenüs.
3. Wähle unter **Ansicht > Warcraft-III-Grafiken** den Eintrag **Classic** oder **Reforged (HD)**. So vergleichst du beide Grafiken.

## Schritt 4: Das Modell ändern und sofort sehen

1. Wähle in 3ds Max ein Mesh aus und verschiebe es ein wenig.
2. Sieh dir die Vorschau an: Sie zeigt die Änderung sofort.
3. Mach die Änderung mit [[key:Strg+Z]] rückgängig.

!!! tip
    Klicke in der Vorschau auf **Neu einlesen**, nachdem du Objekte hinzugefügt oder gelöscht hast. Die Vorschau liest dann die ganze Szene neu.

**Nächste Lektion:** Exportiere das Modell.
