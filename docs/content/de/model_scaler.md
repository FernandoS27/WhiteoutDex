# Anim: Modell-Skalierer

Skaliert das ganze Modell, mit seinen Knochen, Animationen und besonderen Objekten. Nutze es, wenn ein Modell für das Spiel zu groß oder zu klein ist.

Öffne ihn über **WhiteoutDex > [[t:menu_anim_scaler]]**.

[[shot:model_scaler|Der Modell-Skalierer.]]

| Nr. | Was es macht |
|---|---|
| [[ctl:4]] | Eine Zielhöhe aus dem Spiel, zum Beispiel *Footman* oder *Townhall* (Klassisch oder Reforged). |
| [[ctl:6]] | Skaliert das Modell auf die gewählte Höhe. |
| [[ctl:10]] | Dein eigener Faktor. 2 macht das Modell doppelt so groß, 0.5 halb so groß. |
| [[ctl:11]] | Skaliert das Modell mit deinem Faktor. |

!!! warning
    Modelle mit einem **Biped**- oder **CAT**-Rig und einem Skin-Modifikator lassen sich so nicht gut skalieren. WhiteoutDex warnt dich. Skaliere das Rig stattdessen mit seinen eigenen Werkzeugen.

!!! tip
    Speichere deine Szene, bevor du skalierst. Dann kannst du zurück, wenn das Ergebnis nicht stimmt.
