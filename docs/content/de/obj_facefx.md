# FaceFX

**FaceFX** bewegt das Gesicht von Reforged-Helden, wenn sie sprechen: Mund, Augen und Brauen folgen der Stimme. Die Daten liegen in einer `.facefx_ingame`-Datei. Das FaceFX-Objekt verbindet diese Datei mit dem Modell.

Erstelle es über **Create > Helpers > Warcraft III Plugins > Wc3 FaceFX**. FaceFX funktioniert nur in **Reforged**-Modellen.

[[shot:obj_facefx_r2|FaceFX Einstellungen.]]

| Nr. | Was es macht |
|---|---|
| [[ctl:9]] | Wähle die `.facefx_ingame`-Datei. |
| [[ctl:10]] | Zeigt eine kurze Erklärung. |

Die zwei Felder enthalten den **Zielnamen** (den Namen, den das Spiel für dieses Gesicht nutzt) und den **Dateipfad**.

!!! note
    Der Importer holt FaceFX-Objekte aus Reforged-Modellen in die Szene. Der Exporter schreibt sie unverändert zurück.
