# Raster- & Dummy-Ersteller

Erstellt ein Raster als Größenhilfe und Punkt-Helfer.

Öffne ihn über **WhiteoutDex > [[t:menu_grid_dummy]]**.

[[shot:grid_dummy|Der Raster- & Dummy-Ersteller.]]

| Nr. | Was es macht |
|---|---|
| [[ctl:4]] | Farbe des Rasters. |
| [[ctl:8]] | Größe des Rasters in Welteinheiten. |
| [[ctl:9]] | Erstellt das Raster in der Mitte der Szene (0, 0, 0). |
| [[ctl:11]] | Farbe der Punkte. |
| [[ctl:15]] | Größe der Punkte. |
| [[ctl:16]] | Erstellt an jedem ausgewählten Objekt einen Punkt. Ist nichts ausgewählt, erstellt es einen Punkt in der Mitte. |
