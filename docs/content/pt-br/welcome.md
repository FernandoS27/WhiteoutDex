# Bem-vindo ao WhiteoutDex

O WhiteoutDex é um conjunto de ferramentas para o **3ds Max**. Com ele você cria, altera e testa modelos para o **Warcraft III**. Ele funciona com o jogo clássico (Warcraft III, versão 1.x) e com o **Warcraft III: Reforged**.

![O WhiteoutDex no 3ds Max 2027. À esquerda: o pré-visualizador WhiteoutFlakes. À direita: o Gerenciador de nós e o modelo na viewport.](media_1.png)

## O que você pode fazer

- **Importar** um modelo do Warcraft III (`.mdx` ou `.mdl`) para o 3ds Max. O WhiteoutDex também carrega as texturas do seu jogo.
- **Editar** o modelo como qualquer outro objeto do 3ds Max: altere a malha, os ossos, as animações e os materiais.
- **Pré-visualizar** o modelo no **WhiteoutFlakes**. Esta janela mostra o modelo do mesmo jeito que o jogo.
- **Exportar** o modelo de volta para `.mdx` ou `.mdl`, para o jogo clássico ou para o Reforged. O WhiteoutDex converte as texturas para você.
- Usar **objetos especiais** que só o Warcraft III tem: emissores de partículas, rastros, pontos de anexo, objetos de evento, formas de colisão e mais.

## O que você precisa

| | |
|---|---|
| Windows | Windows 10 ou mais novo |
| 3ds Max | Qualquer versão de 2016 a 2027 |
| Warcraft III | Opcional, mas recomendado: o WhiteoutDex pega texturas e modelos da pasta do seu jogo. |

## Como ler este manual

O manual tem quatro tipos de página:

- **Primeiros passos** ajuda você a instalar e configurar o WhiteoutDex.
- **Tutoriais** são lições curtas. Faça-as em ordem se você é iniciante.
- **Páginas de ferramentas e objetos** explicam uma janela ou um objeto. Cada imagem tem números. A tabela abaixo da imagem diz o que cada número faz.
- As páginas do **Apêndice** são listas para consulta.

Palavras em uma **caixa azul**, como [[t:menu_importer]], são as palavras que você vê no 3ds Max. As teclas aparecem assim: [[key:Ctrl+Z]].

!!! tip
    O manual está no mesmo idioma do WhiteoutDex. Você pode mudar o idioma do WhiteoutDex em [[t:menu_settings]]. Veja *Configurações*.
