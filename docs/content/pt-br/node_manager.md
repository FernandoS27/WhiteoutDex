# Gerenciador de nós

Um modelo tem muitos tipos de objeto: malhas, ossos, auxiliares, emissores e mais. O Gerenciador de nós mostra, oculta ou congela todos os objetos de um tipo de uma vez.

Abra-o com **WhiteoutDex > [[t:menu_node_manager]]**.

[[shot:node_manager|O Gerenciador de nós.]]

## 2. Fazer algo com eles

| N.º | O que faz |
|---|---|
| [[ctl:20]] | Mostra os objetos. |
| [[ctl:21]] | Oculta os objetos. |
| [[ctl:22]] | Congela os objetos. Assim você não os seleciona por engano. |
| [[ctl:23]] | Descongela os objetos. |
| [[ctl:24]] | Mostra os objetos transparentes. |
| [[ctl:25]] | Mostra os objetos sólidos de novo. |

!!! tip
    Oculte todos os auxiliares, ossos e emissores enquanto você trabalha na malha. Congele os ossos enquanto você pinta os pesos de skin.
