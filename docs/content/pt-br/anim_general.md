# Anim.: ferramentas gerais

Pequenos auxiliares que poupam tempo quando você anima ou termina um modelo.

Abra-os com **WhiteoutDex > [[t:menu_anim_general]]**.

[[shot:anim_general|As ferramentas gerais.]]

| N.º | O que faz |
|---|---|
| [[ctl:4]] | Adiciona chaves no quadro 0 e no início e no fim de cada sequência, para os objetos selecionados. Assim uma animação não altera a próxima. |
| [[ctl:6]] | Usa a ferramenta TCB nas chaves de posição. |
| [[ctl:7]] | … nas chaves de rotação. |
| [[ctl:8]] | … nas chaves de escala. |
| [[ctl:9]] | Define *Continuity* como 0 nas chaves atuais dos objetos selecionados. Isto remove o excesso de movimento das chaves TCB. |
| [[ctl:11]] | Chaves de rotação que giram mais de 90° entre duas chaves podem ficar erradas no jogo. Esta ferramenta adiciona uma chave no meio. Use-a de novo para giros muito grandes (acima de 180°). |
| [[ctl:13]] | Cria pontos de anexo para ossos com nomes conhecidos (por exemplo *Head*, *Chest*, *Hand*). |
| [[ctl:14]] | Cria uma câmera de retrato que olha para o objeto selecionado. Sem nada selecionado, ela olha para o alto do modelo. |
| [[ctl:15]] | Cria duas esferas de colisão que se ajustam ao modelo, como a Blizzard faz para unidades. |
| [[ctl:16]] | Cria uma caixa de colisão que se ajusta ao modelo, como a Blizzard faz para construções. |

!!! tip
    Use as ferramentas **de um clique** em um modelo pronto. Elas medem o modelo. Por isso funcionam melhor quando ele tem o seu tamanho final.
