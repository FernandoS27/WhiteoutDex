# FaceFX

O **FaceFX** move o rosto dos heróis do Reforged quando eles falam: a boca, os olhos e as sobrancelhas seguem a voz. Os dados ficam em um arquivo `.facefx_ingame`. O objeto FaceFX liga esse arquivo ao modelo.

Crie-o com **Create > Helpers > Warcraft III Plugins > Wc3 FaceFX**. O FaceFX só funciona em modelos **Reforged**.

[[shot:obj_facefx_r2|Configurações do FaceFX.]]

| N.º | O que faz |
|---|---|
| [[ctl:9]] | Escolha o arquivo `.facefx_ingame`. |
| [[ctl:10]] | Mostra uma explicação curta. |

Os dois campos guardam o **nome do alvo** (o nome que o jogo usa para este rosto) e o **caminho do arquivo**.

!!! note
    O importador traz os objetos FaceFX dos modelos Reforged para a cena. O exportador os escreve de volta sem mudanças.
