# Glossário

Palavras que você encontra no WhiteoutDex e neste manual.

| Palavra | Significado |
|---|---|
| **MDX / MDL** | Os arquivos de modelo do Warcraft III. `.mdx` é binário e pequeno. `.mdl` é texto que você pode ler e editar. Os dois guardam os mesmos dados. |
| **Clássico** | O Warcraft III versão 1.x e os gráficos clássicos. Os modelos usam MDX versão 800. |
| **Reforged** | O Warcraft III: Reforged com gráficos HD. Os modelos usam MDX versão 900 a 1800. O WhiteoutDex exporta a versão 1800. |
| **MPQ** | Os arquivos compactados do jogo clássico (por exemplo `War3.mpq`). |
| **CASC** | O armazenamento do Warcraft III: Reforged. |
| **BLP** | O formato de textura do jogo clássico. |
| **DDS** | O formato de textura do Reforged. |
| **Geoset** | Uma malha de um modelo. Um modelo pode ter muitos geosets. |
| **Osso** | Um nó que move vértices de uma malha com skin. |
| **Auxiliar** | Um nó que move outros nós, mas que você não vê no jogo. |
| **Skin** | Diz qual osso move qual vértice e com que força (peso). |
| **Sequência** | Uma animação do modelo, por exemplo *Walk*. Ela tem um nome, um quadro inicial e um quadro final. |
| **Sequência global** | Uma animação que se repete o tempo todo, independente da sequência atual. Boa para coisas que sempre se movem, como um cristal que gira. |
| **Chave / quadro-chave** | Um valor em um momento do tempo. O jogo faz a transição entre as chaves. |
| **Controlador** | Como o jogo passa de uma chave para outra: *None* (salto), *Linear*, *Bezier* ou *Hermite* (suave). |
| **Ponto de anexo** | Um lugar no modelo onde o jogo prende coisas: armas, efeitos de magia, o círculo de seleção. |
| **Objeto de evento** | Inicia algo em um momento de uma animação: um som, uma pegada, sangue, um modelo gerado. |
| **Emissor de partículas 1** | Emite pequenos modelos. |
| **Emissor de partículas 2** | Emite partículas com textura: fogo, fumaça, faíscas. |
| **Emissor de rastros** | Desenha um rastro atrás de um ponto que se move. |
| **Popcorn FX** | O sistema de partículas do Reforged (arquivos `.pkfx`). |
| **Forma de colisão** | Uma caixa ou esfera. O jogo a usa para saber onde você pode clicar no modelo. |
| **Extensões** | O tamanho do modelo em uma sequência. O jogo as usa para saber quando o modelo está na tela. |
| **Textura substituível** | Uma textura que o jogo preenche, por exemplo a cor de equipe. |
| **Cor de equipe / brilho de equipe** | A cor do jogador em uma unidade. |
| **Modo de filtro** | Como um material é desenhado: sólido, transparente, aditivo (brilha) e mais. |
| **Billboard** | Um nó que sempre se vira para a câmera. |
| **Arte da cena** | Quais gráficos o pré-visualizador mostra: Classic, Reforged (HD) ou Definitive. |
| **WhiteoutFlakes** | O pré-visualizador que mostra o seu modelo como o jogo. |
