# Trocador de skin

Prepara o skin das suas malhas para o Warcraft III.

Abra-o com **WhiteoutDex > [[t:menu_skin_changer]]**. Selecione as malhas com skin primeiro.

[[shot:skin_changer|O Trocador de skin.]]

| N.º | O que faz |
|---|---|
| [[ctl:3]] | Altera o skin para que cada vértice tenha no máximo 5 ossos com pesos limpos. Você pode desfazer. |
| [[ctl:7]] | Os pesos iguais ou menores que este valor são removidos. 0,0 remove só os pesos que são exatamente zero. |
| [[ctl:8]] | Remove os pesos pequenos e distribui a parte deles entre os outros ossos do vértice. |
| [[ctl:11]] | Junta as malhas com skin selecionadas que usam o mesmo material em uma malha com um só Skin. Os ossos, os pesos e a pose continuam iguais. Assim a malha se move exatamente como antes. Você pode desfazer. |

!!! tip
    Menos malhas deixam o modelo mais rápido. Use *Combinar malha + Skin* quando um modelo tem muitas partes pequenas com a mesma textura.
