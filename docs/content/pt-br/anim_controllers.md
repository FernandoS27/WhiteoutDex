# Anim.: controladores

O Warcraft III conhece quatro formas de passar de uma chave para outra: *None* (salto), *Linear*, *Bezier* e *Hermite* (TCB). Esta ferramenta dá aos objetos selecionados os controladores que você escolhe, para posição, rotação e escala de uma vez.

Abra-a com **WhiteoutDex > [[t:menu_anim_controllers]]**.

[[shot:anim_controllers|A ferramenta de controladores.]]

| N.º | O que faz |
|---|---|
| [[ctl:4]] | A posição se move em linhas retas entre as chaves. |
| [[ctl:5]] | A posição se move em curvas suaves. |
| [[ctl:6]] | A posição usa chaves TCB (suaves, com tensão, continuidade e viés). |
| [[ctl:7]] | Deixa o controlador de posição como está. |
| [[ctl:10]] | A rotação gira de forma uniforme entre as chaves. |
| [[ctl:11]] | A rotação gira de forma suave. |
| [[ctl:12]] | A rotação usa chaves TCB. |
| [[ctl:13]] | Deixa o controlador de rotação como está. |
| [[ctl:16]] | A escala muda de forma uniforme. |
| [[ctl:17]] | A escala muda em curvas suaves. |
| [[ctl:18]] | A escala usa chaves TCB. |
| [[ctl:19]] | Deixa o controlador de escala como está. |
| [[ctl:22]] | Dá esses controladores aos objetos selecionados. |

!!! note
    O exportador também troca os controladores que o jogo não consegue ler (veja *Problemas da cena e Corrigir tudo*). Com esta ferramenta, você mesmo escolhe o tipo.
