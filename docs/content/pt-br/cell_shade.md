# Criador de cell shading

Dá a uma malha um contorno de desenho animado. A ferramenta faz uma cópia um pouco maior da malha em volta dela, com as faces viradas do avesso. No jogo você então vê uma linha escura em volta do modelo.

Abra-o com **WhiteoutDex > [[t:menu_cell_shade]]**. Selecione as malhas primeiro.

[[shot:cell_shade|O Criador de cell shading.]]

| N.º | O que faz |
|---|---|
| [[ctl:4]] | A cor do contorno. Clique para escolher outra cor. |
| [[ctl:6]] | Cores rápidas. Clique em uma para usá-la. |
| [[ctl:19]] | A espessura do contorno. |
| [[ctl:21]] | Vira do avesso as faces da cópia. Isto cria o contorno (a escolha normal). |
| [[ctl:22]] | Deixa as faces como estão. |
| [[ctl:25]] | O contorno é sólido. |
| [[ctl:26]] | O contorno usa a transparência da textura. |
| [[ctl:27]] | O contorno brilha (adiciona luz). |
| [[ctl:28]] | O contorno brilha e usa a transparência da textura. |
| [[ctl:30]] | Cria o contorno para as malhas selecionadas. |

!!! tip
    O contorno é uma malha normal com um *Wc3Material*. Você pode mudar a cor ou a espessura dele depois, como em qualquer outra malha.
