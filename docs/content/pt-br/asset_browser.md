# Navegador do jogo

O navegador do jogo mostra os arquivos que estão dentro do seu Warcraft III: modelos, texturas e efeitos de partículas. Você vê uma pequena imagem de cada arquivo. Assim você encontra rápido o que precisa.

Ele abre a partir de muitos lugares:

| Onde | Botão | Você escolhe |
|---|---|---|
| Menu WhiteoutDex | [[t:menu_import_casc]] | um modelo para importar |
| Ponto de anexo | *Navegar pelos arquivos do jogo* | um modelo para o anexo |
| Particle Emitter 1 | *Browse Game Archives* | um modelo para as partículas |
| Particle Emitter 2 | *Navegar MPQ / CASC* | uma textura para as partículas |
| Popcorn FX | *Navegar pelos arquivos do jogo* | um efeito `.pkb` ou `.pkfx` |
| Wc3Bitmap | *Abrir o Navegador de texturas* | uma textura |
| Wc3Material | o botão ⚙ ao lado de um mapa | uma textura para este slot |

## Como usar

1. Digite uma parte do nome no campo de busca, por exemplo `footman`.
2. Alterne entre a **grade** (imagens) e a **árvore** (pastas).
3. Aumente ou diminua o zoom das imagens.
4. Clique em um arquivo. A linha de baixo mostra o arquivo selecionado.
5. Clique em **Selecionar**.

!!! note
    O navegador precisa das pastas do seu jogo. Defina-as em [[t:menu_settings]]. Os modelos clássicos vêm dos arquivos MPQ, os arquivos do Reforged vêm do CASC.
