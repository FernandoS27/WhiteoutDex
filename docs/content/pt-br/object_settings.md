# Configurações de objeto

Os objetos do Warcraft III têm configurações extras que o 3ds Max não tem, por exemplo *billboard*. As Configurações de objeto aplicam essas configurações aos objetos selecionados. O WhiteoutDex as salva no objeto (como propriedades de usuário) e o exportador as escreve no modelo.

Abra-as com **WhiteoutDex > [[t:menu_object_settings]]**. Selecione um ou mais objetos primeiro.

[[shot:object_settings|As Configurações de objeto com um osso selecionado.]]

## Sinalizadores

| N.º | O que faz |
|---|---|
| [[ctl:4]] | O objeto não se move com o seu pai. |
| [[ctl:5]] | O objeto não gira com o seu pai. |
| [[ctl:6]] | O objeto não muda de escala com o seu pai. |
| [[ctl:7]] | O objeto sempre fica de frente para a câmera. Bom para brilhos e efeitos planos. |
| [[ctl:8]] | Fica de frente para a câmera, mas só gira em torno do eixo X. |
| [[ctl:9]] | … só em torno do eixo Y. |
| [[ctl:10]] | … só em torno do eixo Z. |
| [[ctl:11]] | O objeto fica no mesmo lugar na visão da câmera. |

## Malha

| N.º | O que faz |
|---|---|
| [[ctl:13]] | **Skinning normal:** usa o modificador Skin ou os ossos vinculados. |
| [[ctl:14]] | **Skinning ArtTools:** une os vértices de malhas separadas na exportação. Use só em malhas que você quer fundir umas com as outras. |
| [[ctl:17]] | O jogador não pode clicar nesta malha no jogo. |
