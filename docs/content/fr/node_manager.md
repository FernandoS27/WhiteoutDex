# Gestionnaire de nœuds

Un modèle contient de nombreux types d'objets : maillages, os, aides, émetteurs et plus encore. Le gestionnaire de nœuds affiche, masque ou gèle en une fois tous les objets d'un type.

Ouvrez-le avec **WhiteoutDex > [[t:menu_node_manager]]**.

[[shot:node_manager|Le gestionnaire de nœuds.]]

| [[ctl:6]] | Les os d'un rig Biped. |
| [[ctl:7]] | Les os d'un rig CAT. |
| [[ctl:8]] | Les aides et les dummies. |
| [[ctl:9]] | Les points d'attache. |
| [[ctl:10]] | Les objets d'événement. |
| [[ctl:11]] | Les lumières. |
| [[ctl:12]] | Les caméras. |
| [[ctl:13]] | Particle Emitter 1. |
| [[ctl:14]] | Particle Emitter 2. |
| [[ctl:15]] | Les émetteurs de traînées. |
| [[ctl:16]] | Les émetteurs Popcorn FX. |
| [[ctl:17]] | Les objets FaceFX. |
| [[ctl:18]] | Les formes de collision. |
| [[ctl:27]] | Coche tous les types. [[ctl:28]] décoche tout, [[ctl:29]] inverse chaque case. |

## 2. Agir sur ces objets

| N° | Fonction |
|---|---|
| [[ctl:20]] | Affiche les objets. |
| [[ctl:21]] | Masque les objets. |
| [[ctl:22]] | Gèle les objets pour que vous ne puissiez pas les sélectionner par erreur. |
| [[ctl:23]] | Dégèle les objets. |
| [[ctl:24]] | Affiche les objets en transparence. |
| [[ctl:25]] | Affiche à nouveau les objets en plein. |

!!! tip
    Masquez toutes les aides, tous les os et tous les émetteurs pendant que vous travaillez sur le maillage. Gelez les os pendant que vous peignez les poids de skin.
