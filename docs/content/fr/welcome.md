# Bienvenue dans WhiteoutDex

WhiteoutDex est un ensemble d'outils pour **3ds Max**. Avec lui, vous pouvez créer, modifier et tester des modèles pour **Warcraft III**. Il fonctionne avec le jeu classique (Warcraft III, version 1.x) et avec **Warcraft III: Reforged**.

![WhiteoutDex dans 3ds Max 2027. À gauche : l'aperçu WhiteoutFlakes. À droite : le gestionnaire de nœuds et le modèle dans le viewport.](media_1.png)

## Ce que vous pouvez faire

- **Importer** un modèle Warcraft III (`.mdx` ou `.mdl`) dans 3ds Max. WhiteoutDex charge aussi les textures depuis votre jeu.
- **Modifier** le modèle comme tout autre objet 3ds Max : changez le maillage, les os, les animations et les matériaux.
- **Prévisualiser** le modèle dans **WhiteoutFlakes**. Cette fenêtre montre le modèle comme le jeu le montre.
- **Exporter** le modèle en `.mdx` ou `.mdl`, pour le jeu classique ou pour Reforged. WhiteoutDex convertit les textures pour vous.
- Utiliser des **objets spéciaux** qui n'existent que dans Warcraft III : émetteurs de particules, traînées (ribbons), points d'attache, objets d'événement, formes de collision et plus encore.

## Ce qu'il vous faut

| | |
|---|---|
| Windows | Windows 10 ou plus récent |
| 3ds Max | Toute version de 2016 à 2027 |
| Warcraft III | Facultatif, mais conseillé : WhiteoutDex prend les textures et les modèles dans le dossier de votre jeu. |

## Comment lire ce manuel

Le manuel contient quatre types de pages :

- **Prise en main** vous aide à installer et à configurer WhiteoutDex.
- Les **tutoriels** sont des leçons courtes. Si vous débutez, suivez-les dans l'ordre.
- Les **pages d'outils et d'objets** expliquent une fenêtre ou un objet. Chaque image porte des numéros. Le tableau sous l'image indique la fonction de chaque numéro.
- Les pages de l'**annexe** sont des listes à consulter.

Les mots dans un **cadre bleu**, comme [[t:menu_importer]], sont les mots que vous voyez dans 3ds Max. Les touches ressemblent à ceci : [[key:Ctrl+Z]].

!!! tip
    Le manuel est dans la même langue que WhiteoutDex. Vous pouvez changer la langue de WhiteoutDex dans [[t:menu_settings]]. Voir *Paramètres*.
