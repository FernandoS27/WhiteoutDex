# Premiers pas

Après l'installation, WhiteoutDex ajoute deux éléments à 3ds Max : le **menu WhiteoutDex** et la **barre latérale**.

## Les objets Warcraft III

WhiteoutDex ajoute de nouveaux objets au panneau **Create** de 3ds Max :

- **Create > Helpers > Warcraft III Plugins** : points d'attache, formes de collision, lumières, objets d'événement, Popcorn FX, FaceFX.
- **Create > Geometry > Particle Systems** : Particle Emitter 1, Particle Emitter 2 et Ribbon Emitter.
- **Material Editor** : le matériau *Wc3Material* et la map *Wc3Bitmap*.
- **Modifier list** : *Wc3 Vertex Color*.

Les chapitres *Objets Warcraft III* et *Matériaux* les expliquent.

## Vos premiers pas

1. Ouvrez [[t:menu_settings]] et indiquez le dossier de votre jeu (voir *Paramètres*).
2. Faites le tutoriel *Importer un modèle*.
3. Regardez le modèle dans l'aperçu : tutoriel *Prévisualiser votre modèle*.
4. Exportez-le à nouveau : tutoriel *Exporter un modèle*.
