# Créateur de contour

Donne à un maillage un contour de style dessin animé. L'outil crée autour du maillage une copie un peu plus grande, avec les faces retournées. Dans le jeu, vous voyez alors une ligne sombre autour du modèle.

Ouvrez-le avec **WhiteoutDex > [[t:menu_cell_shade]]**. Sélectionnez d'abord les maillages.

[[shot:cell_shade|Le créateur de contour.]]

| N° | Fonction |
|---|---|
| [[ctl:4]] | La couleur du contour. Cliquez pour choisir une autre couleur. |
| [[ctl:6]] | Des couleurs rapides. Cliquez sur l'une d'elles pour l'utiliser. |
| [[ctl:19]] | L'épaisseur du contour. |
| [[ctl:21]] | Retourne les faces de la copie. C'est ce qui crée le contour (choix normal). |
| [[ctl:22]] | Garde les faces telles quelles. |
| [[ctl:25]] | Le contour est opaque. |
| [[ctl:26]] | Le contour utilise la transparence de la texture. |
| [[ctl:27]] | Le contour brille (il ajoute de la lumière). |
| [[ctl:28]] | Le contour brille et utilise la transparence de la texture. |
| [[ctl:30]] | Crée le contour des maillages sélectionnés. |

!!! tip
    Le contour est un maillage normal avec un *Wc3Material*. Vous pouvez modifier plus tard sa couleur ou son épaisseur, comme pour tout autre maillage.
