# Anim. : contrôleurs

Warcraft III connaît quatre façons de passer d'une clé à l'autre : *None* (saut), *Linear*, *Bezier* et *Hermite* (TCB). Cet outil donne aux objets sélectionnés les contrôleurs choisis, pour la position, la rotation et l'échelle en une seule fois.

Ouvrez-le avec **WhiteoutDex > [[t:menu_anim_controllers]]**.

[[shot:anim_controllers|L'outil Contrôleurs.]]

| N° | Fonction |
|---|---|
| [[ctl:4]] | La position se déplace en ligne droite entre les clés. |
| [[ctl:5]] | La position se déplace sur des courbes douces. |
| [[ctl:6]] | La position utilise des clés TCB (douces, avec tension, continuité et biais). |
| [[ctl:7]] | Laisse le contrôleur de position tel quel. |
| [[ctl:10]] | La rotation tourne de façon régulière entre les clés. |
| [[ctl:11]] | La rotation tourne de façon douce. |
| [[ctl:12]] | La rotation utilise des clés TCB. |
| [[ctl:13]] | Laisse le contrôleur de rotation tel quel. |
| [[ctl:16]] | L'échelle change de façon régulière. |
| [[ctl:17]] | L'échelle change sur des courbes douces. |
| [[ctl:18]] | L'échelle utilise des clés TCB. |
| [[ctl:19]] | Laisse le contrôleur d'échelle tel quel. |
| [[ctl:22]] | Donne ces contrôleurs aux objets sélectionnés. |

!!! note
    L'exportateur remplace aussi les contrôleurs que le jeu ne peut pas lire (voir *Problèmes de la scène*). Avec cet outil, vous choisissez le type vous-même.
