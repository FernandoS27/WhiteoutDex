# Anim. : skinning

Parfois, des maillages sont liés à des os et vous voulez modifier les os. Si vous déplacez les os, les maillages liés bougent aussi. Cet outil délie les maillages un moment et les relie plus tard.

Ouvrez-le avec **WhiteoutDex > [[t:menu_anim_skin]]**.

[[shot:anim_skinning|L'outil Skinning.]]

| N° | Fonction |
|---|---|
| [[ctl:4]] | Enregistre le parent de chaque objet sélectionné et le délie. |
| [[ctl:5]] | Relie les objets sélectionnés à leurs parents enregistrés. |

## Utilisation

1. Sélectionnez les maillages liés aux os.
2. Cliquez sur [[ctl:4]].
3. Modifiez les os, par exemple convertissez-les de l'IK en FK.
4. Sélectionnez à nouveau les maillages et cliquez sur [[ctl:5]].
