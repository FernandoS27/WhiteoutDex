# Formes de collision

Les formes de collision indiquent au jeu où le joueur peut **cliquer** sur le modèle. Elles sont invisibles dans le jeu. Les unités ont en général des sphères, les bâtiments une boîte.

Créez-les avec **Create > Helpers > Warcraft III Plugins > Wc3 CollisionSphere** ou **Wc3 CollisionBox**. Liez-les à l'os qui doit les déplacer.
