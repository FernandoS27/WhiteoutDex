# Explorateur du jeu

L'explorateur du jeu montre les fichiers de votre jeu Warcraft III : modèles, textures et effets de particules. Vous voyez une petite image de chaque fichier. Vous trouvez ainsi vite ce qu'il vous faut.

Il s'ouvre depuis de nombreux endroits :

| Où | Bouton | Vous choisissez |
|---|---|---|
| Menu WhiteoutDex | [[t:menu_import_casc]] | un modèle à importer |
| Point d'attache | *Parcourir les archives du jeu* | un modèle pour le point d'attache |
| Particle Emitter 1 | *Parcourir les archives du jeu* | un modèle pour les particules |
| Particle Emitter 2 | *Parcourir MPQ / CASC* | une texture pour les particules |
| Popcorn FX | *Parcourir les archives du jeu* | un effet `.pkb` ou `.pkfx` |
| Wc3Bitmap | *Ouvrir l'explorateur de textures* | une texture |
| Wc3Material | le bouton ⚙ à côté d'une map | une texture pour cet emplacement |

## Utilisation

1. Saisissez une partie du nom dans le champ de recherche, par exemple `footman`.
2. Passez de la **grille** (images) à l'**arborescence** (dossiers) et inversement.
3. Agrandissez ou réduisez les images.
4. Cliquez sur un fichier. La ligne du bas indique le fichier sélectionné.
5. Cliquez sur **Select**.

!!! note
    L'explorateur a besoin des dossiers de votre jeu. Définissez-les dans [[t:menu_settings]]. Les modèles classiques viennent des archives MPQ, les fichiers Reforged viennent de CASC.
