# FaceFX

**FaceFX** anime le visage des héros Reforged quand ils parlent : la bouche, les yeux et les sourcils suivent la voix. Les données se trouvent dans un fichier `.facefx_ingame`. L'objet FaceFX relie ce fichier au modèle.

Créez-le avec **Create > Helpers > Warcraft III Plugins > Wc3 FaceFX**. FaceFX ne fonctionne que dans les modèles **Reforged**.

[[shot:obj_facefx_r2|Paramètres FaceFX.]]

| N° | Fonction |
|---|---|
| [[ctl:9]] | Choisissez le fichier `.facefx_ingame`. |
| [[ctl:10]] | Affiche une courte explication. |

Les deux champs contiennent le **nom de la cible** (le nom que le jeu utilise pour ce visage) et le **chemin du fichier**.

!!! note
    L'importateur amène dans la scène les objets FaceFX des modèles Reforged. L'exportateur les réécrit sans les modifier.
