# Popcorn FX

**Popcorn FX** est le système de particules de Warcraft III: Reforged. L'effet lui-même est un fichier `.pkfx` (ou `.pkb`) créé avec l'éditeur PopcornFX. L'objet Popcorn de 3ds Max place cet effet sur le modèle et contrôle quand il est joué.

Créez-le avec **Create > Helpers > Warcraft III Plugins > Wc3 Popcorn**. Popcorn ne fonctionne que dans les modèles **Reforged**.
