# Changeur de skin

Prépare le skin de vos maillages pour Warcraft III.

Ouvrez-le avec **WhiteoutDex > [[t:menu_skin_changer]]**. Sélectionnez d'abord les maillages skinnés.

[[shot:skin_changer|Le changeur de skin.]]

| N° | Fonction |
|---|---|
| [[ctl:3]] | Modifie le skin pour que chaque sommet ait au plus 5 os avec des poids propres. Vous pouvez annuler cette action. |
| [[ctl:7]] | Les poids inférieurs ou égaux à cette valeur sont supprimés. 0.0 supprime seulement les poids exactement nuls. |
| [[ctl:8]] | Supprime les petits poids et répartit leur part sur les autres os du sommet. |
| [[ctl:11]] | Combine les maillages skinnés sélectionnés qui utilisent le même matériau en un seul maillage avec un seul Skin. Les os, les poids et la pose restent identiques. Le maillage bouge donc exactement comme avant. Vous pouvez annuler cette action. |

!!! tip
    Moins de maillages donnent un modèle plus rapide. Utilisez *Combiner maillage + Skin* quand un modèle a beaucoup de petites parties avec la même texture.
