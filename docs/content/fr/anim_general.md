# Anim. : outils généraux

De petits outils qui font gagner du temps quand vous animez ou finalisez un modèle.

Ouvrez-les avec **WhiteoutDex > [[t:menu_anim_general]]**.

[[shot:anim_general|Les outils généraux.]]

| N° | Fonction |
|---|---|
| [[ctl:4]] | Ajoute des clés à l'image 0 ainsi qu'au début et à la fin de chaque séquence, pour les objets sélectionnés. Ainsi, une animation ne modifie pas la suivante. |
| [[ctl:6]] | Applique l'outil TCB aux clés de position. |
| [[ctl:7]] | … aux clés de rotation. |
| [[ctl:8]] | … aux clés d'échelle. |
| [[ctl:9]] | Met la *Continuity* à 0 sur les clés actuelles des objets sélectionnés. Cela supprime le dépassement des clés TCB. |
| [[ctl:11]] | Les clés de rotation qui tournent de plus de 90° entre deux clés peuvent mal s'afficher dans le jeu. Cet outil ajoute une clé au milieu. Relancez-le pour les très grandes rotations (plus de 180°). |
| [[ctl:13]] | Crée des points d'attache pour les os aux noms connus (par exemple *Head*, *Chest*, *Hand*). |
| [[ctl:14]] | Crée une caméra de portrait qui regarde l'objet sélectionné. Sans sélection, elle regarde le haut du modèle. |
| [[ctl:15]] | Crée deux sphères de collision adaptées au modèle, comme Blizzard le fait pour les unités. |
| [[ctl:16]] | Crée une boîte de collision adaptée au modèle, comme Blizzard le fait pour les bâtiments. |

!!! tip
    Utilisez les outils **en un clic** sur un modèle terminé. Ils mesurent le modèle. Ils fonctionnent donc mieux quand le modèle a sa taille finale.
