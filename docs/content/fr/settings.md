# Paramètres

Dans les paramètres, vous choisissez la langue de WhiteoutDex et vous lui indiquez où se trouve votre jeu.

Ouvrez-les avec **WhiteoutDex > [[t:menu_settings]]** ou avec le bouton en forme d'engrenage en bas de la barre latérale.

[[shot:settings|Les paramètres de WhiteoutDex.]]

## Langue

| N° | Fonction |
|---|---|
| [[ctl:5]] | La langue de toutes les fenêtres de WhiteoutDex. Une fenêtre déjà ouverte change quand vous la rouvrez. Le menu WhiteoutDex change après un redémarrage de 3ds Max. |

## Jeu classique (MPQ)

Warcraft III classique (version 1.x) range ses fichiers dans des archives **MPQ**. WhiteoutDex y lit les textures et les modèles.

| N° | Fonction |
|---|---|
| [[ctl:10]] | Le dossier de votre Warcraft III classique. |
| [[ctl:12]] | Choisissez le dossier vous-même. |
| [[ctl:14]] | Trouve le dossier automatiquement. |
| [[ctl:15]] | Retire le dossier. |
| [[ctl:16]] | Définit l'ordre des archives MPQ. La première archive qui contient un fichier l'emporte. En général, vous n'en avez pas besoin. |

## Reforged (CASC)

Warcraft III: Reforged range ses fichiers dans un stockage **CASC**.

| N° | Fonction |
|---|---|
| [[ctl:20]] | Le dossier de Warcraft III: Reforged, en général `C:\Program Files (x86)\Warcraft III`. |
| [[ctl:24]] | Trouve le dossier automatiquement. |
| [[ctl:25]] | Retire le dossier. |
| [[ctl:27]] | **Graphismes de la scène.** Les textures utilisées par l'aperçu : [[t:set_art_tier_items#2]], [[t:set_art_tier_items#3]] ou [[t:set_art_tier_items#4]]. [[t:set_art_tier_items#1]] choisit automatiquement. Ce réglage est enregistré avec votre scène. |

!!! note
    Il vous suffit du jeu pour lequel vous travaillez. Pour les modèles classiques, indiquez le dossier MPQ. Pour les modèles Reforged, indiquez le dossier CASC. Avec les deux, WhiteoutDex trouve le plus de fichiers.

## Barre latérale et mises à jour

| N° | Fonction |
|---|---|
| [[ctl:30]] | Affiche la barre latérale WhiteoutDex au démarrage de 3ds Max. |
| [[ctl:32]] | Le côté de l'écran pour la barre latérale : gauche ou droite. |
| [[ctl:35]] | Cherche une nouvelle version de WhiteoutDex au démarrage de 3ds Max (une fois par jour). |
| [[ctl:36]] | Cherche une nouvelle version maintenant. |
| [[ctl:37]] | Enregistre et ferme la fenêtre. |
