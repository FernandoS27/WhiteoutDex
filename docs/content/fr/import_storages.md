# Importer depuis le jeu

Vous pouvez importer un modèle directement depuis votre jeu Warcraft III, sans fichier sur votre disque.

1. Choisissez **WhiteoutDex > [[t:menu_import_casc]]**.
2. L'explorateur du jeu s'ouvre. Trouvez le modèle, par exemple en cherchant `footman`.
3. Cliquez sur le modèle, puis sur **Select**.
4. La fenêtre d'import normale s'ouvre (voir *L'importateur*). Choisissez vos options et cliquez sur **Importer**.

WhiteoutDex copie le modèle et ses textures dans un dossier temporaire et l'importe depuis ce dossier. Vos fichiers de jeu ne changent pas.

!!! tip
    Pour modifier un modèle du jeu, importez-le de cette façon et modifiez-le. Puis exportez-le sous un nouveau nom dans le dossier de votre carte ou de votre mod.

!!! note
    Les modèles du jeu appartiennent à Blizzard Entertainment. Utilisez-les uniquement comme Blizzard l'autorise, par exemple dans des cartes et des mods pour Warcraft III.
