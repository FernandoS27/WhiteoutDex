# Paramètres d'objet

Les objets Warcraft III ont des réglages supplémentaires que 3ds Max n'a pas, par exemple *billboard*. Les paramètres d'objet les appliquent aux objets sélectionnés. WhiteoutDex les enregistre dans l'objet (comme propriétés utilisateur) et l'exportateur les écrit dans le modèle.

Ouvrez-les avec **WhiteoutDex > [[t:menu_object_settings]]**. Sélectionnez d'abord un ou plusieurs objets.

[[shot:object_settings|Les paramètres d'objet avec un os sélectionné.]]

## Indicateurs

| N° | Fonction |
|---|---|
| [[ctl:4]] | L'objet ne se déplace pas avec son parent. |
| [[ctl:5]] | L'objet ne tourne pas avec son parent. |
| [[ctl:6]] | L'objet ne change pas d'échelle avec son parent. |
| [[ctl:7]] | L'objet fait toujours face à la caméra. Utile pour les lueurs et les effets plats. |
| [[ctl:8]] | Fait face à la caméra, mais tourne seulement autour de l'axe X. |
| [[ctl:9]] | … seulement autour de l'axe Y. |
| [[ctl:10]] | … seulement autour de l'axe Z. |
| [[ctl:11]] | L'objet reste fixe dans la vue de la caméra. |

## Maillage

| N° | Fonction |
|---|---|
| [[ctl:13]] | **Skinning normal :** utilise le modificateur Skin ou les os liés. |
| [[ctl:14]] | **Skinning ArtTools :** réunit à l'export les sommets de maillages séparés. Utilisez-le seulement sur des maillages qui doivent se fondre l'un dans l'autre. |
| [[ctl:17]] | Le joueur ne peut pas cliquer sur ce maillage dans le jeu. |
