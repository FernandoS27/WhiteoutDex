# Lumière

Une lumière Warcraft III éclaire le modèle et le sol autour de lui, par exemple la lueur d'une torche ou d'un cristal magique.

Créez-la avec **Create > Helpers > Warcraft III Plugins > Wc3 Light**.

## Fonctions générales

[[shot:obj_light_r1|Fonctions générales.]]

| N° | Fonction |
|---|---|
| [[ctl:3]] | Cliquez ici, puis cliquez sur un objet. La lumière se place sur cet objet et se lie à lui. |

## Paramètres de base

[[shot:obj_light_r3|Paramètres de base.]]

| N° | Fonction |
|---|---|
| [[ctl:4]] | *Omnidirectionnelle* éclaire dans toutes les directions à partir d'un point. *Directionnelle* éclaire dans une seule direction, comme le soleil. *Ambiante* éclaire tout de façon uniforme. |
| [[ctl:9]] | La distance à partir de laquelle la lumière commence à faiblir. |
| [[ctl:16]] | La distance où la lumière s'arrête. |
| [[ctl:21]] | La couleur de la lumière. |
| [[ctl:29]] | L'intensité de la lumière. |
| [[ctl:35]] | La couleur de la part ambiante. |
| [[ctl:43]] | L'intensité de la part ambiante. |
| [[ctl:11]] | **Contrôle :** la façon dont une valeur animée change entre les clés. Chaque valeur a son propre contrôle. |

## Paramètres Reforged

[[shot:obj_light_r2|Paramètres Reforged.]]

Seuls les modèles Reforged utilisent ces valeurs.

| N° | Fonction |
|---|---|
| [[ctl:6]] | L'intensité de l'ombre. Sur la lumière principale d'une scène, elle met aussi à l'échelle l'éclairage par image (IBL). |
| [[ctl:8]] | La lumière projette des ombres. |
| [[ctl:12]] | La distance où l'ombre commence. |
| [[ctl:16]] | La distance où l'ombre s'arrête. |
| [[ctl:21]] | La vitesse à laquelle la lumière faiblit : part quadratique … |
| [[ctl:25]] | … part linéaire … |
| [[ctl:29]] | … et amortissement. |
